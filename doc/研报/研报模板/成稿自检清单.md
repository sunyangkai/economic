# 成稿自检清单（数据校验版）

> **用途**：主报告 / 财报跟踪成稿后的**数据校验**，也是**校对子代理的执行清单**（prompt 模板附文末）。每条必须能对着一篇 md 独立判定 ✅ / ⚠️ / ❌——主观判断质量（归因、假设、观点是否合理）不在校对范围。清单是"索引 + 判定标准"，规则正文以锚点所指文件为准；改规范时同步改本清单。
>
> **2026-09 范围调整**：格式与排版、章节结构、头部要素**不再逐条校验**——写作时按模板规范（[README.md](README.md) "五、格式与排版" / "六、主报告版式规则"、[主报告规范.md](主报告规范.md) §三 / §四）执行即可。本清单只验**数字自洽**与**跨章数据一致**，原 G（全局排版）/ H（头部）/ C（逐章）组及 X1（色值）/ X3（术语）/ X5（路径）已移除，不再验收。

## D 数字自洽（本地复核，不需要外部请求；锚：主报告规范 §二、估值纪律）

- D1 分部占比加总 = 100%；分部收入加总 = 总收入

- D2 抽 5—8 个同比 / 比率 / 占比复算

- D3 护城河加权算式复算 = 总分结论

- D4 净现比 = 经营现金流 ÷ 归母净利复算

- D5 情景表：按报告声称的参数重跑 `node tools/valuation.js <spec.json>`，逐格比对（内在 PE / 股价 / 相对现价）

- D6 EPS × 股本 ≈ 净利 的口径自洽（口径差须有解释，参照口径卡）

- D7 机构预测 EPS / PE 与 `api/orgForecast.js` 一致——**涉及外部请求，默认不执行**，由主代理决定是否对源

## X 跨章数据一致性（仅保留数据项）

- X2 同一阈值 / 口径跨章一致（抽查 2—3 个核心阈值在零 / 三 / 五 / 六章的表述）

- X4 除 §一.5 豁免处与八章表外，无任何"最新一期"季度数字；基线时点数据有日期标注

## 附：校对子代理 prompt 模板

```text
你是独立校对代理，核对一份已完成的研报的数据是否自洽。

输入：
- 报告文件：<路径>
- 清单：doc/研报/研报模板/成稿自检清单.md（本文，数据校验版）
- 口径卡：<doc/知识库/公司/<公司>/口径卡.md 路径，或"无">

任务：逐条执行清单 D / X，每条输出：结果（✅/⚠️/❌）、
位置（章节 + 行引用或原文片段，违规必给）、一句修正建议。
只校数据（数字自洽 + 跨章数据一致），不做格式 / 排版 / 章节结构校验。

硬约束：
1. 只核对，不修改任何文件——修改决定权在主代理；
2. 禁止联网、禁止调用外部数据接口；数字复核只用本地计算与报告/口径卡
   内的参数（D5 例外：允许运行 node tools/valuation.js 复跑情景表）；
3. 不评价主观判断质量（归因、假设、观点），只查清单内的可机械判定项；
4. 全部条目过完再输出：先给"违规清单表"（❌/⚠️，附编号与位置），
   再给逐条明细。
```
