# 财报跟踪规范

> **财报跟踪 = 主报告框架的"实绩账本"**：每报告期一个文件，**按主报告章节骨架（零~八）逐章检查最新状态**——核心逻辑验证、业务说明数据、宏观背景、财务报表分析、业绩预期、估值、跟踪项（重点数据 / 催化剂 / 风险）、治理结构变化、流通股东变化。
>
> **详略分层**：〇 / 一 / 二 / 四 / 七章由分析者按当期实绩自主决定（有明显变化 → 详细写；无明显变化 → 一句话带过，甚至整章省略）；**三（财务报表）/ 五（估值）/ 六（跟踪项）/ 八（流通股东）四章每期完整更新**——按主报告同口径把表格全部列出来（允许与主报告重复），逐项评估变化，不得以"无实质变化"的简述替代表格。只更新主报告定义过的变量，不发明新变量；发现框架缺变量时，先改主报告，再在当期跟踪引用。
>
> 与主报告的关系：主报告 = 框架 + 基线（最新年报），本文档对应的文档 = 实例层（逐期更新）。共用规则见 [README.md](README.md)。

## 一、定位与纪律

| 项 | 规则 |
| --- | --- |
| 本质 | 主报告框架的逐期实绩与验证（对应主报告零~八章；主报告九章"名词解释"为静态表，不逐期跟踪） |
| 触发 | 每期财报披露后新建 / 补填对应文件；两次财报间如有重大变化（管理层交流、月度数据、突发事件）可补充更新 |
| 更新内容 | 逐章检查（〇~八）：核心逻辑验证 / 业务说明数据 / 宏观背景 / **财务报表分析（四表完整）** / 业绩预期 / **估值（重算 + 两张情景表完整）** / **跟踪项（重点数据 / 催化剂 / 风险逐项）** / 治理结构变化 / **流通股东变化（三期对比表完整）**——〇 / 一 / 二 / 四 / 七视实绩定详略，**三 / 五 / 六 / 八必须完整列表更新** |
| 详略原则 | 〇 / 一 / 二 / 四 / 七：有明显变化 → 详细更新；无明显变化 → 简要带过或省略。**三 / 五 / 六 / 八：每期完整表格更新、逐项评估，与主报告重复亦不省略、不以简述替代** |
| **估值纪律** | **估值每期基于最新数据重新计算并完整列表**：现价、最新一致预期、隐含 θ、θ 测定表 + 增速情景表（`tools/valuation.js` 重新生成、完整粘贴，数值与 CLI 输出一致），并与上期对比修正——重算参数与上期完全相同时，表格照列并在对比表注明"参数未变、数值与上期一致" |
| 不做什么 | 不重写框架、不发明新跟踪项、不覆盖历史文件（追加式） |
| 发现缺口 | 框架缺变量 → 先修订主报告对应章节，再在当期跟踪引用 |

## 二、文件命名与存放

```
doc/研报/公司/<公司>/
└── 财报跟踪/
    ├── 2026一季报.md       # 已披露：实绩 + 逐项更新
    ├── 2026中报.md
    └── 2026三季报.md       # 未披露：模板 / 待披露
```

命名规则：`<YYYY><报告期>.md`，报告期用"一季报 / 中报 / 三季报 / 年报"。


## 四、正文结构（九个部分，对应主报告零~八章）

> 骨架 = 检查清单：逐章过一遍，判断当期有没有值得写的变化。**每章可按当期情况自主取舍详略，甚至省略**；以下每章的"参考建议"是写作方向，不是硬性条目。

```markdown
## 〇、核心逻辑验证（最新）          ← 对应主报告"零、核心逻辑"
## 一、业务说明数据（最新）          ← 对应主报告"一、业务说明"（分部/区域经营数据）
## 二、宏观背景（最新）              ← 对应主报告"二、宏观背景"
## 三、财务报表分析（最新）          ← 对应主报告"三、财务报表分析（财务基线）"，四表完整
## 四、业绩预期（最新）              ← 对应主报告"四、业绩预期（基准情景）"，含管理层观点
## 五、估值（重新计算，对比上期）     ← 对应主报告"五、估值（估值框架）"，两张情景表完整
## 六、跟踪项（重点数据 / 催化剂 / 风险） ← 对应主报告"六、跟踪清单"，逐项全列
## 七、治理结构变化（最新）          ← 对应主报告"七、治理结构"
## 八、流通股东变化（最新+前两期）   ← 对应主报告"八、流通股东变化（筹码方法）"，三期表完整
## 九、关键解读与总结
```

### 三、财务报表分析（最新）

**本章每期完整更新**：按主报告三章同口径列全四张要点表（本期 vs 上期两列 + 同比列 + 解读列 + 表后"这张表告诉我们"一句），结构对齐主报告三章 1—4 节，数字换成本报告期：

1. **经营相关数据**：主报告三章 §1 列过的指标逐项更新（收入、产销量 / 采浆量、产能、终端覆盖等；分部明细见"一、业务说明数据"，不重复）。

2. **利润表**：收入 / 成本 / 毛利 / 费用 / 减值 / 利润逐行同比；毛利率与费用率驱动以官方归因为准。

3. **资产负债表**：主报告三章 §3 列过的大额科目逐项列（货币资金、应收、存货、固定资产 / 在建、商誉、有息负债等），变动原因以官方口径为准。

4. **现金流量表**：经营 / 投资 / 筹资 + 收现比 / 净现比，逐行同比 + 一句解读。

5. **对照主报告三章"关键项目跟踪阈值"**：**逐项全列**（不只列有变化项），每行"主报告基线 → 本期最新 → 状态"：

| 分析项目 | 主报告基线 | 本期最新 | 评价 |
| --- | --- | --- | --- |
| …（主报告三章阈值表全部行） | … | … | ✅ / ⚠️ / ❌ |

### 四、业绩预期（最新）

- **一致预期更新**：最新一致预期（`api/orgForecast.js`）vs 上期 vs 主报告基准——有变化才详细对比（上修 / 下修 / 持平，差异在哪）；持平可一句带过。

- **利润路径兑现**：实际增速 vs 主报告基准 [g1,g2,g3]——第一年 g1 是否兑现、偏离方向。

- **管理层观点**：本期管理层在投资者交流会 / 业绩说明会等公开场合的新表态（市场担忧 vs 管理层回应表，**注明时间与场合**）——对应主报告四章"管理层观点"小节；本期无新表态可不写。

### 五、估值（重新计算，对比上期）

**估值每期基于最新数据重算，且必须完整列表**（与主报告五章同构，不沿用上期数字）：

1. **重算输入**：现价（新基准日）、最新一致预期、θ（固定值复核）——参数有变先说明变化；

3. **与上期对比修正**：

| 项 | 上期 | 本期 | 变化 / 原因 |
| --- | --- | --- | --- |
| 一致预期（归母） | … | … | 上修 / 下修 |
| 利润路径兑现 | … | … | 符合 / 偏离 |
| 现价 / 隐含定位 | … | … | … |
| 基准情景内在价值 | … | … | 低估 / 合理 / 高估 |

### 七、治理结构变化（最新）

对照主报告七章，列出本期的治理变化点：股权 / 质押 / 增减持 / 接班 / 分红政策等。**无变化时写"无重大变化"即可，甚至整章省略。**

### 八、流通股东变化（最新一期 + 前两期）

- **完整三期对比表每期必列**：列式与主报告八章一致（股东 | 前一期末 | 中间期末 | 较上期 | 最新期末 | 较上期 | 变化要点），**即使与主报告重复也完整粘贴**——跟踪文件自成一体，不依赖读者回查主报告。"较上期" = (本期 − 上期) ÷ 上期，按未舍入原值计算；变动不足 0.05% 记"—"，首列为基准期不标；含新进 / 跌出标注；表注写口径（占期末总股本、对比基准、已披露数据、明细去向）。

- **表后写筹码总结**：按筹码主线 3—4 点（每条独立成段、短加粗引导词）——① 边际资金方向（外资 / 北向、内部人等与基本面是否共振）；② 结构变化（股东户数集中 / 分散、个人与机构）；③ 被动资金进出（宽基 / 行业 ETF 换仓）；④ 使用纪律一句。股东户数趋势、大宗交易、质押解押等明细随本期数据更新在本文件。

### 九、关键解读与总结

- **关键解读**：本期最重要的 2—6 条（超预期点、低于预期点、验证窗口）——数量随本期信息量浮动，信息少时 2—3 条即可。

- **总结**：正面（✅）/ 负面（❌）/ 验证窗口 三段（可精简）。

## 六、披露后同步事项

- 按主报告章节骨架逐章过一遍（〇~八）：〇 / 一 / 二 / 四 / 七章**有变化详细写，无变化简要带过或省略**；**三 / 五 / 六 / 八章每期完整列表更新**（财务四表、两张估值情景表、跟踪项三张全量表、流通股东三期对比表）；

- **估值节重算并完整粘贴 θ 测定表 + 增速情景表**（`tools/valuation.js`），含"与上期对比修正"；

- 分部 / 区域经营数据有变化时刷新（对应主报告"一、业务说明"），无变化一句话带过；

- 若本期有重大管理层交流，补充"管理层观点"；

- 新增名词时回补主报告"九、备注：名词解释"。
