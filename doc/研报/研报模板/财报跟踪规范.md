# 财报跟踪规范

> **财报跟踪 = 主报告框架的"实绩账本"**：每报告期一个文件，**按主报告章节骨架（零~八）逐章检查最新状态**——核心逻辑验证、业务说明数据、宏观背景、财务报表分析、业绩预期、估值、跟踪项（催化剂 / 风险）、治理结构变化、流通股东变化。
>
> **写什么、写多细，由分析者按当期实绩自主决定**：有明显变化 → 详细写；无明显变化 → 一句话带过，甚至整章省略（如宏观无变化、治理无变化）；不为了凑篇幅而重复主报告。骨架是**检查清单**（提醒"这九块都过一遍，别漏了变化"），不是**每期必填的模板**。只更新主报告定义过的变量，不发明新变量；发现框架缺变量时，先改主报告，再在当期跟踪引用。
>
> 与主报告的关系：主报告 = 框架 + 基线（最新年报），本文档对应的文档 = 实例层（逐期更新）。共用规则见 [README.md](README.md)。

## 一、定位与纪律

| 项 | 规则 |
| --- | --- |
| 本质 | 主报告框架的逐期实绩与验证（对应主报告零~八章；主报告九章"名词解释"为静态表，不逐期跟踪） |
| 触发 | 每期财报披露后新建 / 补填对应文件；两次财报间如有重大变化（管理层交流、月度数据、突发事件）可补充更新 |
| 更新内容 | 逐章检查（〇~八）：核心逻辑验证 / 业务说明数据 / 宏观背景 / 财务报表分析 / 业绩预期 / **估值（重新计算）** / 跟踪项：催化剂、风险 / 治理结构变化 / 流通股东变化。**各章写不写、写多细，视当期实绩而定** |
| 详略原则 | 有明显变化 → 详细更新；无明显变化 → 简要带过或省略；不重复主报告、不凑篇幅。**同一期允许部分章节整章省略**（如宏观、治理无变化），但"有变化的章节"不能漏，尤其估值 |
| **估值纪律** | **估值每期基于最新数据重新计算**：现价、最新一致预期、隐含 θ、情景表（`tools/valuation.js`），并与上期对比修正，不沿用上期数字——若重算结果与上期无实质差异，简述"无实质变化"即可 |
| 不做什么 | 不重写框架、不发明新跟踪项、不覆盖历史文件（追加式） |
| 发现缺口 | 框架缺变量 → 先修订主报告对应章节，再在当期跟踪引用 |

## 二、文件命名与存放

```
doc/研报/公司/<公司>/
└── 财报跟踪/
    ├── 2026一季报.md       # 已披露：实绩 + 逐项更新
    ├── 2026中报.md
    └── 2026三季报.md       # 未披露：模板 / 待披露
```

命名规则：`<YYYY><报告期>.md`，报告期用"一季报 / 中报 / 三季报 / 年报"。

```markdown

> 估值框架与跟踪变量见主报告《<公司>》（`doc/研报/公司/<公司>/<公司>.md`；财务基线：<YYYY> 年报）。
```

## 四、正文结构（九个部分，对应主报告零~八章）

> 骨架 = 检查清单：逐章过一遍，判断当期有没有值得写的变化。**每章可按当期情况自主取舍详略，甚至省略**；以下每章的"参考建议"是写作方向，不是硬性条目。

```markdown
## 〇、核心逻辑验证（最新）          ← 对应主报告"零、核心逻辑"
## 一、业务说明数据（最新）          ← 对应主报告"一、业务说明"（分部/区域经营数据）
## 二、宏观背景（最新）              ← 对应主报告"二、宏观背景"
## 三、财务报表分析（最新）          ← 对应主报告"三、财务报表分析（财务基线）"
## 四、业绩预期（最新）              ← 对应主报告"四、业绩预期（基准情景）"，含管理层观点
## 五、估值（重新计算，对比上期）     ← 对应主报告"五、估值（估值框架）"
## 六、跟踪项（催化剂 / 风险）       ← 对应主报告"六、跟踪清单"
## 七、治理结构变化（最新）          ← 对应主报告"七、治理结构"
## 八、流通股东变化（最新+前两期）   ← 对应主报告"八、流通股东变化（筹码方法）"
## 九、关键解读与总结
```

### 三、财务报表分析（最新）

**参考方向**（按本期特点挑重点，不要求五条全写；大额/重点项目优先）：

1. **经营相关数据**：本期经营发生了什么——收入与结构、订单/合同负债、市占率、经营效率等（经营先行；分部明细见"一、业务说明数据"，不重复）。

2. **利润表**：收入 / 成本 / 毛利 / 费用 / 利润本期变化；毛利率与费用率驱动（如成本增速 vs 收入增速、利息收入等非经营项）。

3. **资产负债表关键科目**：大额科目变动（货币资金与理财、应收、存货、合同负债、应付、有息负债、受限资金等），**变动原因以官方口径为准**（如合同负债下降可能是销售折扣计提方式而非需求下滑）。

4. **现金流量表结构**：经营 / 投资 / 筹资三大活动 + 净现比，各一句解读（如"经营偏弱因备货支付、筹资流出因分红"）。

5. **对照主报告三章"关键项目跟踪阈值"**：**只列有变化或贴近阈值的项目**（不必逐项全列），每行写清"主报告基线 → 本期最新 → 状态"：

| 分析项目 | 主报告基线 | 本期最新 | 评价 |

| 毛利率 | 60.32% | 61.87%（阈值：守住 60%） | ⚠️ 守住但未回升 |
| …（只列有变化项） | … | … | … |

### 四、业绩预期（最新）

- **一致预期更新**：最新一致预期（`api/orgForecast.js`）vs 上期 vs 主报告基准——有变化才详细对比（上修 / 下修 / 持平，差异在哪）；持平可一句带过。

- **利润路径兑现**：实际增速 vs 主报告基准 [g1,g2,g3]——第一年 g1 是否兑现、偏离方向。

- **管理层观点**：本期管理层在投资者交流会 / 业绩说明会等公开场合的新表态（市场担忧 vs 管理层回应表，**注明时间与场合**）——对应主报告四章"管理层观点"小节；本期无新表态可不写。

| 利润路径兑现 | [g1,g2,g3] 基准 | 实际增速 vs g1 | 符合 / 偏离 |
| 现价 / 隐含 θ | θ≈0.76（164.03 元） | … | 折价收敛 / 扩大 |
| 基准情景股价 | 196 元（+20%） | 现价 vs 基准 | 低估 / 合理 / 高估 |

### 七、治理结构变化（最新）

对照主报告七章，列出本期的治理变化点：股权 / 质押 / 增减持 / 接班 / 分红政策等。**无变化时写"无重大变化"即可，甚至整章省略。**

### 八、流通股东变化（最新一期 + 前两期）

- **数据来源**：最新一期用 `api/holderData.js` 抓取填入；前两期从已有文档获取（上一期跟踪文件、主报告基线或更早跟踪），不必重复抓取——目的是拼出至少三季的趋势。

- **写什么由当期筹码变化决定**：股东户数三季趋势、重要机构持仓（北向外资 / 国家队社保 / 公募险资 / 内部人）中**有变化的信号**、大股东增减持、筹码面与基本面共振判断。筹码无实质变化的报告期可精简为一段话。

### 九、关键解读与总结

- **关键解读**：本期最重要的 2—6 条（超预期点、低于预期点、验证窗口）——数量随本期信息量浮动，信息少时 2—3 条即可。

- **总结**：正面（✅）/ 负面（❌）/ 验证窗口 三段（可精简）。

## 六、披露后同步事项

- 按主报告章节骨架逐章过一遍（〇~八）：**有变化的章节详细写，无变化的章节简要带过或省略**——不要求每期九章全满；

- **估值节重算**（现价 / 一致预期 / 隐含 θ / 情景表），并含"与上期对比修正"（无实质差异则简述）；

- 分部 / 区域经营数据有变化时刷新（对应主报告"一、业务说明"），无变化一句话带过；

- 若本期有重大管理层交流，补充"管理层观点"；

- 新增名词时回补主报告"九、备注：名词解释"。
