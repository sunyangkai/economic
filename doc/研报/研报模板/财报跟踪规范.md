# 财报跟踪规范

> **财报跟踪 = 主报告框架的"实绩账本"**：每报告期一个文件，按主报告章节逐项刷新最新状态——**最新财务报表分析、最新跟踪项（催化剂 / 风险）、最新业绩预期、最新估值过程与结论（对比上期修正）、最新治理结构变化、最新流通股东变化**。只更新主报告定义过的变量，不发明新变量；发现框架缺变量时，先改主报告，再在当期跟踪引用。
>
> 与主报告的关系：主报告 = 框架 + 基线（最新年报），本文档对应的文档 = 实例层（逐期更新）。共用规则见 [README.md](README.md)。

## 一、定位与纪律

| 项 | 规则 |
| --- | --- |
| 本质 | 主报告框架的逐期实绩与验证（六个部分对应主报告三/六/四/五/七/八章） |
| 触发 | 每期财报披露后新建 / 补填对应文件；两次财报间如有重大变化（管理层交流、月度数据、突发事件）可补充更新 |
| 更新内容 | ① 最新财务报表分析 ② 最新跟踪项（催化剂 / 风险）③ 最新业绩预期（含管理层观点）④ 最新估值过程与结论（对比上期）⑤ 最新治理结构变化 ⑥ 最新流通股东变化 |
| 不做什么 | 不重写框架、不发明新跟踪项、不覆盖历史文件（追加式） |
| 发现缺口 | 框架缺变量 → 先修订主报告对应章节，再在当期跟踪引用 |

## 二、文件命名与存放

```
doc/研报/公司/<公司>/
└── 财报跟踪/
    ├── 2026一季报.md       # 已披露：实绩 + 逐项更新
    ├── 2026中报.md
    └── 2026三季报.md       # 未披露：模板 / 待披露
```

命名规则：`<YYYY><报告期>.md`，报告期用"一季报 / 中报 / 三季报 / 年报"。

## 三、头部格式

```markdown
# <公司> · <YYYY 年><报告期>跟踪

> 报告期：<2026Q1/H1/Q3> ｜ 披露：<日期> ｜ 上一节点：[<上一报告期>](...md) ｜ 下一节点：[<下一报告期>](...md)
> 估值框架与跟踪变量见主报告《[<公司>](../<公司>.md)》（财务基线：<YYYY> 年报）。
```

## 四、正文结构（六个部分 + 总结）

```markdown
## 一、财务报表分析（最新）          ← 对应主报告"三、财务报表分析（财务基线）"
## 二、跟踪项（催化剂 / 风险）       ← 对应主报告"六、跟踪清单"
## 三、业绩预期（最新）              ← 对应主报告"四、业绩预期（基准情景）"，含管理层观点
## 四、估值（过程与结论，对比上期）   ← 对应主报告"五、估值（估值框架）"
## 五、治理结构变化（最新）          ← 对应主报告"七、治理结构"
## 六、流通股东变化（最新+前两期）   ← 对应主报告"八、流通股东变化（筹码方法）"
## 七、关键解读与总结
```

### 一、财务报表分析（最新）

- **核心指标实绩表**：营收 / 归母 / 扣非 / 毛利率 / 经营现金流 / 合同负债等，同比 + 一句定性总结（如"超预期的开门红"）。
- **分部与区域表现**（可选）：产线 / 区域收入、同比、占比（若主报告框架定义了分部变量）。
- **逐项对照主报告三章"关键项目跟踪阈值"**：每行写清"**主报告基线 → 本期最新 → 状态**"，评价列统一用 ✅ / ⚠️ / ❌：

| 分析项目 | 主报告基线 | 本期最新 | 评价 |
| --- | --- | --- | --- |
| 收入增速 | 2025 年报：-9.38% | +1.39%（Q1） | ✅ 重回正增长 |
| 毛利率 | 60.32% | 61.87%（阈值：守住 60%） | ⚠️ 守住但未回升 |
| …（按主报告阈值表逐项） | … | … | … |

### 二、跟踪项（催化剂 / 风险）

**催化剂**（对应主报告六章"催化剂"表）：逐项评价是否触发 / 部分验证 / 证伪，带最新数据 vs 阈值：

| 催化剂 | 评价 | 跟踪频率与来源 |
| --- | --- | --- |
| 国内收入转正 | ⚠️ 未触发——-11.13% 大幅收窄，但仍在负区间 | 中报 / 季报 |
| … | ✅ 触发 / ⚠️ 部分验证 / ❌ 证伪 | … |

**风险**（对应主报告六章"风险"表）：逐项评价恶化 / 缓解 / 证伪：

| 风险 | 评价 | 跟踪频率与来源 |
| --- | --- | --- |
| 国内复苏 | ⚠️ 边际改善，未确认拐点 | 季报；月度医院招标 |
| … | ✅ 缓解 / ⚠️ 未恶化 / ❌ 恶化 | … |

### 三、业绩预期（最新）

- **一致预期更新**：最新一致预期（`api/orgForecast.js`）vs 上期 vs 主报告基准——上修 / 下修 / 持平，差异在哪里。
- **利润路径兑现**：实际增速 vs 主报告基准 [g1,g2,g3]——第一年 g1 是否兑现、偏离方向。
- **管理层观点**：本期管理层在投资者交流会 / 业绩说明会等公开场合的新表态（市场担忧 vs 管理层回应表，**注明时间与场合**）——对应主报告四章"管理层观点"小节。

### 四、估值（过程与结论，对比上期）

- **本期估值计算**：现价、隐含 θ（= 现价 PE ÷ 无折价 PE）、情景表刷新——用 `tools/valuation.js` 生成，数字与程序输出一致。
- **与上期对比修正**：估值结论较上期修正了什么、为什么（利润路径 / θ / 现价 / 情景假设的变化），列出"上期 → 本期 → 变化原因"：

| 项 | 上期 | 本期 | 变化 / 原因 |
| --- | --- | --- | --- |
| 一致预期（归母） | 87 亿（8/28） | … | 上修 / 下修 |
| 利润路径兑现 | [g1,g2,g3] 基准 | 实际增速 vs g1 | 符合 / 偏离 |
| 现价 / 隐含 θ | θ≈0.76（164.03 元） | … | 折价收敛 / 扩大 |
| 基准情景股价 | 196 元（+20%） | 现价 vs 基准 | 低估 / 合理 / 高估 |

### 五、治理结构变化（最新）

对照主报告七章，列出本期的治理变化点：股权 / 质押 / 增减持 / 接班 / 分红政策等。无变化时写"无重大变化"即可。

### 六、流通股东变化（最新一期 + 前两期）

- **数据来源**：最新一期用 `api/holderData.js` 抓取填入；**前两期从已有文档获取**（上一期跟踪文件、主报告基线或更早跟踪），不必重复抓取——目的是拼出**至少三季的趋势**。
- **股东户数与筹码集中度**：最新一期 + 前两期，看三季趋势（持续集中 / 持续分散 / 反复）。
- **重要机构持仓**（四类信号：北向外资 / 国家队社保 / 公募险资 / 内部人）：最新 + 前两期对比，趋势列按三季综合判断。
- **大股东与重要股东增减持**：最新 + 前两期，三季累计方向（连续增持 / 连续减持 / 先减后增 / 反复）。
- **筹码面与基本面共振判断**：对照主报告核心逻辑——谁在验证逻辑（连续加仓）、谁在撤退（连续减仓）、趋势是否与基本面一致。

### 七、关键解读与总结

- **关键解读**：3—6 条（超预期点、低于预期点、验证窗口）。
- **总结**：正面（✅）/ 负面（❌）/ 验证窗口 三段。
