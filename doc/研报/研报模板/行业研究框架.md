# 行业研究框架

> **行业研究的唯一输出物，是一组关于"利润池"的可证伪判断**：这个行业的钱总共多大、在产业链哪一环、未来三年往哪移、现在走到哪、谁受益、什么信号出现就算我错了。
>
> 本文只管行业报告的**写什么与怎么判断**；路径、文件夹结构、数据与工具、格式排版共用 [README.md](README.md)。行业报告默认放 `doc/知识库/行业/<行业>.md`。

## 判断链（全篇只讲一件事）

```
利润池有多大  ──►  谁在供给（成本曲线）  ──►  价格与单位利润  ──►  钱落在哪一环、谁在吃份额
      ▲                                                                      │
      └────────────── 政策与技术只作为"改写上面某一条"的外生变量 ◄──────────────┘
```

**一个行业就是一道题：池子多大、谁分得到、能分多久。** 其余内容（定义、格局、政策、技术、库存、估值）都是这三问的输入，不是并列的章节主题——写不出"它改变了上面哪一条"的内容，删掉。

## 一、头部格式

```markdown
# <行业>行业研究（<本期专题>）

> **独立行业研究**（写作基准：<YYYY-MM-DD>；覆盖范围：<地域 / 细分口径>；利润池口径：<计量单位与统计来源>；行业基线：<YYYY> 完整年度 + <YYYY-MM> 景气快照；数据边界：<A 股样本到哪期 / 行业数据到哪月 / 政策到哪节点>；下一节点：<事件>，约 <日期>；遵循 `doc/研报/研报模板/行业研究框架.md`）
>
> 相关公司报告：<链接>｜<链接>
>
> 更新：<YYYY-MM-DD>。数据来源：<官方来源与日期>、代表公司财报（`api/`）。跟踪见"十、证伪与跟踪"。
```

四个字段一个字都不能省，理由各不相同：

- **覆盖范围**：地域或细分口径一变就是另一个行业（"中国创新药"与"全球创新药"的规模、格局、估值完全不同）；

- **利润池口径**：全篇所有规模数字必须换算到这个口径上，否则量、价、利三节的数据对不上；

- **数据边界**：行业统计与公司财报更新节奏不同步，不写清"本报只承诺写到哪一期"，读者会把不同时点的数字拼成增速曲线；

- **下一节点**：最近一个可能改变判断的数据或政策时点。

## 二、章节骨架

**固定十章**。可缺章（注明"本章不适用"并说明理由），不可乱序。

| 章 | 一句话目的 | 必须产出 |
| --- | --- | --- |
| 一、结论卡片 | 七个判断，一页说完 | 可被下期逐条核对的七行 |
| 二、行业与利润池 | 这行赚什么钱、池子多大、在哪个环节 | 带口径与时点的池子数字 + 环节利润率排序 |
| 三、量 | 需求从哪来、天花板在哪、成色如何 | 三年量增区间 + 最主观假设 + 一个先行指标 |
| 四、供 | 成本曲线怎么排、出清到哪一步 | 现价落在成本曲线哪一分位 + 出清阶段判定 |
| 五、价与单位利润 | 谁定价、能传多远、单位赚多少 | 单位利润方向 + 定价权结论 |
| 六、分配 | 钱在哪个环节、谁在吃份额 | 利润流向结论 + 吃份额的一方 + 份额指标 |
| 七、变量 | 政策与技术会改写上面哪一条 | 每条变量的影响路径 + 落地信号 |
| 八、位置与情景 | 现在在哪、可能往哪走 | 三档情景 + 行业增速路径 [g1,g2,g3] |
| 九、标的映射 | 谁受益、对应哪份公司报告 | 排序表 + 每行一个公司报告链接 |
| 十、证伪与跟踪 | 什么时候看什么、何时算我错 | 一张不重复的仪表盘 + 一份可执行的日历 |

**推荐写作顺序**（≠ 章序）：

1. 先起草结论卡片的七行（可以粗糙），它决定你要收什么数据；
2. 写二、三、四、五、六——用数据验证或推翻那七行；
3. 回填结论卡片，再写七、八、九、十。

### 一、结论卡片

一页表格，先写初稿、最后回填。后续各章只在论证或反驳这几行。

| 项目 | 内容 |
| --- | --- |
| 一句话判断 | 未来 1—3 年最重要的变化是什么 |
| 利润池 | 多大规模、三年往哪移（哪个环节变厚/变薄） |
| 核心矛盾 | 一组两难，写成"A 侧 vs B 侧" |
| 周期位置 | 萌芽 / 成长 / 成熟 / 出清 / 修复 / 衰退 + 一句依据 |
| 未来 12 个月最关键信号 | 一个可观察的数据点，必须落在仪表盘某一行上 |
| 谁受益 / 谁受损 | 各一句话，点到环节或公司类型 |
| 证伪条件 | 出现什么数据，当前判断即错 |

**每格一句话、带数字锚点**，论证全部留给后续章节。口径提醒（存在多套统计口径时）另起一段，不塞进结论行。

**上期核对（有上一期时必写，一期一段）**：上一期的核心判断逐条标"兑现 / 未兑现 / 待验证"+ 一句原因。**核对的意义大于本期新增内容**——一份从不回头核对的行业报告，会连续三期犯同一个错。

### 二、行业与利润池

目的只有一个：**把"行业"划成一个能计量、能比较的利润池**，而不是先讲一堆行业概况。

- **定义与边界**：按什么口径划线（产品 / 技术 / 牌照 / 地域），含哪些细分、排除哪些邻近行业、为什么这样划。边界是后面所有数字的地基。

- **产业链地图**：上游 → 中游 → 下游 → **支付方单列**（居民 / 企业 / 财政 / 医保 / 出口）。表：环节 | 主要参与者 | 提供的价值 | 议价权 | 环节利润率。支付方的变化常是整个行业规则的源头（医保支付规则一变，全行业的价与量同时改写）。

- **利润池测算**：给一个数——`规模 × 环节利润率`，或 `规模 × 单位利润`。**必须带口径与时点**（哪一年、什么统计来源、含不含税与渠道加价）。算不准就给区间，但不要不给。

- **利润在哪个环节**：按环节利润率从高到低排序，一句话说明为什么钱堆在那里（资源禀赋 / 牌照 / 技术代差 / 品牌 / 规模）。

**常见错法**：把本章写成行业百科（历史沿革、产品分类、发展历程）。这些只在解释"池子边界为什么这么划"时出现，其余全部删掉。

### 三、量

- **三层拆开写，不许混成"需求增长"**：存量替换 / 新增渗透 / 结构升级，各占多少、增速各是多少。三者持续性天差地别，混在一起就判断不了天花板。

- **支付方与支付能力**：谁掏钱、掏钱的能力和意愿在变好还是变坏。量增但支付方变穷，是最典型的陷阱。

- **空间只做到 TAM → SAM**：给出测算口径与关键假设，**标出最主观的那一个变量**（通常是终局渗透率或单价）。SOM（公司能拿到多少）属于公司报告，此处不做。

- **成色判断（必写）**：这层需求是政策托底、低基数修复，还是内生增长。政策托底与低基数修复都会在两年内消失，不能当作长期增速。

**本节产出**：未来三年量增区间 + 最主观假设 + 一个可月度观察的先行指标。

### 四、供

行业研究里信息量最高、也最容易被写成"产能罗列"的一节。**核心工具是成本曲线。**

- **成本曲线**：把行业产能按**现金成本**从低到高排序，画出分布，标三件事——① 当前价格落在曲线第几分位；② 该分位对应的产能占比；③ **现金成本高于当前售价的产能有多少（这就是出清压力，也是下一个供给收缩的来源）**。

- **供给结构**：玩家分层（龙头 / 二线 / 新进入者 / 跨界者）、在建与拟建产能、进口与出口。在建产能的投放时间表比现有产能更重要。

- **壁垒**：资源 / 牌照 / 技术 / 规模 / 渠道，每条写"**防的是谁**"，再加一句为什么学不来（商业模式、资源禀赋、组织能力的本质差异，不是"能力问题"这种空话）。

- **库存三处一起看**：上游 / 渠道 / 终端。只写一处必误判——厂家库存下降，常常只是把货压给了渠道。

- **出清五问**（判断"出清到哪一步"的清单）：

  1. 多少产能在现金成本以下运行、已经亏了多久；

  2. 在建产能还要投放多少、什么时候投完；

  3. 有没有强制退出机制（环保、能耗、安全、政策准入）；

  4. 龙头是否在逆势扩产（**龙头扩产是出清未完成的强信号，不是利好**）；

  5. 开工率与关停家数在往哪个方向走。

**本节产出**：现价落在成本曲线哪一分位 + 出清阶段判定（未出清 / 出清中 / 已出清）+ 一个出清确认信号。

### 五、价与单位利润

- **价格形成机制先定性**：成本加成 / 供需定价 / 品牌溢价 / 政策定价（可混合）。机制决定后面该看什么——政策定价的行业看降幅节奏与续约规则，供需定价的行业看库存与开工率。

- **价格史**：历史中枢、当前价位、上一次大幅波动的触发原因。区间比点位有用。

- **定价权测试（给结论，不给形容词）**：① 这家/这类主体历史上提价成功过吗；② 下行期毛利率守住过吗；③ 涨价后客户有没有跑（份额掉没掉）。三条过不了就是没有定价权，写"有"是自欺。

- **传导链**：成本上涨能否转嫁给下游、转嫁有时滞吗、中游是否被两头挤。**周期行业必须写这一条**——同样涨价，上游与中游的利润含义可以相反。

- **单位利润**：单吨 / 单台 / 单店 / 单客的收入减成本，以及趋势。这是把"价"和"供"接起来的地方：单位利润 = 价格 − 成本曲线位置。

**本节产出**：单位利润的方向判断 + 定价权结论（有 / 无 / 有限，附三条测试的结果）。

### 六、分配

前面的量、供、价共同决定了池子有多大；本章决定**谁把池子里的钱拿走**。

- **议价权迁移**：利润正在从哪一环流向哪一环、驱动是什么（供给紧张、渠道崛起、平台化、品牌集中）。给出方向，不要只给静态快照。

- **集中度**：CRn 的历史与当前、龙头份额及其变化方向。集中度是慢变量，但它一旦形成趋势，比短期价格更确定。

- **份额窗口**：行业调整期是龙头吃小厂份额的窗口——**这是行业研究最有价值的下注点**。明确写出：这一轮谁在吃份额、凭什么吃（成本更低、现金流更厚、还是渠道更强）、份额能吃到什么时候。

- **财务验证（样本聚合）**：选 3—5 家覆盖不同环节或不同规模的代表公司，用 `api/` 逐家拉数后聚合，看环节利润率与份额是否真的如判断那样移动。**必须注明样本、权重、区间，并写明"样本聚合，不代表全行业"**；有官方行业统计年鉴时以年鉴为主、聚合为辅。

**本节产出**：利润流向结论 + 吃份额的一方 + 一个可跟踪的份额指标。

### 七、变量

政策与技术单独成章的唯一理由：**它们能一次性改写上面任何一条**。所以本章的写法是"**影响路径 + 落地信号**"，不是政策清单、不是技术综述。

- **政策**：分四类写——准入（牌照 / 审批）、定价（指导价 / 集采 / 医保支付 / 补贴）、供给（产能与环保约束）、贸易（关税 / 出口管制）。每条写清：管什么、谁管、文件层级、时间表，然后**指向它改写的是量、是价、是供、还是分配**。

- **技术**：当前路线与下一代路线的对比（性能 / 成本 / 成熟度）、迭代周期、当前处于实验室 / 导入 / 放量 / 成熟的哪一段、放量拐点的信号。**技术的本质是移动成本曲线**——写清它把谁的成本降下来、降到多少，等于重写了"四、供"。

- **删掉标准**：写不出"改写了上面哪一条"的政策条目与技术名词，一律删掉。凑数量的政策清单是行业报告最典型的注水。

**本节产出**：每条外生变量的影响路径（指向具体章节）+ 一个可观测的落地信号。

### 八、位置与情景

- **周期位置与景气读数分开写**——这是最容易混的一处：

  - **位置**是阶段判断（萌芽 / 成长 / 成熟 / 出清 / 修复 / 衰退），靠供给与库存结构定；
  - **读数**是当前指标值，靠数据定。
  - **读数高不代表位置靠前**（价格创新高但库存在累积，是修复中后段的典型形态），两者冲突时以结构为准。

- **情景三档**（悲观 / 基准 / 乐观），每档给：触发条件、行业增速路径 [g1, g2, g3]、该档下的关键假设。**行业增速路径是给公司报告用的输入**，区间可以宽，但三档必须单调。

- **市场当前定价的是哪一档**：用行业指数估值分位或龙头股的隐含预期反推。写不出就明说"无法判断"，不要编。

**本节产出**：三档情景 + [g1,g2,g3] + 市场隐含档位。

### 九、标的映射

行业本身没有估值；本章是行业 → 公司的唯一衔接点。

| 标的 | 定位（直接受益 / 间接受益 / 受损 / 不确定） | 利润兑现路径（一句话，含关键假设） | 一次性收益 | 对应公司报告 |
| --- | --- | --- | --- | --- |

三条硬规则：

- **排序按利润兑现度排**（剔除一次性后的经常性利润），不按股价弹性排；

- **一次性收益单列、不参与排序**——授权首付款、资产处置、投资收益、政府补助都属于这一类，写清金额与占利润比重；

- **不做个股估值**。估值计算统一 `tools/valuation.js`，在公司报告里完成；行业层最多引行业指数或龙头的估值分位做交叉验证。

**本节产出**：一张排序表，每行指向一份公司报告。

### 十、证伪与跟踪

本章是行业跟踪的**唯一变量来源**：跟踪只验证这里的东西。

- **证伪条件（3—5 条）**：每条对应结论卡片里的某一句判断，写成"**出现什么数据 → 说明哪句判断错了**"。对应不上的删掉。

- **仪表盘**（一张表，全文指标只在这里出现一次）：

| 层级 | 指标 | 阈值 / 信号 | 频率 | 来源 |
| --- | --- | --- | --- | --- |
| 先行 | 订单 / 招标 / 批文 / 渠道库存 / 上游发运 | | | |
| 同步 | 产量 / 出货 / 价格 / 排产 / 开工率 | | | |
| 滞后 | 收入确认 / 环节利润率 / 资本开支落地 | | | |

  先行预警、同步定性、滞后验证。**价格类"再定价"信号**（批价、集采续约价、大宗报价）既确认本轮、又是下一轮的先行，单独标出。

- **跟踪日历**：什么时候看什么、去哪找、验证哪条判断。日历管时点，指标口径由仪表盘管，两处不重复。

- **数据边界**：A 股样本财报到哪一期、港股到哪一期、行业数据到哪一月、政策到哪一节点；哪些是官方确认的事实、哪些是本报推断。

**本节产出**：一张不重复的仪表盘 + 一份可以照着执行的日历。

## 三、硬纪律

这八条是判定对错的标准，不是风格偏好。

1. **口径链条不可跨级。** `行业规模 → 环节收入 → 样本公司收入 → 归母利润`，每一跳都要有依据，**绝不能从行业总量直接推公司利润**。最典型的反例是授权交易：交易总额 ≠ 许可收入 ≠ 到账现金 ≠ 利润，四者可以差一个数量级。

2. **一个数字，一个口径，一个日期。** 三套统计并存时（如获批数量的发布会口径 / 审评报告口径 / 行业统计口径），选一套写清理由，其余只在脚注出现，**不许拼成一条曲线**。

3. **判断必须落在可观测变量上**：价、量、库存、份额、单位利润。落在"景气度上行""需求旺盛"这类自我指涉的词上，等于没写。

4. **核心矛盾只有一个。** 次要矛盾降为小节。一次列五个矛盾的报告，等于没有主线。

5. **一次性收益必须单列。** 首付款、处置收益、补助、投资收益，写清金额与占比，不进趋势判断、不进排序。

6. **官方原文优先。** 统计公报、政策文件、公司公告是一手依据；券商观点与媒体报道只作交叉验证，须注明来源与日期，冲突时以官方为准并说明差异。

7. **样本聚合不等于全行业。** 用代表公司代表行业时，必须写样本、权重、区间，并明写"不代表全行业"。

8. **行业不写个股估值。** 行业层给排序与受益逻辑，估值在公司报告。

## 五、跟踪与复盘

- **默认单文件**：`doc/知识库/行业/<行业>.md`。仪表盘与日历按节点滚动更新"最新状态"并标日期，骨架与基线不随事件改写。

- **升级文件夹**：数据密集、跟踪成为常态时（范式见 `doc/知识库/行业/创新药/`、`doc/知识库/行业/工程机械/`）：

```
doc/知识库/行业/<行业>/
├── README.md          # 命名规则、本期口径、跨期判断变化表
├── <YYYY>年<M>月.md    # 逐期主报告（十章骨架，按报告期命名，不覆盖历史）
└── 图表/              # 图表/数据/*.spec.json + 图表/图片/*.png
```

- **文件名 = 报告期**：取该期最后一份完整财报的月份（一季报 3 / 中报 6 / 三季报 9 / 年报 12），不是撰写月份。每期新建、不覆盖历史。

- **复盘是本框架的一部分**：每期开头必须核对上一期的判断（见"一、结论卡片"的上期核对），并保留"跨期判断变化表"说明哪条判断被证伪、为什么。
