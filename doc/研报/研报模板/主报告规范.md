# 主报告规范

> **主报告 = 分析框架 + 财务基线**：回答"怎么分析这家公司、看什么、阈值多少、逻辑如何被证伪"；数据底座以**最新年报（当前为 2025 年报）为基线**，后续实绩一律在 `财报跟踪/` 目录逐期更新，主报告**不随季度改写**。
>
> 本规范与 [财报跟踪规范.md](财报跟踪规范.md)、[README.md](README.md) 构成三件套：
> - **主报告规范**（本文）：主报告长什么样（分析框架 + 基线）；
> - [财报跟踪规范.md](财报跟踪规范.md)：跟踪文档长什么样（按框架逐期更新）；
> - [README.md](README.md)：三件套索引 + 共用规则（文件夹结构、路径、工具、分工、格式）。
>

## 一、定位与更新纪律

| 项 | 规则 |
| --- | --- |
| 本质 | **分析框架**（怎么分析、看什么、阈值多少）+ **财务基线**（最新年报锚点） |
| 基线 | 以**最新年报**为财务基线（当前为 2025 年报）；头部明确标注基线年报 |
| 更新触发 | ① **年报重锚**：新年报披露后，财务基线（三章）刷新为新年报；② **框架修订**：核心逻辑、增长方向、阈值、估值基准变化时即时修订；③ **季报不动主报告**——实绩、验证全部进 `财报跟踪/` |
| 头部标注 | 写作基准日期 + 财务基线（<YYYY> 年报）+ 指向 `财报跟踪/` 的链接 + 现价口径 |

**核心纪律：主报告只含"框架 + 基线"，不含逐期实绩。** 所有"最新数据"一律到 `财报跟踪/` 目录查。

## 二、头部格式

```markdown
# <公司>（<代码>.SZ）

> **独立研究报告**（写作基准：<YYYY-MM-DD>；财务基线：<YYYY> 年报 + 截至基线的快照；下一披露节点：<报告期>，约 <日期>；后续实绩见 [`财报跟踪/`](财报跟踪/) 目录，每报告期一个文件）：
> [2026 一季报跟踪](财报跟踪/2026一季报.md)｜[2026 中报（待披露）](财报跟踪/2026中报.md)｜[2026 三季报（待披露）](财报跟踪/2026三季报.md)

> 报告更新：<YYYY-MM-DD>（A 股现价 <X> 元，<日期> <盘中/收盘>）。数据来源：东方财富 F10 财务接口（api/）、机构盈利预测接口（api/orgForecast.js，<日期> 一致预期）、股东户数与前十大流通股东接口；估值计算用 tools/valuation.js（统一三段式模型）。财务基线为 <YYYY> 年报，此后实绩更新见 `财报跟踪/`。
```

要点：①基线明确写"<YYYY> 年报"；②跟踪实绩一律指向 `财报跟踪/` 目录，主报告不重复；③现价必须有日期与口径（框架修订时顺带刷新）；④写明"下一披露节点"（下一报告期 + 预计日期）——公司文件夹不设 README，目录信息由主报告头部承载。

## 三、章节骨架

### 章节速览

| 章节 | 一句话目的 |
| --- | --- |
| 零、核心逻辑 | 全篇的纲：高度总结的一段话。（可证伪的投资判断 + 增长方向 + 护城河） |
| 一、业务说明 | 业务地图：卖什么、钱从哪来（客观描述，不下判断） |
| 二、宏观背景 | 宏观顺风还是逆风、通过什么路径影响公司盈利与估值 |
| 三、财务报表分析（财务基线） | 从最新年报读出经营本质 + 关键项目跟踪阈值 |
| 四、业绩预期（基准情景） | 输出基准利润路径 [g1,g2,g3] + 机构预期 + 管理层观点 |
| 五、估值（估值框架） | 贵不贵、买不买：θ 测定 + 只围绕利润假设的情景 |
| 六、跟踪清单 | 定义跟踪什么：催化剂 / 增长驱动 / 风险的验金石与阈值 |
| 七、治理结构 | 谁说了算、利益是否与股东一致 |
| 八、流通股东变化（筹码方法） | 筹码在谁手里：四类信号 + 三季对比方法 |
| 九、备注：名词解释 | 行业名词一览表，读者无需外部资料 |

> 主报告固定十章（零~九），各章独立成节。下面是每章的**写作指引**——给出结构建议与思考方向，具体取舍按公司情况自定，不必逐条照搬。

### 零、核心逻辑

全篇的"纲"。把对公司的全部判断压缩成高度总结的一段话**可证伪**的核心逻辑——利润靠什么释放（不靠什么）、增长靠什么驱动、护城河在哪、把已验证逻辑变成全年数字的催化剂是什么。本章以结论性判断为主，不展开数据论证；每个判断在后续章节都有对应证据，读者读完本章即掌握全文骨架。

**建议结构**：

- **从业务场景看增长预期**：每个方向回答"钱从哪里来、往哪里扩、在哪里卖"，一般 3—4 个并列方向（如果有的公司特殊，它是层层递进的，就按照递进的方式），可按业务线、内外需、商业模式等维度切分。每个方向写四件套：
  - **逻辑**：为什么这个方向能带来增长（一句话本质，如"把存量资产重新变现，不靠开拓新增市场"）；
  - **驱动力**：现实里哪些因素正在推动它发生（列 2—3 条，写清"政策 / 技术 / 需求"的具体机制，不堆概念）；
  - **验证指标**：看什么指标、阈值是多少、跟踪频率与来源——这是框架的"仪表盘"，**不过期**；如需基线数字佐证，标注基线日期（如"2025 年报：IVD 市占率 10%→13%"），最新值一律到 `财报跟踪/` 查；
  - **现实约束**：什么条件下它会证伪——**必写**，防止只讲乐观面。
  - 有内外需之分的公司，通常单独做一个"地域"方向，把海外增量的确定性与内需企稳的成色（政策托底 / 低基数修复 / 内生结构性，三者可持续性天差地别）拆开看。
- **护城河**：先点明对手是谁（通常是"上攻的巨头 + 下沉的小厂"），再并列组织壁垒方向，每个写"**防的是谁 + 一句话本质 + 论证**"。论证的关键不是罗列优势，而是写出"这不是能力问题，是商业模式 / 组织能力问题"式的本质差异。
- **核心跟踪变量**：一张"可跟踪清单"——变量、看什么指标、阈值、关联哪条逻辑，作为"六、跟踪清单"的输入。

### 一、业务说明

**客观描述**：公司卖什么、钱从哪来、靠什么赚钱。**不下判断**，判断留给"零、核心逻辑"。

**建议结构**：业务构成 → 分部经营数据（表）→ 业务特点。

- **业务构成**：按业务线 / 事业部拆解，每条写定义、规模与增速、所处地位与趋势，逐一说清各自下游是谁。结构性数据（商业模式、产品线、市占率格局）留在这里；时点性数据进跟踪。
- **分部经营数据**：收入、占比、同比增速、特征的汇总表。附注里写清口径与隐藏细节——某板块下滑是主动收缩而非需求崩塌，这类反差最能体现报告深度。
- **业务特点**：提炼每条业务线的**结构性**特点（毛利率高低、增长质量、战略含义），为"三、财务报表分析"与核心逻辑埋伏笔。

体量小、业务单一的公司可以合并业务线、简化分部表——不强制凑满四个板块。

### 二、宏观背景

评估该股票所处的宏观环境——经济周期位置、利率与流动性、汇率、政策与产业环境，回答"宏观是顺风还是逆风、通过什么路径影响公司盈利与估值"。**只做环境评估，不下公司判断**。

**建议结构**：宏观周期定位 → 利率与流动性 → 汇率与外部环境 → 政策与产业环境 → 宏观到公司的传导（表 + 总结段）。

- 写"**传导路径 + 一句话当前定位**"：传导路径相对稳定（如利率 → 估值底座 / 财政发债成本、财政卫生支出 → 医院设备招标、汇率 → 汇兑损益与出口竞争力），留在本章；当前状态随**年报重锚**刷新，宏观重大变化时即时修订。
- 宏观数据同源引用 `../../../宏观/` 文档（如《总览》《央行》《财政》等），行业政策引用 `../../../行业/`（如医疗集采.md），不重复展开。
- 传导表：宏观变量 | 当前状态 | 传导路径 | 对公司的影响 | 跟踪指标。末尾一段总结：宏观整体顺风 / 逆风 / 中性；最大的宏观变量是什么；它对"零、核心逻辑"里哪条假设影响最大、证伪阈值是什么。
- 与公司关联弱的宏观变量可以略写，不必面面俱到——重点写影响最大的 2—4 条路径。

### 三、财务报表分析（财务基线）

从数字读出经营本质。本章 = **财务基线（最新年报锚点）**：只分析最新年报，不随季度改写；季度变化在 `财报跟踪/` 逐期更新。

**建议结构**（参考建议，可按公司情况调整；**重点关注大额/重点项目，其余按需取舍，不必面面俱到**）：

1. **经营相关数据**：先讲经营本身——收入规模与结构（分业务/产品/地区）、订单与合同负债、市占率、产能与人员、经营效率等。回答"公司这一年在经营上发生了什么"。
2. **利润表**：收入 → 成本 → 毛利 → 费用率 → 利润。毛利率变化要写清**是成本红利还是产品结构升级**（持续性完全不同）；大额费用项目（销售/研发/财务/资产减值等）单独说明。
3. **资产负债表**：按余额与占比找大额科目（货币资金与理财、应收账款、存货、固定资产/在建、商誉、有息负债等），每项写"数字是什么 + 说明什么"；关注质量（应收/存货是否恶化、债务结构是否优化）。
4. **现金流量表**：经营/投资/筹资三大活动 + 净现比；经营现金流与净利润的匹配度（利润质量），大额流向（并购/分红/理财）单独说明。

- **每张表原则上配一句"这张表告诉我们什么"的定性解读**，不是搬运数字——判断才是研报的价值。
- **关键项目跟踪阈值**：列出需要逐期盯的科目（如毛利率、合同负债、商誉、经营现金流）与阈值、数据来源，作为 `财报跟踪/` 逐项更新的基线参照。
- 新年报披露后，本章整体刷新为新年报（年报重锚）。

### 四、业绩预期（基准情景）

给出未来 1—3 年的业绩基准、增长驱动、利润拆分预测与机构一致预期。本章输出**基准利润路径 [g1,g2,g3]**——这是估值的输入，主观判断集中在这里。

**建议结构**：业绩基准 → 增长驱动 → 利润拆分预测（拆分口径 / 利润增速预期怎么拆）→ 机构预测参考（基线时点）→ 管理层观点。

- **业绩基准**：上年实际 + 公司当年经营目标（收入 / 利润口径）。
- **增长驱动**：按重要性列出未来几年的增长驱动，每条写清机制与验证指标。
- **利润拆分预测**：把增长驱动翻译成"未来三年利润从哪来、按什么口径拆、增速怎么推"。拆分维度：①按业务分部（各板块利润基数、增速假设、增量贡献）——通常必做，业务单一、拆分无增量信息的可整体口径并注明；②按利润性质（经常性 vs 一次性）——仅存在大额一次性项目时使用；③按内外需 / 产品结构——适用于收入结构二元分化的公司。写清口径规则（哪些业务计入 / 不计入、一次性项目单独处理），并**标出主观判断最强的一步与可证伪的跟踪指标**。
- **机构预测参考**：基线时点的一致预期（表格：年份 / 预测 EPS / 对应净利 / 增速 / 基线 PE），与拆分结果交叉验证；与一致预期的**逐期对照移入财报跟踪**。
- **管理层观点**：管理层在投资者交流会、业绩说明会等公开场合发表的观点——官方经营目标与指引、对市场关切的回应、战略方向表态。写清**时间与场合**（避免把不同时期的表态混为一谈），用"市场担忧 vs 管理层回应"表格记录；新表态的验证在 `财报跟踪/` 的"业绩预期（最新）"节更新。

### 五、估值（估值框架）

把前文所有定性判断翻译成"贵不贵、买不买"。**核心纪律：估值只由利润路径（[g1, g2, g3]）与兑现系数 θ 决定；经营风险全部计入利润预测，不在 θ 上打折。** 统一采用 `../../../估值理论/估值模型.md`（R = rf + 5.5%、g∞ ≈ 2.33%、**过渡期统一 3 年**——风险补偿，不调整），计算用 `tools/valuation.js`。

**建议结构**：

```
### 1. 估值测算
#### <公司>的 θ 测定
#### 基于利润路径测算估值      # 增速情景表（固定 θ）
### 2. 估值结论
#### 模型结论
### 3. 验证窗口
```

- **θ 测定**：根据公司的现金转化画像一次测定 θ₀ / θₓ——轻资产还是重营运资本、净现比、账上净现金，给出基准 θ（θ = 0.15θ₀ + 0.85θₓ）。**测定后固定，不再做 θ 分档情景**——θ 只反映利润兑现质量，不做高估/低估分档。
- **基于利润路径测算估值**：**估值情景只围绕利润假设**——固定 θ，做不同增速假设 [g1,g2,g3] 下的情景（悲观 / 保守 / 中性 / 基准 / 乐观），每档给出利润路径、内在 PE、股价、相对现价的涨跌幅。情景表**必须用 `tools/valuation.js` CLI 生成**（`node tools/valuation.js <spec.json>`），数字与程序输出一致。**关键读数**：现价落在哪个增速情景附近，反推市场隐含的利润路径。
- **模型结论**：①现价是"低估 / 合理 / 高估"及**低估的位置**（利润路径的哪一段、哪个板块假设被低估）；②赔率结构（下行 / 上行空间，用数字）；③买入的本质（买的是什么）；④核心张力（市场假设 vs 基准假设，验证信号是什么）；⑤安全边际（确定性现金、分红承诺、净现金等）。
- **验证窗口**：列出未来几个关键时点（季报、全年业绩、事件进展），各自验证哪条逻辑——优先验证"四、业绩预期"里利润拆分主观假设最强的变量。

### 六、跟踪清单

定义跟踪什么（**写一次**）：催化剂、增长驱动、风险的验金石 / 阈值 / 跟踪频率。本章是 `财报跟踪/` 目录的**唯一变量来源**——跟踪只验证这里的项目，不发明新变量（除非出现了新的必须关注的变量，再更新这里）；最新状态与验证按财报节点在跟踪中更新，本章不随季度滚动。

**建议结构**：催化剂（表 + 关键解读）→ 增长驱动（表）→ 风险（表）。

- **催化剂**：不是独立事件清单，而是"同一件事的不同触发器"——把已验证的逻辑从"阶段事实"变成"全年数字"。按"**N 个验金石 + 1 个传动轴**"组织：验金石 = 每个增长方向成立的关键验证信号（带可观察阈值）；传动轴 = 财报、指引这类把逻辑传导为市场定价的东西。附 2—4 条关键解读（哪个是全场最关键的验金石、藏在哪里面的免费期权）。
- **增长驱动**：每个驱动一个跟踪项——看什么指标、阈值是多少、跟踪频率与来源。
- **风险**：按影响程度排序（高 → 低），每条写成"**如果发生什么 → 会造成什么后果**"，不写空话；风险是核心逻辑的逆命题。

### 七、治理结构

回答"谁说了算、利益是否与股东一致、有无减持 / 质押隐忧"。信息表 + 一段定性评价。

- 信息表：股权结构、实控人、董事长 / 总经理、重要股东、总股本、董事会构成、累计分红、员工人数等。
- 定性评价：治理模式（创始人驱动 / 体系驱动）、内部人信号（增减持、质押）、分红政策、接班与合规等长期观察点。相对静态，随重大变化修订。

### 八、流通股东变化（筹码方法）

回答"筹码在谁手里、聪明钱在进出什么"。本章写**方法 + 关注点**：看哪四类信号（北向外资、国家队 / 社保、公募 / 险资、内部人增减持）、至少连续三季的对比规则、筹码面与基本面共振的判断方法。**具体股东户数、前十大持仓、增减持表格进 `财报跟踪/` 对应报告期**，主报告不堆表格。

**纪律**：筹码面是**验证信号**，不是选股依据——要与"零、核心逻辑"的基本面相互印证；单独出现（如国家队增持但基本面恶化）要打问号。
