## 拆分约定

- **主报告 = 静态分析 + 跟踪框架**：公司逻辑、财务基线（2025 年报）、业绩预期、估值方法与基准情景；第六章"跟踪框架"定义催化剂 / 增长驱动 / 风险的验金石、阈值与跟踪频率，不随季度滚动改写。
- **跟踪报告 = 逐期更新**：每报告期一个文件，记录核心指标实绩、财务报表分析项目、催化剂 / 风险逐项更新（统一用 ✅ / ⚠️ / ❌ 评价列）、管理层观点、关键解读与验证窗口。
- 主报告中的"核心跟踪变量"与"验证窗口"是跟踪的检查清单；具体实绩一律到 `财报跟踪/` 目录对应文件查找。
- 中报（8/31）披露后：把 [2026中报.md](财报跟踪/2026中报.md) 的前瞻清单转为已核对结果，并新建 2026三季报.md（约 10 月底披露）作为下一节点模板。
