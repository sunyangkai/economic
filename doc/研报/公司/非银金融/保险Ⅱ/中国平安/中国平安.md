## 零、核心逻辑

**一句话核心逻辑：利润靠 NBV 高增、财险承保盈利与增配权益对冲利差三条腿释放（不靠投资端的股市运气），增长靠寿险价值、财险质效与医养变现三引擎，护城河是综合金融交叉销售 + 医养差异化服务，催化剂是 NBV 前向增速能否守住 ~15%（对应寿险 P/EV 0.83x 回归）。**

中国平安 2025 年营收 10,505.06 亿（+2.1%）、归母净利润 1,347.78 亿（+6.5%）、归母营运利润 1,344.15 亿（+10.3%）、营运 ROE 12.7%、每股股息 2.70 元（连续 14 年增长）——数字稳健，但市场给它的估值（P/EV 仅约 0.65 倍、股息率近 5%）说明了一件事：**大家买平安，买的不是当期利润，而是"利率下行这个最大的宏观叙事，究竟会不会把平安的利差、EV 假设和新单价值同时击穿"。**

平安是中国唯一一家真正意义上的综合金融集团——寿险、财险、银行、资管、科技五大板块协同。要看清它的增长，不能按单一保险公司，也不能按制造业"卖更多货"的逻辑，而要顺着四个方向拆解：钱从寿险价值增长里来、从财险承保质效里来、从投资端对冲利差里来、从医养与交叉销售里来。

### 从业务场景看增长预期

**方向一：寿险价值——从"人海战术"到"银保 + 代理人双轮"**

- **逻辑**：寿险是平安价值创造的发动机（占营运利润约 74%），增长的本质已从"堆人力卖保单"切换到"银保冲量 + 代理人提质"双轮——NBV 连续三年双位数增长，是估值修复的核心抓手（NBV 增速决定该给多少 P/EV）。
- **驱动力**：①"报行合一"落地后银保渠道费用率下行、盈利效率提升，银保 NBV 暴增 138%；②代理人从峰值约 120 万缩减至 35.1 万（-70%+），但人均 NBV +17.2%，"减员提质"兑现；③存款搬家——定存利率跌破储蓄险预定利率，居民存款持续导入保单。
- **数据证据**：2025 年 NBV 368.97 亿（+29.3%），NBV Margin（标准保费口径）28.5%（+5.8pct）；银保 NBV 94.08 亿（+138%）、占比 25.5%，非个险渠道贡献已超 1/3；13/25 个月继续率双双改善。
- **现实约束**：代理人 Q1 仍降至 33.2 万（-5.4%）、人均月收入 9,299 元（-10.5%）——"减员提质"尚未结束；银保 Margin 24.5% 仍低于代理人的 30.8%，量增能否转化为质改善是第二个验证点；Q1 Margin 23.5%（-4.8pct）主因分红险转型压缩 Margin。

**方向二：财险质效——承保利润接近翻倍**

- **逻辑**：财险是第二大利润支柱，核心是 COR（综合成本率）三年连降（100.7%→98.3%→96.8%），承保利润 +96.2% 接近翻倍——行业下行期靠风控和成本优势抢份额，复苏期吃盈利弹性，逻辑与寿险一致。
- **驱动力**：①车险 COR 95.8% 行业最优；②新能源车险保费 525 亿（+39%）、市场份额 27.7%、已实现承保盈利，是车险增长核心；③保证保险扭亏为盈是 COR 优化的关键驱动。
- **数据证据**：2025 年原保费 3,431.68 亿（+6.6%）、承保利润 107.17 亿（+96.2%）、车险承保利润 94.96 亿（+126%）。
- **现实约束**：责任险仍承保亏损 16.42 亿（COR 106.8%），是非车险主要拖累。

**方向三：投资与利率——增配权益对冲利差**

- **逻辑**：利率下行 → 投资收益下降 → 利差损，是市场最深的担忧。平安的应对是把权益仓位从约 12% 提至 **19.2%**（历史最高），用"固收 + 权益增强"对冲利差压力，这是整个利润表弹性最大的变量。
- **驱动力**：①股票 + 基金增配至约 1.24 万亿，其中 57% 股票计入 FVTOCI，贡献税前浮盈超 900 亿元；②近 10 年平均综合投资收益率 4.9% 持续高于 4.0% 长期假设。
- **数据证据**：2025 年综合投资收益率 6.3%（近五年最高）、总投资收益 2,343 亿（+13.5%）。
- **现实约束**：净投资收益率 3.7% 仍在下降，若跌破 3.5% 利差损从"远虑"变"近忧"；Q1 2026 已演示双刃剑——上证仅跌 1.9%，公允价值变动即接近 -500 亿、归母净利 -7.4%。

**方向四：医养与综合金融——客户经营型护城河**

- **逻辑**：当保险产品高度同质化时，谁能提供差异化服务（AI 医生覆盖 1.13 万种疾病、全国 7.7 万家药店一键支付）谁就能在客户争夺中胜出——医养不是成本中心，是获客和提频的引擎。
- **驱动力**：①2.51 亿个人客户交叉销售（客均合同 2.94 个）；②医养权益客户的保单转化倍数远超普通客户（居家养老 5.2 倍、高品质养老 23.4 倍）。
- **数据证据**：3 类及以上产品客户留存率 99%、服务 5 年以上客户占比 75%；医养服务客户 1,829.8 万人；平安健康 2025 年净利 3.80 亿扭亏为盈。
- **现实约束**：养老社区回报周期极长（5—8 年开始盈利），医养商业化变现路径仍需观察。

### 护城河

平安面对的竞争格局是"上下夹击"——上方是友邦（品牌 + 高 Margin）这样的质量标杆，下方是国寿、太保等规模型对手。但平安的护城河不在一款产品，而在"综合金融 + 医养"的生态叠加：

| 壁垒方向 | 防的是谁 | 一句话本质 |
| --- | --- | --- |
| **方向一·综合金融交叉销售网络** | 单一险企 | 2.51 亿客户 × 客均 2.94 个合同，多产品持有带来 99% 留存 |
| **方向二·医养差异化服务** | 同质化竞争 | AI 医生 + 居家/社区养老 + 药店网络，服务锁定获客与提频 |
| **方向三·客户规模与品牌** | 中小险企 | 保险业资产第一、客均合同数是首年客户 1.7 倍的复利 |
| **方向四·国企体制 + 市场化机制** | 体制束缚型对手 | 无实控人 + 管理层主导，能持续十年推进长期布局 |

**方向一：综合金融交叉销售网络（对抗单一险企的生态壁垒）**

- 论证：平安是唯一真正的综合金融集团，寿险、财险、银行、资管、科技五大板块共享 2.51 亿个人客户。关键不是客户数量，而是**多产品持有带来的高留存和高价值**——持有 3 类及以上产品客户留存率 99%、服务 5 年以上客户占比 75%（客均合同数是首年客户 1.7 倍）。任何单一业务的竞争对手都无法复制这张交叉销售网络。

**方向二：医养差异化服务（对抗保险产品同质化的服务壁垒）**

- 论证：保险产品高度同质化时，谁能提供差异化服务谁就胜出。平安的医养服务（AI 医生覆盖 1.13 万种疾病、全国 7.7 万家药店一键支付）让医疗健康权益客户的寿险新单件均保费是普通客户的 1.5 倍、居家养老 5.2 倍、高品质养老 23.4 倍。**这不是能力问题，是"金融 + 医疗 + 养老"的生态位问题**——纯保险公司没有医疗资源，纯互联网医疗没有金融牌照和线下网络。

**方向三：客户规模与品牌（对抗中小险企的规模壁垒）**

- 论证：总资产 13.9 万亿（保险业第一）、个人客户 2.51 亿，规模带来三重协同：投资端议价（6.49 万亿保险资金）、渠道复用（银保 + 代理人 + 互联网）、品牌信任（寿险/财险/银行一体）。中小险企可以打一个细分市场，但打不赢"全牌照 + 全客户 + 全服务"的平台。

**方向四：国企体制 + 市场化机制（对抗体制束缚的组织壁垒）**

- 论证：平安是罕见的"无实控人 + 职业经理人"大型金融集团，创始人马明哲 1988 年执掌至今、联席 CEO 制度运行平稳。分散股权带来决策独立性，让平安能持续十年推进寿险改革、医养布局这类长期投入。**这种治理形态的稀缺性，是它作为"国企背景 + 市场化机制"能持续领先的制度性护城河。**

## 一、业务说明

中国平安（601318.SH / 02318.HK，A+H 两地上市）1988 年创立于深圳，是中国规模领先的综合金融集团，业务覆盖寿险及健康险、财产保险、银行、资产管理、金融赋能（科技）五大板块。商业模式一句话：**一个客户、多个产品**——以寿险及健康险为核心，通过"保险 + 银行 + 科技"协同，向同一批个人与机构客户交叉销售保险、银行、资产管理、医疗健康等多种金融产品与服务，五大板块共享客户、渠道与数据（综合金融）。本章是业务地图，只客观描述公司做什么、钱从哪来、靠什么赚钱，不下判断（判断见"零、核心逻辑"）；结构为业务构成 → 分部经营数据 → 业务特点。

### 业务构成

五大板块业态不同、所受监管不同、下游客户不同，但共享同一批客户与渠道，共同构成"一个客户、多个产品"的综合金融生态。本节只讲每块业务具体做什么——服务内容、产品形态、销售渠道、下游客户、与渠道/监管的分工边界（公司提供什么、别人做什么）及其在集团商业模式中的位置；经营数字（NBV、COR、保费、利润、增速等）一律见下文"分部经营数据"。

**寿险及健康险——长期人身保险产品的设计、销售与契约经营**

寿险及健康险以平安人寿、平安健康险为主体，是集团历史最久、体量最大的板块，向个人客户（另有少量企业团体客户）销售保障期限长达数年至终身的人身保险产品：

- 产品形态：**传统寿险**（定期寿险、终身寿险、重疾险等保障型产品，提供身故、重疾、医疗给付）、**分红险**（在保证利益之上分享公司经营成果）、**年金保险**（按约定提供长期现金流）、**万能险**（保障 + 独立账户投资）、**长期健康险**（医疗险、重疾险等）等，产品组合覆盖"保障、储蓄、长期现金流"三类需求。
- 赚钱方式：先收保费、后按约定条件给付的负债经营——当期保费大部分形成保险准备金（对未来给付的负债），沉淀资金交由集团投资端统一运用；利润来自"三差"（利差：投资收益率与负债成本之差；死差/病差：实际赔付与定价假设之差；费差：实际费用与定价费用之差），存量保单的未实现利润以合同服务边际（CSM，见"九、备注：名词解释"）逐年摊销进入利润表——新单确认价值、存量逐年释放利润。
- 销售渠道与分工边界：①**代理人渠道**——公司自有销售队伍，与客户一对一销售并提供长期服务，是保障型高价值产品的主力渠道（销售、核保、承保、服务由平安自己完成）；②**银保渠道**——依托合作银行的网点与客户资源代销：银行负责客户触达与销售、收取手续费，平安负责产品设计、承保核保、资金运用与保单服务，银行储蓄与理财客户是主要客群；③互联网、电话、经代中介与团体业务等其他渠道。
- 下游与行业分工：最终客户是个人及家庭投保人；人身风险由平安自留并按需再保险分担；医疗健康服务商（医院、药店等，见"金融赋能"与医养生态）作为保单权益的服务提供方，与寿险共同服务客户。
- 在集团商业模式中的位置：寿险是集团价值创造的核心——是长期资金（准备金）的最大积累器、内含价值（EV）与合同服务边际的主要载体、个人客户的最大入口；寿险客户经综合金融平台向银行、财险、医疗健康服务延展，是"一个客户、多个产品"的起点。
- 所处地位与趋势（结构层面）：中国寿险市场正经历代理人渠道从"人海战术"向精英化、高质量队伍的整体转型，产品结构在低利率与监管引导下从传统险独大转向分红险等"利差与保户共担"的形态——这是行业性结构变迁，平安的渠道与产品结构转型与之同步。

**财产保险——一年期保障的承保、理赔与浮存金投资**

以平安产险为主体经营保险期限一年以内的财产与意外险，是集团第二大持牌保险业务：

- 产品形态：**车险**（交强险 + 商业车险，按车辆、出险记录与保额定价）与**非车险**——责任险、意外伤害与健康险（意健险）、企业财产险、保证保险等；意健险保障个人意外与医疗风险，责任险与企业财产险服务企业客户，保证保险承担信用担保职能。
- 赚钱方式：承保利润（保费收入 − 赔付成本 − 获取与运营费用）+ 浮存金投资收益——财险先收全年保费、赔付在保险期内陆续发生，沉淀的"浮存金"由投资端运用；综合成本率 COR（赔付率 + 费用率，见"九、备注：名词解释"）低于百分之百即承保盈利、高于则承保亏损，是承保端最核心的仪表。
- 销售渠道与分工边界：车险经**车商（4S 店）**、公司直销（电话、网络、自有 App）、经代中介等渠道销售——渠道负责客户触达与促成，平安负责核保定价、风控与理赔服务；责任险、企财险等多经经纪公司与直销展业。
- 下游客户：个人车主与家庭（车险、意健险）、各类企业与机构（财产险、责任险、保证保险的投保人）。
- 在集团商业模式中的位置：财险单均保费小、期限短、几乎每年续保，是与客户发生最高频接触的板块——续保与理赔触点是集团把车险客户转化为寿险、银行客户的重要入口；财险利润由承保端主导、对利率的敏感性低于寿险，与寿险形成利润结构互补。
- 所处地位与趋势（结构层面）：车险是承保基本盘、竞争充分，新能源车险等新品类带来产品结构升级空间；行业承保盈利的分化取决于数据化定价与风控的组织能力。

**银行——存贷、支付与财富管理的账户经营**

以平安银行为主体（集团控股并表），是集团唯一持银行牌照的板块：

- 业务内容：全国性股份制商业银行，向个人与公司客户提供存款、贷款、支付与财富管理——零售侧（信用卡、消费贷、住房按揭、财富管理与代销），对公侧（公司存贷款、供应链金融、投资银行、交易银行）。
- 赚钱方式：净息差（贷款利息收入与存款利息支出的差）为主、手续费及佣金等中间业务收入为辅；资产质量（不良率、拨备）决定减值成本与利润稳健性。
- 销售渠道与分工边界：物理网点 + 手机银行 App 线上经营；银行既直接经营客户账户与信贷，也代销集团内外的保险、基金与理财产品——代销集团保险时，银行是银保渠道的渠道方（收取代销收入），集团寿险是产品方。
- 下游客户：零售个人客户与公司客户（以中小客户为主）。
- 在集团商业模式中的位置：银行提供客户"金融主账户"场景——把集团保险客户转化为存款、信贷与财富管理关系，网点与 App 同时反哺银保渠道，是综合金融交叉销售网络的枢纽。

**资产管理——受托资金管理与投融资服务**

资产管理是多个持牌主体的组合，各自业态独立：

- 业务内容与主体：**平安信托**（资金信托、财富管理、服务信托等；历史上曾大量配置非标资产，是集团历史风险敞口的主要载体）、**平安证券**（证券经纪、投资银行、资产管理、自营）、**平安资管**（受托管理集团保险资金与第三方资金的资产管理平台）、**平安融资租赁**（设备与交通工具融资租赁）等。
- 赚钱方式与客户：受托管理按规模收管理费与业绩报酬，证券业务赚经纪佣金、投行与自营收入，信托与租赁赚利差与手续费——服务对象既有集团内部资金（保险资金），也有第三方机构资金、企业与高净值个人。
- 在集团商业模式中的位置：对内是保险资金与集团资金的受托运用平台（保险资金的投资配置在集团统一架构下进行），对外是以自有牌照面向市场的金融服务商；信托历史非标敞口正处主动收缩与出清阶段，板块当期业绩受存量风险出清进度主导。

**金融赋能（科技）——科技子公司集群，服务客户与主业**

金融赋能由集团旗下科技与专业服务子公司组成，各公司主业独立、商业模式各不相同：

- 业务内容与主体：**陆金所**（零售信贷科技平台，撮合/助贷个人与小微信贷）、**金融壹账通**（向金融机构输出金融科技系统与解决方案）、**平安健康（好医生）**（互联网医疗健康平台：在线问诊、健康管理、处方药与药房网络）、**汽车之家**（汽车资讯、交易与后市场服务）等；医疗养老生态另含以北大医疗集团为代表的线下医疗资产（医院等医疗服务机构）。
- 客户：C 端用户（医疗健康用户、信贷借款人、购车用户等）与 B 端机构（采购金融科技的金融机构、汽车厂商与经销商等）。
- 在集团商业模式中的位置：板块历史上曾以孵化、独立上市为目标，现定位"服务主业"——平安健康与医疗养老生态为集团保险客户提供差异化服务（医疗服务网络、居家与社区养老权益、AI 医生等），是寿险/健康险获客、服务提频与保单增值的载体，也是"零、核心逻辑·方向四（医养与综合金融）"的落地主体；壹账通等对外输出集团沉淀的科技能力。医疗服务的实际提供方（医院、药店、养老服务商）多位于集团体系之外，由平安的医疗网络与支付通道连接起来服务客户。

### 业务特点

本节提炼各板块与集团层面的**结构性**特点（商业模式与战略含义），为"零、核心逻辑"与"三、财务报表分析"埋伏笔；各板块的经营数字见上文"分部经营数据"，本节不重复。

- **寿险及健康险——渠道与产品双重结构转型进行时**：渠道从"人海战术"转向"银保 + 代理人双轮"——代理人把价值重心从队伍规模转向人均产能，银保把银行储蓄客户转化为保单客户；产品结构从传统险独大转向分红险占比提升，把低利率环境下的利差风险改为公司与保户共担；利润来源是"新单价值 + 存量 CSM 逐年摊销"的双池结构，新单决定增量、存量决定利润底盘——寿险因此是集团对利率最敏感、价值弹性最大的板块。经营数据见上文"分部经营数据"。
- **财产保险——承保主导的双轮结构，集团利润的稳定器**：利润由承保端主导（COR 为核心仪表）、浮存金投资为辅，期限短、年年续保、对利率敏感度低于寿险；产品上"车险基本盘 + 非车险内部高波动"并存，新能源车险是产品结构升级的新品类，承保盈利的分化本质是数据化定价与风控组织能力的差异。经营数据见上文"分部经营数据"。
- **银行——综合金融的枢纽与稳定利润板块**：与集团共享同一客户池，把保险客户转化为存贷与财富管理关系，网点与 App 同时是银保渠道的线下通道；集团内定位是"客户场景 + 稳定利润"而非弹性来源，息差随利率下行走低是行业共性，分化关键在资产质量与获客协同。经营数据见上文"分部经营数据"。
- **资产管理——集团的"排水渠"**：牌照最全，但历史非标敞口（信托为主）使板块利润天然随风险出清节奏大起大落；市场化业务（证券、租赁）与仍在收缩的信托历史业务并存的板块结构，决定了它当前是利润的"减负项"而非"增长项"——出清进度是集团利润确定性的开关之一。
- **金融赋能（科技）——从"孵化独角兽"转向"服务主业"**：各子公司业态独立、资本与牌照属性各异，共同定位已从独立估值转向与主业深度协同、自主造血；医养生态（平安健康 + 线下医疗资产）是保险获客、服务提频与保单增值的差异化抓手，其发展路径与寿险主业深度绑定。经营数据见上文"分部经营数据"。
- **集团层面——"一个客户、多个产品"的综合金融结构**：五大板块共享同一批客户、渠道与数据，交叉销售摊薄获客成本、抬高客户留存；寿险贡献价值与长期资金、财险贡献承保利润与高频续保触点、银行贡献账户场景与稳定利润、资管承担风险出清、科技提供服务粘性——板块互为渠道与客户，这种跨牌照协同是单一保险公司无法复制的生态结构（机制论证见"零、核心逻辑·护城河"）。经营数据见上文"分部经营数据"。

## 二、宏观背景

**一句话核心逻辑：美联储降息扩表对平安是"间接受益、弹性大、路径依赖强"的宏观变量——通过权益市场、中国利率与汇率资金三条通道传导，方向偏正，但兑现程度取决于宽松的触发路径（主动宽松 vs 衰退触发），且必须叠加中国自身的财政传导才能落地。本章把外部宏观变量翻译成平安的业务与估值语言，回答"美联储宽松下，平安的预期是什么、靠什么兑现、什么信号会证伪"。**

### 宏观环境坐标（2026 年 8 月）

| 维度 | 最新数据 | 对平安的含义 |
|------|------|------|
| 美联储 | 联邦基金利率 3.50%—3.75%，连续 8 个月按兵不动；7 月 FOMC 出现 2016 年以来首次加息反对票（3 票）；CME 年底前加息概率约 60% | "降息扩表"是预期而非现实；市场在通胀（加息）与衰退（降息）两种路径之间摇摆 |

| 中国货币 | M2 +7.7%、7 月新增贷款 -3,400 亿（单月净减少）、同业拆借利率 1.40% | 宽货币、紧信用；利率"1% 时代"下存款搬家持续（住户 -6,300 亿 → 非银 +11,100 亿） |

### 三条传导链

**① 权益市场通道（最直接、弹性最大）**：美联储宽松 → 全球风险偏好回升 → A/H 股上行 → 平安权益投资收益与净资产双重受益。平安股票+基金仓位已升至 19.2%（约 1.24 万亿，历史最高），TPL 股票占 43.5% 直接波动当期损益、约 57% 计入 FVTOCI 增厚净资产——市场每涨一分，利润和 EV 同步放大。2025 年综合投资收益率 6.3%（近五年最高）、OCI 股票浮盈超 900 亿是这条通道的兑现；Q1 2026 上证仅跌 1.9% 即带来约 -500 亿公允价值变动、归母净利 -7.4%，是同一通道的反面演示。

**② 中国利率通道（双刃剑）**：美联储宽松 → 中美利差收窄、人民币升值压力缓解 → 中国降准降息空间打开 → 中国利率可能进一步走低。对平安的影响分两层：利空面——存量固收到期再投资收益下降（NII 3.7% 仍在降、警报线 3.5%）、准备金折现率下调增提准备金；利多面——①负债成本重定价（预定利率下调、分红险转型后利差风险由保户共担）；②存量债券公允价值与 OCI 浮盈上升；③低利率环境本身带来估值抬升（无风险利率修正系数 ×1.14—1.24，见第五章估值）。净效应是"利空收益率、利多估值与负债端"，不是单边利空。

**③ 汇率与外资通道**：美元走弱 → 人民币升值 → 人民币资产重估 + 北向外资回流。2026Q1 北向减持平安（沪股通 -861 万股），与"高权益仓位下利润波动放大"的担忧一致；若美联储宽松落地带来外资回流，该变量可能反转——但它是前两条通道兑现后的"结果"而非"原因"。

### 分通道对平安的含义

| 通道 | 关键数据 | 含义 |
|------|------|------|
| 权益端 | 仓位 19.2%、TPL 43.5%；2025 CII 6.3%；Q1 2026 公允价值变动约 -500 亿；H1 2026 券商预期归母净利 +23%~33% | 宽松落地 → 综合投资收益率抬升 + 净资产增厚，是利润弹性最大的来源；高仓位也意味着利润波动常态化 |
| 利率端 | 10Y 国债 1.7%—1.8%、NII 3.7%（警报线 3.5%）、EV 投资回报假设 4.0% | 降息空间打开 → 再投资收益承压（利空）vs 负债成本重定价 + 低利率估值修正（利多），净效应取决于利率下行斜率 |
| 负债端 | 定存利率不足 1.5% vs 储蓄险预定利率约 2.5%；银保 NBV +138%、寿险 NBV 连续三年双位数 | 利率越低，储蓄险比价优势越强 → 存款搬家延续 → NBV 前向增速（2026—2028 约 15%）获得宏观支撑，是本轮宽松下最可持续的正面逻辑 |
| 汇率外资 | 2026Q1 北向减持 -861 万股；跨境收支人民币占比 52.9%（人民币国际化） | 美元走弱 → 人民币资产重估 + 外资回流潜力，是估值修复的辅助变量 |

### 情景分析：宽松的两种触发路径

| 情景 | 权益市场 | 利率环境 | 对平安的预期 | 对应估值情景 |
|------|------|------|------|------|
| A：主动宽松 / 通胀化债 | 风险偏好持续回升，A/H 股走牛 | 中国利率低位企稳或温和下行，存款搬家延续 | 利润（权益弹性）与估值（低利率修正）双击，最顺的路径 | 基准 69.9 元 → 修正后 80—87 元，乃至乐观 94—102 元 |
| B：衰退触发（先挤兑后宽松） | 第一阶段流动性挤兑、股市先跌；第二阶段 V 型反转 | 中国利率更快下行，NII 压力更大但储蓄险更受益 | 先抑后扬：短期利润表难看（Q1 2026 已演示 -500 亿级杀伤），中期靠市场反转修复 | 短期贴近悲观 49.1 元，中期向基准回归 |
| C：宽松落空 / 美债风险扩散 | 30Y 破 6%、信用利差走阔，风险资产重定价 | 中国利率被动承压 | 权益端与利率端双杀，最差路径 | 悲观 49.1 元（下行地板，由净资产与股息托底） |

> **关键结论：平安不是黄金那种"直接吃美联储"的资产——它吃的是"权益市场 + 中国利率"两个中间变量。** 美联储宽松只有通过"让 A 股涨"或"让存款搬家延续"传导到平安，预期才会兑现；若宽松以衰退方式触发，第一阶段利润波动会先于估值修复到来。

### 对估值预期差的含义

现价 55.5 元对应集团 P/EV 0.65x、隐含寿险 P/EV 约 0.61x（市场按 NBV 增速 ~3% 定价），而基本面数据显示 2026—2028 前向复合增速约 15%（对应 0.83x P/EV、约 69.9 元，叠加低利率修正后 80—87 元）。**美联储降息扩表是修复这个预期差的宏观催化剂之一，但不是充分条件**——还需三个国内变量确认：①中报 NBV 增速守住 +10%~15%（8/20 晚已兑现：H1 +11.2%）；②10 年期国债收益率低位企稳（NII 守住 3.5%）；③权益市场真正走牛（宽松传导至 A/H 股）。

### 组合定位：与黄金的差异

平安与黄金在本轮宽松中互补不互斥：**平安赚"宽松 → 风险资产上涨"的钱（权益贝塔 + 存款搬家），黄金赚"宽松 → 货币信用受损"的钱（实际利率下行 + 央行购金）**。平安有股息（约 4.8%—5%）与净资产托底，是蓝筹组合里的"现金流底仓"；黄金无现金流，是"尾部保险"。若押注宽松落地且经济企稳，平安的赔率结构优于黄金；若押注通胀失控或信用危机，黄金反超——两者按各自定位配置，而非二选一。

## 五、估值

> 估值基准：2026-08-04 现价 55.5 元。中报后的重估（寿险 EV 上修至 9,708 亿、基准约 71 元、隐含寿险 P/EV 0.52x）见 [财报跟踪/2026中报.md](财报跟踪/2026中报.md)。

### 为什么用分部估值：平安不是一家可以"整体打折"的公司

平安是综合金融集团，五个板块的估值语言完全不同——寿险看 **P/EV**（内含价值倍数），银行看 **P/B/市值**，财险看 **P/B**（叠加承保利润率），科技看**市值**。用集团 EV 乘一个统一的 P/EV，会把银行、财险这些本不该被"寿险折价"拖累的板块也一并打折——**这正是平安估值长期被低估的机制性来源**。分部估值（SOTP）逐板块定价，再合并集团层面，才是综合金融集团正确的估值方法。

### 分部估值框架与数据基础

数据基础（2025 年末，公司年报）：

- **集团内含价值 15,043 亿元**（+5.7%），其中**寿险及健康险 EV 9,300 亿元**（+11.2%，2019 年后首次两位数增长）；非寿险部分 5,743 亿元（财险/银行/资管/科技，按 EV 即净资产口径计入）。
- **平安银行**：市值约 2,255 亿元（A 股 000001，现价 11.62 元 × 194.06 亿股），归母净资产约 4,512 亿元，P/B 约 0.50 倍；平安持股 58% → 对应市值 **1,308 亿元**（在集团 EV 中按净资产 2,617 亿元计入，市值口径较净资产折价 1,309 亿元）。
- **财险 + 资管 + 科技 + 集团调整**：集团 EV 中非寿险非银行部分约 **3,126 亿元**（按 EV/净资产口径，不另打折）。

### 寿险 P/EV 校准规则：NBV 前向增速 → 倍数

寿险板块的 P/EV 由 NBV 前向增速决定，用两个历史锚点校准成一条线性规则：

```
P/EV = 0.55 + 1.84 × NBV 前向增速
```

| 锚点 | NBV 增速 | P/EV |
| --- | ---: | ---: |
| 阵痛期（2021—2022） | ≈0% | 0.55x（取 0.5—0.6 中点） |
| 高增长期（2017） | +32.6% | 1.15x（取 1.0—1.3 中点） |

- **斜率 1.84** = (1.15 − 0.55) ÷ 0.326——增速每提高 1 个百分点，P/EV 约提高 0.018 倍；
- **截距 0.55**——增速为 0 时倍数不归零，因为 EV 仍靠"期望回报"每年自然增值、存量业务有价值；
- 代入平安前向增速 ~15%（2026—2028 复合）→ 0.55 + 1.84 × 0.15 ≈ **0.83x**（基准情景）；
- 反向可用：现价对应 P/EV 0.61x → 市场认为的 NBV 增速 ≈ (0.61 − 0.55) ÷ 1.84 ≈ **+3.3%**。

规则里代入的"前向增速"取多少？看下面的展望：

**NBV 增速展望（2025—2028）**

| 年份 | NBV 增速 | 驱动 |
| --- | ---: | --- |
| 2025A | +29.3% | 已实现（银保 +138%），仅作历史背景，不计入前向 |
| 2026E | +10%—15% | 银保高基数回落 + 分红险转型压缩 Margin（Q1 -4.8pct） |
| 2027E | +15%—20% | 转型消化、银保期交占比提升驱动 Margin 企稳、代理人队伍企稳 |
| 2028E | +12%—15% | 正常化中枢：存款搬家延续 + 医养渗透提升件均 |
| **2026—2028 前向复合** | **≈ +14.5%（约 15%）** | **定价基准：按规则 P/EV ≈ 0.83x** |

**为什么是这条曲线（逐年的"为什么"）：**

- **2026 回落（+10%—15%）——三股力量叠加**：
  - **银保高基数**——2025 年银保 NBV +138%（新单保费 +95.1%）是异常高的基数，2026 年银保即使绝对额继续增长，同比增速也必然大幅回落，而银保已占 NBV 超 1/3，它的减速直接拖累总量；
  - **分红险转型压缩 Margin**——低利率环境下，监管与公司共同推动产品转向分红险（预定利率下调、利差风险由保户共担），但分红险 Margin 天然低于传统险，Q1 首年保费 +45.5% 而 NBV 仅 +20.8%，差额就是 NBV Margin 压缩（Q1 23.5%，-4.8pct）——量增质平的代价；
  - **个险仍在缩**——代理人 33.2 万（-5.4%）、人均月收入 -10.5%，个险端增量有限，只靠人均产能（+17.2%）硬撑。

- **2027 回升（+15%—20%）——转型代价出清后回到新单同步轨道**：
  - **分红险占比趋稳** → Margin 不再继续大幅下行（最剧烈的压缩发生在 2026 年，一次性消化后基数效应消失）；
  - **银保从"冲量"转向"期交为主"**（2025 年新单期交 +163%）——期交产品 Margin 高于趸交，银保 Margin 从 24.5% 继续提升，对冲分红险的 Margin 压力；
  - **代理人队伍企稳**——连续缩减多年后（120 万→33 万）有望进入企稳区间，人均产能（+17.2%/年）的复利开始"净贡献"NBV 增量；
  - **存款搬家延续**——定存利率不足 1.5%、储蓄险预定利率约 2.5%，利差倒挂的比价效应持续把居民存款导入保单。

- **2028 正常化（+12%—15%）——高基数 + 结构性约束下的中枢回落**：
  - **高基数**——2025—2027 连续高增后基数已高，增速自然回落到两位数中段；
  - **预定利率下调压住 Margin 天花板**——传统险预定利率已到约 2.5%，这是长期结构性约束，使 NBV 增速中枢低于 2017—2018 时代；
  - **存款搬家边际放缓**——定存利率已很低，进一步下行的空间收窄；
  - **但仍有支撑**——银保期交质量提升、代理人产能复利、医养渗透率仍低（仅 7.3%），使增速中枢守在两位数中段而非更低。

**这条曲线的含义**：2025 的 +29.3% 是"转型红利"的一次性释放（银保 +138%、Margin 大幅提升），2026 的回落是"转型代价"（分红险 Margin 压缩 + 银保高基数），2027 的回升是"代价出清后的重新加速"。**前向复合（2026—2028）≈ (1.125×1.175×1.135)^(1/3) − 1 ≈ +14.5%（约 15%）——这才是估值要用的增速：0.83 倍 P/EV 对应的是这个前向中枢（介于阵痛期 0.5—0.6 倍与高增长期 1.0—1.3 倍之间），而非包含 2025 已实现的 20% 复合数。**

**这条规则是"NBV 增速 → EV 增速中枢 → 市场倍数"链条的压缩**：增速越高，NBV/EV 占比逐年上升、EV 增速中枢被推高，市场倍数越高；增速归零，EV 增速回落到"期望回报 − 分红"，倍数回到阵痛期。规则与展望合起来：**前向 ~15% → 0.83x（基准）；现价 0.61x 只对应 ~3% 的前向增速——这就是预期差的量化来源。**

### 无风险利率修正：把业务价值调整到当前低利率环境

分部估值用的是历史基本面的 P/EV/PB——**利差问题的压制已经通过低倍数体现在业务折价里**（0.85x 中枢 vs 高利率时代的 1.0—1.3x）。但低利率本身还有另一层独立的影响：无风险利率下行 → 折现率 `R = rf + 5.5%` 下行 → 同样的业务现金流现值更高。这一层是**估值抬升**，与"业务折价"分开，在分部估值的最后一步单独修正：

```
最终估值 = 分部业务价值（利差折价已含） × 无风险利率修正系数
修正系数 = (R_参照 − g∞) / (R_当前 − g∞)，R = rf + 5.5%，g∞ ≈ 2.33%
```

当前 10 年期国债约 1.8%（R = 7.3%，R − g∞ = 4.97%）。参照利率取历史 P/EV 中枢形成时的 10Y 区间：

| 参照 rf（历史 P/EV 中枢形成时） | R_参照 | R−g∞ | 修正系数 |
| --- | ---: | ---: | ---: |
| 2.5% | 8.0% | 5.67% | ×1.14 |
| 3.0% | 8.5% | 6.17% | ×1.24 |

**各情景最终估值（业务价值 × 系数）**

| 情景 | 业务价值（元/股） | × 修正系数 | 最终估值（元/股） | 相对现价 55.5 元 |
| --- | ---: | ---: | ---: | ---: |
| 当前 | 57.5 | ×1.14—1.24 | 66—71 | +19%—+28% |
| 基准 | 69.9 | ×1.14—1.24 | 80—87 | +44%—+56% |
| 乐观 | 82.6 | ×1.14—1.24 | 94—102 | +69%—+84% |

注：①**悲观情景不修正**——其 0.55x 谷底倍数本身就是低利率时代（2021—2022 年）的产物，再乘系数会重复计入利率，故维持 49.1 元作为下行地板；②修正系数取区间而非单一值——参照 rf 2.5%（×1.14）为保守、3.0%（×1.24）为中性，历史 P/EV 中枢跨越多个利率环境，2.5%—3.0% 是合理参照带；③修正主要作用于历史锚定的寿险 P/EV（分部价值大头），平安银行按市值计价（P/B 0.50）已反映当前利率，本框架对其不重复修正，整体偏保守。**修正后，"当前"情景 66—71 元、"基准"情景 80—87 元——市场 55.5 元的定价，既压了利差折价、又完全没有给低利率的估值抬升。**

### 现价意味着什么：市场隐含寿险 P/EV 约 0.61 倍

反推现价隐含的分部参数（银行按市值、其余按 EV 口径）：市值约 10,107 亿元 = 寿险 X + 银行 1,308 + 财险/资管/科技 3,126 → 寿险估值约 5,673 亿元 → **隐含寿险 P/EV ≈ 0.61 倍**。

**这个读数说明市场在用"寿险 NBV 只增长个位数 + 银行继续破净 + 财险/资管/科技不给任何价值"的三重悲观组合定价**——与手边所有数据（NBV +29.3%、OPAT +10.3%、2H25 加速至 +22.5%、寿险 EV +11.2%）的方向正好相反。NBV 已连续三年双位数增长（银保 +138%），0.61 倍 P/EV 对应的是改革阵痛期（2021—2022 年 NBV 下滑）的定价水平——**倍数与增速的错配，是平安估值最核心的预期差：市场还在按"NBV 个位数时代"给寿险定价，而 NBV 前向增速（2026—2028）约 15%、按规则对应 0.83 倍 P/EV。**

还需要强调的是：**上面的隐含 P/EV 是"业务价值"口径——它反映的是利差折价后的倍数。如果叠加无风险利率修正（当前情景 ×1.14—1.24），市场 55.5 元对应的低估程度比"隐含寿险 P/EV 0.61 倍"所显示的还要大**：修正后当前情景的公平价值在 66—71 元，市场在利差折价之上又额外折让了约 20%—25% 的利率抬升空间。

### 是不是价值投资

- **是典型的深度价值 + 高股息 + 分部折价三重叠加**：P/B 1.01 倍、股息率约 5%（连续 14 年增长）、且分部估值（SOTP）高于整体市值——三个维度都指向"便宜"。
- **但便宜不等于立即涨**：市场给分部折价的机制性原因有三个——这三个折价不被修复，分部价值就难以系统性兑现：
  - **利率下行**终将击穿净投资收益率（NII 3.7%，若跌破 3.5% 利差损从"远虑"变"近忧"），压制寿险 P/EV 的天花板；
  - **高权益仓位**（19.2%、TPL 占 43.5%）让利润随股市大起大落（Q1 已演示），压制整体风险偏好；
  - **平安银行 P/B 0.50 倍、科技子公司集体破净**，集团账面价值不被市场认可。
- **预期差在哪**：市场用"整体打折"（集团 EV × 0.65）给平安定价，而分部估值显示——即使三分部全部停留在"当前"（寿险 0.65、银行 0.50 破净、财险/资管/科技按账面），业务价值也有 57.5 元（+4%）；一旦三分部同步修复（寿险 0.83 倍、银行 P/B 0.60、财险/资管/科技 1.10x），业务价值 69.9 元（+26%）。**而低利率环境的估值抬升（无风险利率修正 ×1.14—1.24）尚未计入——修正后当前情景 66—71 元、基准情景 80—87 元、乐观情景 94—102 元。市场 55.5 元既压了利差折价、又没给利率抬升。** 三个正在发生的正面变量支撑这个修复：
  - **NBV 连续三年两位数增长**（存款搬家驱动银保 +138%）；
  - **OPAT 重回双位数**（+10.3%）；
  - **分红连续 14 年增长、股息率近 5%** 构成收益底。
- **安全边际**：P/B 1.01 倍 + 股息率约 5% 是硬底；三分部同步悲观下业务价值仍有 49.1 元（不修正，避免与低利率谷底倍数重复），距离现价约 -11%——**意味着市场已经按接近最悲观的分部组合定价，下行空间被净资产和股息托住，上行则来自业务价值向基准（69.9 元）回归、再叠加利率修正（80—87 元），乃至乐观情景（94—102 元）。**

### 验证窗口

> 本节是估值框架的验证清单；各报告期的逐项验证实绩见 [`财报跟踪/`](财报跟踪/) 目录对应文件（2026 中报的完整验证与重估见 [财报跟踪/2026中报.md](财报跟踪/2026中报.md)）。

- **EV 精算假设**：中报已披露寿险及健康险 EV 9,708 亿（+4.5%）、集团 EV 较年初 +4.2%，EV 增长未现假设大幅下修的冲击；投资回报假设（4.0%）是否调整待中报全文确认——假设不下调，寿险 EV 的真实性守住，P/EV 修复才有基础；假设下调，EV 承压但利差损风险出清，需重新评估分部价值。
- **平安银行估值**：P/B 0.50 倍能否修复——银行在分部估值中按 P/B 情景计（当前 0.50、基准 0.60），若净息差企稳（2026 H1 已回升至 1.80%）、不良率保持 1.05%，银行 P/B 回升将直接增厚分部价值（每 +0.1x 对应约 262 亿、每股 +1.4 元）。
- **存款搬家信号**：银行定存利率、监管预定利率调整、银保新单增速——这是 NBV 高增能否延续的方向盘，也是寿险 P/EV 的主驱动。
- **10 年期国债收益率**：当前约 1.7%—1.8%，若低位企稳，利差损担忧缓释，寿险 P/EV 的修复条件成立——同时这也是无风险利率修正系数（参照 rf 2.5%—3.0%）成立的宏观前提：利率长期低位稳定则修正空间（×1.14—1.24）得以保留；若利率继续下行，利差风险加剧（修正前提动摇）；若利率明显回升，修正系数本身会收窄。
- **代理人数量**：32.5 万（H1，-7.4%）继续探底，但人均月收入 10,418 元（+5.3%）由降转升、活动率 55.5%（+5.6pct）——量缩质升，队伍何时企稳仍是寿险 NBV 持续性的观察点。

关键解读：

- **估值预期差是全场最核心的催化剂**：2025 年 NBV +29.3% 已实现，但估值要用的前向增速（2026—2028）约 15%，按 `P/EV = 0.55 + 1.84×增速` 规则对应 0.83x——而 P/EV 还停留在 0.65x，反推现价隐含寿险 P/EV 仅约 0.61x（对应 NBV 增速仅 ~3%）。**倍数与增速的错配是平安估值最核心的预期差：市场还在按"NBV 个位数时代"给寿险定价，而前向增速约 15% 对应 0.83x。**
- **利率是催化剂里唯一的双刃剑**：增配权益（19.2%）让综合投资收益率回到 6.3%（五年最高），但 Q1 已演示高仓位下利润随市波动——利率下行的利差压力靠权益对冲，但权益本身带来利润波动。净投资收益率 3.7% 是否守住 3.5%，是利差问题唯一要盯死的警报线。

中国平安是中国罕见的"无实际控制人"大型金融集团，股权结构高度分散，形成了市场化、专业化的公司治理模式。创始人马明哲自 1988 年起执掌公司，联席 CEO 制度运行平稳。分散股权结构的好处是决策不受单一股东意志左右，坏处是管理层与股东利益可能不完全一致——长期服务计划（员工持股 2.74%）和分红政策（连续 14 年增长）是绑定管理层与股东利益的核心机制。2025 年 CEO 郭晓涛税后薪酬 771.01 万元居管理层之首。

与多数 A 股公司"创始人或国资控股"的治理不同，平安是"管理层主导 + 股东监督"的典型——这种治理形态对公司治理成熟度要求极高，但也让平安能持续十年推进寿险改革、医养布局这类长期投入。分红连续 14 年增长、股息率近 5%，是管理层向股东兑现价值的最直接证据。

> **治理评价**："无实控人 + 职业经理人"治理的典型样本——股权分散带来决策独立性，长期服务计划和持续分红绑定管理层与股东利益。马明哲执掌 37 年的战略连续性（寿险改革、综合金融、医养生态）是平安最深的治理资产，但"创始人逐步退居二线后的继任安排"与"分散股权下的管理层代理成本"是长期观察点。

## 八、流通股东变化

> 筹码面是**验证信号**，不是选股依据——只看四类信号与基本面是否共振；单独出现要打问号。具体股东户数、前十大流通股东、大股东增减持的逐期表格与最新实绩见 [`财报跟踪/`](财报跟踪/) 目录对应报告期文件（如 [2026 一季报](财报跟踪/2026一季报.md)与 [2026 中报](财报跟踪/2026中报.md)"六、流通股东变化"）。

### 方法：看哪四类信号

| 信号 | 看什么 | 含义 |
| --- | --- | --- |
| **北向外资** | 「香港中央结算有限公司」（沪股通）持股比例与变动 | 反映境外资金对"高权益仓位 + 利率下行"的态度；持续流出为谨慎信号 |
| **国家队 / 社保** | 中央汇金、证金系资管计划（工银瑞信 / 嘉实中证金融）、社保持仓 | 汇金是筹码最稳定的压舱石；证金系（2015 救市资金）退坡关注节奏 |
| **公募 / 险资** | 基金、保险产品（同业险资如中国人寿）持股市值与比例 | 同业险资与公募（长线 / 配置盘）是否加仓，与内部人交叉验证 |
| **内部人** | 员工长期服务计划（员工持股）增减持 | 与公司长期激励绑定的资金，内部人对基本面的最直接投票 |

> 注：香港中央结算（代理人）为 H 股全体股东的统一登记通道，不代表单一资金行为；真正反映北向资金的是「香港中央结算有限公司」（沪股通）。商发控股为卜蜂集团（正大集团）旗下 H 股实体。

### 关注点：至少连续三季的对比规则

- **股东户数**：每期与上两期比较，看趋势是"持续集中 / 持续分散 / 反复"——户数大降（集中）多为机构吸筹，户数大增（分散）多为散户追高。
- **重要机构持仓**：四类信号各自连续三季的方向（增持 / 减持 / 稳定），不取单期孤证。
- **大股东与重要股东增减持**：三季累计方向（连续增持 / 连续减持 / 先减后增 / 反复）。

### 筹码面与基本面共振判断

- **谁在验证逻辑（加仓）**：内部人（员工持股）、同业险资 / 公募等长线配置盘在低位增配，与基本面向上共振为加分项。
- **谁在撤退（减仓）**：北向外资、证金系退坡、散户涌入（户数大增）——提示"上涨后的拥挤度"在上升、短期抛压与追高情绪并存。
- **判断要求**：筹码面必须与"零、核心逻辑"的基本面相互印证；单独出现（如国家队增持但基本面恶化）要打问号。内部人增持 + 汇金稳定为"跌不深"的底部信号，外资退坡 + 散户涌入提示拥挤度——核心还是看基本面变量（NBV 前向增速）能否让筹码与基本面重新共振。

> 小结示例（每期数据见各 [`财报跟踪/`](财报跟踪/) 文件）：从 2025 全年"机构集中、四季度 -19.9% 大幅集中"到 2026 年"散户分散、Q1 +22.8%、H1 +14.7% 继续分散"，筹码从机构流向散户；内部人（员工持股）持续增持、汇金纹丝不动，但北向持续大幅减持、证金系退坡——整体呈"内部人增持 + 外资 / 证金系退坡 + 散户涌入"，为验证信号而偏谨慎。

## 九、备注：名词解释

| 名词 | 解释 |
| ---- | ---- |
| **P/EV（内含价值倍数）** | 股价 ÷ 每股内含价值。内含价值（EV）= 调整后净资产 + 有效业务价值，把"已售业务的现值"和"新单价值"都装进去，是寿险股估值的基础语言。分部估值（SOTP）中给寿险板块用 P/EV（平安寿险当前隐含约 0.61 倍，历史区间 0.5—1.3 倍），银行/财险则用 P/B 或市值。 |
| **NBV（新业务价值）** | 当年新签保单未来利润的折现值，是保险股估值的增长发动机。平安 2025 年 NBV 368.97 亿（+29.3%），连续三年双位数增长。NBV 增速决定市场愿意给多少 P/EV。 |
| **EV（内含价值）** | 保险公司现有业务未来产生的股东价值现值 + 调整后净资产。2025 年末平安集团 EV 1.50 万亿，寿险 EV +11.2%（2019 年后首次两位数增长）。 |
| **CSM（合同服务边际）** | 保险合同准则下的"未来利润蓄水池"——新单首日确认的未实现利润，未来按服务期逐步摊销进入利润表。平安 CSM 余额 7,251 亿，余额稳定说明存量业务盈利能力未恶化。 |
| **OPAT（营运利润）** | 剔除短期投资波动、一次性项目后的"核心利润"，是保险公司衡量经营质量和管理层分红的锚。平安 2025 年 OPAT 1,344.15 亿（+10.3%），分红率 36.4% 按 OPAT 计算。 |
| **COR（综合成本率）** | 财险的"承保成本 ÷ 保费"，<100% 表示承保盈利。平安 2025 年 COR 96.8%（-1.5pct），车险 COR 95.8% 行业最优。COR 每降 1pct 对应数十亿承保利润。 |
| **利差损** | 投资收益低于负债成本（预定利率/保证收益）导致的亏损。是保险行业在利率下行期最大的系统性风险。平安 NII 3.7% vs EV 假设 4.0%，3.5% 是警报线。 |
| **净投资收益率（NII）** | 利息、股息等"确定性收入"÷ 投资资产。平安 2025 年 3.7%（-0.1pct），反映存量固收资产再投资收益持续走低，是利差损风险的直接指标。 |
| **综合投资收益率** | 净投资收益 + 公允价值变动 + 资产减值后的"全口径"收益率，最能反映保险资金实际回报。平安 2025 年 6.3%（近五年最高），近 10 年平均 4.9% 高于 4.0% 假设。 |
| **TPL / FVTOCI 股票** | 新会计准则下股票的两种计量：TPL（以公允价值计量且其变动计入当期损益，波动直接进利润）和 FVTOCI（计入其他综合收益，波动进净资产）。平安股票中 TPL 占 43.5%，意味着近半股票波动直接影响当期损益。 |
| **RDR（风险贴现率）** | 计算 EV 时对未来现金流的折现率（约 11%），是粘性精算假设，不随国债利率变动。 |
| **分部估值（SOTP）** | 对多元化集团逐板块定价再加总：寿险用 P/EV、银行用市值或 P/B、财险用 P/B、科技用市值，再合并集团层面。平安 SOTP：寿险 EV 9,300 亿 × P/EV + 平安银行市值 × 58% + 财险/资管/科技（EV 口径）。基准情景分部价值约 57.5 元。 |
| **集团折价（整体折价）** | 市场对多元化集团"整体打一个统一的估值倍数"，导致各板块被按最悲观的板块倍数定价——平安被按寿险 P/EV 打折，银行、财险本不该受此拖累，却一并被压。SOTP 的核心价值正是消除这种整体折价、暴露分部的真实价值。 |
| **无风险利率修正** | 分部估值最后一步的独立修正：`最终估值 = 业务价值 × 无风险利率修正系数`，`系数 = (R_参照 − g∞)/(R_当前 − g∞)`、`R = rf + 5.5%`。含义是"利差压制已体现在业务折价（P/EV 低倍数）里，低利率的估值抬升（折现率下行）应单独加回"。平安取参照 rf 2.5%—3.0% → 系数 ×1.14—1.24；悲观情景不修正（谷底倍数本身已含低利率）。 |
| **存款搬家** | 定存利率跌破储蓄险预定利率后，居民存款转向购买储蓄型保单的现象。是平安银保 NBV +138% 的核心驱动，也是利率下行的"流量表现"。 |
| **偿付能力充足率** | 保险公司可资本 ÷ 最低资本要求，衡量赔付能力。平安集团综合偿付能力 193.3%（监管底线 100%），高权益仓位会占用更多资本、压低充足率。 |
