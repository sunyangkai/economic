# 美的集团

> 报告更新：2026-08-14（A 股现价约 84 元）。数据来源：东方财富 F10 财务接口（api/）、机构盈利预测接口（api/orgForecast.js）、前十大流通股东接口；估值计算用 tools/valuation.js（统一三段式模型）。本报告为 2026 年中报（8/29 披露）前瞻版本，中报披露后按"十、业绩跟踪"追加。

## 零、核心逻辑

**一句话核心逻辑：利润靠 ToB（商业及工业解决方案）与海外双轮释放（不靠 ToC 家电走量），增长靠楼宇/机器人/工业技术的第二曲线与全球化渗透，护城河是"全产业链自供 + 渠道纵深 + 职业经理人治理"的平台，催化剂是 ToB 兑现速度与海外 OBM 占比提升能否对冲 2026 年的增长降速。**

美的集团 2025 年营收 4,585.02 亿（+12.08%）、归母净利 439.45 亿（+14.03%）、扣非 412.67 亿（+15.46%）、ROE 19.70%——连续多年"增利与增收同步、双位数增长"的白马成绩单。但这份成绩单背后藏着一个 2026 年的关键转折：**Q1 营收增速从去年同期的 +20.61% 骤降到 +2.45%，归母增速从 +38.02% 骤降到 +2.03%。** 市场担心的不是美的"不赚钱"，而是"增长引擎是不是熄火了"——这正是当前 13.6 倍（2026E PE）、股息率约 5% 的估值所定价的东西。

拆开看，美的的增长其实在发生一场**结构性的"接力"**：以旧换新退坡后，ToC 智能家居（占 65%）增速回落到个位数，但 ToB 商业及工业解决方案（占 26.8%）仍保持 +17.5% 的高增，海外（占 42.7%）仍保持 +15.9%。**美的不再是一家"靠卖空调冰箱"的家电公司，而是一家"用家电现金牛养 ToB 第二曲线、用全球化对冲国内地产周期"的科技集团**——这个身份切换的成败，决定了它是"低增长白马"还是"重新提速的成长股"。

### 从业务场景看增长预期

**方向一：ToC 智能家居——基本盘的"以旧换新 + 高端化"**

- **逻辑**：智能家居（2,999 亿、占 65%）是美的的现金牛和估值地基。它不负责高增长，负责"稳住基本盘 + 贡献现金流"——增长靠以旧换新政策托底和 COLMO/东芝等高端品牌的结构升级，而非量增。
- **驱动力**：①以旧换新补贴（2025 年政策驱动 ToC +11.28%）；②高端化（COLMO 双洗、东芝高端，客单价提升）；③电商下沉（电商占智能家居内销 55%+）。
- **数据证据**：2025 年智能家居 2,999.27 亿（+11.28%）；但 2026 Q1 集团营收整体只 +2.45%，说明以旧换新的脉冲在退坡。
- **现实约束**：以旧换新政策退坡后 ToC 增速回落；地产链（空调/家电后周期）长期承压；行业价格战（格力、海尔、小米夹击）。

**方向二：ToB 商业及工业解决方案——第二增长曲线**

- **逻辑**：ToB 是美的从"家电"到"科技集团"的身份切换——楼宇科技、机器人与自动化（库卡）、工业技术（电机/芯片/部件）、新能源四大板块，把美的在"制造 + 供应链 + 电机压缩机"上的能力复制到 B 端工业场景。
- **驱动力**：①楼宇科技（中央空调 + 电梯 + 楼宇自控）受益建筑节能改造与暖通升级，2025 年 +25.72%；②库卡机器人国产替代（国内出货 3.2 万台、+30%+，300kg 以上负载份额 47.4%）；③工业技术（美芝压缩机、威灵电机全球份额第一）向芯片、新能源部件延伸；④其他创新业务（储能、医疗、物流）2025 年 +26.94%。
- **数据证据**：2025 年 ToB 合计 1,227.53 亿（+17.47%），其中楼宇 357.91 亿（+25.72%）、机器人 310.11 亿（+8.05%）、工业技术 272.32 亿（+10.24%）、其他创新 287.19 亿（+26.94%）。
- **现实约束**：ToB 整体毛利率低于 ToC（楼宇/机器人重资产、项目制），占比提升会稀释综合毛利率；机器人与自动化增速仅 +8%（库卡受欧洲工业投资疲软拖累）；商誉 342.57 亿（含库卡并购）有减值风险。

**方向三：海外全球化——OBM 与本地化的确定性增量**

- **逻辑**：海外（1,959.48 亿、占 42.7%）是美的增长确定性最高的方向——国内地产周期见顶，海外靠 OBM（自有品牌）替代 OEM、本地化制造与并购（Arbonia、东芝电梯中国、锐珂医疗）打开第二市场。
- **驱动力**：①海外 OBM 占智能家居海外收入超 45%，收购 TEKA 带动欧洲双位数高增；②本地化自营覆盖 50 个国家（从 27 个增至 50 个）、29 个海外研发中心、43 个制造基地；③新兴市场（东南亚/中东/拉美）渗透。
- **数据证据**：2025 年海外 1,959.48 亿（+15.92%），显著高于国内 +9.4%。
- **现实约束**：贸易摩擦与关税（美国对华关税）、汇率波动、海外地缘风险；OBM 转型仍在进行，品牌溢价不及本土巨头。

**方向四：股东回报——高分红 + 回购的现金牛属性**

- **逻辑**：美的是 A 股少有的"真金白银回报股东"的现金牛——全年拟现金分红超 320 亿、股息率约 5%，经营现金流 533 亿远超净利。
- **驱动力**：①经营现金流 533.46 亿（净现比 1.21x）；②账上货币资金 852.47 亿；③持续回购注销。
- **数据证据**：2025 年分红支付 330.80 亿；A 股每 10 股派 38 元；股息率约 5%。
- **现实约束**：分红率已较高，进一步大幅提升空间有限；未来三年投 600 亿科研，资本开支可能上升。

关键解读：

- **中报是全场最关键的分水岭**：2026 Q1 增速骤降（营收 +2.45%、归母 +2.03%）是高基数 + 以旧换新退坡的结果，市场要判断的是"这是增速中枢永久性下移，还是一次性回落"。若中报（8/29）营收增速企稳、ToB 与海外继续高增，13.6 倍的估值会被重新定价；若中报继续降速，市场会坐实"增长熄火"的判断。
- **藏在 ToB 里的"免费期权"**：楼宇科技（+25.72%）和新能源储能是低概率高赔率的期权——建筑节能改造 + 数据中心温控 + 储能是未来五年的结构性赛道，美的靠"电机 + 压缩机 + 供应链"的底层能力切入，若兑现将成为第二条增长曲线，市场当前几乎未定价。

### 护城河

美的面对的竞争格局是"上下夹击"——上方是海尔（高端品牌 + 全球布局）、格力（空调单品冠军）这样的老对手，下方是小米（性价比 + 生态）、华凌（互联网品牌）等新势力。但美的的护城河不在一款产品，而在"全产业链 + 渠道 + 治理"的叠加：

| 壁垒方向 | 防的是谁 | 一句话本质 |
| --- | --- | --- |
| **方向一·全产业链自供** | 格力/中小家电厂 | 压缩机、电机、芯片自供，成本与供应链自主 |
| **方向二·渠道纵深** | 小米/华凌 | 电商 55%+ + 下沉 + 海外 50 国，全渠道覆盖 |
| **方向三·治理与机制** | 国企背景对手 | 方洪波职业经理人 + 分权授权 + 现金流管理 |
| **方向四·规模与成本** | 所有竞争者 | 全球家电最大规模，采购议价 + 研发分摊 |

**方向一：全产业链自供（对抗格力与中小厂的供应链壁垒）**

- 论证：美的通过美芝压缩机（全球份额第一）、威灵电机（全球第一）实现核心部件自供，并延伸至芯片（MCU）、新能源部件。这意味着当行业价格战打响时，美的的成本底线比对手更低；当供应链波动时，美的的交付确定性更强。**这不是能力问题，是二十年在供应链上游的垂直整合问题**——对手可以仿一台空调，但建不起同等的压缩机/电机产能。

**方向二：渠道纵深（对抗小米与互联网品牌的渠道壁垒）**

- 论证：美的是唯一同时吃透"线上 + 线下 + 下沉 + 海外"全渠道的家电龙头——电商占智能家居内销 55%+（不比小米弱）、下沉渠道覆盖乡镇、海外本地化自营 50 国。小米靠线上生态、华凌靠性价比，但都缺线下安装售后网络和海外本地化能力。**家电不是快消品，安装、售后、渠道下沉的沉没成本，后来者补不起。**

**方向三：治理与机制（对抗国企背景对手的组织壁垒）**

- 论证：美的的治理是 A 股的经典样本——何享健"交棒"方洪波，职业经理人主导经营，实行事业部制分权授权 + 严格的现金流/利润考核。这套机制让美的在 2012 年战略转型（砍掉低毛利业务）、2020 年重启增长、2024 年 ToB 扩张上都能快速转身。**国企背景的对手（如部分家电国企）受制于决策链条和考核机制，美的的机制优势是制度性的。**

**方向四：规模与成本（对抗所有竞争者的平台壁垒）**

- 论证：营收 4,585 亿、全球家电最大规模，规模带来三重协同：采购议价（压缩机/钢材/芯片）、研发分摊（未来三年投 600 亿科研，摊到 4,500 亿营收上仍可控）、制造效率（灯塔工厂 + 数字化）。单品类冠军可以打赢一个细分市场，但打不赢"全品类 + 全渠道 + 全产业链 + 全球化"的平台。

**行业横向对比**

| 维度 | 美的集团 | 海尔智家 | 格力电器 |
| --- | --- | --- | --- |
| 体量（2025 营收） | 4,585 亿 | ~2,700 亿 | ~1,900 亿 |
| 商业模式 | 全品类 + ToB + 全球化 | 高端品牌 + 全球并购 | 空调单品冠军 |
| 海外占比 | 42.7% | 较高（海外并购多） | 较低 |
| ToB 布局 | 楼宇/机器人/工业技术 | 弱 | 弱（机器人不成气候） |
| 利润率 | 净利率 9.75%、ROE 19.7% | 净利率较高 | 净利率高但单一 |
| 治理 | 职业经理人（方洪波） | 海尔系（张瑞敏后） | 董明珠主导 |
| 估值 | 13.6x（2026E）、股息率 5% | 中高 | 极低（增长停滞） |

> 一句话：**ToC 是现金牛（保稳），ToB 是第二曲线（接棒增长），海外是对冲（确定性增量），治理是底层机制（职业经理人）。美的的投资逻辑不是"高成长"，而是"低估值 + 高分红 + 第二曲线的成长期权"——市场按 13.6 倍定价，等于只买了"现金牛"这部分，ToB 和海外几乎白送。**

## 一、业务说明

美的集团是全球规模最大的家电企业，业务从家电逐步扩展至 ToB 工业领域。公司定位为"全球化科技集团"，业务涵盖智能家居（ToC）与商业及工业解决方案（ToB）两大板块，其中 ToB 又细分为楼宇科技、机器人与自动化、工业技术、其他创新业务（新能源/医疗/物流）。2025 年总营收 4,585.02 亿元（+12.08%），海外收入占 42.7%，业务覆盖全球 200+ 国家和地区。

### 业务构成

**智能家居（ToC，2,999.27 亿，+11.28%，占 65.41%）**：以空调、冰箱、洗衣机、厨电、小家电为核心，覆盖高端（COLMO、东芝）与大众（美的、小天鹅、华凌）多品牌矩阵。增长主要受益于以旧换新政策与高端化升级，电商占内销 55%+。

**商业及工业解决方案（ToB，1,227.53 亿，+17.47%，占 26.8%）**：
- **楼宇科技**（357.91 亿，+25.72%）：中央空调、电梯、楼宇自控，通过并购 Arbonia 完善暖通与节能解决方案，中央空调国内销售额占比超 20%。
- **机器人与自动化**（310.11 亿，+8.05%）：以库卡（KUKA）为核心，国内工业机器人出货 3.2 万台（+30%+），市场份额 9.6% 行业前三，300kg 以上负载国内份额 47.4%。
- **工业技术**（272.32 亿，+10.24%）：美芝压缩机、威灵电机（全球份额第一）、芯片及核心部件。
- **其他创新业务**（287.19 亿，+26.94%）：新能源（储能）、医疗、物流等，是 ToB 中增速最快的板块。

**海外业务（1,959.48 亿，+15.92%，占 42.7%）**：海外收入增速显著高于国内，本地化自营覆盖 50 个国家，海外 OBM 占智能家居海外收入超 45%。

### 业务特点

- **智能家居（ToC）**：贡献约 65% 营收，是现金牛。以旧换新政策驱动 2025 年 +11.28%，但政策退坡后 2026 Q1 集团整体增速骤降至 +2.45%，ToC 增速回落是主因。高端化（COLMO、东芝）是毛利率的支撑。
- **商业及工业解决方案（ToB）**：占 26.8%、+17.47%，是增长核心引擎。楼宇科技（+25.72%）和新能源（+26.94%）增速最快，但机器人（+8.05%）受库卡欧洲拖累。ToB 毛利率低于 ToC，占比提升会稀释综合毛利率。
- **海外**：占 42.7%、+15.92%，增长确定性最高。OBM 转型 + 本地化制造 + 并购（Arbonia、东芝电梯中国、锐珂医疗），对冲国内地产周期。
- **现金流与股东回报**：经营现金流 533.46 亿（净现比 1.21x），全年拟现金分红超 320 亿，股息率约 5%，是 A 股少有的"现金牛 + 高分红"白马。

## 四、风险分析

**1. 增长失速风险（最核心）**：2026 Q1 营收增速从 +20.61% 骤降至 +2.45%、归母从 +38.02% 骤降至 +2.03%。若以旧换新政策退坡 + 高基数效应持续，全年增速可能降至中个位数甚至更低，美的将从"双位数成长"降级为"低增长现金牛"，估值中枢下移。

**2. 地产链与需求周期风险**：家电是地产后周期，空调/厨电与房地产竣工、销售强相关。国内地产长期下行压制 ToC 需求天花板，仅靠以旧换新和高端化对冲，长期增长空间受限。

**3. 价格战与竞争加剧风险**：格力（空调）、海尔（高端）、小米（性价比生态）、华凌（互联网品牌）在存量市场贴身肉搏。若价格战升级，美的的毛利率（26.39%）可能承压，ToB 低毛利占比提升也会稀释综合毛利率。

**4. 商誉减值风险**：商誉 342.57 亿（+15.81%），主要来自库卡等 ToB 并购。若机器人与自动化、楼宇科技等 ToB 业务不及预期，商誉减值将一次性冲击利润。库卡 2025 年增速仅 +8%，受欧洲工业投资疲软拖累，是重点观察对象。

**5. 海外贸易摩擦与汇率风险**：海外占 42.7%，美国对华关税、欧洲贸易政策、新兴市场地缘风险都可能影响海外增长。汇率波动（人民币升值）会侵蚀海外收入的汇兑收益。

**6. 治理与接班风险**：美的控股（何享健家族）持股 28.53% 为实控人，方洪波作为职业经理人已执掌多年。虽然"交棒"是 A 股经典成功案例，但方洪波之后的继任安排、以及实控人家族与职业经理人之间的长期利益一致性，是治理层面的长期观察点。

## 七、估值结论

### 估值看什么：统一模型把旋钮收死

本项目估值体系（`../../估值理论/估值模型.md`）中，折现率 `R = rf + 5.5%`（当前 rf 1.8% → R 7.3%）、终局增速 `g∞ ≈ 2.33%` 均为统一规则化参数，不因个股调整。因此美的的估值只由两个变量决定：

1. **未来三年利润增速 [g1, g2, g3]** —— 增长失速还是接棒、ToB 兑现速度、海外渗透，全部定性判断都要翻译成利润路径才进入估值。
2. **兑现系数 θ = 0.15θ₀ + 0.85θₓ** —— 只反映利润兑现质量（现金转化），经营风险一律计入利润预测，不在 θ 上打折。

### 美的的 θ 该怎么取

`DP₀ = NP_adj + DA − MC − ΔWC`。美的的现金转化画像——**轻资产、高现金转化、强现金流管理**：

- **净现比优异**：2025 年经营现金流 533.46 亿，是归母净利 439.45 亿的 1.21 倍、扣非 412.67 亿的 1.29 倍——利润几乎全额转化为现金。
- **低维持性资本开支**：购建固定资产 111.42 亿，相对 412 亿扣非占比约 27%；自由现金流约 422 亿，与净利基本相当。
- **账上现金充裕**：货币资金 852.47 亿，财务费用为净收益 -59 亿。

据此：
- **θ₀（当前）**：净现比 1.21x、自由现金流约等于净利，取 **0.90**。
- **θₓ（成熟期）**：美的属"一般制造业"偏轻资产端（核心部件自供但不重资产），参考一般制造业 0.70~0.85 区间，美的现金流质量优秀、分红慷慨，取偏上限 **0.85**。

### 贵不贵取决于利润路径（θ 固定 0.86）

| 三年增速 | 2026E 归母 | 内在 PE | 对应股价（2026E EPS 6.18） | 相对现价 84 元 |
| --- | ---: | ---: | ---: | ---: |
| [3%, 3%, 3%]（悲观：增长永久性熄火） | 452.6 亿 | 16.19x | ~100 元 | +19% |
| [5%, 5%, 5%]（保守：低增长现金牛） | 461.4 亿 | 18.68x | ~115 元 | +37% |
| [7%, 8%, 8%]（一致预期） | 470.2 亿 | 21.90x | ~135 元 | +61% |
| [9%, 9%, 8%]（基准：ToB+海外接棒） | 479.0 亿 | 22.51x | ~139 元 | +66% |
| [12%, 11%, 10%]（乐观：第二曲线兑现） | 492.2 亿 | 24.74x | ~153 元 | +82% |

注：对应股价 = 内在 PE × 2026E EPS 6.18 元。悲观/保守情景 θ 分别为 0.765/0.8，一致/基准/乐观 θ 为 0.86/0.86/0.865。

**现价 84 元（2026E PE 13.6x）连最悲观的"增长永久性熄火"情景（16.19x、100 元）都达不到**——这意味着市场对美的的定价，比"3% 永续增速 + 保守 θ"还要悲观约 16%。反推现价隐含的 θ：按一致预期增速 [7%,8%,8%] 的无折价 PE 约 25.5x，现价 13.6x 隐含 θ ≈ 0.53——市场认为美的约一半的利润永远无法兑现为股东价值。**对一个净现比 1.21x、股息率 5%、账上现金 852 亿、ROE 19.7% 的现金牛，这是"按破产折价"式的定价。**

### 是不是价值投资

- **是典型的"低估值 + 高分红 + 第二曲线期权"型深度价值**：2026E PE 13.6x、TTM PE 14.6x、股息率约 5%、PB 约 2.8x（归母净资产 2,232 亿对应市值 6,486 亿）——静态估值在白马股里属于"不贵"，且现金流和分红构成硬底。
- **但"便宜"有它的理由，也有它的误判**：
  - **便宜的理由**（市场对的部分）：2026 Q1 增速骤降（+2.45%），ToC 增长引擎熄火，国内地产周期见顶，家电是"低增长成熟行业"，给 13.6x 是行业常态。
  - **便宜的误判**（市场错的部分）：ToB（+17.5%）、海外（+15.9%）的结构性增长被"整体低增长"的标签掩盖；美的是全球家电最大规模 + 全产业链 + 职业经理人治理，理应享受"现金牛 + 第二曲线期权"的双重定价，而非单一的"低增长现金牛"折价。
- **核心张力**：市场当前定价（隐含 θ≈0.53，或"增长永久熄火"）与基本面（ROE 19.7%、净现比 1.21x、股息率 5%、ToB+海外高增）之间存在明显裂缝。要么市场对——ToB 和海外的高增不可持续、增长永久性降级、利润被价格战和商誉侵蚀；要么市场错——中报（8/29）验证增长企稳后，估值向一致预期的 21.9x（135 元）甚至基准 22.5x（139 元）回归。
- **安全边际**：悲观情景（16.19x、100 元）对应 +19% 的上行空间，股息率 5% 构成"跌不深"的底部——**现价已隐含"增长永久熄火 + 利润大幅打折"的双重悲观，再悲观的定价空间有限；只要中报证明"增长降速而非熄火"，估值就有修复空间。**

### 验证窗口

- **中报（8/29，最关键）**：Q2 营收增速能否从 +2.45% 企稳、ToB/海外是否续增、毛利率能否守住 26%、中期分红——直接验证"增长降速还是熄火"。
- **ToB 兑现**：楼宇科技、新能源、库卡机器人的季度/半年度增速，验证第二曲线能否接棒。
- **海外 OBM**：海外收入增速与 OBM 占比，验证全球化确定性。
- **分红与回购**：全年分红率、回购注销规模，验证现金牛属性。
- **商誉**：年报减值测试，库卡等 ToB 资产是否触发减值。

### 筹码面与基本面共振判断

- **谁在验证逻辑（加仓）**：中国人寿（险资新进 + 增持）、美的控股（控股股东稳定 28.53%）——长线资金在 84 元附近低位配置。
- **谁在撤退（减仓）**：北向外资（持续减持）、证金（退坡）——外资对"增长降速 + 家电成熟行业"的担忧用脚投票。
- **筹码趋势与基本面方向是否一致**：**分歧。** 基本面（ROE 19.7%、净现比 1.21x、股息率 5%、ToB+海外高增）向上，但北向和证金在减、散户小幅涌入——市场把这份基本面按"增长永久熄火"定价。**筹码面是验证信号而非选股依据**：北向减持是短期压力，但控股股东稳定 + 险资增持 + 股息率 5% 构成"跌不深"的底部；若中报（8/29）验证增长企稳、北向回补，筹码面与基本面将重新共振。

**总结（正面/负面/验证窗口）**：
- 正面：控股股东稳定（28.53%）、险资中国人寿新进增持、汇金 1.16% 纹丝不动、股息率 5%。
- 负面：北向持续减持、证金退坡、散户户数 +6%。
- 验证窗口：中报（8/29）后的北向持仓——若北向回补 + 险资继续增持，筹码面与基本面拐点将共振。

## 九、备注：名词解释

| 名词 | 解释 |
| --- | --- |
| **ToC / ToB** | ToC（To Consumer）智能家居业务，面向消费者（空调/冰箱/洗衣机/厨电等）；ToB（To Business）商业及工业解决方案，面向企业（楼宇科技/机器人与自动化/工业技术/新能源）。美的正从 ToC 家电龙头向"ToC + ToB"双轮驱动的全球化科技集团转型。 |
| **OBM / OEM** | OBM（自有品牌制造）：以自有品牌销售；OEM（代工）：为其他品牌代工。美的海外 OBM 占智能家居海外收入超 45%，反映从"代工出海"向"品牌出海"的升级。 |
| **库卡（KUKA）** | 德国工业机器人巨头，美的 2017 年收购。2025 年国内工业机器人出货 3.2 万台（+30%+），市场份额 9.6% 行业前三，300kg 以上负载国内份额 47.4%。是美的机器人与自动化业务的核心载体，也是商誉（342.57 亿）的主要来源。 |
| **美芝 / 威灵** | 美芝（压缩机，全球份额第一）、威灵（电机，全球份额第一），是美的工业技术板块的核心，实现核心部件自供，构成"全产业链"护城河。 |
| **COLMO / 东芝** | 美的高端品牌矩阵。COLMO 是自创高端 AI 科技家电品牌，东芝是通过并购获得的高端品牌，用于海外市场（欧洲等）。 |
| **以旧换新** | 政府推动的家电以旧换新补贴政策，2025 年驱动美的 ToC 智能家居 +11.28%，是 2025 年增长的重要政策托底；政策退坡是 2026 年增速放缓的主因之一。 |
| **净现比** | 经营现金流净额 ÷ 净利润。美的 2025 年 1.21x（533.46/439.45），利润几乎全额转化为现金，是"现金牛"属性的核心指标。 |
| **Arbonia** | 瑞士暖通/节能解决方案企业，美的 2025 年并购，用于完善楼宇科技板块的欧洲暖通与节能能力。 |
| **θ（兑现系数）** | 估值模型中的利润兑现折价系数，`θ = 0.15θ₀ + 0.85θₓ`，反映账面利润转化为股东价值的比例。美的 θ₀=0.90、θₓ=0.85，整体 θ≈0.86。 |
