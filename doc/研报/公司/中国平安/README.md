## 拆分约定

- **主报告 = 静态分析**：公司逻辑、宏观与行业框架、2025 年报财务基线、估值方法与基准情景；不随季度滚动改写。
- **跟踪报告 = 逐期更新**：每报告期一个文件，记录核心指标实绩、增长驱动 / 风险逐项更新、披露前预期对照、财报质量评价、估值刷新与下一验证窗口。
- 主报告中的"核心跟踪变量"与"验证窗口"是跟踪的检查清单；具体实绩一律到 `财报跟踪/` 目录对应文件查找。
- 新报告期披露后：新建对应文件（可从 [2026三季报.md](财报跟踪/2026三季报.md) 模板复制），并在本 README 更新状态。
