## 跟踪清单（披露后逐项更新）

1. **利润率修复持续性（最关键的验金石）**：Q3 净利率能否守住 10%+——11.01% 含促销收敛 + 有税收缩 + 减值出清的一次性成分，Q3 是检验"剔除一次性后净利率是否仍有 9-10%"的第一窗口；

2. **收入转正**：Q3 单季营收同比能否转正（Q2 -5.75%）——"收入弱、利润强"若持续第三季度，则利润修复的持续性打折扣；

3. **海南离岛免税**：7-9 月海口海关月度金额增速（2026 H1 +18.8%），守住双位数 = 封关红利可持续；回落到个位数 = 触发主报告"方向一"证伪警报；

4. **上海地区 / 日上上海**：三季报分部数据是否披露日上上海盈亏——减亏/扭亏 = 机场业务修复；继续亏损 = 商誉（4.85 亿）减值风险仍在；

5. **DFS 整合**：三季度 DFS 分部收入与经营情况（商誉 7.85 亿、预测利润率 6.78%-6.92% 的假设是否站稳）——年报减值测试前最后一次分部观察；
