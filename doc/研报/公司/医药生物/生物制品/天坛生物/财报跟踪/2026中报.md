## 四、业绩预期（最新）

- **一致预期更新**：近六月平均 2026E EPS 0.53（隐含归母 10.5 亿，2026-09-04）——但中报与预减公告（2026-07-15，H1 约 3.05 亿）后券商集中下修：中国银河 0.32（09-01）、中金 0.39、开源 0.49、西南 0.44（08-31 至 09-04）。**趋势：下修中，且均值滞后于最新单家值**；对照主报告基准 6.55 亿（<span style="color:#0f7a33">-40%</span>）：H1 实绩 2.99 亿隐含 H2 需 3.56 亿（较 2025H2 的 4.58 亿 <span style="color:#0f7a33">-22%</span>）即可达成——基准路径的 g1 假设与实绩轨迹一致。

- **利润路径兑现**：g1 = <span style="color:#0f7a33">-40%</span> 需要 H2 归母约 3.56 亿——Q2 单季 1.73 亿（自算）外推 H2 季均 1.8 亿以下有距离，但 H2 去年基数更低（2025H2 归母 4.58 亿中 Q4 已含降价影响），判断 g1 兑现概率中性偏上，验证节点为三季报。

- **管理层观点**：2026-07-15 业绩预减公告与中报归因一致（价格延续 25Q4 水平 + 增值税政策调整），无新表态；2026-08-27 董事会通过中期分红预案（10 派 1 元，1.98 亿）——利润 <span style="color:#0f7a33">-53%</span> 背景下维持一年两派节奏。

## 九、关键解读与总结

**关键解读**：

- 本期最重要的信号是**经营现金流转正（<span style="color:#d02020">+2.89 亿</span> vs 上年同期 <span style="color:#0f7a33">-2.02 亿</span>）**——主报告判断"信用放宽是一次性、利润质量可修复"的核心证据出现，净现比（H1）0.97 已回到历史中枢下方附近。

- **价格平台期确认但企稳未确认**：官方"价格延续 2025Q4 水平"意味着降价动作停止，但白蛋白 <span style="color:#0f7a33">-25.11%</span> 说明渠道去库仍在压制量价，毛利率 35.84% 贴着主报告底线——三季报若跌破 32%，基准情景下修。

- **g1 假设与实绩轨迹一致**：H1 归母 2.99 亿，达成基准全年 6.55 亿只需 H2 约 3.56 亿（<span style="color:#0f7a33">-22%</span>），判断兑现概率中性偏上；一致预期均值（10.5 亿）与实绩的裂口已被券商下修追认，方向与本报告基准一致。

- **产能与品种如期落地**：云南 / 兰州竣工验收 + 皮丙获批——零章方向一 / 方向二的验证指标全部按期触发，长期供给能力的故事在推进，与短期盈利下行并存。

**总结**：

- 正面（✅）：现金流修复、采浆恢复增长、产能与新品落地、中期分红维持。

- 负面（❌）：收入与利润降幅深（<span style="color:#0f7a33">-16.56%</span> / <span style="color:#0f7a33">-52.75%</span>）、白蛋白毛利率 29.10% 逼近盈亏敏感区、应收余额微超阈值。

- 验证窗口：2026-10 下旬三季报——毛利率 35% 底线、H2 归母路径、应收收口三项同时验证。
