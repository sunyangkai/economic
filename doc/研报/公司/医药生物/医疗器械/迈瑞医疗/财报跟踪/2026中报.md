**竞争格局新信号（主报告"对手是谁"的实际进展）**：

- **对下方国产追赶者的领先**：MT 8000 国内新增订单超 260 套、装机近 200 套并**上调全年订单目标**，说明在"流水线 + 试剂"这一外资与国产共同争夺的制高点上，公司装机节奏在加快。

- **价格端**：IVD 毛利率同比 <span style="color:#d02020">+1.32pp</span>（61.06%），说明本轮集采降价与产品结构改善（免疫占比提升、自产原料）已经大致对冲——这与主报告"集采是永久性降价、以量换价只能对冲一部分"的判断相比，**对冲效果好于预期**。

**模式质地新证据**：销售商品收到现金 193.41 亿元 / 营收 177.47 亿元 = 收现比 1.09（2025H1 为 1.06）；合同负债 33.86 亿元、较去年同期 <span style="color:#d02020">+65.14%</span>——预收订单继续扩张，"先收钱后发货"的商业模式未被破坏。

## 九、关键解读与总结

### 关键解读

1. **收入与订单是本期的亮点，利润是被汇兑掩盖的**：收入 <span style="color:#d02020">+6.00%</span>、合同负债同比 <span style="color:#d02020">+65.14%</span>、IVD 国内市占率升至近 14%、MT 8000 上调全年订单目标；归母 <span style="color:#0f7a33">-5.37%</span> 完全可由财务费用同比 +7.19 亿元等外部项解释，剔除汇兑后 <span style="color:#d02020">+7.22%</span>。

2. **利润路径的兑现完全押在下半年**：H1 完成 2026E 的 55.6%（去年同期占比 62.3%），要落在 g1 = +6% 上，H2 需 <span style="color:#d02020">+25.0%</span>——依赖低基数 + 汇兑不再扩大，属于"方向对、斜率待验证"。

3. **集采对冲好于主报告假设**：IVD 毛利率同比 <span style="color:#d02020">+1.32pp</span>、分部收入由降转增，说明"以量换价 + 自产原料 + 免疫占比提升"的对冲效果强于主报告"只能对冲一部分"的保守判断；这一项若延续，2027 年的 g2 有上修空间。

4. **现金质量改善是最扎实的正面变化**：经营现金流 <span style="color:#d02020">+24.35%</span>、收现比 1.09、净现比（半年）由 0.77 升至 1.02，且存货 / 应收增速均低于收入增速——不是靠放宽信用或压库存换增长。

5. **商誉下降是汇率折算而非减值**：111.12 亿元（-2.56%）与人民币升值同向；全年减值测试在年报，本期不能替代结论（主报告列为"中高"风险，本期的正确状态是"未恶化、未出清"）。

6. **估值参数三项（现价 / 一致预期 / θ）与主报告完全相同**，两张情景表数值未变：基准 175 元（<span style="color:#d02020">+6%</span>）、悲观 136 元（<span style="color:#0f7a33">-18%</span>）；以一致预期路径反推，市场隐含 θ ≈ 0.825、低于本报告 0.907——**市场仍要求"利润兑现质量"的额外折价，而本期报表恰恰在改善这一点**。

### 总结

**正面（✅）**：收入重回正增长且订单（合同负债 +65.14%）与份额（IVD 近 14%、硬镜国内第二）超预期；国际业务提速至双位数并站稳 53%；经营现金流 +24.35%、收现比 1.09；毛利率较年报回升 0.51pp、IVD 毛利率逆势 +1.32pp；中期分红 13.30 元 / 10 股落地。

**负面（❌）**：汇兑使财务费用同比增加 7.19 亿元，直接导致归母负增长；医学影像产线仍 <span style="color:#0f7a33">-5.78%</span>，境内收入尚未转正；利润进度落后于去年同期，全年兑现集中在下半年，容错空间变小。

**验证窗口**：**2026 三季报（约 2026-10-30）**——① 财务费用中的汇兑损益是否收窄（决定 g1 成败的第一变量）；② 单季毛利率能否守住 60%；③ 境内收入能否转正；④ 合同负债能否延续高增。四者中若①③兑现、②不破，则维持基准路径 [+6%, +13%, +12%] 与 175 元的内在价值判断。
