# 东鹏饮料 vs 伊利股份：估值对比

> 两份研报均用本项目估值体系（`tools/valuation.js` 的 `calculateIntrinsicPe`）测算：θ 固定反映利润兑现质量，经营与管理风险全部计入利润路径。本文对比两家的估值结构、市场定价与赔率。

## 零、结论先行

**两家都被模型判定为低估，但低估的性质完全不同，选哪只取决于你要什么：**

- **东鹏是"高赔率、高波动"的成长修复**：现价已按"特饮崩 + 平台化失败"的悲观三杀定价，向上看平台化接棒的预期差修复（+76%—141%），弹性大但依赖经营兑现。
- **伊利是"低赔率、高确定性"的价值修复**：现价按"零增长价值陷阱"定价，向下有 5.3% 股息垫底，向上看液奶企稳 + 估值修复（+28%—59%），弹性小但安全垫厚。

**一句话**：东鹏赚的是"成长被低估"的钱（赌平台化），伊利赚的是"价值被无视"的钱（赌股息和企稳）。**风险承受型选东鹏，确定性偏好型选伊利；两者不是替代品，是同一个"消费板块低估"主题下的两种打法。**

## 二、生意质量：为什么 θ 一高一低

θ 只反映利润兑现质量（现金转化），两家差距来自商业模式：

**东鹏（θ=0.95）——轻资产快消平台的顶级现金转化。**
- 净现比三年超 140%，经营现金流常年大幅高于净利——饮料是"先款后货 + 终端现结"的生意，应收极低、合同负债（经销商预付款）常年高企。
- 存货仅 6.6 亿、应收周转极快，几乎没有营运资本占用。θ₀ 本可接近 1，固定取 0.95。
- 治理/返利/存贷双高等风险**不计入 θ**，全部进利润预测。

**伊利（θ=0.80）——成熟消费股的现金转化，但上游重资产拖累。**
- 净现比 124%（2024 年 257%），利润兑现质量好但明显弱于东鹏。
- 三个折价点：①上游重资产（优然牧业 36.07%、牧场产能持续消耗现金）；②应收/存货变动侵蚀（2025 年经营现金流 -34%，净现比从 257% 骤降）；③高杠杆（有息负债 397 亿，年利息约 8 亿）。
- 液奶萎缩、原奶反转、竞争、减持等风险同样**不计入 θ**，全部进利润预测。

> **核心含义**：两家都把经营风险扔进利润路径，θ 只比"利润变成现金"的能力。东鹏 0.95 vs 伊利 0.80，差距即"轻资产 vs 重资产"的现金转化差。

## 三、增长引擎：一个靠平台化接棒，一个靠结构升级

| 引擎       | 东鹏                                                         | 伊利                                                         |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 基本盘     | 特饮 156 亿，**失速**（H1 +6.9%，Q2 接近零增长）             | 液奶 704 亿，**企稳**（2025 -6.11% → 2026 Q1 +2.32%）        |
| 第一增量   | 茶饮料 +209%（果之茶 H1 10.58 亿，全年冲 25 亿+）            | 奶粉 +10.42%（婴配粉市占率 18.3% 跃居第一）                  |
| 第二增量   | 补水啦 +12%（去库存 + 价格战压制）                           | 冷饮 +12.63%（连续 31 年第一）                               |
| 期权       | 非特饮占比 28%，平台化接棒（接力赛交接棒在收窄）              | 非乳业务 +112%（水饮/肉牛，Q1 +241%）；海外三大单元           |
| 成本/周期  | PET 锁价红利（H2 到期后回落）                                | **原奶成本红利**（2027 年后反转），增持优然牧业逆势锁仓        |
| 风险集中点 | 特饮降速速度 vs 新品提速速度的**交接棒时间差**                | 液奶零增长 vs 奶粉冷饮接棒的**增速换挡**                      |

**本质差异**：东鹏的增量要靠"新品接棒"（从无到有，不确定性高），伊利的增量靠"存量结构升级"（奶粉/冷饮已在放量，确定性高但弹性小）。东鹏赌的是平台化的**质变**，伊利赌的是液奶企稳后的**量变**。

## 四、估值测算：利润路径对比（θ 固定）

两家一致预期都需要"打折看"——东鹏中报后需下修（56→52 亿），伊利的 2026E 本就只 +5.5%（2025 高基数）。各路径按其自身 2026E 净利换算股价：

| 情景 | 东鹏（θ=0.95） | 伊利（θ=0.80） |
| ---- | ----------: | ----------: |
| 悲观路径 | [8%,6%,5%] → **147 元（+20%）** | [3%,6%,6%] → **34.9 元（+28%）** |
| 谨慎/下修 | [18.1%,13%,12%] → **216 元（+76%）** | [5%,8%,8%] → **38.5 元（+41%）** |
| 一致预期 | [26.8%,19.6%,17.9%] → **296 元（+141%）** | [5.5%,11.9%,11.7%] → **43.4 元（+59%）** |
| 乐观路径 | — | [8%,12%,12%] → **45.8 元（+68%）** |

**共同的结论**：两家现价都低于**全部**利润路径的内在价值——即使最悲观的路径（东鹏 +20%、伊利 +28%）也高于现价。**模型对两家的判断都是"低估"，只是低估的幅度和来源不同。**

**分档看赔率**：

| 情景       | 东鹏   | 伊利   | 谁更便宜 |
| ---------- | -----: | -----: | :------: |
| 悲观       | +20%   | +28%   |   伊利   |
| 基准       | +76%   | +41%   |   东鹏   |
| 一致预期   | +141%  | +59%   |   东鹏   |

> 悲观情景伊利更有底（+28% vs +20%），基准及以上东鹏弹性更大（+76% vs +41%）。**伊利的估值曲线更平缓（确定性），东鹏的估值曲线更陡峭（弹性）。**

## 五、市场怎么定价的：隐含 θ 对比

反推现价 2026E PE ÷ 该增速下的底价 PE：

| 项目                   | 东鹏                                       | 伊利                                   |
| ---------------------- | ------------------------------------------ | -------------------------------------- |
| 现价 2026E PE          | 16.1x（共识 56 亿）/ 17.3x（下修 52 亿）    | 14.1x（共识 122 亿）                   |
| 市场隐含 θ（一致口径） | **0.41**                                   | **0.50**                               |
| 市场隐含 θ（下修口径） | 0.57（下修后盈利）                          | —                                      |
| 模型 θ                 | **0.95**                                   | **0.80**                               |
| θ 缺口                 | 0.95 − 0.41~0.57 = **0.38~0.54**           | 0.80 − 0.50 = **0.30**                 |

**两个关键观察：**

1. **市场对两家的 θ 定价都在 0.41—0.57**——都不信利润兑现质量。但东鹏的模型 θ 是 0.95（轻资产顶级转化），伊利的模型 θ 是 0.80（重资产），所以**东鹏的"θ 低估"更极端**（缺口 0.38—0.54 > 伊利的 0.30）。
2. **东鹏的 16.1x 有一部分是"盈利虚高"假象**——用共识 56 亿算 PE 低估了真实估值；若按下修后 52 亿算，隐含 θ 升到 0.57。**市场可能不是对东鹏的现金转化极度悲观，而是已经预期了盈利下修。** 伊利的 14.1x 则没有这个修正——它的盈利预期本身就低（+5.5%）。

## 七、谁更值得买

**不是二选一，是两种投资风格的答案：**

| 维度           | 东鹏（成长修复）                          | 伊利（价值修复）                          |
| -------------- | ----------------------------------------- | ----------------------------------------- |
| 赚什么钱       | 预期差修复（平台化被低估）                | 股息 + 温和估值修复                       |
| 赔率结构       | 悲观 +20% / 基准 +76% / 一致 +141%        | 悲观 +28% / 基准 +41% / 一致 +59%         |
| 安全垫         | 悲观路径兜底（+20%），无股息依赖          | **5.3% 股息率** + 悲观路径（+28%）双保险   |
| 主要变量       | 茶饮料能否冲 25 亿+、补水啦能否回升 20%+  | 液奶 Q2 能否续正、原奶拐点时点            |
| 兑现风险       | 高（平台化接力棒不能掉）                  | 低（奶粉/冷饮已在放量，分红是硬承诺）      |
| 适合谁         | 能承受波动、赌成长修复的进攻型投资者      | 要确定性、吃股息的价值型投资者            |

**模型视角的排序**：
- **要弹性** → 东鹏。θ 缺口更大（0.95 vs 市场 0.41—0.57），平台化一旦兑现，估值中枢从"大单品崩溃"切回"品牌平台"的空间是伊利的 2 倍以上。
- **要确定性** → 伊利。悲观路径 +28%、股息 5.3%、增速低但可预期——回撤有限，等待成本低。
- **两者都不买的风险情形**：东鹏若特饮崩到 0% 且茶饮料接不住（现价已低于悲观路径约 17%，最坏情形已大部分被价格反映，但下行并非零）；伊利若原奶 2027 反转 + 液奶再转负（现价已定价悲观路径，向下约 0）。**两者的共同特征都是"最坏情形已经被价格反映"，向上的期权是免费的。**

**最终判断**：若只能选一只做多，**风险偏好中性者选伊利**（安全垫厚、兑现确定性强、5.3% 股息提供等待成本补偿）；**激进者选东鹏**（更大的 θ 缺口 + 平台化期权，前提是接受特饮失速叙事被打脸的风险）。两者的共同逻辑是同一个：**消费板块里，市场愿意为"增长"付溢价、却不愿为"现金流质量"付溢价——而这两家恰好都是现金流质量被严重低估的品种。**
