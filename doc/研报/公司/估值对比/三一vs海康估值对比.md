# 三一重工 vs 海康威视：估值对比

> 两份研报均用本项目估值体系（`tools/valuation.js`）测算：θ 固定反映利润兑现质量，经营与管理风险全部计入利润路径。本文对比两家的估值结构、市场定价与赔率，数据截至 2026-08-20（三一）/ 2026-08-19（海康）。

## 零、结论先行

**模型判定两家都是低估，但低估的性质完全不同——三一是"待验证的折价"，海康是"已验证的折价"：**

- **三一（600031 / 06031）是"高赔率、高兑现风险"的周期重估**：现价 19.06 元按"悲观增速 × 重周期 θ"定价（2026E 16.2x、市场隐含 θ≈0.36），向上看全球化稀释周期后的估值中枢抬升（基准 +69%、乐观 +101%）；但一致预期 108 亿隐含 **H2 +72%**——H1 预计仅 +1~4%，全年弹性全部押在"汇率走平 + 初裁不追溯 + Q4 少计提"三个条件上（兑现概率约 55—65%），且欧盟反倾销终裁（基准个体税率 25—35%）是 2027 的重估变量。
- **海康（002415）是"中高赔率、低兑现风险"的现金转化修复**：现价 35.18 元按"利润兑现折价 + 悲观增速"定价（2026E 18.6x、市场隐含 θ≈0.55）；H1 归母 +39.6% 已实绩、完成全年一致预期的 45.5%，一致预期隐含 H2 仅 +10.6%——**没有兑现压力**，向上是 Q3 毛利率站稳 50% 后的上修期权（基准 +51%、乐观 +82%），向下有双保守组合 37.1 元兜底（悲观 -4.7%）。

**一句话**：三一赚的是"H2 赌局 + 全球化重估"的钱，海康赚的是"现金转化偏见修复"的钱。**若必须二选一：风险中性者选海康（兑现确定性 + 硬下行保护 + 3.3~3.7% 股息）；激进者选三一（θ 缺口更大 + 每档赔率更高，前提是接受 H2 兑现风险）。**

## 二、生意质量：θ 差 0.07，但现金转化路径完全相反

θ 只反映利润兑现质量（利润变成现金的能力），两家差距不大（0.842 vs 0.772），来源却正好相反：

**三一（θ=0.772）——重资产行业的"占款型"现金异类。**
- 净现比 2.38x、连续两年 >2.3x，2025 年经营现金流 199.75 亿创新高——主要来自"先款后货 + 金融租赁出表 + 应付 > 应收"（应付 272 亿 vs 应收 255 亿，占用上游资金 101 亿增量）。
- θ₀ 取 0.90：现金质量真实，但周期性坏账风险（2012—2015 按揭/融资租赁坏账史）仍在营运资本中潜伏。
- θₓ 取 0.75：重资产 + 强营运资本行业的成熟期上限，周期尾部利润兑现打折。

**海康（θ=0.842）——轻资产但"重营运资本"的锁定型龙头。**
- 固定资产仅 96.82 亿撑起 925 亿营收，但应收 + 存货约 503 亿（占总资产 36%），政企回款周期长、备货规模大；2025 年现金流爆发含应收大降 21% 的一次性回款，2026 H1 经营现金流 32.31 亿（-39.5%）被存货 +44% 的主动备货拖累。
- θ₀ 取 0.80：正常化转化率约 0.8，H1 承压属旺季备货的季节性插曲。
- θₓ 取 0.85：软件平台（iVMS/HikCentral）+ AI 订阅让成熟期现金转化优于纯硬件商。

> **核心差异**：三一的转化质量来自"供应链占款"（对上游的议价力），海康的转化质量来自"软硬一体锁定"（对下游的粘性）。三一的潜在风险在周期尾部坏账，海康的潜在风险在营运资本膨胀（294.88 亿存货能否去化）。

## 三、增长引擎对比：一个赌"全球化稀释周期"，一个赌"AI 换新抬毛利"

| 引擎 | 三一重工 | 海康威视 |
| --- | --- | --- |
| 基本盘 | 国内挖机置换窗口（2028 见顶）+ 海外 64% 收入 / 71% 毛利 | 存量摄像头换 AI 摄像头（毛利率 49.97%，+4.77pct） |
| 第一增量 | 海外 +18% 预期（7 月出口 +21.2%、非洲 +55%） | 创新业务 151.70 亿（+28.93%），占比 32.4% |
| 第二增量 | 国内更新替换（内销 +8.25%）+ 提价（挖机 +5%、起重机 +2~5%） | 汽车电子（+46%）、存储涨价周期、微影 |
| 期权 | 新能源 86→150 亿、电动化四项市占率第一 | FCC 诉讼（估值期权）、车路云、机器人海外 |
| 外部变量 | **汇率（每升 1% 税前 -5~6 亿）+ 欧盟反倾销（基准税率 25—35%）** | 地缘/FCC（不构成当期利润风险，是估值期权） |

**本质差异**：三一的增量靠"全球份额 + 周期回升"（量价弹性大，但波动源是汇率与贸易政策）；海康的增量靠"产品结构升级"（毛利率 +4.77pct 已经发生，剩下是验证能否持续）。三一赌的是周期的**质变**（波动被全球化稀释），海康赌的是毛利的**量变**（AI 溢价能否延续）。

## 四、利润节奏与一致预期质量（两者最本质的差异）

**三一：一致预期是"H2 赌局"。**
- H1 预计约 53 亿（+1%~+4%），一致预期 108 亿隐含 **H2 需 55 亿（+72%）**——2025 H2 低基数（31.92 亿，占全年仅 38%，被 Q4 汇兑与年末计提拖低）是主要来源。
- H2 利润桥区间约 50—57 亿（中枢约 53—54），55 亿在区间上沿：需"汇率走平（不破 6.5）+ 初裁不追溯（或少计提）+ Q4 不大额计提"三条件同现，基准情景兑现概率约 55—65%。
- 中报（8/31）若 H1 仍是个位数增速，一致预期存在下修风险——**近端事件对三一是风险，不是期权**。

**海康：一致预期是"H1 已兑现 + H2 轻松"。**
- H1 实绩 78.96 亿（+39.57%），完成全年一致预期 173.4 亿的 45.5%，符合 H1 占全年 40%—45% 的旺季节奏。
- 一致预期隐含 H2 同比仅 +10.6%，远低于 H1 实绩——**没有透支**；8 月一致预期已从 164 亿上修至 173 亿，Q3 毛利率站稳 50% 则仍有上修空间。
- 近端事件（Q3 季报）对海康是**免费的上修期权**，不是风险。

**结论**：买三一 = 为"H2 兑现 + 全球化重估"付钱；买海康 = 为"已验证的利润 + 现金转化偏见修复"付钱。**两者的信息结构完全不同：三一的近端偏风险，海康的近端偏期权。**

## 六、市场怎么定价的：隐含 θ 对比

| 项目 | 三一重工 | 海康威视 |
| --- | --- | --- |
| 现价 2026E PE | 16.2x | 18.6x |
| 无折价 PE（一致增速、θ=1） | ~45x（2026E 口径） | 33.5x |
| 市场隐含 θ（2026E 口径） | **≈0.36** | **≈0.55** |
| 模型 θ | 0.772 | 0.842 |
| θ 缺口 | **0.772 − 0.36 ≈ 0.41** | 0.842 − 0.55 ≈ 0.29 |

**两个关键观察：**

1. **市场对三一的折价更极端**（隐含 θ 0.36，即认为一半以上的利润永远无法兑现成现金），且这个折价里混杂了"周期见顶回落"的增速悲观——三一的低估是**"增速 + 兑现"双折价**；海康的隐含 θ 0.55 对应"约 45% 利润不兑现"的纯粹兑现偏见，增速预期并不悲观（一致预期 +22% 且无透支）——海康的低估是**"兑现"单折价**。
2. **修复三一需要同时纠正两个偏见**（周期增速 + 现金转化），弹性更大但门槛更高；**修复海康只需纠正一个偏见**（现金转化），且验证信号（Q3 毛利率）已经在朝好的方向走。这也解释了为什么三一每档赔率都更高——它的"低估"更极端，也更有待验证。

## 八、谁更值得买

**不是二选一，是两种投资风格的答案：**

| 维度 | 三一（周期重估） | 海康（兑现修复） |
| --- | --- | --- |
| 赚什么钱 | H2 兑现 + 全球化稀释周期的估值中枢抬升（17—19x → 25—35x） | 现金转化偏见修复 + Q3 验证后的盈利上修 |
| 赔率结构 | 悲观 +10% / 保守 +36% / 基准 +69% / 一致 +67% / 乐观 +101% | 悲观 -4.7% / 保守 +21% / 基准 +51% / 一致 +52% / 乐观 +82% |
| 下行保护 | 依赖成长中枢 θ=0.772；若市场正确（重周期），悲观对应 -16% | **双保守组合 37.1 元 > 现价**；悲观 -4.7%；股息 3.3~3.7% |
| 主要变量 | 中报 H1 增速、9 月初裁是否追溯、Q4 计提、反倾销终裁税率 | Q3 毛利率站稳 50%、存货去化、创新增速、FCC 诉讼 |
| 兑现风险 | **高**（H2 +72% 需三条件同现，外部变量不可控） | **低**（H1 已兑现 45.5%，H2 只需 +10.6%） |
| 适合谁 | 能承受 H2 赌局与外部变量噪音的进攻型投资者 | 要确定性、要求下行可验证的稳健型投资者 |

**模型视角的排序：**
- **要赔率 → 三一**。θ 缺口更大（0.41 vs 0.29）+ 增速双折价，全球化重估一旦兑现（中报验证 Q2 汇兑收敛 + 9 月初裁不追溯 + 终裁税率温和），估值中枢从周期股切回半成长股的空间是海康兑现修复的 1.3 倍以上。
- **要确定性 → 海康**。H1 +40% 已落地、一致预期无透支（H2 仅 +10.6%）、双保守组合兜底、股息 3.3~3.7% 提供等待成本补偿——回撤有限，等待 Q3 验证的成本低。
- **两者都不买的风险情形**：三一若 H2 兑现失败（汇率破 6.5 或初裁追溯 + Q4 大额计提），一致预期下修至保守甚至悲观路径，现价 16.2x 的"折价"变成"合理定价"；海康若毛利率红利消退 + 存货去化失败，悲观路径 -4.7%（约 -17% 若 θ 同步下修至 0.735）。**三一的最坏情形（-16%）比海康（-4.7%）深——折价更深通常意味着赌注更大。**

**最终判断**：若只能选一只做多，**风险中性者选海康**——三一的 108 亿一致预期是"H2 赌局"（兑现概率仅 55—65%，且由汇率与反倾销两个公司不可控的变量主导），海康的 173 亿是"H1 已兑现 + H2 轻松"（隐含 +10.6%），两者的一致预期质量不在一个量级；**激进者选三一**——若 H2 兑现 + 反倾销温和，全球化重估的弹性（基准 +69%、乐观 +101%）显著大于海康的兑现修复（+51%、+82%），且三一现价已把最坏情形（悲观 × 重周期）price in。

> 两者的共同逻辑：市场都在为"确定性"付溢价、却不愿为"现金流质量与周期结构改善"付溢价。海康是"利润已经兑现、偏见待修复"，三一是"结构已经改善、利润待兑现"——**海康的低估更接近事实，三一的低估更接近信仰。**
