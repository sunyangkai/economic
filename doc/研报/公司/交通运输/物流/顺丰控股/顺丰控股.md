## 要点速览

**利润**——这是一门"毛利极薄、杠杆极大"的生意。2025 年营收 3,082 亿元、归母净利 111 亿元，归母净利率仅 3.6%；每 100 元收入里 43 元是收派员与小哥的人工成本、33 元是运力成本，毛利只有 13.3%。所以利润不靠"做大"，靠"改结构"：一是票均收入的修复（2025 年主动跌 11.4% 换件量 +25.4%，2025Q4 毛利率已回升至 14.28%），二是人工成本率的下降（43.0% 是全行业最高，也意味着最大的可压缩空间）。**票均收入每修复 1%（0.137 元/票），在件量不变的前提下增厚收入约 23 亿元、毛利 15—18 亿元——这是全篇最灵敏的单一杠杆。**

**增长**——三条线：① 时效快递的"价值回归"（1,310 亿元收入、42.5% 占比，2025 年用票均 -11.4% 换来件量 +25.4%，2025Q4 毛利率已回升至 14.28%）；② 供应链及国际（729 亿元，2025 年增 3.5%，但剔除 KLN 后增 32.3%，是第二曲线）；③ 同城即时配送（127 亿元，2025 年增 43.4%，净利翻倍）。前两条决定 2027—2029 年的利润斜率，第三条体量太小（收入占比 4.1%）只能贡献增量、改变不了格局。

**护城河**——8/10：时效品牌 + 90 架自有全货机 + 鄂州货运枢纽 + 直营网络四层叠加，国内没有第二家能同时提供"次日达确定性 + 全重量段 + 端到端"的公司；但定价权有天花板，2025 年票均收入 -11.4% 证明它在电商件上必须跟着比价。它不是垄断，是"高端市场的默认选项"。

**估值**——模型给出基准情景 **49 元（+58%）**、机构一致预期情景 58 元（+85%），现价 31.18 元对应 14.2 倍 2026E PE。但先说清一件事：现价几乎精确落在模型里"未来三年零增长"那条路径上（14.1 倍 → 31 元），即市场不是在争论顺丰增长多快，而是在给它"不增长"定价。**分歧全在利润路径，不在"利润能不能变成钱"**——十年扩张性支出合计 254 亿元（归母 228.6 亿），账上可供发展资金 372 亿元全额垫得住，扩张期的可分配利润恒等于归母净利；把稳态 ROIC_own 从 28.09% 压到 9%，内在 PE 仍有 20.0 倍（44 元）。

先记一个读数口径：顺丰的净利润里，非经常性损益占比不低（2025 年 18.5 亿元，占归母 16.7%，主要是政府补助与结构性存款收益），而 2025 年最大的一笔一次性收益（REIT 处置，税后 5.9 亿元）落在上半年。因此看利润趋势要盯**扣非归母**（2025 年 92.6 亿元，仅增 1.3%），不要用归母增速（+9.3%）判断经营改善。

## 一、业务说明

顺丰是中国及亚洲第一大、全球第四大综合物流服务商（《财富》2025 年世界 500 强第 393 位，唯一入榜的中国民营快递企业），2025 年营收 3,082 亿元，服务超过 8 亿个人客户与 235 万家企业客户。公司按**三个经营分部**披露（速运及大件、同城即时配送、供应链及国际），分部内再按**六条产品线**拆分。

### 1. 业务构成：卖什么、怎么赚钱

**① 时效快递（旗舰产品，2025 年收入 1,310.5 亿元、占 42.5%）**

卖的是"确定性"：承诺时限内送达，超时赔付。产品矩阵按承诺时效分层（顺丰即日 / 顺丰特快 / 顺丰标快），覆盖文件、样品、高价值商品、医药、生鲜等对时效敏感、对价格不敏感的品类。交付方式是**直营制**——收派员是公司员工而非加盟商，中转场、干线车辆、全货机自有，全链路可监控，这是"敢承诺、必赔付"的物理基础。2025 年 12 月推出的"放心寄·超时赔"（因公司原因超时即赔现金或优惠券）是这条护城河的定价化尝试。

典型场景：一家消费电子品牌的区域备件仓需要"今天下单、明天到门店"，走的是顺丰特快 + 航空大件专线；一家三甲医院的检验样本需要 4 小时内跨院送达，走的是同城即时配送叠加医药冷链。客户买的不是运输，是**库存的替代品**——时效越快，客户能压的库存越低。

**② 经济快递（2025 年收入 320.5 亿元、占 10.4%）**

卖的是电商履约的"品质分层"：以 B2C 履约配送为基础，向上游延展仓储与增值服务、向下游延展售后安装与逆向物流。它面对的是中通、圆通、韵达、申通主导的电商件市场，顺丰的定位是"独立第三方 + 品质溢价"，不是价格领先者。仓配一体是这条线的差异化载体——为家电、美妆头部品牌做全量自动化标杆仓，做 To B 与 To C 的"全渠道一盘货"。

**③ 快运（2025 年收入 421.3 亿元、占 13.7%）**

卖的是 30 公斤以上的大件与零担。三张网络并行：直营的"顺丰快运"（高品质、时效）、加盟的"顺心捷达"（23,000 个网点、乡镇覆盖率 88%）、以及 2025 年与大票零担服务商德坤的协同（整合发运货量日均超 1,600 吨）。快运是顺丰进入工业供应链的入口——2025 年 100kg 以上工业大件直营货量增长超 60%。

**④ 冷运及医药（2025 年收入 106.1 亿元、占 3.4%）**

卖的是温控能力：生鲜寄递（累计服务 5,500 个生鲜品种、2025 年特色农产品运送 800 万吨）、食品冷运（仓配一体 / 冷运大件 / 冷链店配，服务茶饮咖啡、西式快餐、中式连锁）、医药物流（精温、常温、国际、医院四大板块，梳理出 27 个核心场景）。护城河在"多温区冷仓 + 医药合规资质"——全国 101 万平方米食品冷仓、17 万平方米医药冷仓。

**⑤ 同城即时配送（顺丰同城，2025 年收入 127.2 亿元、占 4.1%）**

卖的是 3 公里内、分钟级的履约。独立第三方定位（不绑定任何流量平台），服务商家（连锁餐饮、商超）、平台（直播电商、商超小时达）与个人消费者。2025 年活跃商家 112 万家（+72%）、活跃消费者超 2,606 万人，覆盖近 2,400 个市县。它是顺丰唯一"轻资产、靠骑手弹性运力"的业务，也是唯一独立上市的子公司。

**⑥ 供应链及国际（2025 年收入 729.4 亿元、占 23.7%）**

卖的是跨境与端到端：国际快递、跨境电商包裹、国际货运代理（含控股子公司 KLN，持股 51.52%，港交所上市）、海外仓（37 个国家、255 万平方米）、以及面向七大行业（高科技、工业设备、汽车、消费品、零售食品、零售餐饮、生命科学与医药）的供应链解决方案。2025 年第四季度公司把分散的供应链业务整合为集团层面的供应链 BG。这条线是"卖资源"向"卖方案"转型的载体，也是当前最大的投入方向。

## 二、业务分析

### 1. 竞争格局与护城河

**行业空间与格局**

中国快递行业 2025 年业务量 1,989.5 亿件（+13.6%）、业务收入 1.5 万亿元（+6.5%）——量增速是收入增速的两倍，说明 2025 年全行业仍在以价换量。社会物流总费用 19.5 万亿元、占 GDP 13.9%（连续五年下降），行业主线是"降本"而非"扩容"。2025 年下半年在"反内卷"共识推动下，票均收入开始修复，竞争重心从低价转向服务品质。

市场结构是三层的：

- **电商件（占行业件量约八成）**：中通、圆通、韵达、申通 + 极兔的价格竞争区，顺丰的经济快递在这里，份额小（约 2%—3%）、定位是品质分层；
- **时效件与高端商务件**：顺丰的绝对优势区，主要对手是**京东物流**（同样自营、同样主打时效，且背靠商流）与中国邮政 EMS；这是顺丰唯一能把价格定在行业 2—3 倍的战场；
- **综合物流（快运 / 冷运 / 供应链 / 国际）**：对手按细分不同——零担是德邦（已被京东收购）与安能、百世，冷运是京东冷链与区域性玩家，国际货代是 DHL、DSV、中外运与 KLN 自身，跨境小包是极兔、菜鸟。

所以对顺丰真正构成威胁的是两类：**京东物流（同一模式的直接对手，且商流自带）**与**电商件价格体系（决定它的经济件与部分时效件能收多少钱）**。海外与新兴市场则是极兔——2026 年两家通过换股形成交叉持股，从对手变成"竞争 + 合作"关系。

**护城河评分：8 / 10（第一梯队强护城河，未到垄断级）**

| 综合物流产品矩阵与端到端（15%） | 7 | 单一赛道玩家（德邦只做零担、顺心只做加盟快运） | 快递 / 快运 / 冷运 / 同城 / 国际 / 供应链六线齐全，可承接客户的"全渠道一盘货"；但除时效与快运外，其余四条线的份额优势并不牢固，供应链业务仍处能力建设期 |
| 成本效率（15%） | 5 | 中通（单票成本行业最低）、极兔（东南亚起网成本低） | 人工成本占收入 43.0%，是中通等加盟制同行的数倍——直营换来服务质量，也换来成本劣势。2025 年毛利率 13.32% 低于中通的约 25%（口径不同但方向明确）。**这是全篇最大的扣分项，也是"激活经营"与 AI 提效要解决的问题** |

加权总分：0.25×9 + 0.25×9 + 0.20×8 + 0.15×7 + 0.15×5 = 2.25 + 2.25 + 1.60 + 1.05 + 0.75 = **7.90 ≈ 8**

**一句话定位**：为什么不是更高分——离垄断级差在定价权，2025 年票均收入 -11.4% 就是证据：它在电商件上必须跟着比价，在时效件上也要面对京东物流的贴身竞争，且鄂州枢纽的产能还没被国际货量填满；为什么不是更低分——够得上"强"的证据是逆风检验：2024—2025 年全行业价格战、公司主动降价 11.4% 换份额，份额从 7.6% 升到 8.4%、毛利率只降 0.61pp、经营现金流仍有 275 亿元，这是"壁垒互相强化"而非"景气托底"的表现。

**下调条件**：① 若连续两个报告期出现"票均收入同比转负 且 速运及大件分部净利率跌破 4.5%"（2025 年为 4.87%）→ 下调至 7；② 若时效快递收入连续两年负增长（意味着高端市场被京东物流实质替代）→ 下调至 6；③ 若鄂州枢纽国际货量连续两年不达规划、单位折旧上升 → 下调至 7。验证进 `财报跟踪/`。

### 2. 商业模式与经营质地

**这是一门"规模刚性 + 单位利润极薄"的生意，本质是用重资产买确定性、用件量摊薄固定成本。**

- **量价结构：量的弹性远大于价的弹性。** 2025 年件量 +25.4%、票均 -11.4%，两者相乘（1.254 × 0.886）= 速运物流收入只增约 11.1%；再叠加只增 3.5% 的供应链及国际，总收入仅增 8.4%。这意味着只要价格继续跌，件量增长并不能带来同比例的收入增长。反过来，票均收入每修复 1%（13.7 元/票 → 13.84 元）乘以 166.3 亿票，在不增加一件货的前提下直接增厚约 23 亿元收入；因成本不变，这部分几乎全额转化为毛利（保守按 75% 折算约 17 亿元）——**这是全篇利润弹性最大的单一变量**。

- **成本结构：人工是刚性、运力是弹性。** 人工成本 1,298 亿元占收入 43.0%，其中收派员薪酬是主体，与件量正相关但难以随件量下降而下降（直营、不能随意裁撤）；运力成本 989 亿元占收入 32.8%，可通过集约发货、拉直线路、调整招采快速压缩（2025 年已省 0.97pp）。**这决定了顺丰的毛利率在件量上行时改善有限（人工同步增长），在件量下行时恶化很快（人工不降）**——顺周期的成本结构，逆周期的利润表现。

- **资本密集度：capex 已过峰值，折旧是主要非现金成本。** 资本开支从 2021 年的 192 亿元降至 2025 年的 95 亿元，占收入比 3.1%；同期折旧摊销 164 亿元（固定资产折旧 98.4 + 使用权资产折旧 65.3）。**capex 低于折旧，说明网络已建成、进入收获期**——这是自由现金流（2025 年 180 亿元）远高于净利润（111 亿元）的根本原因，也是本报告十年表里扩张性支出只占归母净利 14% 的依据。风险是国际扩张可能重启 capex 上行周期。

- **客户结构：极度分散，回款质量好。** 前五大客户合计只占销售总额 9.61%（最大客户 3.11%），应收账款 306 亿元对应 3,082 亿元收入（周转约 36 天），销售商品收到的现金/营业收入 = 103.5%。**没有大客户依赖，也没有政府类应收账款**——这是它比多数 B2B 物流公司质地更好的地方。

- **增长质量：经常性收入为主，项目制占比低。** 六条产品线里五条是"按票/按公斤计费"的经常性收入，只有供应链解决方案含项目制成分（且合同期正在从 1—2 年拉长至 3—5 年）。**没有订阅收入、没有预收款蓄水池**——合同负债只有 19.9 亿元（占收入 0.6%），意味着报表没有"寅吃卯粮"的空间，也没有藏利润的容器。这是一份"干净但缺乏缓冲"的报表。

### 3. 增长方向与验证指标

**方向一：时效快递的价值回归（利润弹性最大）**

- **逻辑**：2025 年公司用票均 -11.4% 换了件量 +25.4%，2025 年第三季度起把"激活经营"从规模驱动切换为价值驱动，2025Q4 毛利率回升至 14.28%（全年 13.32%）。票均收入每修复 1% 约带来 23 亿元收入、15—18 亿元毛利，是利润表上最灵敏的杠杆。
- **驱动力**：① "反内卷"政策使行业价格竞争回归理性，2025 年下半年起票均收入持续修复；② 场景化产品（文旅、演出、滑雪、CBD、校园）把标准产品卖成解决方案，提升单票价值；③ "放心寄·超时赔"把服务确定性变成可定价的产品。
- **验证指标**：月度票均收入同比（来源：公司月度快递物流业务经营简报），阈值：连续 3 个月同比 ≥ 0；速运及大件分部净利率（半年报 / 年报分部附注），阈值 ≥ 5.0%。
- **现实约束**：电商件占比在提升（经济快递 2025 年 +17.6%，快于时效的 +7.2%），结构性拉低票均；一旦份额压力再现，公司会优先保量而非保价——2025 年已经证明过这一点。因此"票均修复"只能期待 1%—3%/年，不能期待回到 2021 年的水平。

**方向二：供应链及国际（第二曲线，决定长期天花板）**

- **逻辑**：国内快递件量增速已降至个位数（2025 年行业 +13.6%、2026 年上半年 +5.0%），增量在跨境与产业供应链。顺丰的抓手是"中国企业出海"——产能出海带来的不是单一运输需求，而是"国内集货—国际空海运—海外清关—本地仓配—逆向退换"的端到端合同。
- **驱动力**：① 中国出口结构升级（2025 年装备制造业占出口 59.4%、高技术产品出口 +13.2%），高货值、时效敏感型货品增多；② 跨境小包免税政策取消，履约模式从"国内直邮"转向"海外仓 + 本地履约"，具备海外仓与合规能力的头部公司受益、小型货代出清；③ 亚洲区域内贸易（RCEP、产能转移）带来亚洲内部半成品物流增量，与公司"亚洲唯一"战略吻合。
- **验证指标**：供应链及国际收入增速（剔除 KLN，年报 / 半年报分部表），阈值 ≥ +20%；海外仓面积与海外网点数（年报核心竞争力章节）；鄂州枢纽国际货运吞吐量增速（2025 年 +85%），阈值 ≥ +30%。
- **现实约束**：① KLN 的国际货代业务与海运运价高度相关，运价下行时拖累整条线（2025 年该分部仅增 3.5%）；② 国际业务需要持续的航线、海外仓与清关投入，短期是利润拖累（2024 年该分部亏损 7.6 亿元）；③ 关税与地缘政策不可控，2025 年 KEX 的减亏就是靠收缩而非扩张实现的。

**方向三：同城即时配送（即时零售的beta，体量小但增速最快）**

- **逻辑**：即时零售是 2025—2026 年少数高增长消费场景，顺丰同城作为"独立第三方"承接所有流量平台（不站队），2025 年收入 +43.4%、净利翻倍、活跃商家 +72%。
- **驱动力**：① 即时零售渗透率提升，商超小时达、前置仓履约需求爆发（2025 年商超行业配送收入 +80%）；② 品牌连锁化率提升带来稳定的商家侧订单；③ 无人车在最后一公里、校园、餐饮场景的规模化落地降低成本。
- **验证指标**：同城分部收入增速（阈值 ≥ +15%）、分部净利率（2025 年 2.2%，阈值 ≥ 2%）、活跃商家数。
- **现实约束**：体量太小——2025 年收入 127 亿元、净利 2.78 亿元，即使再翻倍也只贡献 5 亿元利润；且这门生意面对美团、饿了么的运力网络，第三方定位既是差异也是天花板（拿不到平台的最优质单量）。

**方向四：效率革命（AI 与自动化替代人工，决定净利率的天花板）**

- **逻辑**：人工成本占收入 43.0%，是整个成本结构里唯一有数量级压缩空间的科目。若人工成本占收入比每年降 0.5—1.0pp，对应 15—30 亿元毛利，相当于 2025 年归母净利的 14%—27%。
- **驱动力**：① 物流垂域大模型已应用于内部超 30 个业务场景、智能体超 5,000 个，规划智能体分钟级输出 2,000 多条线路方案；② 中转自动化（2025 年新增约 580 套自动化分拣设备、34 个航空大件专属智能中转场）；③ 无人车 / 无人轻卡 / 机械臂在末端与支线的规模化应用。
- **验证指标**：人工成本占收入比（年报成本构成表），阈值 ≤ 43%（2025 年 43.04%）、目标 2028 年降至 41% 以下；管理费用率（阈值 ≤ 6.4%）。
- **现实约束**：① 一线员工薪酬竞争力是公司主动选择（"提升员工获得感"），会抵消部分效率红利；② 社保合规成本随监管趋严上升（年报明确提示）；③ 自动化设备本身是 capex 与折旧，短期会先增成本后降成本。

### 4. 宏观环境与传导

**周期定位**：2026 年的宏观环境对顺丰是"外需强、内需弱、成本端有压力"的组合。上半年 GDP +4.7%（K 型分化：高技术制造业 +13.3%，社零仅 +1.3%）；前三季度出口 +16.4%、单月首破 5 万亿（外需是唯一全面强项）；PPI 9 月 +5.0% 创本轮新高、其中煤炭 +35.3%，布伦特油价高位震荡。社会物流总费用占 GDP 已降至 13.9%——物流行业的"降本"是长期政策主线，这对顺丰既是压力（客户要降运费）也是机会（一体化方案替代单点运输）。

**必看细分数据**：对顺丰而言，宏观总量（GDP、社零）只是底色，真正对应业务的是四组细分：① **快递业务量与业务收入**（国家邮政局，决定行业量与价）；② **出口分商品结构**（装备制造占比、集成电路、锂电池，决定国际货量）；③ **服务零售额增速**（决定同城即时配送的需求）；④ **PPI 中的燃料与运输相关分项**（决定运力成本）。2025 年快递量 +13.6%、收入 +6.5% 的反差，正是"量增价减"这一行业特征的宏观注脚。

**传导路径与当前定位**

| 宏观变量 | 当前状态 | 传导路径 | 对公司的影响 | 跟踪指标 |
| --- | --- | --- | --- | --- |
| 外需（出口） | 前三季度 +16.4%，9 月单月 +29.6% | 出口量 → 国际空海运货量 → 货代与跨境收入 | <span style="color:#d02020">顺风</span>：供应链及国际分部的量增确定，但运价（价）与货量（量）方向相反，净效应取决于结构 | 出口增速、国际航空货量、海运运价指数 |
| 内需（社零） | 1—8 月 +1.1%，8 月单月 +0.4% | 商品消费 → 电商件量 → 时效与经济快递收入 | <span style="color:#0f7a33">逆风</span>：件量增速中枢下移（行业从 +13.6% 降至 +5.0%），只能靠份额提升对冲 | 社零分品类、快递业务量月度增速 |
| 服务消费 | 服务零售额 1—8 月 +4.9%（商品 4.8 倍） | 服务消费 → 即时零售 / 同城配送需求 | <span style="color:#d02020">顺风</span>：同城分部是纯受益者，但体量小 | 服务零售额、即时零售渗透率 |

**总结**：宏观整体**顺风大于逆风**——外需与服务消费两条正贡献的线，正对应顺丰国际与同城两个增长方向；内需偏弱与油价高企是两条逆风，但都被"份额提升 + 新能源运力"部分对冲。最大的宏观变量是**油价**：运力成本占收入 32.8%，油价每上涨 10% 大致对应 8—10 亿元成本，直接压缩毛利率 0.3pp 左右——它对开篇"利润靠票均修复"这条假设的证伪阈值最低。

## 三、财务报表分析（财务基线）

本章只分析 2025 年报，作为全篇的财务基线；季度变化一律进 `财报跟踪/`。

### 1. 经营相关数据

收入规模与结构已在"一、业务说明"列示，此处只补充三项基线：**资本开支 95.06 亿元**（占收入 3.08%，2021 年为 192 亿元 / 9.3%）、**折旧摊销 163.72 亿元**（固定资产折旧 98.40 + 使用权资产折旧 65.32）、**员工 158,761 人**（另有全网管理收派员约 42 万人）。capex 低于折旧 68 亿元，是自由现金流高于净利润的结构性原因，也是本章最重要的一条经营事实。

## 四、业绩预期（基准情景）

### 1. 业绩基准

2025 年实际：营收 3,082.27 亿元（+8.4%）、归母 111.17 亿元（+9.3%）、扣非 92.64 亿元（+1.3%）。

**2026 年官方未给出收入或利润的数字指引**——年报"2026 年经营计划"只给了方向（时效聚焦场景、经济快递"规模与效益平衡"、快运做大货量、供应链深挖七大行业、国际锚定亚洲），没有可量化的目标。因此 2026 年基准由本报告自建，与一致预期并列作为交叉验证。

本报告 2026 年基准：**营收 3,286.5 亿元（+6.6%）、归母净利 112.0 亿元（+0.7%）**。低于机构一致预期（114.1 亿元 / +2.6%）约 2 亿元，理由：① 上半年归母 -4.1%，全年要靠下半年回补，而 2026 年下半年基数干净（2025 年上半年的 REIT 一次性收益 5.9 亿元落在 H1），门槛其实不低；② 油价高位对运力成本的压制在下半年仍将延续；③ 2025 年实际税率 21.7% 的低点不会重现，按 22% 假设已属乐观。

### 2. 增长驱动

以下四条即"二、业务分析 §3"的四个方向，此处只量化、不重复论证：

- **票均收入修复**：2026 年假设票均 +2%（H1 已实现 +3.3%），贡献收入约 25 亿元、毛利约 19 亿元；2027—2029 年假设票均 +1%/年。
- **供应链及国际**：2026 年假设 +13%（H1 +15.5%），其中不含 KLN 部分维持 +30% 以上；2027—2029 年假设 +15%/+14%/+12%，是收入增速的主要来源。
- **同城即时配送**：2026 年假设 +20%（H1 +21.7%），2027—2029 年 +18%/+16%/+15%。
- **效率革命**：人工成本占收入比 2026 年持平（43.0%，因仍在投入自动化），2027—2029 年每年降 0.5pp 至 41.5%，对应毛利率每年 +0.15—0.25pp。

## 五、估值（估值框架）

**核心纪律：估值只由利润路径与资本开支规划决定；经营风险全部计入利润预测，不在兑现率上打折。** 统一采用 `doc/估值理论/估值模型.md`：**R = 8.45%（$r_f$ 1.65% + ERP 6.8%）、$g_\infty$ ≈ 2.33%、过渡期固定 7 年**；**前 10 年逐年扣扩张性消耗，只有永续期用兑现系数 $\theta_x = 1 - g_\infty/ROIC$**。计算用 `tools/valuation.js`。

> **过渡期 7 年的方向性影响（必须披露）**：T=7 不是"统一更保守"——**对 g3 > g∞ 的公司抬高估值、对 g3 < g∞ 的公司压低估值**。顺丰基准 g3 = +8.0%，显著高于 g∞ 2.33%，故 T=7 对顺丰是抬升的；R = 8.45% 的固定口径方向相反，两者部分对冲。

#### 1.3 这条路径怎么来的

- **利润**：2027—2029 年 +11%/+10%/+8% 即四章 ④ 的路径（本表 136.8/147.7 与四章的 136.7/147.6 只差取整）；2029 年后按规则从 8.0% 线性衰减到 2.33%（2030 +7.3% → 2036 +3.0%），**这一段不含经营判断**，是模型的过渡期机制。
- **Capex**：122 → 138 亿（2026E 122 亿，H1 已投 60.83），占收入 3.7% → 2.8%。**没有假设资本开支收缩**——绝对额比 2025 年的 95 亿高 28%—45%，只是收入增长把它摊薄；仍低于六章 4.0% 的警戒线。
- **租赁本金**：74 → 84 亿。2025 年实际 70.4 亿（筹资活动租赁付现 75.4 − 计提利息 5.0），随租赁资产小幅上行。**这一步在多数 DCF 里被漏掉**，它才是顺丰"经营现金流好看、可分红现金少"的主因。
- **DA**：169 → 201 亿，年均 +2.0%，慢于合计资本支出（196 → 222 亿），所以净经营资本每年只增 22—30 亿，收入增长主要靠周转率（收入/经营资本从 3.3 升到 4.0）而非继续堆资产。
- **ΔWC**：十年合计只有 12 亿，几乎可以忽略。这是顺丰与多数物流公司的关键差异——应收（310 亿）与应付（303 亿）同步增长，营运资本基本自平衡；2021 年那种 +72 亿的占用是收购整合期的特例，不作常态。
- **E 与 DP**：E 从 29 亿降到 22 亿、十年 254 亿，账上 372 亿全额垫得住，所以**DP ≡ 归母净利**，期末还余 130 亿。**换句话说：模型认为顺丰未来十年不需要为增长向股东要钱，也不需要挪用分红。**
- **最该被质疑的地方**：capex 只按收入的 2.8%—3.7% 排，而公司历史上 2021 年曾达 9.3%。若国际扩张把 capex 抬到 ×1.2（capex/收入 4.4%），十年 E 升到 488 亿、超过 $F$ 372 亿，第八年起要用利润补缺口——内在 PE 20.6x（45 元），**只降 2%**；要到 ×1.5（E 857 亿）才降到 18.8x（41 元）。**资本开支不是这只股票估值的胜负手。**

> **为什么这么钝**：$\theta_x = 1 - g_\infty/ROIC_{own}$ 是双曲线，$g_\infty$ 只有 2.33% 时它离 1 很近——$ROIC_{own}$ 从 28.1% 一路降到 12.9%，$\theta_x$ 才从 0.917 掉到 0.819，内在 PE 从 22.5x 掉到 21.1x（−6%）；再降到 9% 也只有 20.0x（−11%）。**只有 ROIC 逼近 $g_\infty$ 时 $\theta_x$ 才会塌**，顺丰离那个区间很远。
>
> **ROIC 的口径与取值**：2026-11-13 按模型 §5.3.1 更正了三处取数——①$D$ 补入**租赁负债 154.17 亿**（原只取借款 338.08 亿，违反模型"漏计租赁负债即取错项"的规则）；②$q$ 改用**权益份额 0.9001**（原用 0.951，实为利润份额 $p$）；③$IC$ 改用**经营资产 − 经营负债 = 929.4 亿**（原 1,002.7 亿，勾稽对不上 225 亿）。更正后 $ROIC_{own}$ 从 12.9% 升到 **28.09%**、$\theta_x$ 从 0.819 升到 **0.917**、基准内在价值从 46 元升到 **49 元**。**方向是"原来算得太保守"**，不是更激进——因为 $d$ = 0.527 说明过半经营资本由有息负债提供，归母股东实际只投入 395.7 亿。
>
> **勾稽校验**：非经营资产 663.40 + $(IC-D)$ 439.6 = **1,103.0 ≈ 所有者权益合计 1,103.25**。成立。

#### 1.6 读数

- **内在 PE 22.5x × 2026E EPS 2.194 = 49.4 元**——这个倍数乘的是基准年 EPS，因为 [g1,g2,g3] 已经把 2027—2029 年的增长折进去了；**不能乘 2025A EPS 2.178**（会把 2026 年的增长算两遍）。
- 现价 31.18 元对应 **14.2x**，落在"零增长"（约 11.6x，25 元）与保守档（16.4x，36 元）之间、**贴近保守档下沿**。对应 2027E EPS（2.435 元）为 12.8x、PB 1.69x。
- **把 ROIC_own 压到 9%（$\theta_x$ 74%），内在 PE 仍有 20.0x（44 元）**——现价与基准之间 8.3 倍 PE 的差，资本强度解释不了，只能由利润路径解释。**这是本报告与市场分歧的全部所在。**
- 终值占总价值 54%，扩张期占 46%。

**两条必须说清的限制**

① **折现率是统一口径，不是个股判断。** R = 8.45% 对一家净利率 3.6%、增长预期被市场打到零的公司不算高；若按市场对低净利率物流股通常要求的 9.5% 折现（rf 2.7%），基准内在价值降到 **40 元**、对应 <span style="color:#d02020">+28%</span>——**方向不变，幅度缩水四成**。R 每 0.5pp 约值 2—3 元。

② **+58% 的上行几乎全部来自利润路径，而不是估值倍数。** 三年增速从基准的 +11%/+10%/+8% 换成 +1%/+2%/+3%，价值就从 49 元掉到 35 元（-29%）；而把稳态 ROIC_own 从 28.09% 压到 9%，价值只从 49 元掉到 44 元（-10%）。**模型对分母极不敏感、对分子极敏感**——原因在十年表：顺丰的扩张性支出已被账上现金全额覆盖，capex 假设要到 ×1.5 才伤及估值。

- **换股带来的结构性改变**：极兔以 4.29% 进入前十大，是 2026 年最重要的筹码事件——它不是财务投资者，而是战略对手变成的战略股东（同时顺丰持有极兔 10%）。这类交叉持股在短期是"锁定筹码"（双方都不会轻易卖出），在中长期是"战略绑定的双刃剑"（协同不成时，退出成本高）。

- **使用纪律**：筹码是验证信号，不是选股依据。本期信号是"外资/被动资金流出 + 保险/散户集中"——与基本面（扣非改善、分红率提升）**反向**。按纪律以基本面为准，但需记录：若下一期陆股通继续减持且股价不跌，说明有承接盘（保险、产业资本），反而是筹码结构改善的证据。

## 九、备注：名词解释

| 名词 | 解释 |
| --- | --- |
| 时效快递 | 承诺在约定时限内送达的快递产品，按时效分层（即日 / 特快 / 标快），单价显著高于电商件 |
| 经济快递 | 面向电商 B2C 履约的快递产品，价格敏感、件量大，与中通、圆通等在同一市场竞合 |
| 快运 / 零担 | 运输 30 公斤以上的大件货物；"零担"指不足整车的小批量货物拼车运输 |
| 票均收入 | 速运物流业务收入 ÷ 业务量（元/票），反映单价水平；其同比变化是量价结构的核心读数 |
| 单票成本 | 营业成本 ÷ 业务量，反映单位履约成本；与票均收入之差决定单票毛利 |
| 直营制 / 加盟制 | 直营制 = 网点与收派员均为公司员工（顺丰、京东物流）；加盟制 = 网点由加盟商经营（中通、圆通、韵达） |
| 全货机 / 腹舱 | 全货机 = 专门运货的飞机（顺丰自有 90 架）；腹舱 = 客机机腹的货运空间（顺丰通过合作使用 206 万次客运航班资源） |
| 航权时刻 | 航空公司在特定航线上起降的时间窗口与运输权利，属行政稀缺资源（顺丰有 357 对） |
| 鄂州货运枢纽 | 湖北鄂州的花湖国际机场，亚洲第一、全球第四座专业货运机场，顺丰以此构建"轴辐式"航空网络 |
| 轴辐式网络 | 货物先汇集到中心枢纽再分发（hub-and-spoke），用以在有限运力下实现全网时效覆盖 |
| 多式联运 | 同一票货在航空、铁路、公路、海运之间组合运输，按客户时效与成本需求匹配 |
| 仓配一体 | 把仓储与配送打包提供，客户只需对接一个物流商，库存与配送由物流商统一管理 |
| "全渠道一盘货" | 把线上、线下、To B、To C 的库存合并管理，统一由一套仓配网络履约 |
| 即时零售 / 同城即时配送 | 即时零售 = 线上下单、分钟级到家的零售形态；同城即时配送 = 为其提供 3 公里内的骑手履约 |
| 端到端供应链 | 从原料采购、生产配送、仓储、成品分销到售后回收的全链条物流服务，区别于"单点运输" |
| 独立第三方 | 不隶属于任何电商平台或流量平台的物流服务商，可同时服务所有平台（顺丰同城的定位） |
| KLN | KLN Logistics Group Limited（嘉里物流），顺丰持股 51.52% 的港交所上市公司，主营国际货代与综合物流 |
| 极兔速递（J&T） | 起家于东南亚的快递公司，2026 年 6 月与顺丰完成换股：顺丰持其 10%，其持顺丰 H 股 4.29% |
| 权益法 | 对联营企业投资按持股比例确认投资收益（而非合并报表），顺丰对极兔 10% 股权的会计处理方式 |
| 网络分层 | 把快件按产品分层走不同的网络（小件/大件分层、快慢分离），使资源与产品精准匹配以降本 |
| 反内卷 | 2025 年下半年起的行业政策导向，抑制快递低价恶性竞争、推动票均收入修复 |
| 净现比 | 经营活动现金流量净额 ÷ 归母净利润，衡量利润的现金含量；>1 说明利润有现金支撑 |
| 自由现金流 | 经营活动现金流量净额 − 资本开支，即可用于分红、回购、还债的现金 |
| 资本开支占收入比 | 购建固定资产等支付的现金 ÷ 营业收入，衡量扩张强度；下降意味着从建设期进入收获期 |
| 分红率 | 现金分红总额（含回购注销金额）÷ 归母净利润 |
| 社会物流总费用率 | 社会物流总费用 ÷ GDP，衡量一国物流效率；中国 2025 年为 13.9%，连续五年下降 |
| 票均收入修复 | 本报告用词，特指票均收入同比由负转正、并逐季回升的过程 |
