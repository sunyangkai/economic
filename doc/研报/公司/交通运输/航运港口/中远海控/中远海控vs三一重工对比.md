# 中远海控 vs 三一重工：同一把尺子下的投资价值比较

> **写作基准：2026-11-19**（两家现价均为 2026-11-19 盘中）。两家的个股结论分别见 [`中远海控.md`](中远海控.md) 与 `doc/研报/公司/机械设备/工程机械/三一重工/三一重工.md`，本文只做**同框架横比**，不重复各自的全套论证。
> **方法**：两者都是周期股，统一按 `doc/估值理论/周期股估值.md`——**PB—ROE 分位定位 + 顶部利润 × 顶部 PB 给价格带，不报目标价、不算内在 PE**。为使比较公平，两家的 PB 分位窗口都做了**剔泡沫格**处理（把 2015 牛市与 2021 超级周期这类不可重复的估值极值从分布中剔除），这是本文相对两份个股报告新增的口径。
> 数据来源：`api/quote.js`（2026-11-19 行情）、`api/kline.js`（月线不复权）、`api/balanceSheet.js`（季末 BPS）、`api/mainFinanceData.js`（ROE 与年报）、`api/orgForecast.js`（一致预期）。

## 一、结论先行

**如果只能选一个：中远海控。**

不是因为它的成长性更好（正好相反），而是因为**同样的"周期不便宜"判断下，中远海控付出的价格低得多、拿到的现金回报高得多，而它最大的风险（供给过剩）已经被市场定价、下行有明确的资产垫**。三一重工是一家更好的公司，但要为它付的价格已经包含了"周期属性改变"这件**尚未验证**的事。

| 维度 | 中远海控 | 三一重工 | 胜方 |
| --- | --- | --- | --- |
| 现价 / 市值 | 17.39 元 / 2,646 亿 | 18.81 元 / 1,730 亿 | — |
| PB | **1.10×** | 1.84× | 中远（低 40%） |
| PE-TTM | **7.7×** | 18.6× | 中远 |
| **正常化 PE**（剔极值年份的中位利润） | **11.1×** | 29.0× | 中远（差 1.6 倍） |
| **剔除净现金后 PE**（2026E） | **3.9×** | 13.5× | 中远 |
| 净现金 / 市值 | **42%** | 21% | 中远 |
| 股息率（2026E） | **7.4%** | 2.9% | 中远 |
| 2026E 利润增速 | -3%（vs 一致预期） | **+20%** | 三一 |
| 2027E / 2028E 增速 | -21% / -13% | **+32% / +20%** | 三一 |
| 前瞻 ROE（2028E） | **9.7%**（下行） | 15.1%（上行） | 三一 |
| 周期位置 | 高位回落中（利润为峰值的 35%） | **上行中段**（利润为峰值的 65%） | 三一 |

| 定价权实证 | **无**（运价随行就市，SCFI -37% 即毛利 -9.79pp） | **有**（2026.5 挖机提价 +5%、8 月扩至起重机，徐工/柳工跟涨） | 三一 |
| 最大的风险 | 供给过剩（已定价） | "周期属性改变"未验证 + 汇率 + 反倾销 | 平 |

**一句话：三一是"贵一点的成长型周期股"，中远是"很便宜的收租型周期股"。** 前者赌的是 ROE 修复能否延续三年，后者赌的是运价别崩——而后者已经用 42% 的净现金和 7.4% 的股息率给了你补偿。

## 二、为什么"PB 分位"这一个指标会骗人

两份个股报告都给了 PB 分位：中远 33%、三一 12%。单看这个数，会得出"三一更便宜"的结论——**这是本次比较里最需要纠正的一点**。

| | 中远海控 | 三一重工 |
| --- | ---: | ---: |
| 窗口 | 2015-01 — 2026-11 | 2019-01 — 2026-11 |
| 全样本 PB 中位 | 1.86× | 2.30× |
| **剔泡沫后中位** | **1.43×** | **2.14×** |
| 现价 PB | 1.10× | 1.84× |
| 全样本分位 | 33.1% | 12.0% |
| **剔泡沫后分位** | **38.1%** | **14.9%** |
| **距剔泡沫中位** | **-23%** | **-14%** |

**两个纠正**：

- **分位数不可比，是窗口造成的**。中远的窗口含 2015 年牛市（PB 6.7×）与 2021 年运价超级周期（PB 6.3×）两个极端，把中位拉到 1.86×；三一的窗口从 2019 年起，恰好避开了 2015 年那一段。剔掉泡沫格后，两者的"距中位距离"从"三一更便宜"变成 **中远便宜 23%、三一便宜 14%**。
- **但分位低本身也不等于便宜**。三一的 14.9% 分位，是在**自己的历史里**低；而它的历史（2019—2026）恰好是 ROE 从 29.55% 一路掉到 6.67% 再修复到 11.18% 的完整一轮。**在一个 ROE 中枢不断下移的历史里，PB 分位会自动显得低**——2020 年三一 ROE 29.55% 时 PB 能到 6.1×，如今 ROE 11% 时 PB 1.84×，这在数学上是自洽的，不是错杀。

**所以 PB 分位只能当刻度，不能当结论。** 真正决定投资价值的是下面三件事。

## 三、决定投资价值的三件事

### 1. 价格：付了多少钱（中远明显便宜）

| 口径 | 中远海控 | 三一重工 | 说明 |
| --- | ---: | ---: | --- |
| PE-TTM | **7.7×** | 18.6× | 当期利润口径，周期股仅作参照 |
| 正常化 PE（剔极值年中位） | **11.1×** | 29.0× | 中远取 2023/25/19/20/24 中位 238.6 亿；三一取 2022—25 加 2021 中位 59.6 亿 |
| 2026E PE（一致预期） | 6.8× | 17.2× | — |
| **剔除净现金后 2026E PE** | **3.9×** | **13.5×** | 中远净现金 1,112 亿（占市值 42%）；三一约 369 亿（21%） |

**这张表告诉我们**：无论用哪个口径，中远都比三一便宜一个量级。**最关键的是"剔净现金后"这一行**——中远的市值里有 42% 是现金，买它等于用 10 元买一家每年赚 2.56 元/股的公司；三一的现金只占 21%，要付 14.8 元买 1.09 元/股。

> **口径提醒**：净现金不参与估值是周期股框架的设计约定（`周期股估值.md` §三），上表只为说明"付了多少钱"，**不作为目标价依据**。

### 2. 周期位置：利润在往上还是往下（三一明显更好）

| | 中远海控 | 三一重工 |
| --- | --- | --- |
| 当前单季利润 | 172 亿（2026Q3） | 23.1 亿（2026Q3） |
| 历史单季峰值 | 372 亿（2022Q2） | 63.5 亿（2020Q2） |
| **完成度** | **46%** | **36%** |
| 年度口径完成度（2026E/峰值年） | 35%（389 / 1,097） | **65%**（100.7 / 154.3） |
| 方向 | **从峰值往下**（2023 已跌 73%） | **从底部往上**（2022 见底后连升四年） |
| 领先信号 | 在建工程/固资 11.3%→**18.0%（已转升，顶部前兆）** | 在建工程/固资 **5.0%（仍是出清特征）** |
| 前瞻 ROE | 16.0% → 11.8% → **9.7%**（三年下行） | 10.7% → 13.4% → **15.1%**（三年上行） |

**这张表告诉我们**：这是两家公司最本质的区别。**中远现在是"利润还在高位、但方向已经向下"**——单季 172 亿看似不错，可年度利润只有峰值的 35%，且在建工程已经转升，这是教科书式的顶部前兆。**三一是"利润在低位、方向向上"**——在建工程只有固定资产的 5%，是彻底的出清特征，ROE 从 6.67% 修复到 11.18% 且还在爬。

**周期股的钱，赚的是"位置"不是"便宜"。** 从这一条看，三一的胜面大很多——这正是它 PE 20 倍还能被机构给出 +32%/+20% 增速预期的原因。

### 3. 下行保护：跌下去有多少垫（中远明显更好）

| | 中远海控 | 三一重工 |
| --- | ---: | ---: |
| 净现金 / 市值 | **42%** | 21% |
| 股息率（2026E，按 50% 派息） | **7.4%** | 2.9% |
| 资产负债率 | **41.4%** | 48.7% |
| 净现比（最新） | 1.56× | 1.54× |
| 历史极值 PB | 0.73×（2023） | 1.63×（2016） |
| 跌到极值 PB 的空间 | **-24%** | +4%（已在极值附近） |

**这张表告诉我们**：向下看，中远的跌幅空间更大（-24% vs +4%），但**它每跌一年给你 7.4% 的股息**，而且市值里 42% 是现金——**跌下去的同时垫子也在变厚**。三一的 PB 已经贴近自己的历史极值（1.78×），看似"跌无可跌"，但它的历史极值 1.63× 是在 2016 年公司几乎不赚钱（ROE 0.89%、归母 2.0 亿）时创下的——**如果这一轮再来一次那样的下杀，1.63× 并不是铁底**（三一 2015—2016 年的 PB 曾从 3.16× 跌到 1.63×，跌了一半）。

## 四、两个情景表：两年后各能拿到什么

把两家放在同一张表里，用**剔泡沫后的中位 PB** 当"中性"，用历史极值当"悲观"、用本轮顶部 PB 当"乐观"，都算上两年股息：

| 情景 | 中远海控（现价 17.39） | 三一重工（现价 18.81） |
| --- | --- | --- |
| **悲观**（回到自身历史极值 PB） | PB 0.85 → 15.3 元，含息 17.6 元，<span style="color:#d02020">+1%</span> | PB 1.78 → 21.3 元，含息 22.5 元，<span style="color:#d02020">+20%</span> |
| **中性**（回到剔泡沫中位 PB） | PB 1.43 → 25.8 元，含息 28.1 元，<span style="color:#d02020">+62%</span> | PB 2.14 → 25.6 元，含息 26.8 元，<span style="color:#d02020">+43%</span> |
| **乐观**（回到本轮顶部 PB） | PB 3.12 → 56.3 元，含息 58.6 元，<span style="color:#d02020">+237%</span> | PB 4.12 → 49.3 元，含息 50.5 元，<span style="color:#d02020">+168%</span> |

> 参数：2028 年末 BPS——中远 18.04 元（2026Q3 的 15.876 + 两年留存 ÷ 152.18 亿股）、三一 11.95 元（同样算法）。两年股息——中远 2.29 元（2026/2027 各按 50% 派息）、三一 1.27 元。**这是"回到自己历史中位"的机械测算，不是目标价**；两家回到中位需要的前提完全不同（见下）。

**这张表告诉我们一件反直觉的事**：**中性情景下中远的空间（+62%）反而大于三一（+43%）**——因为中远现价离自己的中位更远（-23% vs -14%）。但**悲观情景下三一明显更有韧性（+20% vs +1%）**，因为它的 PB 已经贴着历史底、而中远的 PB 在 38% 分位还有下探空间。

**所以"谁更有投资价值"取决于你问的是哪个问题**：

- 问"**现在这个价格，往上空间谁大**"——中远（因为更便宜）；
- 问"**我买的这家公司在变好还是变坏**"——三一（因为 ROE 在上行）；
- 问"**跌的时候谁更扛得住**"——三一（PB 已贴底，且有 +32% 的机构增利预期作缓冲），但中远靠股息和净现金扛。

## 五、两家的真实分歧在哪（各自的成与败）

### 中远海控：便宜是真的，但它便宜得有理由

- **为什么便宜**：市场在给它的下一轮 ROE 打折。PB 1.10× 意味着市场认定这 16% 的 ROE 不可持续——**而这与供给面的实际情况一致**：2026 年行业运力 +4.2% vs 需求 +2.5%—3.0%，公司自己的在建工程已从 11.3% 转到 18.0%，手持订单相当于现有运力 32%。**便宜不是错杀，是定价。**
- **那它的价值在哪**：不在运价弹性，在**1,112 亿净现金 + 7.4% 股息率 + 50% 派息规划**。近三年累计分红与回购注销 542.62 亿，是同期年均净利的 156.78%——这是一台"周期赚了钱就分掉"的机器。
- **什么会让它证伪**：CCFI 季度均值跌破 1,000 点、红海复航一次性释放 7%—9% 有效运力。**这两个风险都写在明面上，市场已经price in 了一部分。**

### 三一重工：公司更好，但价格已经把好事算进去了

- **为什么更好**：护城河更实（海外毛利占 71%、海外毛利率 31.64% 是国内 1.53 倍、四大品类电动化市占第一），**而且有中远完全没有的东西——定价权实证**：2026 年 5 月全系列挖机提价 +5%、8 月扩至起重机，徐工、柳工、山推跟进。**一家能在三年价格战后率先提价且同行跟涨的公司，和中远这种运价随行就市、SCFI 一跌 37% 毛利率就掉 9.79pp 的公司，护城河不在一个层级。**、周期位置更好（ROE 上行、在建工程 5% 的出清特征）、一致预期三年 CAGR 约 +25%。
- **价格里的问题**：正常化 PE 29 倍（剔极值年）。**市场付的是"周期属性改变"的价钱**——即"这轮不会再像 2015 年那样跌到不赚钱"。而这件事有两个尚未落地的变量：**欧盟反倾销终裁（2026-12-19 / 硬顶 2027-02-19，压着 125 亿欧洲收入，三季报未计提）** 与 **汇率（9M 汇兑损失约 29.7 亿，已超全年基准区间上沿）**。
- **什么会让它证伪**：若"周期属性改变"被证伪、回到国内周期股定价（8—11×），从 17.2× 的 2026E PE 看仍有显著下修空间。

## 六、选择建议

| 如果你是 | 选中远海控 | 选三一重工 |
| --- | --- | --- |
| 追求当期现金回报 | ✅ 7.4% 股息率 + 42% 净现金垫 | ❌ 2.9% |
| 追求两年内的赔率（回到自身中位） | ✅ +62% | ⚠️ +43% |
| 追求"公司基本面在变好"的确定性 | ❌ ROE 三年从 16.0% 降到 9.7% | ✅ ROE 三年从 10.7% 升到 15.1% |
| 能接受的最坏情况 | 需承受 -24% 到历史极值（但有股息） | 已贴历史底（+4%），但历史上曾跌一半 |
| 容忍的持有周期 | 1—3 年（吃股息 + 等运价再起） | 2—4 年（等海外份额与国内置换兑现） |

**最终判断**：**中远海控更具投资价值，但这是"便宜 + 现金回报"的胜利，不是"生意更好"的胜利。** 三一重工是更优质的资产，只是当前 29 倍正常化 PE 已经把它能做的好事定价了；在"周期属性改变"和"反倾销终裁"落地之前，它为投资者留的安全边际比中远薄。

**给一个可操作的分界线**（以当前 BPS 10.25 元计）：若三一因反倾销终裁或人民币继续升值跌到 **PB 1.6×（约 16.4 元，较现价 -13%，2026E PE 15.0×）**，两家的性价比会接近；跌到 **PB 1.4×（约 14.3 元，-24%，2026E PE 13.1×）**，三一将反过来更具投资价值——因为它是那个 ROE 在往上的公司。**反过来说，中远的"便宜"是有底的：一旦运价证伪（CCFI 破 1,000）或红海复航，它跌到 0.73× 历史极值（约 13.2 元）也只需 -24%，与三一跌到 1.4× 的幅度相同——而那时中远还拿着 7.4% 的股息。**
