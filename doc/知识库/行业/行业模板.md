# 行业研究模板

> **这份模板和公司研报模板不是同构的。** 公司研究从一家公司的报表出发，行业研究从一组"量、价、供、利"的关系出发。写作时先找核心矛盾，再用数据填空；不要求每一节都写满，但核心矛盾必须贯穿始终。
>
> **推荐写作顺序**：先写「一、结论卡片」的初稿（哪怕粗糙）→ 再填「二、行业定义」和「三、核心矛盾」→ 用「四～七」的数据去验证、修正核心矛盾 → 最后回填结论卡片，补上「八、景气指标」「九、标的映射」「十、风险」和「十一、跟踪日历」。

---

## 一、结论卡片

这一页是全文的纲。先写初稿，最后回填；所有后续章节都在论证或反驳这几行。

| 项目 | 内容 |
| --- | --- |
| 一句话判断 | 这个行业未来 1—3 年最重要的变化是什么 |
| 周期位置 | 萌芽 / 成长 / 成熟 / 出清 / 修复 / 不确定 |
| 核心矛盾 | 供给 vs 需求？价格 vs 量？政策 vs 市场？集中 vs 分散？ |
| 未来 12 个月最关键验证信号 | 一个可观察的数据点 |
| 谁受益 / 谁受损 | 一句话各列一类 |

---

## 二、行业定义与产业链

先讲清楚"这个行业到底在赚什么钱"，再画产业链。这是后面所有分析的坐标系，避免讨论范围漂移。

**行业本质（一句话）**：这个行业的钱，本质上是赚什么？是成本领先、品牌溢价、政策牌照、渠道周转，还是别的？

**产业链全景表**

| 环节 | 主要参与者 | 提供的价值 | 议价权（高/中/低） | 利润率水平 |
| --- | --- | --- | --- | --- |
| 上游 | | | | |
| 中游 | | | | |
| 下游 | | | | |

**边界与口径**：行业规模怎么算，包含什么、不包含什么。写清口径是为了让"量价供利"四节的数据能对齐，否则上下游、渠道、终端各说各话。

---

## 三、核心矛盾（全文的纲）

这是行业模板和公司模板最大的不同：行业分析要有主线，不能把供需、格局、政策平铺成清单。好的核心矛盾是一组**两难**——一边是 A，一边是 B，当前天平倾向哪边，未来可能往哪边转。

**核心矛盾**：写一段话，说清这个行业的根本张力是什么。

- 矛盾 A 侧（现有力量）：……（附关键数据）
- 矛盾 B 侧（新生力量）：……（附关键数据）
- 当前谁占上风：……
- 天平可能翻转的条件：……

**证伪条件**：出现什么数据，就说明当前判断错了。这是全篇最重要的一句话——它决定了这份报告什么时候该被推翻，而不是被事后解释。

> **示例**：白酒的核心矛盾不是"消费升级 vs 消费降级"，而是"量缩 vs 价升"——产量 -70%，龙头靠提价撑起利润。因此证伪条件不是社零转弱，而是**飞天 / 普五的批价中枢下移**；批价一旦跌破某个位置，行业逻辑就变了。
>
> **示例**：医疗集采的核心矛盾是"医保降价 vs 龙头以量换价"——价格中枢下移是确定的，真正要判断的是龙头能否靠份额提升和成本领先把量的弹性补回来。证伪条件是**续约二次降价后，龙头市占率停止上升**。

---

## 四、量：需求从哪来，天花板在哪

回答"行业的总盘子还有多大、增量来自哪里"。把需求拆成三层，而不是笼统写"需求增长"。

**需求三层来源**：

1. **存量替换**：已有市场的更新换代，占比多少。
2. **新增渗透**：从无到有的新增用户 / 场景 / 区域，当前渗透率多少、上限在哪。
3. **结构升级**：量的盘子不变，但产品结构向高价值迁移。

**关键指标**：渗透率、人均消费量、下游景气、场景数量。每个指标写当前值 + 趋势。

**成色判断**：这层需求是政策托底、低基数修复、还是内生增长？三者持续性天差地别，必须拆开写，不能混为一谈。

---

## 五、价：定价权在谁手里

回答"价格还能不能涨、谁说了算"。价格是这个行业利润的开关，要写清楚形成机制，而不是只贴一个价格走势。

**价格形成机制**：成本加成 / 品牌溢价 / 政策定价 / 供需定价，属于哪一种（或混合）。

**价格现状**：历史中枢、当前价格、最近一次大幅波动的触发原因。

**定价权判断**：价格能不能继续涨？由谁决定？涨价的传导链是否通畅（上游涨价能否转嫁给下游，还是中游被两头挤压）？

---

## 六、供与库：产能和库存是行业的"体温计"

需求看天花板，供给看地板。这一节回答"行业现在是在扩、在缩，还是在出清"。

**供给状态**：扩产 / 退出节奏、产能利用率、在建产能规模、行业资本开支方向。

**库存位置**：上游、渠道、终端三个环节的库存各在什么位置。只写一个环节的库存容易误判——厂家库存下降有时只是把货压到了渠道。

**出清信号**：什么样才算供给出清完成？给出一个可观察的标志（如"中小厂关停家数""行业开工率回升到 X%"）。

---

## 七、利：利润沿着产业链流向谁

量、价、供都讲完后，看利润最终被谁拿走。这是行业研究里最有信息量、也最容易写出判断的一节。

**各环节利润率与趋势**：上游 / 中游 / 下游各赚多少，过去 2—3 年如何变化。

**议价权转移方向**：利润正在从哪个环节流向哪个环节，为什么。

**集中度**：CRn、龙头份额、追赶者。集中度是慢变量，但它一旦形成趋势，往往比短期价格更确定——行业调整期是龙头吃小厂份额的窗口。

---

## 八、景气度指标体系

把核心矛盾翻译成一张"仪表盘"，用先行 / 同步 / 滞后三层来盯，每层都要有**阈值、频率、来源**，否则指标只是摆设。

| 层级 | 指标 | 阈值 / 信号 | 频率 | 来源 |
| --- | --- | --- | --- | --- |
| 先行 | | | | |
| 同步 | | | | |
| 滞后 | | | | |

**判读要点**：滞后指标用来验证逻辑是否兑现，先行指标用来提前预警。特别注意"价格再定价"类信号（如集采续约价、白酒批价、大宗商品报价）——它们往往既是确认信号，又是下一轮的先行信号。

## 九、标的映射

行业模板的终点，是把行业结论落到个股。行业本身没有估值，结论必须回答"这个判断里，谁直接受益、谁间接受损"。

| 标的 | 定位（直接受益 / 间接受益 / 受损 / 不确定） | 一句话逻辑 | 对应研报 |
| --- | --- | --- | --- |
| | | | |

> 这一步是行业模板和公司研报模板的衔接点：行业模板里"谁受益"的判断，正是打开某份公司研报的理由。

## 十、风险与证伪清单

核心矛盾的逆命题，按影响程度排序。每条写成"**如果发生什么 → 会造成什么后果**"，不写空话。风险不是凑字数，而是提醒自己在什么情况下这份报告作废。

## 十二、数据边界与待更新

写清哪些是已确认的事实、哪些是待验证的假设、以哪个官方口径为准。历史数据与仓库研报口径冲突时，以官方公告为准；每次拿到新数据就往「八、景气指标」和「十、风险」里回填。
