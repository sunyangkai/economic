## 命名与维护规则

- **文件名 = 报告期**：`YYYY年M月.md`，M 取该期**最后一份完整财报的报告期月份**（一季报 3 / 中报 6 / 三季报 9 / 年报 12），不是撰写月份；
- **触发**：每期财报（或重大行业事件，如国谈结果、审批大改革）后新建当期文件，**不覆盖历史文件**；
- **做法**：复制上一期文件 → 更新头部"本期版本 / 数据边界 / 更新要点"→ 替换数据 → **滚动修订核心判断**（不是简单追加）；
- **口径**：每期文件头部必须写清"本期数据边界"（A 股代表公司财报到哪一期、港股到哪一期、行业数据到哪个月、政策到哪个节点），因为行业数据的更新节奏与公司财报不同步；
- 数据以官方发布为准（NMPA 审评报告与获批公告、国家医保局国谈与商保目录、国家卫健委基药目录、公司财报与公告），跨期比较注意基期与口径变化。

## 本行业的三条特有口径（每期必读）

1. **获批数量有三套口径**：NMPA 发布会口径（"2025 年批准创新药 76 个"）、NMPA《药品审评报告》口径（"获批创新药 34 个"）、行业统计口径（"1 类新药 77 款"）。**引用时必须注明口径**，不可拼成增速曲线；2026 年起统一以"1 类创新药"为准。
2. **BD 交易额 ≠ 收入 ≠ 利润**：交易总额含里程碑（非当年现金流）、许可收入按履约义务进度确认、到账现金才是真的。**三个口径必须分开写**（行业总额 / 公司许可收入 / 公司现金流入）。
3. **扣非在 Biotech 上部分失效**：授权首付款计入经常性损益，扣非无法剔除。看创新药公司必须同时看"归母、扣非、剔除 BD 后的产品销售"三个口径。
