## 命名与维护规则

- **文件名 = 报告期**：`YYYY年M月.md`，M 取该期**最后一份完整财报的报告期月份**（一季报 3 / 中报 6 / 三季报 9 / 年报 12），不是撰写月份；

- **触发**：每期财报（或重大行业事件）后新建当期文件，**不覆盖历史文件**；

- **做法**：复制上一期 → 更新头部"数据边界 / 本期专题" → 替换数据 → **滚动修订核心判断**（不是追加）→ **回填"上期核对"表**（上期判断逐条标兑现 / 证伪）；

- **月度数据在报告期内滚动更新**（如 `2026年9月.md` 的月度销量已到 10 月），**只有跨报告期才新建文件**；

- **口径**：头部必须写清"数据边界"（月度销量到几月、出口额到几月、公司财报到哪一期、海外龙头到哪一季），因为行业数据与公司财报更新节奏不同步；

- 数据以官方发布为准（CCMA 快报一 / 二、海关进出口快报、公司财报、卡特 / 小松 IR），跨期比较注意基期与口径变化。

## 本行业的三条特有口径（每期必读）

1. **快报一 ≠ 快报二**：快报一含挖机 + 装载机（次月 7—10 日），快报二含起重 / 路面 / 桩工 / 工业车辆 / 高空（次月 16—18 日），**不可混算**。只看快报一会把"土方正增长"误读成"内外双旺"——**判断内需真伪必须看快报二的非土方内销**。

2. **单月同比 ≠ 趋势**：2026 年挖机内销单月同比已被基数搅乱 5 次（2 月 -42.0%、3 月 +23.5%、5 月 +38.6%、7 月 +4.1%、10 月 +12.2%）。**趋势一律用两年 CAGR + 绝对量**，单月同比只作拐点观察。

3. **台数 ≠ 金额**：协会台数（CCMA）与出口额（海关）是两套口径，**不能相除算单价**；单价只能用同口径海关金额 ÷ 海关台数。
