## 命名与维护规则

- **文件名 = 报告期**：`YYYY年M月.md`，M 取该期**最后一份完整财报的报告期月份**（一季报 3 / 中报 6 / 三季报 9 / 年报 12），不是撰写月份；
- **触发**：每期财报（或重大行业事件）后新建当期文件，**不覆盖历史文件**；
- **做法**：复制上一期文件 → 更新头部"本期版本 / 数据边界 / 更新要点"→ 替换数据 → **滚动修订核心判断**（不是简单追加）；
- **口径**：每期文件头部必须写清"本期数据边界"（月度销量到几月、公司财报到哪一期、海外龙头到哪一季），因为行业数据的更新节奏与公司财报不同步；
- 数据以官方发布为准（协会快报一/二、海关进出口快报、公司财报、卡特/小松 IR），跨期比较注意基期与口径变化。

| 维度 | 2026年6月（归档） | 2026年9月（最新） | 变化性质 |
