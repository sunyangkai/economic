# 面馆三表案例：从一碗面到资产负债表、利润表、现金流量表

> **用途**：用一个最小可复算的经营案例，讲清三张财务报表怎么编、怎么互相勾稽、以及"赚钱"和"有现金"为什么不是一回事。
> **性质**：教学案例。全部数字为假设，不是真实企业；单位统一为**元**，期间为**经营第一年**。
> **定位**：`doc/知识库/` 下的财务阅读基础材料，供读公司财报前建立"三表联动"直觉；不构成任何公司判断。
> **状态**：v1，2026-10-28。数据来源：案例假设自洽，全部勾稽已用脚本复算。

---

## 一、案例设定

老王开了一间 80 平方米的面馆，堂食 + 外卖，注册为有限责任公司。为把问题压到最小，做四条简化：

1. **增值税简化**：收入、成本均为不含税口径，不单独处理进销项税；
2. **无应收账款**：堂食即时收款，外卖平台账期忽略，销售全部当年收现；
3. **无期初余额**：第一年开业，期初除现金外无存货、无固定资产；
4. **直线法**：装修按 3 年摊销，设备按 5 年折旧，均无残值。

### 1.1 经营假设

| 项目 | 假设 | 年金额 |
|---|---|---:|
| 经营规模 | 日均约 200 碗，客单价 25 元，年营业 360 天 | — |
| 营业收入 | 200 × 25 × 360 | 1,800,000 |
| 食材成本率 | 40% | 720,000 |
| 人工 | 4 名员工（含老王不领薪） | 342,000 |
| 租金 | 月租 22,500 | 270,000 |
| 水电燃气 | — | 72,000 |
| 外卖佣金及营销 | — | 54,000 |
| 清洁、耗材、保险及杂费 | — | 72,000 |

### 1.2 投资、融资与营运资本

| 项目 | 假设 | 金额 |
|---|---|---:|
| 初始投入 | 装修 120,000（3 年摊销）+ 设备 80,000（5 年折旧） | 200,000 |
| 租赁押金 | 一次性支付，退租时收回 | 30,000 |
| 股东投入 | 开业时实缴 | 300,000 |
| 银行借款 | 100,000，年利率 5%，第一年只付息不还本 | 100,000 |
| 期初现金 | 股东投入 + 借款，均已到账 | 400,000 |
| 期末存货 | 食材库存 | 45,000 |
| 期末预付租金 | 已付未耗用的租金 | 45,000 |
| 期末应付账款 | 供应商货款未付 | 60,000 |
| 期末应付职工薪酬 | 12 月工资跨年发放 | 30,000 |
| 期末应交税费 | 全部为应交企业所得税 | 10,000 |
| 当年股利 | 股东分红 | 50,000 |

> 折旧摊销：装修 120,000 ÷ 3 = **40,000**；设备 80,000 ÷ 5 = **16,000**；合计 **56,000**。

## 二、利润表

利润表回答"这一年赚了多少"，按**权责发生制**确认——收入在卖出时确认，费用在耗用时确认，与钱什么时候进出无关。

| 项目 | 金额 | 占收入 |
|---|---:|---:|
| 营业收入 | 1,800,000 | 100.0% |
| 减：营业成本（食材） | 720,000 | 40.0% |
| **毛利** | **1,080,000** | **60.0%** |
| 减：期间费用 | 866,000 | 48.1% |
| 　职工薪酬 | 342,000 | 19.0% |
| 　租金 | 270,000 | 15.0% |
| 　水电燃气 | 72,000 | 4.0% |
| 　外卖佣金及营销 | 54,000 | 3.0% |
| 　清洁、耗材、保险及杂费 | 72,000 | 4.0% |
| 　折旧与摊销 | 56,000 | 3.1% |
| **营业利润（EBIT）** | **214,000** | **11.9%** |
| 减：利息费用（100,000 × 5%） | 5,000 | 0.3% |
| **利润总额（EBT）** | **209,000** | **11.6%** |
| 减：所得税费用（25%） | 52,250 | 2.9% |
| **净利润** | **156,750** | **8.7%** |

三个读数：

- **毛利率 60%**，是面馆的生死线。食材成本率每变动 1 个百分点，按 180 万元收入计，税前利润直接变动 18,000 元。
- **净利率 8.7%**，一碗 25 元的面净赚约 2.18 元。餐饮业净利率普遍在 5%—10%，这个案例属于"生意不错但经不起折腾"的水平。
- **折旧摊销 56,000 元**是账面费用，本年没有对应的现金流出——它是过去 200,000 元投入的分摊。这一条是理解后面现金流量表的关键。

## 三、资产负债表

资产负债表是**时点照片**：期末这一天，钱变成了什么（资产）、欠了谁（负债）、真正属于股东的是多少（所有者权益）。

| 项目 | 期初 | 期末 | 变动 |
|---|---:|---:|---:|
| **资产** |  |  |  |
| 货币资金 | 400,000 | 342,750 | −57,250 |
| 存货 | 0 | 45,000 | +45,000 |
| 预付租金 | 0 | 45,000 | +45,000 |
| **流动资产合计** | **400,000** | **432,750** | **+32,750** |
| 长期待摊费用——装修 | 0 | 80,000 | +80,000 |
| 固定资产——设备（净值） | 0 | 64,000 | +64,000 |
| 租赁押金 | 0 | 30,000 | +30,000 |
| **非流动资产合计** | **0** | **174,000** | **+174,000** |
| **资产总计** | **400,000** | **606,750** | **+206,750** |
| **负债** |  |  |  |
| 应付账款 | 0 | 60,000 | +60,000 |
| 应付职工薪酬 | 0 | 30,000 | +30,000 |
| 应交税费 | 0 | 10,000 | +10,000 |
| **流动负债合计** | **0** | **100,000** | **+100,000** |
| 长期借款 | 100,000 | 100,000 | 0 |
| **负债合计** | **100,000** | **200,000** | **+100,000** |
| **所有者权益** |  |  |  |
| 实收资本 | 300,000 | 300,000 | 0 |
| 未分配利润 | 0 | 106,750 | +106,750 |
| **所有者权益合计** | **300,000** | **406,750** | **+106,750** |
| **负债和所有者权益总计** | **400,000** | **606,750** | **+206,750** |

### 3.1 三个容易记错的科目

| 支出 | 记到哪 | 为什么 |
|---|---|---|
| 装修 120,000 | 长期待摊费用，3 年摊完 | 受益期跨年，不能一次性进当年费用 |
| 设备 80,000 | 固定资产，5 年折旧 | 同上，按使用年限分摊 |
| 押金 30,000 | 租赁押金（资产） | 钱没花掉，只是换了个形态，退租能收回；**不是费用** |
| 期末库存食材 45,000 | 存货（资产） | 买了没耗用，成本还没发生 |
| 预付租金 45,000 | 预付租金（资产） | 钱付了、店还没用，属于未来的费用 |

### 3.2 权益变动

```text
期初未分配利润            0
+ 本年净利润        156,750
− 本年股利           50,000
= 期末未分配利润    106,750
```

资产端净值核对：

```text
装修：120,000 − 40,000 = 80,000
设备： 80,000 − 16,000 = 64,000
```

## 四、现金流量表

现金流量表只认**钱的实际进出**，按经营、投资、筹资三类归集。习惯上用间接法从净利润倒推，再用直接法验算。

### 4.1 间接法

| 项目 | 金额 |
|---|---:|
| **一、经营活动现金流量** |  |
| 净利润 | 156,750 |
| 加：折旧与摊销 | 56,000 |
| 存货增加 | −45,000 |
| 预付租金增加 | −45,000 |
| 应付账款增加 | +60,000 |
| 应付职工薪酬增加 | +30,000 |
| 应交税费增加 | +10,000 |
| **经营活动现金净流量（CFO）** | **222,750** |
| **二、投资活动现金流量** |  |
| 装修支出 | −120,000 |
| 设备购置 | −80,000 |
| 支付租赁押金 | −30,000 |
| **投资活动现金净流量（CFI）** | **−230,000** |
| **三、筹资活动现金流量** |  |
| 分配股利 | −50,000 |
| **筹资活动现金净流量（CFF）** | **−50,000** |
| **四、现金净增加额** | **−57,250** |
| 加：期初现金余额 | 400,000 |
| **五、期末现金余额** | **342,750** |

> 借款本金 100,000 在期初已到账，属于期初余额，不在本年筹资活动里重复计；本年筹资活动只有分红一笔。

### 4.2 直接法验算

| 项目 | 计算 | 金额 |
|---|---|---:|
| 销售收现 | 收入 1,800,000（无应收） | 1,800,000 |
| 采购付现 | 采购 765,000 − 应付增加 60,000 | −705,000 |
| 工资付现 | 342,000 − 应付工资增加 30,000 | −312,000 |
| 租金付现 | 270,000 + 预付租金增加 45,000 | −315,000 |
| 水电燃气付现 | — | −72,000 |
| 外卖佣金及营销付现 | — | −54,000 |
| 其他付现 | — | −72,000 |
| 利息付现 | — | −5,000 |
| 所得税付现 | 52,250 − 应交税费增加 10,000 | −42,250 |
| **经营活动现金净流量** | 合计 | **222,750** |

两条路径相等。关键推导：

```text
采购额   = 营业成本 720,000 + 期末存货 45,000 − 期初存货 0 = 765,000
采购付现 = 765,000 − 应付账款增加 60,000 = 705,000
租金付现 = 270,000 + 45,000 = 315,000
工资付现 = 342,000 − 30,000 = 312,000
```

## 五、三表勾稽

| 勾稽关系 | 验证 |
|---|---|
| 净利润 → 未分配利润 | 0 + 156,750 − 50,000 = 106,750 ✅ |
| 净利润 → 经营现金流 | 间接法以净利润 156,750 起算 ✅ |
| 折旧摊销 | 利润表费用 56,000 = 现金流量表加回 56,000 = 非流动资产投入 200,000 − 账面 144,000 ✅ |
| 投资支出 → 非流动资产 | 现金投入 230,000 − 折旧摊销 56,000 = 非流动资产 174,000 ✅ |
| 期末现金 | 现金流量表 342,750 = 资产负债表货币资金 342,750 ✅ |
| 会计恒等式 | 资产 606,750 = 负债 200,000 + 权益 406,750 ✅ |

用一张图表示：

```text
利润表 净利润 156,750
   ├──→ 现金流量表间接法起点
   └──→ 资产负债表 未分配利润 +106,750（已扣股利 50,000）

现金流量表 期末现金 342,750 ───→ 资产负债表 货币资金 342,750
```

> 勾稽不是"碰巧相等"，而是同一套复式记账的三种切面。只要分录记得对，三表必然自洽；对不上，一定是某处把"资本化/费用化""收付实现/权责发生"搞混了。

## 六、关键财务比率

| 指标 | 计算 | 结果 | 解读 |
|---|---|---:|---|
| 毛利率 | 1,080,000 ÷ 1,800,000 | 60.0% | 食材成本是最大变量 |
| 净利率 | 156,750 ÷ 1,800,000 | 8.7% | 一碗面净赚约 2.18 元 |
| ROE（平均权益） | 156,750 ÷ 353,375 | 44.4% | 第一年权益基数小，偏高，不宜外推 |
| 净现比（CFO/净利润） | 222,750 ÷ 156,750 | 1.42 | 利润有现金支撑，>1 |
| 流动比率 | 432,750 ÷ 100,000 | 4.33 | 短期偿债无压力 |
| 速动比率 | (432,750 − 90,000) ÷ 100,000 | 3.43 | 剔除存货与预付后仍充裕 |
| 资产负债率 | 200,000 ÷ 606,750 | 33.0% | 杠杆温和 |
| 利息保障倍数 | 214,000 ÷ 5,000 | 42.8 倍 | 利息负担很轻 |
| 总资产周转率 | 1,800,000 ÷ 606,750 | 2.97 次 | 小餐饮的典型高周转 |
| 自由现金流 | CFO 222,750 − 资本开支 200,000 | 22,750 | 扣除押金后为 −7,250 |

**注意 ROE 的分母**：第一年是从 0 起算，用期末权益会得到 38.5%，用平均权益 44.4%，都显著高于成熟期水平——因为权益还没靠留存利润滚大。跨年比较时必须统一口径。

## 七、这个案例真正想说明的三件事

### 7.1 利润 ≠ 现金

净利润 156,750 元，经营现金流 222,750 元，多出 66,000 元，来自两处：

- **折旧摊销 56,000**：计入费用但不付现，所以要加回；
- **营运资本净贡献 10,000**：占用项（存货 45,000 + 预付租金 45,000 = 90,000）小于来源项（应付账款 60,000 + 应付工资 30,000 + 应交税费 10,000 = 100,000）。

反过来说，如果面馆为了备货把存货堆到 150,000，或者预付了全年租金，经营现金流就会明显低于净利润——**利润表好看、账上没钱**，是餐饮倒闭最常见的原因。

### 7.2 经营赚钱，现金仍可能减少

经营赚了 222,750 元，但装修、设备、押金投出去 230,000 元，再分红 50,000 元，期末现金反而比期初少 57,250 元。

这不是经营出了问题，而是**成长期企业的正常形态**：投资活动吃掉了经营积累。判断健康与否要看两点——经营现金流是否为正且可持续；投资是否换来了未来的收入能力。

### 7.3 固定成本决定生死线

把折旧摊销和利息视为固定成本：

```text
盈亏平衡收入（EBIT = 0）
= (期间费用 866,000 + 利息 5,000) ÷ 边际贡献率 60%
= 1,451,667 元     → 约 161 碗/天

现金盈亏平衡（不考虑折旧摊销）
= (866,000 − 56,000 + 5,000) ÷ 60%
= 1,358,333 元     → 约 151 碗/天
```

实际 200 碗/天，安全边际约 **19.4%**。也就是说，客流下滑两成、或食材涨价两成，面馆就滑到盈亏线附近。租金和人工是刚性支出，这正是餐饮业"高毛利、低净利、怕淡季"的结构性原因。

## 八、敏感性：两个变量决定一年成败

以收入（客流×客单价）和食材成本率为轴，测算净利润：

| 年收入 ＼ 食材成本率 | 38% | 40%（基准） | 42% |
|---|---:|---:|---:|
| 162 万（−10%） | 100,050 | 75,750 | 51,450 |
| **180 万（基准）** | 183,750 | **156,750** | 129,750 |
| 198 万（+10%） | 267,450 | 237,750 | 208,050 |

读法：

- 收入下降 10%，净利润从 156,750 掉到 75,750，**跌幅 51.7%**——经营杠杆约 5 倍；
- 食材成本率上升 2 个百分点，净利润减少 27,000 元，**跌幅 17.2%**；
- 两者同时恶化（162 万 + 42%），净利润只剩 51,450 元，几乎回到"给房东和供应商打工"的状态。

这就是为什么餐饮企业要死盯**翻台率、客单价、食材成本率**三个数——它们直接对应利润表最上面的两行。

## 九、如果只记流水账，会错在哪

| 常见做法 | 错在哪 | 正确做法 |
|---|---|---|
| 装修 12 万当年一次性进费用 | 第一年巨亏、后两年虚胖 | 资本化，按受益期摊销 |
| 押金 3 万记成费用 | 少记资产、少记利润 | 挂"租赁押金"，退租收回 |
| 进货全额进成本 | 库存 4.5 万被提前费用化 | 期末盘存，只结转已耗用部分 |
| 分红记成费用 | 利润被压低、权益被低估 | 股利是利润分配，不进利润表 |
| 借款本金记成收入 | 收入虚增、负债漏记 | 本金进筹资活动，利息进利润表 |
| 只看银行余额判断赚没赚 | 把投资支出和经营成果混为一谈 | 三表分开看，再合起来勾稽 |

## 十、口径提醒与变形

- **个体工商户**：不缴企业所得税，改缴经营所得个人所得税；"股利"变成业主提款，属于利润分配而非筹资活动现金流。
- **新租赁准则**：租期一年以上的门店需确认**使用权资产**和**租赁负债**，租金拆成"利息费用 + 折旧"，资产负债表变长、前几年利润前低后高，但三表勾稽逻辑不变。
- **增值税**：若按含税口径记账，收入需价税分离，采购进项可抵扣，现金流中的"付现"要区分税款，案例中的净额法不再直接适用。
- **多期扩展**：第二年应把期末余额搬为期初，新增"期初存货/应收/应付"对现金流的影响；若扩张第二家店，投资活动与筹资活动会显著放大，此时更应看**单店模型**而非合并三表。
