> 连续变化：1—2 月高开（+18.3%，抢出口与春节因素），累计增速 4 月回落至 +14.9% 低点后逐月抬升（+15.3% → +16.9% → +17.3% → +17.6% → **+18.8%**）；**进口累计增速始终快于出口**（1—9 月差 5.9pct），为 2021 年三季度以来最强表现。9 月单月进出口 **5.16 万亿元（+27.5%），历史首次突破 5 万亿**，连续 6 个月两位数增长。
>
> **季度口径（2026-10-14 发布会口径）**：Q1 +15.3% → Q2 +18.3% → **Q3 +22.3%**，逐季攀升。注：上表"一季度 +15.0%"取自 4 月发布，与本次发布会的 +15.3% 存在 0.3pct 差异，疑为基数修订，**保留原始记录不改写**，引用时以发布会口径为准。
