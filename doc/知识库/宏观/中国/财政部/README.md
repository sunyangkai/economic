# 中国财政收支数据（财政部）

> **数据版本：2026 年 1—6 月（2026-07-22 发布）**
> 下次更新：2026 年 8 月中下旬（1—7 月数据）
> 数据来源：财政部国库司《财政收支情况》、财政部新闻发布会、全国预算报告（详见下方"三、数据来源与查找指南"）

---

## 长期口径警示（每次看数据前先过一遍）

- **累计 vs 单月**：官方发布多为累计口径，单月需自行相减（本目录单月值为相邻两期累计数之差推算，表内以 * 标注）；
- **政府性基金与一般公共预算分开看**：卖地收入不进一般公共预算，只看一本账会漏掉地方真实财力；
- **出口退税是收入减项**：数值越大说明出口退税越多，不代表收入差；
- **非税收入注意一次性因素**（如 2024 年中央单位上缴专项收益抬高基数，导致 2025 年非税 -11.3%）；
- **增值税受留抵退税政策扰动**，同比要结合政策背景看；
- **官方数据可能修订**，引用时以最新发布为准；
- **2025 年赤字率跳升至 4.0% 并延续至 2026 年**，标志财政政策进入"更加积极"的新区间（详见 [历史年度.md](历史年度.md)）。

## 一、核心监测清单（重要数据看哪些）

| 数据 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| 一般公共预算收入（总量、同比） | 月度（次月 18—22 日） | 财政"造血"能力，与名义经济冷暖挂钩 |
| 税收 vs 非税 | 月度 | 税收占比高 = 收入质量好；非税高增常含一次性因素 |
| 主要税种 | 月度 | 增值税→工业流通、企业所得税→企业盈利、个税→居民收入、印花税→股市、消费税→消费、契税+土增→地产 |
| 一般公共预算支出（总量、同比） | 月度 | 支出增速 > 收入增速 = 财政扩张；反之偏紧 |
| 支出科目 | 月度 | 民生 vs 基建取向 |
| 收支差额/赤字进度 | 月度 | 累计赤字 vs 全年预算赤字 → 下半年发力空间 |
| 政府性基金收支、土地出让收入 | 月度 | 地方"第二本账"，地产冷热最直接的财政指标 |
| 专项债/特别国债发行进度 | 月度（财政部/中债登） | 基建实物工作量前瞻 |
| 债务付息支出 | 月度 | 财政腾挪空间的刚性约束 |
| 年度预算目标（赤字率、赤字、专项债、特别国债） | 每年 3 月 | 全年锚，所有执行数据对照它看 |

> **只盯五个核心数字：一般公共预算收入增速、税收收入增速、一般公共预算支出增速、累计赤字占预算赤字比例、土地出让收入增速。**

## 三、数据来源与查找指南

| 数据 | 官方入口 |
|------|------|
| 月度/季度财政收支情况 | 财政数据栏目：[www.mof.gov.cn/zhengwuxinxi/caizhengshuju/](http://www.mof.gov.cn/zhengwuxinxi/caizhengshuju/)（手机版 [m.mof.gov.cn/czsj/](http://m.mof.gov.cn/czsj/) 列表更稳定） |
| 详细统计表（全税种、央地分账） | 国库司统计数据：[gks.mof.gov.cn/tongjishuju/](http://gks.mof.gov.cn/tongjishuju/) |
| 新闻发布会文字实录 | 财政新闻：[www.mof.gov.cn/zhengwuxinxi/caizhengxinwen/](http://www.mof.gov.cn/zhengwuxinxi/caizhengxinwen/) |
| 预算报告/决算 | 财政数据栏目（每年 3 月预算、次年 6 月决算） |
| 政府债券发行 | 中国债券信息网 [chinabond.com.cn](https://www.chinabond.com.cn)、地方政府债券信息公开平台 [celma.org.cn](http://www.celma.org.cn) |
| 站内检索（兜底） | [search.mof.gov.cn](http://search.mof.gov.cn) |

**发布日历**：月度收支 18—22 日发布；季度/半年发布会（4 月、7 月、10 月）；两会预算报告（3 月）；上年决算（6 月）。
