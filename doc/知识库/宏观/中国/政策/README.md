# 政策文件夹 · 索引

> **数据版本：2026-10**
>
> 本文件夹存放**政策类知识**（非月度统计数据的部分）——目前下辖一个子文件夹：
>
> - **`会议/`**：重要会议跟踪，**按档位分三层文件夹**：`S/`（定全年 / 定五年方向：中央经济工作会议、两会、全会、五年规划）、`A/`（季度方向微调：政治局经济会议）、`B/`（领域型政策会议槽位：农村 / 城市 / 金融工作会议、国务院常务会议，默认不建档、空置＝未升档）。规范（跟哪些会议、什么时点跟、跟出什么、落在哪个文件）+ 会议定调台账索引，见 `doc/知识库/宏观/中国/政策/会议/README.md`。
>
> 与上层目录的关系：本文件夹的父级索引见 `doc/知识库/宏观/中国/README.md`；月度统计数据（CPI / PMI / PPI / 外贸 / 央行 / 财政部等）在父级目录下按「指标 → 年份 → 月度」组织，不在本文件夹内。

## 一、存放规则

| 内容类型 | 是否放本文件夹 | 说明 |
| --- | --- | --- |
| 重要会议定调卡与兑现台账 | ✓ | 放 `会议/`，档位（S / A / B）与模板见该目录 `README.md` |
| 五年规划（《建议》/《纲要》） | ✓ | 并入会议体系，作为会议记录归档（全会《建议》+ 两会《纲要》），不单设政策脉络文件 |
| 政策文件原文摘录（与会议无关的部委文件等） | ✓（按需新建子文件夹） | 目前无此类内容；新建时在本文件登记一行 |
| 月度统计数据（CPI / PMI / 央行 / 财政部等） | ✗ | 归父级 `doc/知识库/宏观/中国/<指标>/` |
| 分析判断（政策影响、行业含义、投资结论） | ✗ | 归报告层 `doc/研报/`；本文件夹只存事实、口径与来源 |

## 二、写作纪律（与本文件夹所有内容共用）

- **官方原文优先**：表述一律来自官方通报 / 公报 / 报告原文，标注来源与日期；二手解读（媒体报道、券商观点）不作观点基准。

- **只存事实与口径，不写判断**：判断进报告层（`doc/研报/`）、行业含义进行业报告"四、政策与监管"。

- **一处维护**：同一政策表述在本文件夹只维护一份，报告层引用路径、不复制粘贴。
