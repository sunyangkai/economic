## 一、定位与纪律

### 1.1 定位

| 项 | 规则 |
| --- | --- |
| 本质 | **年度 / 季度政策口径的一手原文台账**——"一次会议一张定调卡"，为后续一切研究提供可回溯的官方依据 |
| 服务对象 | ① 主报告"二、业务分析（宏观）"的政策传导输入；② 行业报告"四、政策与监管"；③ 月度宏观跟踪（`doc/知识库/宏观/中国/`）的定调背景；④ 年度策略口径的统一（全年只引一套官方表述，避免各处重述走样） |
| 更新节奏 | 事件驱动：会议结束即归档；S 档另有半年 / 年末"兑现对照"复核（见"五 跟踪流程"） |
| 不做什么 | 不写投资建议、不做行情解读、不预测政策力度、不转述券商观点、不维护本文件夹之外的重复台账 |
| 与月度知识库分工 | 月度数据文件（CPI / 央行 / 财政部等）管**实绩**，本目录管**定调**——两条线在报告层"宏观"小节交汇 |

**核心纪律：本目录只回答"官方说了什么"，不回答"这意味着什么"。** 判断进报告层（`doc/研报/`），行业含义进行业报告"四、政策与监管"；本目录给出的接口是"四、定调卡 → 七、待验证清单"，不是结论。

### 1.2 四条写作纪律

- **原文优先**：

  - 表述拆解（"四、记录模板"§4.2）中每一行都必须能在官方原文中找到对应句子或段落；**没有原文就不写这一行**，缺口在来源节明说"未获取到全文，仅据新华社通稿"。

- **只记变化、不重述全文**：

  - 存档的是"官方原文的结构化索引"，不是新闻稿搬运——照抄整段通稿既无价值也难维护。

- **对比必须可核**：

  - 表述对比表（本次 vs 上次同类会议）"上次表述"列必须指向已归档的上一份记录文件或原文链接；上次未归档时，先补建再对比，不用记忆转写。

- **口径一致**：

  - 同一提法在不同场合有差异时（如政治局会议"适度宽松"vs 央行报告的具体工具表述），以**发布层级最高者**为准；差异本身写进"口径备忘"行，供报告层在冲突时说明原因。

## 二、跟踪档位与纳入范围

### 2.1 三个档位

| 档位 | 判据 | 跟踪要求 | 落盘产出 | 存放位置 |
| --- | --- | --- | --- | --- |
| **S** | 定全年 / 定五年方向，直接构成下一年（或下一个五年）研究框架的宏观假设 | 会前建**预告台账**节；会后 48 小时内**完整定调卡**（含表述对比 + 待验证清单）；半年 / 年末各做一次**兑现对照** | 独立年度 / 届次文件（一次会议一个文件） | `S/<会议类型>/`：`S/中央经济工作会议/`、`S/两会/`、`S/全会/`、`五年规划/` |
| **A** | 季度方向微调；表述变化方向改变季度跟踪重点 | 会后 24 小时内建档：**头部 + 原文口径 + 与上次同类会议的表述对比**三节；不写待验证清单（并入下一份 S 档或月度知识库） | 按会议周期建档；**与年度会议同月召开者并入该 S 档记录**（12 月政治局会议 → `S/中央经济工作会议/<年>.md`） | `A/政治局经济会议/<年>-<月>.md` |
| **B** | 领域型政策会议（金融 / 城市 / 农村 / 财经委等） | **默认不建档**：只增补对应领域已有知识文件的相关表述；出现中长期口径变化、新设机构部署或五年一遇的定调变化时**升级为 S 档**建档 | 默认无独立文件；升档后按 S 档模板建档（在 `S/` 下建对应会议类型文件夹） | `B/` 四个领域槽位（`中央农村工作会议/`、`中央城市工作会议/`、`中央金融工作会议/`、`国务院常务会议/`）；**空置＝尚未升档** |

**B 档的落点（不新建重复文件）**：

- 中央金融工作会议 → 补 `doc/知识库/宏观/中国/央行/`（金融监管与货币政策口径）；

- 中央农村工作会议 → 补 `doc/知识库/` 相关农业 / 食品链知识文件，并在其头部注明会议来源与日期；

- 中央城市工作会议 → 补地产链相关行业知识文件（城市更新、城镇化路径）；

- 中央财经委员会会议 → 按议题归入对应领域文件（财税、统一大市场、共同富裕等）。

### 2.2 纳入跟踪的会议清单

| 会议 | 层级 | 档位 | 频率 | 常规时点 | 归档文件 |
| --- | --- | --- | --- | --- | --- |
| 党的全国代表大会 | 党中央 | S | 5 年 | 秋季 | `S/全会/<届次>全国代表大会.md` |
| 中央委员会全会 | 党中央 | S | 每年 1 次左右 | 视议题，多在秋 / 冬 | `S/全会/二十届<序数>中全会.md` |
| 中央经济工作会议 | 党中央 + 国务院 | **S** | 每年 | 12 月上中旬 | `S/中央经济工作会议/<年>.md` |
| 全国两会（人大 + 政协） | 国家机构 | **S** | 每年 | 3 月 5 日前后开幕 | `S/两会/<年>.md` |
| 中央政治局会议（分析研究经济形势） | 党中央 | **A** | 每年 2 次 | **4 月 / 7 月**（12 月会议并入中央经济工作会议记录） | `A/政治局经济会议/<年>-<月>.md` |
| 中央政治局会议（其他议题） | 党中央 | B | 每月左右 | — | 不建档（纪要口径变化时并入相关文件） |
| 中央农村 / 城市 / 金融工作会议 | 党中央 | B（可升 S） | 不定期 / 五年一遇 | — | 见"2.1 B 档落点" |
| 国务院常务会议 | 国务院 | B | 每周左右 | 通常周五 | 不建档（落到对应领域文件）；被列为 S 档"待验证"事项时，在 S 档记录里留一行"兑现时点" |
| 部委年度工作会议 | 部委 | B | 每年 12 月—次年 1 月 | — | 不建档（发改委 / 财政部 / 央行口径已各有月度文件） |

> **档位不是地位，是投入产出比**：S 档抓"下一年的假设从哪来"，A 档抓"年内方向有没有变"，B 档抓"领域里有没有结构性新提法"。B 档不建档不等于不看——是**不单独建一份会被重复维护的台账**。

> **12 月政治局会议的归属**：每年 12 月政治局会议（分析研究当年经济形势、为次年经济工作定调）与中央经济工作会议**通常在相邻数日内召开**，故不单独建 A 档文件，其原文口径与表述对比写在 `S/中央经济工作会议/<年>.md` 的"一、定调卡"中（两段表述并列，便于看中央经济工作会议前的口径铺垫）——全年完整节奏见"八、全年固定日程"。

## 三、记录文件命名与存放

> **分层规则：档位在前、会议类型在后。** 先按档位进 `S/` / `A/` / `B/`，再按会议类型进子文件夹。

```
doc/知识库/宏观/中国/政策/会议/
├── README.md                          # 本文：规范 + 台账索引
├── S/                                 # S 档：定全年 / 定五年方向
│   ├── 中央经济工作会议/                #   年度文件 <YYYY>.md（2026.md 为模板 + 2015—2025 历年对照表）
│   ├── 两会/                           #   年度文件 <YYYY>.md；规划年份另建专题 <YYYY>-<规划>纲要.md
│   ├── 全会/                           #   届次文件 <届次><序数>中全会.md、<届次>全国代表大会.md
│   └── 五年规划/                       #   主线文件 五年规划主线.md（三轮规划《建议》+《纲要》对照）
├── A/                                 # A 档：季度方向微调
│   └── 政治局经济会议/                  #   周期文件 <YYYY>-<MM>.md（仅 4 / 7 月经济议题）
└── B/                                 # B 档：领域型政策会议（默认不建档，空置＝未升档）
    ├── 中央农村工作会议/
    ├── 中央城市工作会议/
    ├── 中央金融工作会议/
    └── 国务院常务会议/
```

命名规则：

| 类型 | 文件名 | 示例 |
| --- | --- | --- |
| 年度型（中央经济工作会议、两会） | `<YYYY>.md` | `S/中央经济工作会议/2025.md` |
| 届次型（全会、党代会） | `<届次><序数>中全会.md` / `<届次>全国代表大会.md` | `S/全会/二十届五中全会.md` |
| 周期型（政治局经济会议） | `<YYYY>-<MM>.md` | `A/政治局经济会议/2026-07.md` |
| 专题型（规划纲要、专项部署） | `<YYYY>-<专题名>.md` | `S/两会/2026-十五五规划纲要.md` |
| 主线型（跨轮次对照） | `<主题>主线.md` | `S/五年规划/五年规划主线.md` |

年份取**会议所属年度**（跨年会议如 12 月中央经济工作会议记入召开年份：2025-12 的会议 → `S/中央经济工作会议/2025.md`，其部署的是 2026 年工作，文件头部注明"部署年度"）。

**B 档的升档动作**：达到升档判据时（五年一遇定调 / 新设机构部署 / 中长期口径变化），按 S 档模板在 `S/` 下建对应会议类型文件夹与新文件（如 `S/中央金融工作会议/2023.md`），并在"8.2（6）B 档会议"表把状态改为"已升档"、写明新路径；`B/` 下的槽位**保留**（作为"该领域暂无独立档案"的占位，不删）。

### 4.2 两会记录补充要求（`S/两会/<年>.md`）

在两会骨架之外，两会文件必含：

1. **主要预期目标表**（当年）：经济增长、城镇调查失业率、城镇新增就业、居民消费价格涨幅、居民收入、国际收支、粮食产量、单位 GDP 二氧化碳排放等，逐项照录官方目标值。

2. **财政与货币取向段**：赤字率与赤字规模、一般公共预算支出规模、超长期特别国债、特别国债（如补充银行资本）、地方政府专项债，逐项照录——这一段的数字是后续所有财政口径的基准。

3. **计划 / 预算报告要点**：与政府工作报告的差异与增量信息（同一目标的不同口径，如支出结构、转移支付安排）。

4. **"全年兑现对照"节**（见 4.1 §四）：本年是当年唯一的年度台账，按季度更新。

5. **五年规划年份另建专题文件**（如 `2026-十五五规划纲要.md`），与两会文件互链；规划文件按 4.3 模板。

## 五、跟踪流程

### 5.1 会前（预计时点已知时）

- **建预告台账节**（写在对应 S 档文件头部，或先在 `A/政治局经济会议/` 下建当月文件）：登记**预计**召开时点、官方发布渠道、需重点关注的维度（对照上次同类会议的定调卡逐项列）——预计时点只作准备用，不作引用口径。

- **等待官方定档**：预计时点一律标注"预计"，**待政治局会议或新华社通稿正式公布后改为确切日期**（如二十届五中全会：2026-09-21 政治局会议决定 10 月 26—29 日召开，方为确切口径）。

### 5.2 会后（本次规范的核心动作）

- **24 小时内**（S / A 档同）：读新华社通稿与会议公报，建立 / 补全头部、原文口径、定调卡（或 A 档三节）。

- **48 小时内**（S 档）：完成表述对比表与待验证清单；**等全文 / 公报发布后再补一次**（公告稿与全文常有细节差异，差异本身记入"版本说明"）。

- **不发无来源的判断**：券商解读、媒体测算一律不进本目录；确实需要（如"赤字率对应赤字规模"的换算）时，标注来源与日期，并放在"口径备忘"里而非正文。

### 5.3 半年 / 年末收口（S 档）

- **半年对照**（7 月政治局会议后）：在当年 S 档记录的"全年兑现对照"节填入上半年实绩。

- **年末收口**（12 月中央经济工作会议后）：把当年 S 档记录的兑现情况汇总进新一年记录文件的"上一节点"与"上次表述"列——形成 S 档之间的**闭环引用链**，不另建汇总文件。

### 5.4 发现缺口时

- 会议出现本目录未登记的类型（新设机构、临时重要会议）→ 先在本文件"二 纳入范围"补行并定档位，再建档；

- 会议表述与月度数据长期背离（如定调"推动价格总水平由负转正"而 CPI 连续为负）→ 属分析问题：在报告层说明，**不改会议记录**；但要在对应数据文件（如 `doc/知识库/宏观/中国/CPI/`）的解读中留一句交叉引用。

## 六、数据来源与版本纪律

### 6.1 来源分层（优先级从高到低）

1. **会议公报 / 决定 / 建议全文**（新华社受权发布、中国政府网）——原文基准。

2. **新华社通稿**（会议报道、快报）——时点与核心口径的第一手。

3. **《人民日报》及部委官网的解读文章**（如起草组解读、发改委解读）——只用于理解官方逻辑，引用须标注为"解读"。

4. **财经媒体**（财新、第一财经、证券时报等）——只用于补充花絮性事实（如会场安排、出席人员），不进定调卡。

5. **券商策略解读**——**不作为来源**（本目录整体不引二手分析；判断层需要时在报告层引并标注）。

### 6.2 版本纪律

- **通稿版 → 全文版**：先按通稿建档（标注"通稿版"），全文发布后补全，并在文件"版本说明"里写明补全时点。

- **不覆盖历史**：会议记录的修订按**追加**处理——在文末"维护记录"节加一行（日期 + 改了什么），正文改动处可在行内标注（如"（YYYY-MM-DD 据全文补正）"）。

- **一处维护**：同一会议的表述只在本目录维护一份；报告层引用时写路径，不复制粘贴到报告正文——**避免三处表述漂移**。

### 6.3 工具与取数

| 用途 | 方式 |

| 会议实绩数据（兑现对照） | 取 `doc/知识库/宏观/中国/<指标>/` 的月度 / 年度文档（其数字来自官方发布，勿另行推算） |
| 本目录的财务 / 行情数据 | 不涉及——本目录不引行情、不引公司财务 |
| 网络检索 | 只用于**定位官方原文链接**与**核对会议时点**；找到原文链接后以官方页面为准 |
