# 中国共产党第十八届中央委员会第六次全体会议（2016-10-24—27）

> 会议：十八届六中全会 ｜ 召开：2016-10-24—27，北京 ｜ 主要议程：全面从严治党；审议通过两部党内法规；决定十九大于 2017 年下半年召开
> 定位：**党建议题的定调会**——确立"以习近平同志为核心的党中央"，通过《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》

## 一、会议要点

- **审议通过**：《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》。

- **核心提法**：正式确立"**以习近平同志为核心的党中央**"；"四个全面"战略布局至此完成系统部署（含全面从严治党）。

- **人事事项**：递补中央委员会委员；确认中央政治局此前作出的开除部分中央委员党籍的决定（按公报口径）。

- **会议决定**：中国共产党第十九次全国代表大会于 2017 年下半年在北京召开。
