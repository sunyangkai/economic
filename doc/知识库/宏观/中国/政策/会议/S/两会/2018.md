> 会议：十三届全国人大一次会议（2018-03-05 开幕） + 全国政协会议（2018-03-03/04 开幕）
> 定位：确定 2018 年主要预期目标与财政货币安排的年度会议（政府工作报告 + 计划 / 预算报告）

## 一、主要预期目标（政府工作报告）

| 目标项 | 2018 年目标 |
| --- | --- |
| 国内生产总值增长 | 6.5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,100 万人以上 |
| 城镇调查失业率 | 5.5% 以内 |
| 单位 GDP 能耗 | 下降 3% 以上（待核） |

## 二、财政与货币取向

| 项 | 2018 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**取向不变**，聚力增效 |
| 赤字率 | **2.6%**（比 2017 年预算降低 0.4 个百分点） |
| 赤字规模 | **2.38 万亿元**（与 2017 年持平，赤字率下降靠名义 GDP 增长实现） |
| 地方政府专项债券 | **1.35 万亿元**（比 2017 年增加 5,500 亿元） |
| 减税降费 | 全年再为企业和个人减税 8,000 多亿元 |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
