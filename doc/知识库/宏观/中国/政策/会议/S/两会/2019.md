# 全国两会（2019-03 开幕）

> 会议：十三届全国人大二次会议（2019-03-05 开幕） + 全国政协会议（2019-03-03/04 开幕）
> 定位：确定 2019 年主要预期目标与财政货币安排的年度会议（政府工作报告 + 计划 / 预算报告）
> 上一节点：[2018.md](../../S/两会/2018.md)｜ 下一节点：[2020.md](../../S/两会/2020.md)
> 来源：中国政府网 / 新华社（积极财政政策加力提效，2019-03-05），[链接](http://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/2019-03/05/content_5370826.htm)

## 一、主要预期目标（政府工作报告）

| 目标项 | 2019 年目标 |
| --- | --- |
| 国内生产总值增长 | 6%—6.5% |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,100 万人以上 |
| 城镇调查失业率 | 5.5% 左右 |
| 单位 GDP 能耗 | 下降 3% 左右（待核） |

## 二、财政与货币取向

| 项 | 2019 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**要加力提效** |
| 赤字率 | **2.8%**（比 2018 年预算提高 0.2 个百分点） |
| 赤字规模 | **2.76 万亿元**（中央 1.83 万亿 + 地方 0.93 万亿） |
| 地方政府专项债券 | **2.15 万亿元**（比 2018 年增加 8,000 亿元） |
| 财政支出 | 超过 23 万亿元，增长 6.5% |
| 减税降费 | 实施更大规模减税降费（制造业等行业增值税率下调） |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
