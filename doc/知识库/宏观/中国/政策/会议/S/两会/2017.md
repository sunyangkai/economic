# 全国两会（2017-03 开幕）

> 会议：十二届全国人大五次会议（2017-03-05 开幕） + 全国政协会议（2017-03-03/04 开幕）
> 定位：确定 2017 年主要预期目标与财政货币安排的年度会议（政府工作报告 + 计划 / 预算报告）
> 上一节点：[2016.md](../../S/两会/2016.md)｜ 下一节点：[2018.md](../../S/两会/2018.md)

## 一、主要预期目标（政府工作报告）

| 目标项 | 2017 年目标 |
| --- | --- |
| 国内生产总值增长 | 6.5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,100 万人以上 |
| 城镇登记失业率 | 4.5% 以内 |
| 单位 GDP 能耗 | 下降 3.4% 以上（待核） |

## 二、财政与货币取向

| 项 | 2017 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策要**更加积极有效** |
| 赤字率 | **3%**（与 2016 年持平） |
| 赤字规模 | **2.38 万亿元**（比 2016 年增加 2,000 亿元） |
| 地方政府专项债券 | **8,000 亿元**（比 2016 年增加 4,000 亿元） |
| 减税降费 | 进一步减税降费，全年再减少企业税负 3,500 亿元左右、涉企收费约 2,000 亿元 |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
