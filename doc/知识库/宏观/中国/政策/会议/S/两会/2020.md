## 二、财政与货币取向

| 项 | 2020 年安排 |
| --- | --- |
| 财政政策 | **积极的财政政策要更加积极有为** |
| 赤字率 | **3.6% 以上**（**突破 3% 的长期上限**；2021 年预算报告口径回顾为 2020 年 3.7%） |
| 赤字规模 | **3.76 万亿元**（比 2019 年增加 1 万亿元） |

| 货币政策 | 稳健的货币政策**要更加灵活适度**；推动利率持续下行、引导广义货币供应量和社会融资规模增速明显高于去年 |
| 直达工具 | 创新直达实体经济的货币政策工具（两项直达工具） |

## 三、政策主线与工具

- **"六稳""六保"**："保居民就业、保基本民生、保市场主体、保粮食能源安全、保产业链供应链稳定、保基层运转"为"六保"；以"六保"促"六稳"。

- **减税降费 + 直达基层**：新增减税降费与财政资金直达市县基层机制。

- **扩大内需**：消费回升、新基建、新型城镇化、重大工程（"两新一重"）。
