## 一、主要预期目标（政府工作报告）

| 目标项 | 2025 年目标 |
| --- | --- |
| 国内生产总值增长 | 5% 左右 |
| 居民消费价格涨幅 | 2% 左右 |
| 城镇新增就业 | 1,200 万人以上 |
| 城镇调查失业率 | 5.5% 左右 |
| 单位 GDP 能耗 | 待核 |

## 二、财政与货币取向

| 项 | 2025 年安排 |
| --- | --- |
| 财政政策 | **实施更加积极的财政政策**（持续用力、更加给力） |
| 赤字率 | **4% 左右**（比上年提高 1 个百分点） |
| 赤字规模 | **5.66 万亿元**（比上年增加 1.6 万亿元） |
| 一般公共预算支出 | **29.7 万亿元**（比上年增加 1.2 万亿元） |
| 超长期特别国债 | **1.3 万亿元**（比上年增加 3,000 亿元；其中 3,000 亿元支持消费品以旧换新） |
| 特别国债 | **5,000 亿元**（支持国有大型商业银行补充资本） |
| 地方政府专项债券 | **4.4 万亿元**（比上年增加 5,000 亿元；重点用于投资建设、土地收储和收购存量商品房、消化地方政府拖欠企业账款等） |
| 新增政府债务总规模 | **11.86 万亿元**（比上年增加 2.9 万亿元） |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
