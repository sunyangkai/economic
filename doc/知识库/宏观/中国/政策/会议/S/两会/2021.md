## 一、主要预期目标（政府工作报告）

| 目标项 | 2021 年目标 |
| --- | --- |
| 国内生产总值增长 | **6% 以上**（官方说明："考虑了经济运行恢复情况"） |
| 城镇新增就业 | 1,100 万人以上 |
| 城镇调查失业率 | 5.5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 居民收入 | 稳步增长 |
| 进出口 | 量稳质升，国际收支基本平衡 |
| 单位 GDP 能耗 | 降低 3% 左右 |
| 粮食产量 | 保持在 1.3 万亿斤以上 |

## 二、财政与货币取向

| 项 | 2021 年安排 |
| --- | --- |
| 财政政策 | **积极的财政政策要提质增效、更可持续**（延续 2020 年中央经济工作会议口径） |
| 赤字率 | **3.2% 左右**（比 2020 年下降 0.5 个百分点左右；来源：财政部预算报告解读） |
| 赤字规模 | **3.57 万亿元**（中央 2.75 万亿 + 地方 0.82 万亿；比 2019 年增加 0.81 万亿元） |
| 地方政府专项债券 | **3.65 万亿元**（比 2020 年减少 1,000 亿元） |
| 一般公共预算支出 | **25 万亿元**（增长 1.8%） |
| 中央对地方转移支付 | 待核 |
| 货币政策 | 稳健的货币政策**要灵活精准、合理适度**；"不急转弯"（政策连续性） |
| M2 / 社融 | 与名义经济增速基本匹配 |

## 三、计划 / 预算报告与规划批准

- **"十四五"规划《纲要》**：本次大会批准，含 20 项主要指标（经济发展、创新驱动、民生福祉、绿色生态、安全保障五类）——完整指标与执行结果见 [五年规划主线.md](../../S/五年规划/五年规划主线.md)。

- 预算报告：财政支出结构向民生、科技创新、乡村振兴倾斜（具体规模待补）。
