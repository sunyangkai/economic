## 一、主要预期目标（政府工作报告）

| 目标项 | 2023 年目标 |
| --- | --- |
| 国内生产总值增长 | 5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,200 万人左右 |
| 城镇调查失业率 | 5.5% 左右 |
| 单位 GDP 能耗 | 下降 2% 左右（待核） |

## 二、财政与货币取向

| 项 | 2023 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**要加力提效** |
| 赤字率 | **3%**（比 2022 年提高 0.2 个百分点） |
| 赤字规模 | **3.88 万亿元**（比 2022 年增加 5,100 亿元） |
| 地方政府专项债券 | **3.8 万亿元**（比 2022 年增加 1,500 亿元） |
| 一般公共预算支出 | **27.5 万亿元**（增长 5.6%） |
| 中央对地方转移支付 | 超过 **10 万亿元** |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
