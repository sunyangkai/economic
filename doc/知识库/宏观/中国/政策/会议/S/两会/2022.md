# 全国两会（2022-03 开幕）

> 会议：十三届全国人大五次会议（2022-03-05 开幕） + 全国政协会议（2022-03-03/04 开幕）
> 定位：确定 2022 年主要预期目标与财政货币安排的年度会议（政府工作报告 + 计划 / 预算报告）
> 上一节点：[2021.md](../../S/两会/2021.md)｜ 下一节点：[2023.md](../../S/两会/2023.md)
> 来源：财政部（2022 年"国家账本"很给力，含预算报告解读），[链接](http://m.mof.gov.cn/czxw/202203/t20220307_3793074.htm)

## 一、主要预期目标（政府工作报告）

| 目标项 | 2022 年目标 |
| --- | --- |
| 国内生产总值增长 | 5.5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,100 万人以上 |
| 城镇调查失业率 | 5.5% 以内 |
| 单位 GDP 能耗 | 下降 3% 左右（待核） |

## 二、财政与货币取向

| 项 | 2022 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**要提升效能，更加注重精准、可持续** |
| 赤字率 | **2.8% 左右**（比 2021 年下降 0.4 个百分点） |
| 赤字规模 | **3.37 万亿元**（比 2021 年减少 2,000 亿元） |
| 地方政府专项债券 | **3.65 万亿元**（与 2021 年持平） |
| 一般公共预算支出 | **26.7 万亿元**（比 2021 年扩大 2 万亿元以上） |
| 中央对地方转移支付 | **9.8 万亿元**（增长 18%，近年最大增幅） |
| 减税退税 | 预计全年退税减税约 **2.5 万亿元**（其中留抵退税约 1.5 万亿元） |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
