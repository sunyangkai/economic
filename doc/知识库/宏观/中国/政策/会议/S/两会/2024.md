## 一、主要预期目标（政府工作报告）

| 目标项 | 2024 年目标 |
| --- | --- |
| 国内生产总值增长 | 5% 左右 |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,200 万人以上 |
| 城镇调查失业率 | 5.5% 左右 |
| 居民人均可支配收入 | 增长与经济增长同步 |
| 粮食产量 | 1.3 万亿斤以上 |
| 单位 GDP 能耗 | 下降 2.5% 左右 |

## 二、财政与货币取向

| 项 | 2024 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**要适度加力、提质增效** |
| 赤字率 | **3%**（与 2023 年年初预算持平） |
| 赤字规模 | **4.06 万亿元**（比 2023 年年初预算增加 1,800 亿元，新增赤字全部安排在中央） |
| 地方政府专项债券 | **3.9 万亿元**（比 2023 年增加 1,000 亿元） |
| 超长期特别国债 | **1 万亿元**（2024 年先发行；拟连续几年发行，专项用于国家重大战略实施和重点领域安全能力建设） |
| 中央预算内投资 | 7,000 亿元（比 2023 年增加 200 亿元） |
| 货币政策 | 见"三、口径备忘"（本文件以财政口径为主，货币口径待补原文） |
