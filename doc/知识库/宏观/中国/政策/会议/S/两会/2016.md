# 全国两会（2016-03-03—16）

> 会议：十二届全国人大四次会议（2016-03-05—16）+ 全国政协十二届四次会议（2016-03-03—14）｜ **批准"十三五"规划《纲要》**
> 定位：**十三五开局之年的两会**——审查批准《国民经济和社会发展第十三个五年规划纲要》，并确定 2016 年主要预期目标与财政货币安排

## 一、主要预期目标（政府工作报告）

| 目标项 | 2016 年目标 |
| --- | --- |
| 国内生产总值增长 | 6.5%—7% |
| 居民消费价格涨幅 | 3% 左右 |
| 城镇新增就业 | 1,000 万人以上 |
| 城镇登记失业率 | 4.5% 以内 |
| 居民收入 | 与经济增长基本同步 |
| 国际收支 | 基本平衡 |
| 单位 GDP 能耗 | 下降 3.4% 以上 |
| 主要污染物排放 | 化学需氧量、氨氮、二氧化硫、氮氧化物排放量分别下降 2%、2%、3%、3% |

## 二、财政与货币取向

| 项 | 2016 年安排 |
| --- | --- |
| 财政政策 | 积极的财政政策**要加大力度** |
| 赤字率 | **3%**（创历史新高，财政部表述为"必要、可行、安全"） |
| 财政赤字规模 | 2.18 万亿元（比 2015 年增加 5,600 亿元） |
| 地方政府专项债券 | 4,000 亿元（首年安排） |
| 减税降费 | 全面实施营改增；取消违规设立的政府性基金 |
| 货币政策 | 稳健的货币政策**要灵活适度**；M2 预期增长 13% 左右 |
| 社会融资规模 | 预期增长 13% 左右 |

## 三、计划 / 预算报告要点

- **"十三五"规划《纲要》**：本次大会审查批准《国民经济和社会发展第十三个五年规划纲要》，内含 4 大类 25 项主要指标（含约束性指标）——完整指标与执行结果见 [五年规划主线.md](../../S/五年规划/五年规划主线.md)。

- 预算报告与政府工作报告的赤字口径一致（赤字率 3%）；财政支出结构向民生、扶贫倾斜。
