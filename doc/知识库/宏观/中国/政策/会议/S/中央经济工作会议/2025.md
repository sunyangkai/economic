# 中央经济工作会议（2025-12-10—11）

> 会议：中央经济工作会议 ｜ 召开：2025-12-10—11，北京 ｜ 部署年度：**2026 年（"十五五"开局之年）**
> 定位：**"十五五"开局之年的部署**——确立"更加积极有为的宏观政策"，要求"实现'十五五'良好开局"；本次会议的八项重点任务即 2026 年经济工作的总清单
> 上一节点：[2024 年会议](../../S/中央经济工作会议/2024.md)｜ 下一节点：[2026 年会议](../../S/中央经济工作会议/2026.md)（预计 2026-12）

## 一、定调卡

**总基调**：坚持稳中求进工作总基调，**"稳中求进、提质增效"**；**实施更加积极有为的宏观政策**，增强政策前瞻性针对性协同性，实现"十五五"良好开局。

| 维度 | 本次表述（部署 2026 年） | 要点 |
| --- | --- | --- |
| 形势判断 | 外部环境变化影响加深，**国内供强需弱矛盾突出**，重点领域风险隐患较多；"经济长期向好的支撑条件和基本趋势没有改变" | — |
| 财政政策 | **继续实施更加积极的财政政策**；保持必要的财政赤字、债务总规模和支出总量；重视解决地方财政困难，兜牢基层"三保"底线 | 延续 2024 取向 |
| 货币政策 | **继续实施适度宽松的货币政策**；把**促进经济稳定增长、物价合理回升**作为重要考量；灵活高效运用降准降息等工具 | 物价目标写入货币考量 |
| 五个"必须" | 必须充分挖掘经济潜能；必须坚持政策支持和改革创新并举；必须做到既"放得活"又"管得好"；必须坚持投资于物和投资于人紧密结合；必须以苦练内功来应对外部挑战 | 规律性认识 |
| 内需 | **坚持内需主导，建设强大国内市场**（首位任务）；深入实施提振消费专项行动，**制定实施城乡居民增收计划** | 与十五五主线一致 |
| 新动能 | 加紧培育壮大新动能；建设北京（京津冀）、上海（长三角）、粤港澳大湾区国际科技创新中心；**深化拓展"人工智能+"** | — |
| 改革 | 制定**全国统一大市场建设条例**，深入整治"内卷式"竞争；制定实施进一步深化国资国企改革方案；健全地方税体系 | 新增立法类表述 |
| 开放 | 稳步推进制度型开放，有序扩大服务领域自主开放；扎实推进**海南自由贸易港**建设 | — |
| 双碳 | **制定能源强国建设规划纲要**；加快新型能源体系；加强全国碳排放权交易市场建设 | 新增规划 |
| 民生 | 实施稳岗扩容提质行动；优化药品集中采购，深化医保支付方式改革；**倡导积极婚育观，努力稳定新出生人口规模** | 人口议题升级 |
| 风险 | 着力稳定房地产市场（控增量、去库存、优供给；收购存量商品房用于保障性住房）；积极有序化解地方政府债务风险 | 地产 + 化债 |
| 规划衔接 | **按照二十届四中全会《建议》编制国家和地方"十五五"规划及专项规划** | 与规划线衔接 |

**重点任务清单（官方排序照录，八项）**：① 坚持内需主导，建设强大国内市场；② 坚持创新驱动，加紧培育壮大新动能；③ 坚持改革攻坚，增强高质量发展动力活力；④ 坚持对外开放，推动多领域合作共赢；⑤ 坚持协调发展，促进城乡融合和区域联动；⑥ 坚持"双碳"引领，推动全面绿色转型；⑦ 坚持民生为大，努力为人民群众多办实事；⑧ 坚持守牢底线，积极稳妥化解重点领域风险。

## 二、与上一次会议的表述对比

| 主题 | 本次（2025-12，部署 2026） | 上次（2024-12，部署 2025） | 变化类型 |
| --- | --- | --- | --- |
| 总基调 | 稳中求进、提质增效；更加积极有为 | 稳中求进、以进促稳，守正创新、先立后破 | 表述调整 |
| 财政 | 更加积极（延续），保持必要赤字与债务规模 | 更加积极 + 提高赤字率 | 口径延续 |
| 货币 | 适度宽松（延续）+ 物价合理回升 | 适度宽松 | 延续 + **新增物价考量** |
| 形势 | 供强需弱矛盾突出 | 需求不足、预期偏弱 | 表述更新 |
| 内需 | 内需主导 + 城乡居民增收计划 | 提振消费专项行动 | **升级** |
| 改革 | 全国统一大市场建设条例；整治内卷 | 出台民营经济促进法 | 升级（立法化） |
| 双碳 | 能源强国建设规划纲要 | 零碳园区 | 升级 |
| 规划 | 编制"十五五"规划及专项规划 | 未涉及 | 新增（年度特征） |
