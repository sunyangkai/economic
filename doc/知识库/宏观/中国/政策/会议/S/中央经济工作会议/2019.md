# 中央经济工作会议（2019-12-10—12）

> 会议：中央经济工作会议 ｜ 召开：2019-12-10—12，北京 ｜ 部署年度：**2020 年**
> 定位：**收官年部署**——部署"十三五"收官与全面建成小康社会决胜之年的经济工作；提出"六稳"延续 + 高质量发展、三大攻坚战收官

## 一、定调卡

**总基调**：坚持稳中求进工作总基调，**坚持新发展理念，坚持以供给侧结构性改革为主线，坚持以改革开放为动力**，推动高质量发展。

| 维度 | 本次表述（部署 2020 年） | 要点 |
| --- | --- | --- |
| 三大攻坚战 | 打好**防范化解重大风险、精准脱贫、污染防治**攻坚战（收官） | 收官年 |
| 六稳 | 全面做好"六稳"工作 | 延续 2018 表述 |
| 财政政策 | 积极的财政政策**要大力提质增效**，更加注重结构调整 | 减税降费 + 专项债 |
| 货币政策 | 稳健的货币政策**要灵活适度**，保持流动性合理充裕 | 降低社会融资成本 |
| 房地产 | **房子是用来住的、不是用来炒的**；落实因城施策，**稳地价、稳房价、稳预期** | "三稳"表述 |
| 民生 | 确保全面建成小康社会和"十三五"规划圆满收官 | 硬任务 |
| 改革 | 深化经济体制改革（国资国企、财税、金融、要素市场化） | — |
| 农业 | 保障重要农产品有效供给，加快恢复生猪生产 | 猪周期背景 |

**重点任务清单（官方排序照录）**：① 坚定不移贯彻新发展理念；② 坚决打好三大攻坚战；③ 确保民生特别是困难群众基本生活得到有效保障和改善；④ 继续实施积极的财政政策和稳健的货币政策；⑤ 着力推动高质量发展；⑥ 深化经济体制改革。
