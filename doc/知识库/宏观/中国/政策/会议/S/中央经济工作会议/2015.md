# 中央经济工作会议（2015-12-18—21）

> 会议：中央经济工作会议 ｜ 召开：2015-12-18—21，北京 ｜ 部署年度：**2016 年**
> 定位：**供给侧结构性改革的首年部署**——把"三去一降一补"确立为年度任务主线，同时是十三五开局之年的经济工作部署
> 上一节点：2014 年会议（未建档）｜ 下一节点：[2016 年会议](../../S/中央经济工作会议/2016.md)
> 来源：新华社（人民日报 2015-12-22 头版），[链接](http://cpc.people.com.cn/n1/2015/1222/c64094-27958723.html)

---

## 一、定调卡

**总基调**："适应经济发展新常态"，"努力实现'十三五'时期经济社会发展良好开局"；**着力加强结构性改革**，"在适度扩大总需求的同时，去产能、去库存、去杠杆、降成本、补短板"（三去一降一补）。

| 维度 | 本次表述（部署 2016 年） | 要点 |
| --- | --- | --- |
| 宏观政策组合 | "宏观政策要稳、产业政策要准、微观政策要活、改革政策要实、社会政策要托底"（五大政策支柱） | 首次系统提出五大支柱 |
| 财政政策 | **积极的财政政策要加大力度**，实行减税政策，阶段性提高财政赤字率 | 赤字率阶段性提高 |
| 货币政策 | **稳健的货币政策要灵活适度**，为结构性改革营造适宜的货币金融环境 | 降低融资成本 |
| 供给侧 | **去产能、去库存、去杠杆、降成本、补短板**（五大任务） | 本轮核心 |
| 房地产 | 化解房地产库存；推进以满足新市民为出发点的住房制度改革；发展住房租赁市场 | 去库存 = 地产主线 |
| 城镇化 | 加快提高户籍人口城镇化率 | 与去库存打通 |
| 扶贫 | 打好脱贫攻坚战，实施"五个一批" | 十三五硬任务 |
| 风险 | 防范化解金融风险，规范各类融资行为 | — |
| 改革 | 推进国有企业改革、财税体制改革、金融体制改革、养老保险制度改革、医药卫生体制改革 | 五大改革领域 |

**重点任务清单（官方排序照录）**：① 积极稳妥化解产能过剩；② 帮助企业降低成本；③ 化解房地产库存；④ 扩大有效供给（含脱贫攻坚、农业现代化）；⑤ 防范化解金融风险。
