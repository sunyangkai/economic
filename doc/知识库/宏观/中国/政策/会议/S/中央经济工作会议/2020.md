# 中央经济工作会议（2020-12-16—18）

> 会议：中央经济工作会议 ｜ 召开：2020-12-16—18，北京 ｜ 部署年度：**2021 年**
> 定位：**"十四五"开局之年的部署**——在疫情冲击后确立"构建新发展格局"为年度主线，明确"明年宏观政策要保持连续性、稳定性、可持续性"

## 一、定调卡

**总基调**：坚持稳中求进工作总基调，**立足新发展阶段，贯彻新发展理念，构建新发展格局**，以推动高质量发展为主题，以深化供给侧结构性改革为主线。

| 维度 | 本次表述（部署 2021 年） | 要点 |
| --- | --- | --- |
| 政策总要求 | 宏观政策**要保持连续性、稳定性、可持续性**；"不急转弯" | 疫情后政策退出的节奏管理 |
| 财政政策 | 积极的财政政策**要提质增效、更可持续** | 保持适度支出强度 |
| 货币政策 | 稳健的货币政策**要灵活精准、合理适度** | 处理好恢复经济与防范风险关系 |
| 新发展格局 | **构建新发展格局要迈好第一步、见到新气象** | 年度主线 |
| 需求侧 | 坚持扩大内需战略基点，**形成强大国内市场** | 与供给侧改革结合 |
| 科技 | **强化国家战略科技力量**（首位任务）、增强产业链供应链自主可控能力 | 安全导向 |
| 房地产 | 解决好大城市住房突出问题；**规范发展长租房市场** | 大城市 + 租赁 |
| 反垄断 | **强化反垄断和防止资本无序扩张** | 新增（平台经济监管） |
| 碳达峰碳中和 | 抓紧制定 2030 年前碳排放达峰行动方案 | 双碳纳入年度任务 |
| 种业 | 解决好种子和耕地问题 | 新增（粮食安全） |

**重点任务清单（官方排序照录）**：① 强化国家战略科技力量；② 增强产业链供应链自主可控能力；③ 坚持扩大内需这个战略基点；④ 全面推进改革开放；⑤ 解决好种子和耕地问题；⑥ 强化反垄断和防止资本无序扩张；⑦ 解决好大城市住房突出问题；⑧ 做好碳达峰、碳中和工作。

## 二、与上一次会议的表述对比

| 主题 | 本次（2020-12，部署 2021） | 上次（2019-12，部署 2020） | 变化类型 |
| --- | --- | --- | --- |
| 主线 | 构建新发展格局 | 高质量发展 + 三大攻坚战收官 | **升级** |
| 政策节奏 | 连续性、稳定性、可持续性（不急转弯） | 未特别强调 | 新增 |
| 科技 | 强化国家战略科技力量（首位） | 高质量发展（泛） | 升级 |
| 反垄断 | 强化反垄断和防止资本无序扩张 | 无 | **新增** |
| 双碳 | 制定 2030 年前碳达峰行动方案 | 污染防治（攻坚战口径） | 转型 |
| 种业 / 粮食 | 解决好种子和耕地问题 | 恢复生猪生产 | 口径扩展 |
