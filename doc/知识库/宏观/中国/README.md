# 中国宏观数据目录

本目录存放**中国宏观统计数据**的长期跟踪文档，按「指标 → 年份 → 月度」三层组织，保证每月更新只新增一个文件、不破坏历史记录。

## 目录结构

```
doc/宏观/中国/
├── README.md            # 本索引：目录结构、更新日历、每月维护流程
├── CPI/                 # 每个指标一个目录
│   ├── README.md        #   元信息：核心监测清单、口径提醒、数据来源、更新日历
│   ├── 历史年度.md       #   年度长序列（每年年末更新一次）
│   └── 2026/            #   年份目录
│       ├── README.md    #     当年逐月滚动序列总表 + 解读索引 + 维护记录
│       ├── 2026-01.md   #     单月文档：当月数据 + 当月解读
│       └── …（逐月）
├── PMI/
├── PPI/
├── 外贸/
├── 央行/
├── 工业企业利润/
├── 工业增加值/
├── 投资/
├── 社零/
├── 财政部/
├── 政策.md              # 五年规划政策脉络（非月度统计数据，保持单文件）
└── 总览/                # 月度综合评价（每月一个文件，如 2026年8月.md）
```

## 各指标更新日历

| 指标 | 发布频率 | 发布时点 | 当月文档归入 |
|------|------|------|------|
| PMI | 月度 | 每月最后一天 / 次月首日 | 当月（如 7 月数据 → 2026-07.md） |
| 外贸 | 月度 | 次月 7—9 日 | 当月 |
| CPI / PPI | 月度 | 次月 9 日前后 | 当月 |
| 央行 | 月度 | 次月中旬（10—15 日） | 当月 |
| 社零 / 工业增加值 / 投资 | 月度 | 次月 15 日前后 | 当月 |
| 财政部 | 月度 | 次月 18—22 日 | 当月 |
| 工业企业利润 | 月度 | 次月 27 日前后 | 当月 |

> 注：央行、外贸等指标 1—2 月为春节月**合并发布**；社零、工业增加值 1 月免报（1—2 月合并）。合并期间（如"1—2 月""上半年""1—7 月"）的解读与截面数据统一归入该期间**最后一个月**的文档。

## 每月维护流程

1. **新建单月文档**：在对应指标 `2026/` 目录下新建 `2026-XX.md`，结构固定为：
   - 标题：`# <指标名>｜2026 年 X 月（数据发布：YYYY-MM-DD）`
   - 头部引用块：数据版本、下次更新、数据来源
   - `## 本期速览`：核心指标判断表
   - `## 本月数据`：当月单月数据 + 当月累计口径数据
   - `## 解读`：判断表 + 分点解读 + 深入观点小结
   - 文末：`> 拆分自原《<指标名>.md》2026-08 版本。` 改为本次维护说明
2. **更新当年滚动序列**：在对应指标 `2026/README.md` 的逐月滚动表中追加该月一行，更新「解读索引」表（新增一行）与「维护记录」。
3. **更新总览**：在 `总览/` 新建当月评价文件（复制上月骨架，刷新数据快照与判断），并在「数据版本」表登记各指标最新版本。
4. **数据纪律**：所有数字以官方发布为准；不编造、不推算缺失分项；跨月比较注意基期与口径变化（见各指标 README「口径提醒」）。

## 与总览的关系

- `总览/`：每月一份的**综合评价**（总体判断 + 数据快照 + 板块解读 + 情景风险），是各指标文档的"索引 + 判断层"；
- 本目录下各指标文件夹：**数据层**，需要查具体数字、历史序列、口径细节时回看对应指标。
