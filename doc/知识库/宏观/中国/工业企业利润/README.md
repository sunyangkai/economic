# 工业企业利润（中国规模以上工业企业利润数据）

> **数据版本：2026 年 1—6 月（2026-07-27 发布）**
> 下次更新：2026-08-27 前后（1—7 月）
> 数据来源：国家统计局月度发布与解读（stats.gov.cn）

---

## 长期口径警示（每次看数据前先过一遍）

- **可比口径**：利润增速按"可比口径"计算，扣除统计范围变化（企业进退出规上名录）等影响，与上年公布值存在口径差异。
- **累计与单月不可直接比较**：本文以累计（1—6 月）为主；单月数为统计局公布的当月数，不可直接与累计增速比较。
- **名义值**：利润、营收均为名义值，不扣除价格因素；与工业增加值（实际增速）背离属正常。

## 一、核心监测清单（重要数据看哪些）

| 指标 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| 利润总额与增速 | 月度（次月 27 日前后） | 企业盈利总盘子；高增不等于全面复苏 |
| 营业收入 / 营收利润率 | 月度 | 盈利质量；利润率上升=效益改善 |
| 分行业利润（上游资源 vs 中下游制造） | 月度 | 利润分配结构；上游暴增+下游转负=涨价挤压 |
| 分经济类型（国有 / 股份制 / 外资 / 私营） | 月度 | 不同所有制主体的盈利分化 |
| 产成品存货 / 应收账款 | 月度 | 库存周期与资金链压力；快于营收=占用上升 |
| 每百元营收成本 / 费用 | 月度 | 成本传导与费用刚性 |

> **只盯四个核心数字：利润总额增速、营收利润率、上游-中下游利润差、产成品存货增速。**

## 二、口径提醒

- **可比口径**：利润增速按"可比口径"计算，扣除统计范围变化（企业进退出规上名录）等影响，与上年公布值存在口径差异。
- **规模以上口径**：年主营业务收入 2000 万元及以上的工业企业。
- **累计与单月**：本文以累计（1—6 月）为主；6 月单月 +15.1% 为统计局公布的当月数，不可直接与累计增速比较。
- **名义值**：利润、营收均为名义值，不扣除价格因素；与工业增加值（实际增速）背离属正常。
- **行业划分**：按国民经济行业分类标准（GB/T 4754-2017）的大类统计。
- **资产负债数据**：为 6 月末时点数；周转天数、回收期同比增减以"天"计。

## 三、数据来源与查找指南

- 国家统计局官网（stats.gov.cn）→「数据解读 / 最新发布」→《2026 年 1—X 月份全国规模以上工业企业利润》，次月 **27 日前后** 发布。
- 交叉验证：PPI 购进价-出厂价差（验证成本挤压）、PMI 价格分项（先行验证）、外贸数据（验证电子等出口链盈利）、工业增加值（验证量）。
- 常用检索词："2026 年 1—X 月份全国规模以上工业企业利润"、"规模以上工业企业利润增长"。
