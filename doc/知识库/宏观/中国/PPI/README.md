# 中国工业生产者出厂价格指数数据（PPI）— 指标目录

> **⚠️ 2026 年基期轮换（长期口径警示）**：2026 年 1 月起 PPI 改用 **2025 年为基期**（此前为 2020 年），调查分类、调查企业、权数均有调整，经测算对同比指数影响平均约 **0.08pct**，不影响趋势判断，但与 2025 年及以前比较时注意基期差异。

## 一、核心监测清单（重要数据看哪些）

| 指标 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| PPI 同比 / 环比 | 月度（次月 9 日左右） | 工业品出厂价格总水平；同比看趋势，环比看边际拐点 |
| 生产资料 vs 生活资料 | 月度 | 上游成本 vs 下游消费价格的传导是否顺畅 |
| 采掘 / 原材料 / 加工 | 月度 | 涨价沿产业链的传导深度（采掘涨而加工不涨=传导受阻） |
| 主要行业（煤炭、石油、有色、黑色、化工、建材、汽车、电子） | 月度 | 各产业链景气：煤炭/石油/有色=资源端；黑色/建材=地产链；汽车=产能与价格战；电子=AI 新动能 |
| 购进价格（PPIRM） | 月度 | 企业成本端；与出厂价之差=利润空间与传导压力 |
| CPI-PPI 剪刀差 | 月度 | 上游与下游价格背离程度：为负=上游涨/下游跌，挤压中下游 |

> **只盯五个核心数字：PPI 同比、PPI 环比、生产资料同比、PPIRM 同比、CPI-PPI 剪刀差。**

## 三、口径提醒

- **基期轮换（重要）**：2026 年 1 月起 PPI 改用 **2025 年为基期**（此前为 2020 年），调查分类、调查企业、权数均有调整，经测算对同比指数影响平均约 **0.08pct**。与 2025 年及以前比较时注意基期差异。
- **统计范围**：PPI 覆盖 **41 个工业行业大类、1300 多个基本分类**；购进价格（PPIRM）覆盖 **9 大类**（燃料动力、黑色金属、有色金属、化工原料、木材纸浆、建材非金属、农副产品、纺织原料、其他）。
- **公布规则**：同比、环比均四舍五入保留 **1 位小数**，0 视为持平。
- **剪刀差解读**：CPI-PPI 为负=上游涨/下游跌（成本挤压）；购进-出厂为正=企业成本端压力大于售价端，中下游利润承压。
- **基期与季节因素**：春节错位影响 1—2 月同比；环比已作季节调整（统计局口径）。

## 四、数据来源与查找指南

- 国家统计局官网（stats.gov.cn）→「数据」→「月度数据」→「工业生产者价格指数」，每月 **9 日左右**发布上月数据。
- 月度新闻稿标题：《2026 年 X 月工业生产者出厂价格指数（PPI）数据》。
- 解读文章：《2026 年 X 月工业生产者价格指数解读》（董莉娟，统计局新闻办）。
- 辅助交叉验证：中国人民银行《企业商品价格指数》、国家发改委价格监测中心大宗商品价格。
