# 中国工业生产者出厂价格指数数据（PPI）｜历史数据（年度长序列）

| 年份 | PPI 同比 | 阶段特征 |
|------|:------:|------|
| 2016 | -1.4% | 去产能驱动期 |
| 2017 | +6.3% | 供给侧改革，PPI 高增 |
| 2018 | +3.5% | 去产能延续 |
| 2019 | -0.3% | 内需走弱 |
| 2020 | -1.8% | 疫情冲击 |
| 2021 | +8.1% | 大宗商品暴涨 |
| 2022 | +4.1% | 俄乌冲突能源通胀 |
| 2023 | -3.0% | 通缩压力 |
| 2024 | -2.2% | 通缩延续 |
| 2025 | -2.6% | 通缩磨底 |
| 2026（1—7 月） | **+1.8%** | 企稳回升（基期已轮换至 2025 年） |

> 阶段划分：**去产能驱动期（2016—18）→ 疫情冲击期（2019—20）→ 大宗通胀期（2021—22）→ 通缩压力期（2023—25）→ 企稳回升期（2026 起）**。本轮回升与 2021 年的区别：2021 年是全球需求共振 + 供给短缺，本轮主要是资源品供给收缩与输入性涨价，需求端证据仍不足。

> 注：2026 年各月明细见 2026/ 目录，全年数据待年度结束后更新。
