## 口径决定

1. **分部口径 = 官方"报告分部"四分法**：化学业务（WuXi Chemistry）/ 测试业务（WuXi Testing）/ 生物学业务（WuXi Biology）/ 其他业务（Others），并区分**持续经营 / 终止经营**——2025 年公司完成 WuXi ATU 业务的美国和英国运营主体及美国医疗器械测试业务出售（终止经营收入 2025A 20.35 亿、2026H1 归零），可比期间已重述。**旧版"ATU / DDSU 独立分部"口径作废**。
2. **利润双口径并存，估值用调整后基数**：①归母净利（含非经常）；②扣非归母。2025A 归母 191.51 亿中含**出售联营企业药明合联（WuXi XDC Cayman）部分股权及剥离业务收益**（投资收益 85.88 亿，2024A 仅 6.04 亿），扣非归母 132.41 亿——**2025 归母被一次性收益抬高约 45%，跨期比较一律双口径并列**。**2026 前三季：归母 193.98 亿（+60.6%）/ 扣非 164.77 亿（+73.0%）**，非经常 29.22 亿（H1 仅 5.08、Q3 单季 24.14——来自 08-28 出售药明合联 4.23%，税前约 31.43 亿）。**注意：2026 年仍有大额处置收益，但归母增速（+60.6%）低于扣非增速（+73.0%）——扣非更高是质量更好的证据，不是经营走弱。**
3. **EPS 三口径**：①年报基本 EPS 6.70 元（加权平均股本 ≈28.6 亿股，含库存股扣减）；②期末股本口径 = 归母 ÷ 期末总股本；③扣非 EPS 4.63 元。**机构一致预期与本文估值统一用"期末股本口径"**（2025 年报披露时点总股本 30.12 亿股：191.51/30.12 = 6.36 元，与东财一致预期 2025A EPS 6.3594 完全吻合）。总股本变动：2023 末 29.69 → 2024 末 28.88（回购注销）→ 2025 末 29.84 亿股（**2025-08-07 完成 7,380 万股 H 股配售 @104.27 港元**）→ **2026-09-30 30.349 亿股**（**67.8 亿元美元结算零息可转债于 2026-09-23 悉数转股**，转 H 股）。**估值与一致预期统一用 30.349 亿股**（校验：2025A 归母 191.51 ÷ 30.349 = 6.31 元，与东财一致预期 2025A EPS 6.3101 吻合）。
4. **区域收入口径 = 管理层讨论口径**（持续经营业务，按客户所在地）：美国 / 欧洲 / 中国 / 其他地区。分地区表另按"境内 / 境外"披露（客户母公司所在地）。美元收入占主导（美国客户 72%），**汇兑损益计入财务费用**（2025A 汇兑损失 10.14 亿 vs 2024A 收益 4.53 亿，系美元兑人民币下行）。
5. **non-IFRS 经调整口径**（公司港股披露习惯）：经调整归母净利（加回股权激励费用等）、经调整自由现金流（经营现金流 − capex）。**2026 前三季：经调整归母 183.80 亿（净利率 40.4%，上年同期 32.1%）、经调整 FCF 121.99 亿**；**2026 全年经调整 FCF 指引已上调至 145-155 亿**（三季报，原 135-145 亿）。该口径仅用于管理层表态与 FCF 佐证，估值基数仍用 A 股口径调整后利润。
6. **净现金口径**：货币资金 351.3 + 交易性金融资产（理财）58.1 − 有息负债（短借 59.9 + 一年内到期 1.6 + 长借 18.2 = 79.7）= **净现金 ≈ 329.7 亿（2025-12-31）**；**2026-09-30：货币资金 371.3 + 理财 163.4 − 有息负债（61.8 + 1.5 + 18.0 = 81.3）= 净现金 ≈ 453.5 亿**（占市值 10.2%）。另持投资组合：其他非流动金融资产 76.2 + 长期股权投资 18.4 = 94.6 亿（2026-09-30）——**货币资金+理财已作为 F 进入模型（垫付扩张支出），不单独加回；投资组合不参与估值**，作安全边际披露。
7. **周期与拐点读数前提**：CXO 订单领先收入（在手订单 → 1-2 年转化），利润被公允价值变动 / 投资处置 / 汇兑三重扰动；2024 年为行业下行年（收入 -2.7%），2025-2026 为订单兑现拐点（美国客户收入 +34.3%）。
8. **现价口径**：**146.00 元**（2026-10-26 收盘，腾讯行情），总市值 **4,431.0 亿**、PE-TTM 16.74×（归母 264.73 亿）/ 21.94×（扣非 201.95 亿）、PB 4.58×（归母权益 968.45 亿）。财务基线 = **2025 年报**（2026-03-24 披露），最新实绩 = **2026 三季报**（2026-10-26 披露），此后实绩一律进 `财报跟踪/`。

## 估值参数留痕（2026-11 重写）

**基准利润**：**2026E 扣非归母 221 亿**（EPS 7.28 元）——前三季 164.77 + Q4 推算 56.2；不取归母 250 亿（含 08-28 出售药明合联 4.23% 的税后一次性收益约 25 亿）。

- 2021-2024 是产能爬坡期（在建工程先计入 IC、产能后满产），按模型 §3.4 **不取爬坡期 ROIC**；取 2025 年满产年。
- 研发费用 2021-2025 累计 **63.5 亿**全部费用化（9.42 + 16.14 + 14.41 + 12.39 + 11.19），按模型 §3.4"表外资本先并进 IC"并入分母：126.4 / (369.7 + 63.5) = **29.2%**（只并分母、不把研发加回 NOPAT，偏保守）。
- **θx = 1 − 2.33% / 29.2% = 92.0%**。若用报表值 34.2%，θx = 93.2%（估值 +2 元）；若用 5 年中位 25.9%，θx = 91.0%（估值 −1 元）——**θx 对结论不敏感**。

## 已知口径坑

- **"持续经营收入 434.2 亿"与"总收入 454.6 亿"别混**：终止经营业务（ATU 美英主体 + 美国医疗器械测试）2025 年收入 20.35 亿、2026 年起归零；同比增速以各自口径计算（持续经营 +21.4%、总收入 +15.8%）。
- **投资收益 85.88 亿在"投资收益"科目、不在终止经营**：出售药明合联部分股权（联营企业权益法处置）走持续经营口径的投资收益；剥离业务收益计入终止经营损益；扣非口径两者均已剔除。
- 2025H1 归母 85.61 亿中非经常 ≈ +29.8 亿（药明合联出售收益主段），2025H2 非经常 ≈ +29.3 亿；2026H1 非经常仅 +5.1 亿——**2026 年归母增速（+29.4%）远低于扣非增速（+89.4%）系基数效应**。
- EPS 分母：机构预测/估值用期末总股本（当前 30.349 亿股，2026-09-30 可转债转股后）；年报披露基本 EPS 用加权平均股本（≈28.6 亿股，含库存股扣减）——两者相差约 5%，跨口径引用需注明。
- H 股（02359.HK）与 A 股（603259.SH）同股同权；HKSCC NOMINEES 持 17.1% 为 H 股名义持有，与北向"香港中央结算（沪股通）"是两回事。
