2. **利润双口径并存，估值用调整后基数**：①归母净利（含非经常）；②扣非归母。2025A 归母 191.51 亿中含**出售联营企业药明合联（WuXi XDC Cayman）部分股权及剥离业务收益**（投资收益 85.88 亿，2024A 仅 6.04 亿），扣非归母 132.41 亿——**2025 归母被一次性收益抬高约 45%，跨期比较一律双口径并列**。**2026 前三季：归母 193.98 亿（+60.6%）/ 扣非 164.77 亿（+73.0%）**，非经常 29.22 亿（H1 仅 5.08、Q3 单季 24.14——来自 08-28 出售药明合联 4.23%，税前约 31.43 亿）。**注意：2026 年仍有大额处置收益，但归母增速（+60.6%）低于扣非增速（+73.0%）——扣非更高是质量更好的证据，不是经营走弱。**
3. **EPS 三口径**：①年报基本 EPS 6.70 元（加权平均股本 ≈28.6 亿股，含库存股扣减）；②期末股本口径 = 归母 ÷ 期末总股本；③扣非 EPS 4.63 元。**机构一致预期与本文估值统一用"期末股本口径"**（当前总股本约 30.12 亿股：191.51/30.12 = 6.36 元，与东财一致预期 2025A EPS 6.3594 完全吻合）。总股本变动：2023 末 29.69 → 2024 末 28.88（回购注销）→ 2025 末 29.84 亿股（**2025-08-07 完成 7,380 万股 H 股配售 @104.27 港元**）→ **2026-09-30 30.349 亿股**（**67.8 亿元美元结算零息可转债于 2026-09-23 悉数转股**，转 H 股）。**估值与一致预期统一用 30.349 亿股**（校验：2025A 归母 191.51 ÷ 30.349 = 6.31 元，与东财一致预期 2025A EPS 6.3101 吻合）。
4. **区域收入口径 = 管理层讨论口径**（持续经营业务，按客户所在地）：美国 / 欧洲 / 中国 / 其他地区。分地区表另按"境内 / 境外"披露（客户母公司所在地）。美元收入占主导（美国客户 72%），**汇兑损益计入财务费用**（2025A 汇兑损失 10.14 亿 vs 2024A 收益 4.53 亿，系美元兑人民币下行）。

7. **周期与拐点读数前提**：CXO 订单领先收入（在手订单 → 1-2 年转化），利润被公允价值变动 / 投资处置 / 汇兑三重扰动；2024 年为行业下行年（收入 -2.7%），2025-2026 为订单兑现拐点（美国客户收入 +34.3%）。
8. **现价口径**：**146.00 元**（2026-10-26 收盘，腾讯行情），总市值 **4,431.0 亿**、PE-TTM 20.45×（归母）/ 21.94×（扣非）、PB 5.42×。财务基线 = **2025 年报**（2026-03-24 披露），最新实绩 = **2026 三季报**（2026-10-26 披露），此后实绩一律进 `财报跟踪/`。

## θ 测定依据（留痕，2026-10-26 按新模型重测）

> **新模型口径**：R = rf 1.65% + ERP 6.8% = **8.45%**、过渡期**固定 7 年**、g∞ ≈ 2.33%；θₓ 从"经验区间取值"改为**可复算的 ROIC 稳态锚** $	heta_x = 1 - g_\infty/ROIC_{经营}$，再打"表外资本折扣"。

- **θ₀ ≈ 0.82**（上一版 0.85，本次下调）。按模型公式 $DP_0 = NP_{adj,0} + DA_0 - MC_0 - \Delta WC^{norm}_0$：

  | 项 | 取值 | 依据 |
  | --- | ---: | --- |
  | NP_adj,0 | **221 亿** | 2026E 扣非归母（前三季 164.77 + Q4 推算 56.2）；**不取归母 250 亿**（含处置收益约 25 亿税后一次性） |
  | + DA₀ | 40 亿 | 2025A 35.6 亿，新产能转固后上行 |
  | − 维持性 capex | 42 亿 | 2026 总 capex 指引 80-85 亿，约一半属维持性 |
  | − 正常化 ΔWC | 38 亿 | 前三季 WC 由 111.0 → 149.3 亿（+38.3），其中约 1/3 属常态化占用 |
  | **= DP₀** | **181 亿** | → θ₀ = 181 / 221 = **0.82** |

  **两口径校验**：①官方经调整 FCF 指引 145-155 亿（含全部 capex）÷ 221 ≈ **0.66-0.70**；②"扣非 − 扩张性 capex（约 42 亿）" ÷ 221 ≈ **0.81**。公式值 0.82 与口径②一致、高于口径①——**取 0.82**（口径①偏低是因为它把扩张性 capex 也当成了永续支出，而扩张性 capex 在稳态不应持续）。

  **为什么比上一版低（0.85 → 0.82）**：①capex 指引由 75-85 上调至 80-85 亿；②**营运资本占收入比由 2025 末 24.4% 升至 2026-09-30 的 32.8%**（应收+存货−应付−合同负债 149.3 亿 / TTM 收入 581.4 亿）——增长确实在更多占用营运资本，这是本期最实在的 θ₀ 下调理由。

- **θₓ = 0.85**（上一版 0.82）。**ROIC 稳态锚复算**（NOPAT 剔除非经营损益：投资收益、公允价值变动、其他收益、资产处置收益）：

  | 年度 | NOPAT | NFA（固资+在建） | WC | IC | ROIC_经营 | 锚值 θₓ |
  | --- | ---: | ---: | ---: | ---: | ---: | ---: |
  | 2021 | 37.1 | 143.3 | 56.1 | 199.3 | 18.6% | 0.875 |
  | 2022 | 75.6 | 216.4 | 75.0 | 291.5 | 25.9% | 0.910 |
  | 2023 | 89.4 | 241.7 | 90.4 | 332.1 | 26.9% | 0.913 |
  | 2024 | 79.1 | 247.5 | 93.5 | 341.0 | 23.2% | 0.900 |
  | 2025 | 126.5 | 258.8 | 111.0 | 369.7 | 34.2% | 0.932 |
  | **5 年中位** | | | | | **25.9%** | **0.910** |

  **为什么取 0.85 而不是锚值 0.91**：①锚值基于 5 年中位 ROIC 25.9%，但样本含 2021-2024 年产能爬坡期（ROIC 被在建工程拖低）；②模型文档要求"锚之上再打一道表外资本折扣"——本公司研发费用全部费用化（2021-2025 五年累计 63.5 亿），若资本化则 IC 增至 433 亿、ROIC 降至 22.1%、锚值降至 0.895；③商誉与并购形成的无形资产不进 IC，同样压低真实回报。**取 θₓ = 0.85**（锚值 0.910 下调 0.06，等于对"表外资本"与"周期波动"各让一步）。

- **θ = 0.15 × 0.82 + 0.85 × 0.85 = 0.123 + 0.7225 ≈ 0.8455**，测定后固定。

- **θ 敏感性（披露用，不改基准）**：基准路径下 θ 取 0.75 / 0.80 / **0.8455** / 0.90 对应 **168 / 180 / 190 / 202 元**——θ 在 0.75-0.90 区间内内在价值均高于现价 146 元，结论不因 θ 取值翻转。

## 已知口径坑

- **"持续经营收入 434.2 亿"与"总收入 454.6 亿"别混**：终止经营业务（ATU 美英主体 + 美国医疗器械测试）2025 年收入 20.35 亿、2026 年起归零；同比增速以各自口径计算（持续经营 +21.4%、总收入 +15.8%）。
