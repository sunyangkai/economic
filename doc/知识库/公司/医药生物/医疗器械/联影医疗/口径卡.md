## 口径决定

1. **利润一律归母口径**。少数股东损益 2025A 为 -0.25 亿（占合并净利 -1.4%），规模小、可忽略；2024A -0.20 亿、2023A +0.03 亿。
2. **两套地区口径并存，不可混用**：
   - **分地区表口径**（年报"主营业务分地区"）：境内 97.60 亿 / 境外 33.93 亿（+52.81%），境外占主营业务收入 **25.79%**；
   - **管理层讨论口径**（按终端客户装机所在地统计）：中国市场 103.69 亿 / 海外 34.31 亿，海外占总营业收入 **24.86%**。
   - 差异源于统计基础（主营业务收入 vs 总营业收入、注册地 vs 终端装机地）。**主报告统一用分地区表口径（境外 33.93 亿 / 25.79%）**，引用管理层口径时注明。
3. **EPS 双口径**：机构口径（东财）2025A 2.2681 元 = 按最新总股本 8.2416 亿股折算；年报基本 EPS 2.28 元 = 加权平均股本口径。全文与一致预期对比统一用**机构口径**。
4. **市值 / PE-TTM 按东财口径**（最新总股本）：107.00 元 → 总市值约 881.9 亿元、PE-TTM 49.87×、PB 4.00×。
5. **净现金为自算**：货币资金 + 交易性金融资产 −（短期借款 + 一年内到期非流动负债 + 租赁负债），2025-12-31 = 55.03 + 49.27 −（9.45 + 0.59 + 2.53）= **92.47 亿元**（约 11.2 元/股）。
6. **研发双口径**：研发费用 18.42 亿（费用化，费率 13.35%）；研发投入合计 26.21 亿（含资本化 7.79 亿，占收入 18.99%）。主报告用**研发费用**作费率口径，资本化部分单列说明。
7. **实际税率偏低**：2025A 6.93%（2024A 8.12%、2023A 7.68%），主因高新技术企业 15% 优惠税率 + 研发加计扣除。**读净利率时不能按 25% 名义税率倒推**。
8. **其他收益体量大**：2025A 4.34 亿（政府补助为主，占利润总额 21.9%），2024A 4.44 亿、2023A 5.86 亿、2022A 5.92 亿——属经常性但非经营性，读营业利润时须单列。
9. **现价口径**：107.00 元（2026-09-08 收盘，东财/腾讯行情；2026 年中期分红 10 派 1.30 元于 2026-09-09 除权除息，现价为含权价）。

## 已知口径坑

- **境外占比两个数**：25.79%（分地区表 / 主营口径）vs 24.86%（管理层 / 总营收 + 终端装机地口径）——写作时先声明用哪一个，全文不混用。
- **"设备收入"口径**：2025 年报"分产品"表中"销售医学影像诊断设备及放射治疗设备"113.90 亿，与业务线合计（MR 45.48 + CT 35.45 + MI 19.08 + XR 7.98 + RT 5.91 = 113.90）一致；**生命科学仪器（动物 MR / 动物 PET/CT）并入设备收入**，不单列。
- **超声收入未单列**：2025-11 才获批上市，2025 年报与 2026 中报均未单独披露超声收入（2026 中报仅在设备收入内合并），无法从报表倒推。
- **2026 中报数据不属主报告基线**：主报告三章基线为 2025 年报；2026 中报实绩只在四章"解释分歧"处引用一次并指向 `财报跟踪/`。
- **机构一致预期覆盖年份**：中金公司未给 2028E；近六月平均行由 19 家机构构成，2028E 平均值为 18 家口径。
