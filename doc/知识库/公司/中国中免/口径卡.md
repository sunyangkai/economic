# 中国中免（601888.SH / 1880.HK）· 口径卡

> **as-of 2026-09-08**（2025 年报基线 + 2026-09-08 行情快照）｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。来源见同目录 [来源索引.md](来源索引.md)。

## 口径决定

1. **利润一律归母口径**。但注意：中免少数股东损益近年波动大（2023A 5.53 / 2024A 5.95 / 2025A 1.03 / 2025H1 3.07 / 2026H1 -0.62 亿），**归母增速与净利润增速会显著背离**——日上上海（51%）、海免（51%）等控股非全资主体的盈亏在少数股东与归母之间分摊。读增速先问"是经营改善还是少数股东摆动"：2026H1 归母 +19.5% 中约 3.7 亿（+14pp 增速）来自少数股东损益由正转负，营业利润本身只 +0.1%。
2. **有效税率失真，2025A 不能外推**：2025A 有效税率 30.5%（所得税 16.18 / 利润总额 53.07），其中"调整期初递延所得税资产 +5.03 亿"为一次性非现金税项、"本期未确认递延所得税资产的可抵扣亏损 +3.38 亿"为亏损子公司（日上上海）扭曲，"子公司适用不同税率 -3.90 亿"为海南 15% 优惠节税。正常化税率中枢约 18–21%（2026H1 实际 18.1%）。预测 2026 年起税率按 ~18% 处理并注明。
3. **分部披露层级**：官方披露到"分产品（免税/有税）+ 分地区（海南/上海）+ 分行业（商品销售业）"三层，**各层只披露收入与毛利率，不披露分部利润**；更细的门店/主体利润只能从"主要子公司表"读（三亚市内免税店、日上上海、海口免税城、中免国际、海免——合并口径、日上上海经公允价值调整）。半年度报告**不披露**分产品/分地区表。
4. **免税 vs 有税业务是两门生意**：免税毛利率 36.97%（2025A）、有税毛利率 17.13%（2025A）——有税业务收缩对毛利率是结构性利好；免税收入增速才是核心景气指标（2025A +1.29%）。
5. **税金及附加含特许经营费**：离境 1%、离岛 4%（按免税品销售收入计缴），2025A 税金及附加 12.62 亿。离岛特许费率高于离境，海南销售占比变化直接影响该项。
6. **减值的口径拆分**：2025A 资产减值 8.79 亿 = 存货跌价 5.33（常态化，2024A 7.42）+ 商誉减值 3.38（上海地区业务，一次性）。预测时存货跌价按年收入 ~1% 常态处理，商誉减值不外推。
7. **股本/EPS 双口径**：2025A 报表 EPS 1.7334（股本 20.69 亿）；**估值与情景表一律用基期 EPS 1.7256 元**（2025 归母 35.86 亿 ÷ 现总股本 20.78 亿，与一致预期 2025A EPS 1.726 同口径）。2026-03-19 增发 893.76 万股 H 股后历史 EPS 与现股本不可直接对比。
8. **总市值口径**：行情接口"总市值 1,139.26 亿"= A 股价 × A+H 总股本；A/H 两个市场实际价差存在（A 54.83 元 vs H 50.20 港元，2026-09-08 盘中），跨市场比较时注明。
9. **现金口径**：货币资金 337.81 亿中含存放关联方中旅集团财务公司存款 89.69 亿（2025A，经风险持续评估报告审议）；"其他流动资产"43.69 亿主要是定期存款。净现金测算时两者都要算入。
10. **估值口径**：θ₀ = 0.95、θₓ = 0.90，固定 θ = 0.9075（测定过程见主报告五章；测定后固定，不做 θ 分档）；R = rf 1.8% + 5.5% = 7.3%，g∞ ≈ 2.33%（m=4），过渡期统一 3 年；基期利润 = 2025 归母 35.86 亿。模型见 `doc/估值理论/估值模型.md`，计算用 `tools/valuation.js`。
11. **基线锚定**：财务基线 = 2025 年报（2026-03-30 披露）。2026 中报（2026-08-20 披露）为"最新已披露报告期"，其数字只在主报告四章以"解释分歧"例外出现一次（§一.5），完整读数见 `doc/研报/公司/中国中免/财报跟踪/2026中报.md`（已建档；历史报告期不回补）。
