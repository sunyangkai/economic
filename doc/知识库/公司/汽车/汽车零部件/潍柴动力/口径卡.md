# 潍柴动力（000338.SZ / 02338.HK）· 口径卡

> **as-of 2026-09-22** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润一律归母口径**。少数股东损益占比高且随凯傲波动：2025 年 27.50 亿元、占合并净利润 136.80 亿元的 20.1%；2026H1 18.38 亿元、占合并净利润 95.40 亿元的 19.3%。**读合并口径的分部业绩或子公司净利润时，须按持股比例折回归母**——凯傲权益比例 46.52%（潍柴卢森堡持股，单一最大股东、并表，少数股东占 53.48%），陕重汽、法士特、潍柴雷沃均为非全资。

2. **两套业务口径不可混用**：
   - **分部口径**（财务报告附注"分部信息"，四个经营分部：发动机 / 汽车及汽车零部件 / 农业装备 / 智慧物流）——给外部客户销售与**分部业绩**，用于利润结构与利润率分析；
   - **分产品口径**（"营业收入构成"表：动力总成、整车整机及关键零部件 / 其他零部件 / 智慧物流 / 农业装备 / 其他）——给分产品毛利率，用于毛利率归因。
   - 两套口径的收入切分不同（分部口径把陕重汽整车、法士特变速箱、汉德车桥并入"汽车及汽车零部件"，分产品口径把整车与动力总成合并为"动力总成、整车整机及关键零部件"），**不可互换、不可相加**。2026 年中报起分产品口径把"其他零部件"改为"其他非主要汽车零部件"单列，跨期比较需注意。

3. **分部业绩 ≠ 净利润**。官方定义：分部业绩为"对利润总额进行调整后的指标，除不包括**财务费用、投资收益、公允价值变动损益以及其他未分配收益或开支**之外，与该集团利润总额一致"。三条推论：
   - ① **减值损失（资产 + 信用）、其他收益、资产处置收益都已包含在分部业绩之内**——不得在分部业绩之外再单列这几项做增量分解，否则重复计列（2026-09 写作时曾犯此错）；
   - ② 分部业绩与**利润总额**之间的差额只有利息收入、股息收入及未分配收益、企业及其他未分配开支、财务成本四项，可逐项还原。官方调节式：`利润总额 = 分部业绩合计 + 利息收入 + 股息收入及未分配收益 + 企业及其他未分配开支 − 财务成本`（2025H1：68.99 + 17.72 + 0.87 − 0.65 − 13.03 = 73.90；2026H1：100.69 + 17.46 + 20.29 − 0.76 − 23.92 = 113.75）；
   - ③ 分部业绩与**归母净利**之间还隔着所得税与少数股东损益，2025 年该差额为 153.96 − 109.31 = **44.65 亿元**（分部业绩 vs 利润总额仅差 +8.18 亿元，勿混用两个差额）。

4. **EPS 双口径**：机构口径 1.2651 元（2025A）= 归母 109.31 亿元 ÷ 最新享有利润分配权股本 8,640,220,621 股（与东方财富一致预期同口径，全文与一致预期对比统一用此口径）；年报基本 EPS 1.27 元 = 加权平均股本口径。**估值情景表的基准年 EPS 用 1.2651 元**。

5. **第三年（2028）机构预测覆盖不全**：`api/orgForecast.js` 近六月平均含 2028E EPS 2.5750 元，但样本内 16 家机构中多数仅给到 2027E；2028E 属"机构未充分覆盖、按延续假设"处理，引用时须注明。

6. **现价口径**：A 股 27.03 元（2026-09-22 收盘）、H 股 31.06 港元（同日收盘）。总市值按总股本 8,640,220,621 股计 2,335.45 亿元（与东财口径一致）。

7. **实际税率**：2025 年 15.63%、2026H1 16.14%（`api/mainFinanceData.js` TAXRATE）。凯傲为德国税制、境外税率高于境内，**境外利润占比（2025 年收入 53%）变化会带动有效税率漂移**，读利润弹性时不可假定税率固定。

8. **汇兑对财务费用的影响是双向大口径**：2025 年财务费用 -4.54 亿元（净收益，主因汇兑收益），2026H1 +6.46 亿元（主因汇兑损失），单期摆动超 10 亿元、影响归母约 8 亿元量级。**公司口径未单独披露汇兑损益金额**，只给"主要系汇兑损益变动所致"的定性说明——主报告中该部分只能定性处理，不得自行编造汇兑数字。

## θ₀ 测定过程（可复核）

DP₀ = NP_adj,0 + DA₀ − MC₀ − ΔWC_norm₀：

| 项 | 取值（2025，亿元） | 依据 |
| --- | ---: | --- |
| NP_adj,0（扣非归母） | 96.62 | 年报扣非归母，剔除 KION 效率计划等一次性 |
| DA₀ | 135.98 | 现金流补充资料：固定资产/投资性房地产/使用权资产折旧 110.99 + 无形资产摊销 23.39 + 长期待摊摊销 1.60 |
| MC₀（维持性资本开支） | 67.97 | 购建固定资产、无形资产和其他长期资产支付的现金（含扩张性投入，作维持性开支保守上限） |
| ΔWC_norm₀ | 0 | 经营营运资本净额为负且 2023/2025 两年分别净贡献现金 170.4/153.5 亿元，按模型"只扣常态占用"取 0，不使用单年波动 |
| **DP₀** | **164.63** | = 96.62 + 135.98 − 67.97 − 0 |
| **θ₀** | **1.70** | = 164.63 / 96.62 |

同口径 2023 年 1.59、2024 年 1.51，三年中枢约 1.60——**θ₀ 长期大于 1**（折旧摊销约为资本开支的 2 倍）是本公司利润兑现画像的结构性特征，不是单年现象。θₓ 取 0.70（模型"重资产、强营运资本占用行业 0.50—0.70"上沿），与实际分派（2025 年分红 + 回购占归母 65%）相互印证；θ = 0.15×1.70 + 0.85×0.70 = **0.850**。

## 已知口径坑

- **中报未披露处置长期股权投资 13.13 亿元的具体标的**：中报"出售重大股权情况"勾选"不适用"，长期股权投资附注中仅见"其他联营企业"减少投资 7.12 亿元，无法据披露还原交易对手与标的，**引用时只能写金额与"处置长期股权投资"性质，不得猜测标的**。
- **凯傲口径为欧元、报表为人民币**：收入/利润的同比受欧元兑人民币汇率影响，且凯傲固定资产、商誉（合计商誉 252.69 亿元中凯傲与 Dematic 占绝大部分）在折算中随汇率波动——2026H1 商誉由 252.69 亿元降至 242.81 亿元，主要是汇率折算而非减值。
- **"境外资产占公司总资产 35.87%"（2026-06-30）几乎全部是凯傲**，境外收入占比 51%—53% 也主要由凯傲贡献，**"出海"叙事须区分凯傲的欧洲本地业务与中国主体的产品出口**（陕重汽 2026H1 出口 3.1 万辆、发动机出口 2025 年 7.5 万台才是中国主体的出口口径）。
- **发动机销量 74.3 万台 ≠ 重卡配套量**：含工程机械、农机、发电、船舶等非道路配套与出口，**不可用重卡行业销量直接推算公司发动机销量**。
- **2025 年分季度看，Q4 归母 20.53 亿元为全年低点**（Q1—Q3 分别 27.11 / 29.32 / 32.34 亿元），但**公司未披露该季度的分部或一次性项目归属，Q4 走弱的原因无法从公开披露还原**——不得据此断定"凯傲计提落在 Q4"。可核实的相关事实只有两项：① 官方将 2025 年全年管理费用 +16.97% 归因于"KION 效率计划计提 12.76 亿元"（未指明季度）；② 分部数据显示智慧物流分部业绩 2025 年上半年仅 9.60 亿元、下半年回到 29.09 亿元，**计提更可能落在上半年**。做 2026 年同比时须注意这一基数结构差异。
- **利润增速的"两张面孔"必须分开读**：归母净利与扣非归母的差额主要来自非经常性损益（2025 年 12.69 亿元、2026H1 15.82 亿元，其中处置长期股权投资 13.13 亿元）。**比较增速时以扣非为准**，否则会把一次性处置收益误读为经营改善。
- **分部业绩率的跨期可比性**：分部业绩不含财务费用、投资收益、公允价值变动与总部未分配开支，因此**汇兑损益、参股企业处置收益等都会落在分部业绩之外**。读"发动机分部收入 +21.4% 而分部业绩 −2.1%"时须同时考虑：① 产品结构（发电产品、出口、新能源的毛利率结构）；② 部分收益可能体现在投资收益/财务费用而非分部业绩。公司未披露分部业绩率的变动原因，**不得替它编造归因**。
- **凯傲收入与利润的欧元-人民币双重口径**：日常跟踪以欧元口径判断经营（2026H1 收入 56.9 亿欧元、净利 2.08 亿欧元），以人民币口径入表（15.34 亿元），两者差异即为汇率折算——**对比时不可混用**。
