## 公司概况

- 全称：中际联合（北京）科技股份有限公司；英文名 3S Industry Group Inc.（品牌 "3S" = Safe / Simple / Specialized）；A 股 605305.SH，上交所主板，2021-05-06 上市（IPO 前身自 2008 年起经营）。

- 总股本 212,520,000 股（2025 年末至 2026-06-30 未变）；无 H 股、无存托凭证。

- 控股股东 / 实际控制人：刘志欣（1970 年生，上海交通大学本科），直接持股 22.35%（47,504,227 股）+ 通过世创（北京）科技发展有限公司 5.69%，合计 28.05%（同花顺 F10 口径，2026-06-30）。

- 董事长兼总裁：刘志欣；高级副总裁：王喜军、马东升、谷雨（职工代表董事）；副总裁：刘文峰；董事会秘书：刘亚锋；财务总监：任慧玲。第五届董事会 2026-06-06 就任，任期至 2029-06-05。

- 员工 956 人（2025 年末）：生产 323 / 销售 144 / 技术 363 / 财务 26 / 行政 100；研发人员 158 人（占 17%）。

- 行业归属：申万（2021 版）**机械设备 — 工程机械**；公司自述证监会行业为 C 制造业 — CG35 专用设备制造业（年报 §三.二）。

- 资质与地位：国家级制造业单项冠军示范企业、国家级专精特新"小巨人"；主营产品在风力发电细分市场占有率第一（公司口径，年报未给具体百分比）；累计 176 项国内外资质认证（CE / UL / ETL / EAC 等）；授权发明专利 65 项、软件著作权 37 项、参与起草国家/行业/团体标准 26 项（2025-12-31）；CNAS 实验室认可 + GWO 培训服务认证 + AEO 高级认证（2025 年取得）。

- 全球布局：产品覆盖 75 个国家和地区、17 个行业；在美国、德国、印度等地设全资子公司，2025 年新设中际中东（全资二级子）与中际烟台（控股子）；境外资产 7.47 亿元，占总资产 19.74%（2025-12-31）。

## 业务构成

三条产品线：**高空安全升降设备**（塔筒升降机〔爬梯导向 / 钢丝绳导向 / 齿轮齿条〕、免爬器、智能免爬系统含塔筒平台盖板自动开闭、工业升降机、爬塔机、物料输送机、单叶片吊具、盘车工装）、**高空安全防护设备**（爬梯及防坠落系统、救生缓降器、速差器、安全锚点、个人防护装备、民用高空应急装备）、**高空安全作业服务**（风机高空检修维护；电网 / 通信 / 桥梁 / 火电厂锅炉烟囱维修；设备安装、培训、年检、维保）。

## 客户与供应链

- 客户：风机制造商（金风、远景、明阳、运达、三一重能、电气风电、中车、西门子歌美飒等）、风力发电业主（含亚、欧、美、澳主要能源企业）、塔筒制造商。2025 年前五名客户销售额 7.37 亿元，占 39.22%（关联方 0）；无单一客户超 50%。

- 供应商：前五名采购额 2.18 亿元，占 33.64%（关联方 0）。

- 销售模式：直销为主（98.90%），部分产品经销与线上零售；海外通过子公司本地化销售 + 服务团队。

- 采购与生产：SRM 系统 + "订单需求 + 供应商安全库存"联动；"预测备货 + 订单拉动"双驱动；以订单与市场预测驱动生产，柔性制造。

## 周期属性与正常化

- 需求端是"电源投资周期"：风电装机受电价市场化与并网节点驱动，呈抢装—退潮节奏。公司收入 2021 +29.6%、2022 -9.5%、2023 +38.2%、2025 +44.6%；归母 2022 -33.0%、2025 +68.5%。国内装机 2025 年 1.3 亿千瓦（+49.9%）、2026H1 38.62GW（-25%）。

- 净利率序列（2016—2025）：26.2 / 24.8 / 26.2 / 26.3 / 27.2 / 26.2 / 19.4 / 18.7 / 24.2 / 28.2（%）；十年均值 24.7%、近五年中位数 24.2%。

- 正常化利润 = 2025 年收入 18.78 亿元 × 24.0% = **4.51 亿元（EPS 2.12 元）**；2025 年实际的 5.30 亿元含费用率一次性压缩与汇兑顺风，不用于估值基准。

- 口径提示：2021 年新收入准则让运输费从销售费用移入营业成本，毛利率序列在 2021 年有约 7pp 断点，净利率无断点。
