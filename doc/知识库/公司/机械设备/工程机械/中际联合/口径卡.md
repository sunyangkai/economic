# 中际联合（605305.SH）· 口径卡

> **as-of 2026-10-25** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润一律归母口径**。少数股东损益极小（2025 年 -29.3 万元，2026H1 为 0；中际烟台持股比例高、尚未盈利），归母与合并净利基本一致，不构成读数分叉。
2. **归母与扣非必须并列**。2025 年非经常性损益 0.29 亿元（归母 5.30 − 扣非 5.01），主要来自政府补助与增值税即征即退（其他收益 0.34 亿元）、理财公允价值变动（-0.07 亿元）；2026H1 非经常 0.17 亿元。**判断经营用扣非，判断股东回报用归母**——两者差额小（5% 以内），但 2025 年扣非增速 85.8% 高于归母 68.5%，说明 2024 年基数里有较多非经常项。
3. **EPS 与股本口径**：总股本 212,520,000 股（报告期至 2026-06-30 未变）；2025 年基本 EPS 2.50 元、2026H1 1.24 元。估值折算一律用 2.1252 亿股，与机构一致预期口径一致。
4. **分部口径双轨、期间不可比**：年报披露"分产品（升降 / 防护 / 服务）+ 分行业（风电 / 其他）+ 分地区（内销 / 外销）"三套；**半年报与季报不披露分部明细**（2026 中报确认无此表）。因此季度跟踪只能用利润表整体口径 + 母公司报表 + 汇率/毛利率倒推，**不得编造季度分部数字**。跨期比较分部毛利率只在年报之间进行。
5. **汇兑是"非经营性但真实"的利润扰动**：财务费用中的汇兑损益直接进利润表，且金额足以改变利润方向（2026H1 汇兑损失 5,226 万元，约相当于当期归母的 20%；2025H1 仅 758 万元）。外币资产以美元、欧元计价，人民币升值即形成损失。**读利润增速前先看财务费用符号**；估值预测中单列"财务费用"行，不并入经营利润率趋势。
6. **收入含税与收现比**：销售商品、提供劳务收到的现金含增值税，**收现比 100% 只是"打了折的正常"**，理论正常值约 113%（13% 增值税）。2025 年收现比 79.8%、2026H1 74.6%——收入确认与现金回收之间存在系统性缺口，是本公司最重要的利润质量口径。
7. **净现金口径**：货币资金 + 交易性金融资产（理财 / 基金）− 短期借款 − 租赁负债。2025-12-31 为 20.27 亿元（10.36 + 10.67 − 0.67 − 0.09）；2026-06-30 为 20.13 亿元（11.38 + 9.43 − 0.59 − 0.09）。**不含债权投资（0.21—0.32 亿元）、不含应付票据**（经营性质）。统一模型不单独加回净现金（`doc/估值理论/估值模型.md` §3.6），故净现金只作"模型外安全垫"披露。
8. **有效税率不是 25%**：2023—2025 分别为 11.20% / 9.86% / 12.44%（高新技术企业 15% + 研发费用加计扣除 + 出口免抵 + 递延所得税转回）。预测统一按 **15%** 取，不按历史 12% 外推（避免把税收优惠当永续）。
9. **现价口径**：27.56 元（2026-10-23 收盘，周五）；总市值 58.57 亿元、PE-TTM 11.02×、PB 1.93×（腾讯行情口径）。写作基准日 2026-10-25（周日）。
10. **财务基线 = 2025 年报**（2026-04-14 董事会通过，2026-04-15 见报）；最新已披露期 = 2026 中报（2026-08-25 董事会，2026-08-26 挂网）；下一披露节点 = 2026 三季报，**约 2026-10 下旬**（2025 年三季报为 10-30 披露，公司未发布预约日期公告，头部写"约 10 月下旬"）。
11. **一致预期口径**：`api/orgForecast.js` 2026-10-25 快照，近六月平均 2026E EPS 2.96 / 2027E 3.66 / 2028E 4.5725 元（对应归母 6.29 / 7.78 / 9.72 亿元）；机构明细仅长江证券一家（2026-09-06，2026E 3.10 / 2027E 3.64 / 2028E 4.32）。样本仅 2 条，"平均"≈ 平均值掺入长江证券，**代表性弱**，与主报告基准的收敛判断以自下而上测算为主、一致预期仅作对照。
12. **周期属性与正常化利润口径**：本公司按"周期成长"（机械设备 B 类 + 风电设备 E 类）处理——不满足强周期三条判据（内销是价格接受者、海外有 58.9% 毛利率的定价溢价；轻资产柔性产线、无产能刚性；只有需求波动一条成立），但**基准利润必须正常化**，不得用 2025 年抢装高点 5.30 亿元。
    - 正常化净利率取 **24.0%**（2016—2025 十年均值 24.7%、2021—2025 中位数 24.2%；2025 年 28.2% 是十年最高，含费用率一次性压缩 5.7pp、汇兑净收益 0.16 亿元、抢装结构上移三项非稳态因素）；

    - 收入不做正常化（2025 年 18.78 亿元落在 2020—2025 年 22.5% 复合增速趋势线上）；

    - **正常化利润 = 18.78 × 24.0% = 4.51 亿元，EPS 2.12 元**（敏感性：净利率 22% / 26% → 4.13 / 4.88 亿元）。

    - 口径提示：2021 年新收入准则把运输费从销售费用移入营业成本，**毛利率序列在 2021 年有约 7pp 断点，净利率序列无断点**——正常化只能用净利率，不能用毛利率跨年比较。
13. **θ 口径（正常化口径）**：θ₀ = 0.89（正常化利润 4.51 + 折旧摊销 0.25 − 维持性资本开支 0.16 − 正常化营运资本增加 0.57 = 4.03 亿元）；θₓ = 0.85（公式锚 1 − 2.33% / ROIC_经营 ≈ 0.95，按周期股手册"强营运资本 + 30% 派息"下移 0.10 作为周期利润波动折扣）；θ = 0.15×0.89 + 0.85×0.85 = **0.856**，测定后固定。敏感性：θ 0.70 / 0.75 / 0.80 / 0.92 / 0.96 → 中周期价值 26 / 28 / 30 / 34 / 36 元（现价 27.56 元）；θ 分歧不改变"现价≈中周期"的结论。
