# 携程集团（09961.HK / TCOM）· 口径卡

> **as-of 2026-11-25** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润主体口径：归母 + 核心归母双轨，缺一不可**。
   - **报表归母**含大额投资相关损益，2025 年归母 332.94 亿中约 **164.5 亿（税后）来自投资**（出售 MakeMyTrip 收益 154.09 亿 + 公允价值变动 39.54 亿），**报表归母不能用作估值基数**。
   - **核心归母 =（营业利润 + 净利息收入 + 政府补助 + 长期投资股息 + 汇兑损益 + 应占联营损益）×（1 − 15%）**，2025A = **169.1 亿**。
   - 采用 15% 而非实际税率倒算的理由：2025 年实际税率 15%（年报 §5 明示），且核心利润与投资利得的税率结构一致；对核心利润单独用 15% 与"归母 − 投资利得 × 0.85"交叉验证差 0.7 亿（0.4%）。
   - **不采用"非 GAAP 归母"作为核心利润**：非 GAAP 只剔除 SBC 与 FV 变动，**不剔除 MakeMyTrip 出售收益**（2025 非 GAAP 归母 318.39 亿，仍含 154 亿处置收益）。用非 GAAP 做估值会把一次性处置当经常性利润。

2. **SBC 不做调整**：本报告核心归母**已扣除** SBC（22.70 亿，2025A）。理由：SBC 是不可税前抵扣的真实薪酬成本、且每年持续发生（年报"非 GAAP 披露"段原文：SBC"已经成为我们业务中重要的持续性费用，并且在可预见的将来仍将如此"）。非 GAAP 口径仅作对照披露。

3. **反垄断罚没的处理三分**：
   - **罚款 35.21 亿 + 没收违法所得 16.58 亿 = 51.79 亿**（Q2 报表记为 52 亿）→ **一次性费用，计入 2026 年、不进核心利润基数**；
   - **退还酒店订单储备金 12.20 亿** → 按**收入抵减**处理（已在 2026Q2 住宿预订收入中冲减），影响 2026 年收入而非费用；
   - **三项合计现金流出 63.99 亿**，对 2026 年现金流全额影响，但对**可持续利润率无影响**——除非整改导致 take rate 结构性下调（见第 5 条）。

4. **税率口径**：核心利润用 **15%**（2025 年实际税率，年报明示）；2024 年亦为 15%。**2026 年因罚款不可税前抵扣、且部分子公司盈利结构变化，实际税率会跳升，不可用报表倒算做常态假设。**

5. **变现率（take rate）是本公司最重要的单一变量**，但**无官方披露**：
   - 年报与季报**从不披露 GMV 绝对值或 take rate**，只有"住宿预订收入与住宿预订商品销售总额 N% 的增长趋势基本保持一致"这类相对表述（2025 年：收入 +21% vs 商品销售总额 +17%）；
   - 反垄断处罚给出了**唯一的官方境内收入锚**：罚款 35.21 亿 ÷ 7.5% = **境内销售额 469.5 亿**，占 2025 年净营收 **75.2%**；
   - 任何"take rate 从 X% 降到 Y%"的表述均为**券商测算**（瑞银称委托分销计划过渡影响"少于 1 个百分点"），须标注来源，不得写成事实。

6. **地域口径无官方分部**：年报不按"境内 / 出境 / 国际"拆分收入。季报只给国际平台的**定性增速**（+60% / +65% / +50%+）。报告中"境内约 75%、国际约 25%"是基于罚单反推的**单点估计**，不是分部披露，须标注"（自算）"。

7. **股本口径三套并存，估值统一用 629.7 百万股**：
   - **已发行在外（扣除库存股）629.7 百万股**（= 市值 2,002.46 亿港元 ÷ 318 港元）→ **估值与每股指标统一用此口径**；
   - 加权平均**基本**股本 2025A 657.75 / 2026H1 640.62 百万股（含报告期内未注销的库存股影响）；
   - 加权平均**摊薄**股本 2025A 698.38 / 2026H1 632.33 百万股（2026H1 因净利亏损，摊薄项被反稀释，故低于基本股本）。
   - **两者差异 10% 以上**，混用会造成 EPS / PE 显著偏差。2026H1 摊薄股本低于基本股本是因为亏损期反稀释，不是股本真的减少。

8. **汇率口径**：1 HKD = **0.852** CNY、1 USD = 6.68 CNY（exchangerate-api，2026-11-25）。公司报表以人民币为功能货币；港股价折算人民币一律用 0.852。**ADS 与普通股 1:1，ADS 价格用美元计价**（2026-11-24 收盘 40.73 美元）。

9. **财务基线 = 2025 年报**（2026-04-28 披露），此后实绩一律进 `财报跟踪/`。最新已披露期 = **2026 中报**（2026-09-16）。下一披露节点 = **2026 三季报（2026-12-02）**。

10. **行业归属**：`doc/研报/industry-map.json` 登记为 **社会服务 — 旅游及景区**（申万 2021 版）。申万分类以 A 股为覆盖主体，携程为港股，**属按主业就近归类、非申万官方逐家核定**；已在 map 的 note 字段注明。

11. **一致预期无本地接口**：`api/orgForecast.js` 与三表接口**均不支持港股**（实测返回空）。本报告机构预期数据来自公开媒体转述的券商研报（中金、瑞银、美银、招银国际、中银国际、第一上海），逐条标注机构与日期；**etnet 综合 18 家券商的 2026E 纯利 129.96 亿、2027E 163.88 亿为彭博/机构汇总口径，含投资损益，不可直接与核心归母对比**。

## 估值口径留痕（十年表 + θₓ）

> **2026-11 口径**：前十年逐年扣扩张性消耗、只有永续期用 $\theta_x$。本卡留痕四个输入：基准利润、$F$、十年 $E$、稳态 ROIC。

**① 稳态 ROIC_own = 60.6%（2025A）**

| 量 | 算式 | 结果 |
| --- | --- | ---: |
| NFA | 物业设备 5,445 + 使用权 881 + 无形 13,013 + **商誉 62,268** | **81,607** |
| WC | 应收 15,241 − 应付 19,150 − 客户预付款 18,185 | **−22,094** |
| $IC$ | 81,607 − 22,094 | **59,513** |
| $D$ | 短期负债 19,335 + 长期债务 11,430 + 长期租赁负债 585 | **31,350** |
| $q$ | 归母权益 170,818 ÷（170,818 + 非控股 1,651） | **0.9904** |
| $IC_{own}$ | (59,513 − 31,350) × 0.9904 | **27,890** |
| $ROIC_{own}$ | 16,910 ÷ 27,890 | **60.6%** |
| $\theta_x$ | 1 − 2.33% ÷ 60.6% | **0.9616** |
| 报表 ROIC（对照） | NOPAT 14,898 ÷ IC 59,513 | 25.0% |
| $p$（利润份额）/ $d$ | 16,910 ÷ 14,898 / 31,350 ÷ 59,513 | 1.135 / 0.527 |

> **⚠ 口径选择必须披露的三个判断**：
>
> ① **商誉计入 $IC$（622.68 亿）**。模型 §5.3.4 规定"表外资本先并进 $IC$：研发费用化、商誉、并购标的未计入 NFA/WC 时，$ROIC_{own}$ 被高估——补进 $(IC-D)$ 后再算"。携程商誉是并购来的品牌与用户资产，**剔除后 $IC_{own}$ 为负（−308 亿），公式失效、$\theta_x$ 被迫取 1.0**——这会掩盖"商誉若减值则利润受损"的风险。故计入商誉、取 60.6%。
>
> ② **WC 不含"预付款项及其他流动资产"（273.51 亿）**。模型对 $WC$ 的定义是"应收 + 存货 − 应付 − 合同负债"。若把预付款项全额计入，$IC_{own}$ 升至 564 亿、$ROIC_{own}$ 降至 28.0%、$\theta_x$ 降至 0.917，内在 PE 从 23.3× 降到 21.3×（−8.6%）。**该科目的构成（预付供应商款、可收回增值税、用户应收贷款）未在年报中细分，无法判断其经营性**，故按模型字面口径处理，并在五章披露敏感性。
>
> ③ **$p > 1$（1.135）** 说明核心归母高于按 15% 计算的 NOPAT——因核心利润中含利息收入 26.03 亿（对应资产未计入 $IC$）。模型 §5.3.3 的门槛（$|q-p| \le 5pp$ 且 $d \le 0.2$）不满足，**必须用 $ROIC_{own}$ 而非报表 ROIC**，本报告已照办。
