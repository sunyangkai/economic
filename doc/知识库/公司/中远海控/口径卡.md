> **as-of 2026-09-06** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润一律归母口径**。少数股东损益 2025A 43.60 亿（合并净利 352.28 亿 − 归母 308.68 亿，占合并净利约 12.4%），主要来自两家港股上市并表子公司的少数股东：东方海外国际（00316.HK，持股 71.07%，少数股东分走约 29%）与中远海运港口（01199.HK，持股 72.27%，少数股东约 27.7%）——读利润表需盯该科目。
2. **EPS 双口径**：年报基本 EPS 1.99 元（2025A，加权平均股本）；期末口径 EPS = 归母 308.68 亿 ÷ 152.68 亿股 = 2.0217 元（机构一致预期即此口径，2.0217 × 152.68 ≈ 308.7 亿自洽）。**全文估值统一用期末口径 2.0217 元**。总股本随回购注销持续缩减：2025-12-31 股本 154.9 亿股 → 2026-03-19 总股本 153.13 亿股 → 2026-06-30 总股本 152.68 亿股。
3. **分部三轨口径并存**（年报原文即三套）：①分行业 = 集装箱航运业务 / 码头业务（+分部间抵销）；②集运内部双品牌 = 中远海运集运 / 东方海外（OOCL，收入 = 板块 − 集运，自算）；③航线五分法 = 跨太平洋 / 亚欧（含地中海）/ 亚洲区内（含澳洲）/ 其他国际（含大西洋）/ 中国大陆。运价与单箱收入以**美元口径**披露（2025 年折算汇率 7.1391、2024 年 7.1140），人民币口径同步列示。
4. **重资产 + 长期租赁上表**：租入船舶形成使用权资产 423.7 亿、租赁负债 320.8 亿（2025-12-31）——读现金流时注意：租赁付款本金与利息计入**筹资活动**流出，经营现金流未含该现金成本，"经营现金流 − 租赁付款"才是更接近自由现金的口径。
5. **净现金口径**：货币资金 1,514.7 亿 − 有息借款（短借 20.7 + 一年内到期非流动负债 167.4 + 长借 252.7 = 440.8 亿）= **净现金 ≈ 1,073.9 亿（不含租赁负债）**；若再扣租赁负债 320.8 亿 ≈ 753.1 亿。另受限资产 301.07 亿（含抵押船舶 216.31 亿）。引用时注明是否含租赁负债。
6. **现价口径**：16.06 元（2026-09-04 收盘），总市值 2,452.06 亿元、PE-TTM 9.17×、PB 1.05×（东财口径，总股本 152.68 亿股）。
7. **周期股读数前提**：利润高度依赖运价指数（SCFI/CCFI/单箱收入），任何单期数字都是周期某一点的读数；主报告财务基线 = **2025 年报**（2026-03-20 披露），此后实绩一律进 `财报跟踪/`。
8. **一致预期口径坑**：东财"近六月平均"（2026-09-06 更新）按 7 家机构均值计算，其中国金证券 2025-05-05 的极端值（2026E 0.313 / 2027E −0.288 / 2028E −0.871 元）显著拉低均值——剔除国金后 6 家均值 2026E ≈ 2.265 / 2027E ≈ 1.802 / 2028E ≈ 1.732 元。引用一致预期时注明是否含该离群值。

## θ 测定依据（留痕）

- **θ₀ ≈ 0.95**：NP_adj,0 = 扣非归母 307.3 亿（非经常项仅 +1.4 亿）。稳态拆解——①自有资产重置投入 ≈ 自有资产折旧（≈97 亿），相抵；②租赁本金偿付与使用权资产摊销（113.2 亿）相抵（两者同为维持租船产能的成本，一个走利润表、一个走筹资活动现金流，稳态下互为镜像）；③营运资本常态化占用 ≈0（应收 13.8 天 + 存货 13.5 天，应付 771.3 亿远大于应收+存货）。故 DP₀ ≈ NP_adj,0 − 净漏出（租赁与借款利息 ≈15 亿）≈ 292 亿 → θ₀ = 292/307.3 ≈ 0.95。旁证：正常年份净现比 1.41—1.79，2025 年度分红 154.12 亿 + 回购 22.67 亿 ≈ 归母的 57%，可分派能力有实盘证据。
- **θₓ = 0.80**：重资产（船队 + 码头）但营运资本占用极低、账上净现金超千亿、派息率 50% + 持续回购——介于"重资产 0.50—0.70"与"一般制造业 0.70—0.85"上沿；取保守值 0.80 反映船队永续更替（新船造价中枢上移 + 绿色燃料加成）对成熟期兑现的侵蚀。θ = 0.15×0.95 + 0.85×0.80 = 0.82。

## 已知口径坑

- **"净利润"三个数别混**：合并净利 352.28 亿 / 归母 308.68 亿 / 集运板块净利 295.02 亿（板块口径 ≠ 合并）。码头 + 其他业务贡献合并净利与归母之间差异的另一部分（码头净利未单独披露归母）。
- OOCL 收入为自算倒挤（板块 − 集运），含分部间未抵销项，与东方海外国际（0316.HK）单独披露收入（2025 年 694.10 亿）口径略差，引用时注明。
- 航线收入"中国大陆"指内贸航线，与分地区口径的"中国大陆"（含所有航线挂靠中国段收入）不同——分航线表是航线口径。
- 2026 中报已披露（2026-08-29，归母 134.19 亿 / -23.5%）：按分工纪律该数字**只允许出现在主报告 §四"业绩预期"的解释分歧处一次**（§一.5 例外），其余一律进 `财报跟踪/2026中报.md`（待补建）。
