# 顺丰控股（002352.SZ）· 口径卡

> **as-of 2026-10-17** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润一律归母口径**。少数股东损益 2025A 5.68 亿（合并净利 116.85 亿 − 归母 111.17 亿，占合并净利 4.9%），主要来自 KLN（嘉里物流，港股 0636.HK，持股 51.52%，2025 年归母净利贡献 5.65 亿、少数股东分走 6.61 亿——**KLN 的少数股东分走的比归母还多**）与顺丰同城（9699.HK，持股约 63%）。读合并净利增速与归母增速时会分叉。
2. **归母 vs 扣非必须并列**。2025A 非经常性损益 18.53 亿（归母 111.17 − 扣非 92.64），占归母 16.7%，构成：政府补助（物流业财政拨款/税收返还/稳岗补贴）、结构性存款公允价值变动与投资收益（年报明确"具有可持续性"）、REIT 处置收益（税后 5.9 亿，一次性，落在 2025 **上半年**）。**判断经营改善用扣非（2025 +1.3%），判断股东回报用归母（+9.3%）**——两者差 8pct。
3. **EPS 与股本口径**：2025 年报基本 EPS 2.178 元（加权平均股本）；2026-06-30 总股本约 52.65 亿股（含向极兔新发 2.2588 亿股 H 股），2026-09-21 回购注销后约 51.05 亿股（对应总市值 1,591.79 亿 / 31.18 元）。**估值折算统一用 51.05 亿股**；机构一致预期 EPS 与此口径基本一致。
4. **分部三轨口径并存**（年报原文即三套）：①按行业 = 物流及货运代理 / 其他非物流业务；②按经营分部 = 速运及大件 / 同城即时配送 / 供应链及国际 / 未分配部分，分部内再分六条产品线（时效、经济、快运、冷运及医药、同城、供应链及国际）；③按地区 = 中国内地 / 中国港澳台 / 海外。**分部净利润口径与收入口径的分子分母必须同源**（速运及大件 2025 净利率 4.87% = 分部净利 106.01 / 分部收入 2,175.53）。
5. **KLN 的融资利息费用已被挪出分部**：自 2025 年报起，并购 KLN 相关的融资利息（2025 年 5.6 亿、2025H1 2.9 亿）划入"未分配部分"，比较期已重述。跨期比较分部利润时须用重述口径。
6. **租赁是重要表外口径**：使用权资产 154.56 亿 / 租赁负债 95.88 亿（2025-12-31）。新租赁准则下**租赁付款本金计入筹资活动**，经营现金流因加回使用权资产折旧 65.32 亿而偏高。因此"经营现金流 − capex"要再扣约 65 亿租赁本金，才是可分配现金——**这是 θ₀ 从 1.08 降到 0.98 的唯一原因**。
7. **净现金口径**：现金及现金等价物 199.60 + 其他流动资产中固定收益凭证 56.18 + 交易性金融资产中结构性存款 160.80 = **416.58 亿（公司披露口径）**；减借款合计 338.1 亿（短借 + 可转债 + 长借 + 应付债券 + 来自非控股权益的贷款 + 供应链金融）= **净现金约 78.5 亿**。**不含租赁负债**；若扣租赁负债 95.88 亿则转为净负债约 17 亿。引用时必须注明是否含租赁负债。
8. **现价口径**：31.18 元（2026-10-16 收盘），总市值 1,591.79 亿元、流通市值 1,446.43 亿元、PE-TTM 14.63×、PB 1.69×（东财口径）。
9. **财务基线 = 2025 年报**（2026-03-30 披露，2026-03-31 见报），此后实绩一律进 `财报跟踪/`；最新已披露期 = 2026 中报（2026-08-28）。下一披露节点 = 2026 三季报（董事会 2026-10-29 审议）。
10. **一致预期口径**：`api/orgForecast.js` 2026-10-17 的"近六月平均"2026E EPS 2.2355 / 2027E 2.56 / 2028E 2.8893 元。窗口内含华源证券 2026-09-09 的 2026E 2.15（低值）与部分 2.30 以上机构，中位数 2.267 元（归母 115.7 亿）**高于**均值（均值被 4 家低值 2.08—2.16 拉低），**收敛判断以中位数为准**。

## θ 测定依据（留痕）

- θ₀ = DP₀ / NP_adj,0 = 108.72 / 111.17 = **0.98**。
  DP₀ = 归母 111.17 + 折旧摊销 163.72 − 维持性 capex 95.06（以全部 capex 作维持性口径，保守）− 正常化营运资本新增 5.79 − 租赁负债本金偿还 65.32（以使用权资产折旧为本金代理）= 108.72。
- θₓ = **0.70**：重资产、强营运资本占用行业经验区间 0.50—0.70，取上沿（理由：经营现金流从未为负、净现比长期 >2；capex 已低于折旧）。
- θ = 0.15 × 0.98 + 0.85 × 0.70 = **0.742**。
- 读 ΔWC 口径：2025 年经营性应收增加 48.76 亿、应付增加 42.97 亿，净占用 5.79 亿——**应收与应付同步增长、营运资本基本自平衡**，这是顺丰与其他重营运资本物流公司的关键差异（故 ΔWC 对 DP 的拖累很小）。
- 反查口径：若不扣租赁本金（即按"净现比 2.48"直读），θ₀ 会高估至约 1.5，θ 升至约 0.88，内在 PE 抬升约 18%——**租赁本金的扣除是本次测定里最容易被漏掉、影响最大的一步**。
