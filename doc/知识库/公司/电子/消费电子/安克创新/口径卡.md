# 安克创新（300866.SZ / 00668.HK）· 口径卡

> **as-of 2026-09-21** ｜ 用途：读利润表 / 估值前必须先知道的"读数前提"，以及主报告 Phase 0 数字核对表的落盘处。口径变化时更新本卡并回查主报告。

## 口径决定

1. **利润一律归母口径**。少数股东损益规模小（2025A 0.72 亿、占合并净利 2.8%；2026H1 0.43 亿），但 2026H1 合并净利 17.45 亿 vs 归母 17.02 亿，差额（0.43 亿）与少数股东损益一致，读利润表时不必单独展开。
2. **A+H 双层股本，EPS / 市值统一用"含 H 股总股本"**：2026-09-18 总股本 **5.8943 亿股** = H 股 5,007.61 万股 + A 股约 5.3935 亿股（A 股数由总股本倒挤）。A 股 2026 中报口径总股本 5.3628 亿股（仅 A 股），**不可直接与 A 股市值/价对比算 PE**。行情总市值（腾讯口径，2026-09-21 收盘 755.36 亿元）与机构一致预期 EPS 均按 5.894 亿股计算，两者自洽（25.45 亿 ÷ 4.318 元 = 5.894 亿股），全文以此为准。
3. **H 股发行**：2026-07-02 港交所主板挂牌（股份代号 00668），发行 46,632,800 股 @ 99.32 港元；2026-07-29 超额配售 3,443,300 股，合计 5,007.61 万股。**募资在 2026-06-30 资产负债表之外**——中报净现金未含该笔款项，做净现金 / 安全边际时必须另行加回（见第 8 条）。
4. **分部口径 = 分产品三类**（年报原文）：充电储能类 / 智能创新类 / 智能影音类（+"其他"0.08 亿，占比 0.03%，可忽略）。年报**未披露储能单独收入**，公司仅在业绩说明会等场合给出"2025 年储能收入超 45 亿元"的口径，属非年报口径，引用需标注。
5. **分地区双轨且并存不换算**：①年报业务口径 = **北美 / 欧洲 / 中国及其他**（2025A 141.33 / 81.51 / 82.31 亿）；②财报附注"营业收入构成"口径 = **境外 / 境内**（2025A 294.83 / 10.32 亿，境外占比 96.62%）。两者不是同一分类（"中国及其他"含港澳台及拉美等，不等于"境内"），**不得混用**。
6. **分渠道口径**：线上（亚马逊 / 其他第三方平台 / 官网）+ 线下；官网单列且毛利率与线上差异大，2025A 线上毛利率 49.65% vs 线下 34.26%——分渠道毛利率是理解公司毛利率结构的关键，勿只引整体毛利率。
7. **减值科目两套数**：东财 F10 利润表接口 `ASSET_IMPAIRMENT_LOSS` / `CREDIT_IMPAIRMENT_LOSS` 字段对安克返回 **null**，与实际不符——**减值一律以官方报告 txt 原文为准**（2025A 资产减值损失 3.65 亿、信用减值 0.46 亿；2026H1 资产减值 4.44 亿、信用减值 0.52 亿）。该科目直接进营业利润，做利润预测时不可漏。
8. **净现金口径**（见数字核对表）：现金类 = 货币资金 + 交易性金融资产中的**债务工具投资（银行理财/资管）** + 其他流动资产中的**银行定期存单**；**不含**交易性金融资产中的权益工具投资（股权投资）与非流动金融资产、长期股权投资。有息负债 = 短期借款 + 长期借款 + 应付债券（安克转债）+ 租赁负债 + 一年内到期非流动负债。
9. **IEEPA 关税退回是 2026H1 的非经常性成本冲减**：中报原文明确"本期收到退回的部分上年度缴纳的 IEEPA 关税，相应冲减本期营业成本"，且**未被列入非经常性损益表**（视同经常性）。金额未单独披露——可观察旁证：2026H1 收到的税费返还 14.47 亿 vs 2025H1 7.58 亿（+6.89 亿），其中含随出口增长（境外 +26.68%）扩大的正常出口退税。**引用 2026H1 毛利率 49.82% 时必须提示该一次性有利因素**，不可直接外推全年。
10. **实际税率快速抬升**：2025A 10.44% → 2026H1 15.92%（中报归因"集团利润增加以及《支柱二立法模板》适用"）。做利润预测必须用抬升后的税率，勿沿用 2025 年的 10%。
11. **营运资本两套口径不可混**（2026-09-21 补齐）：①**余额表口径** = 存货 + 应收票据及应收账款 − 应付票据及应付账款，2025 年净占用 **19.15 亿元**，本卡与主报告的营运资本强度（13%）与 θ 测定用此口径；②**现金流量表补充资料口径** = 存货增加 20.04 亿 + 经营性应收项目增加 6.61 亿 − 经营性应付项目增加 2.12 亿 = 净占用 **24.53 亿元**，差额来自存货跌价等非现金项与应收/应付的科目范围差异（含预付款项、合同负债、应付职工薪酬等）。**两套数分别用于现金流分析与营运资本强度测算，禁止互换引用**。
12. **现价口径**：128.15 元（2026-09-21 A 股收盘），总市值 755.36 亿元、PE-TTM 24.52×、PB 6.39×（腾讯行情）；H 股 00668 收 117.50 港元（同日），按 1 港元 ≈ 0.919 元人民币折算约 107.9 元，**A 股较 H 股溢价约 18.7%**。
12. **汇率敞口**：境外收入占比 96.62%（2025A），以美元、英镑、欧元、日元结算；产成品采购以美元、人民币结算。财务费用方向随汇兑摆动（2025H1 净收益 -0.36 亿 → 2026H1 净费用 1.45 亿，中报归因"汇率波动导致汇兑损失增加"），**正负号方向与直觉相反时以前者为净收益**。

## θ 测定依据（留痕）

- **θ₀ = DP₀ / NP_adj,0 ≈ (25.45 + 1.99 − 2.0 − 7.55) / 25.45 = 0.70**：
  - NP_adj,0 = 2025 归母 25.45 亿（不剔非经常项：当期公允价值变动收益 +1.40 亿与资产减值损失 −3.65 亿方向相反、规模相当，净影响有限）；
  - DA₀ = 1.99 亿（现金流量表补充资料口径）；
  - MC₀（维持性 capex）取 ≈2.0 亿 ≈ DA——2025 年 capex 3.65 亿中含深圳研发中心等扩张性投入，维持性部分与折旧摊销相当；
  - ΔWC^norm,0 = 13% ×（305.14 − 247.10）= **7.55 亿**。13% = 近三年"（存货 + 应收票据及应收账款 − 应付票据及应付账款）/ 营业收入"均值（2023A 13.63% / 2024A 10.69% / 2025A 14.93%）。**不用 2025 年的实际营运资本净占用 19.15 亿元**（资产负债表口径：存货 +17.64、应收 +2.18、应付票据及应付账款 +0.67 亿元；含关税前置备货的阶段性占用，模型纪律只扣常态占用）。
  - 旁证：2020—2025 年净现比（= 经营现金流净额 / 归母净利）序列 0.22 / 0.46 / 1.25 / 0.89 / 1.30 / 0.19，**中位 0.68、均值 0.72**，与上式 θ₀ 一致。
- **θₓ = 0.80**：成熟态假设营收增速 ≈8%、净利率 ≈9%、营运资本强度维持 13%，则 ΔWC/NP ≈ 0.12、MC/DA 相抵，θ ≈ 0.88；取 0.80 作为保守值——理由是安克属"生产外包（轻资产）+ 自持大额存货与应收（重营运资本）"的混合画像，介于模型给出的"一般制造业 0.70—0.85"与"轻资产高转化 0.85—0.95"之间，且 2025—2026H1 存货连续大幅占用现金，成熟态也难回到纯轻资产水平。
- **θ = 0.15 × 0.70 + 0.85 × 0.80 = 0.785**，测定后固定，不做 θ 分档情景。

## 已知口径坑

- **A 股总股本 ≠ 总股本**：2026 中报"股本 536,276,371.00 元"是 A 股股本；全文凡涉及 EPS、市值、每股价值，一律用 5.894 亿股。
- **东财 F10 的减值字段对安克为 null**，直接用接口拼三章表会把减值填成"—"，与年报不符（见第 7 条）。
- **分地区两套口径不可换算**（见第 5 条）：写二章宏观/地域方向时须明确用哪一套。
- **2026H1 毛利率跳升含一次性关税退回**（见第 9 条）；同期资产减值 4.44 亿（>2025 全年 3.65 亿）是反向的一次性压力，两者方向相反、金额相近，读"毛利率 +5.09pp"与"归母 +45.86%"时须合并考虑。
- **一致预期中的"近六月平均"行是汇总行**（ORG_NAME_ABBR = "近六月平均"），机构样本 18 家；表内 PE 列所用的价格与报告现价不同（快照价 131.07 元），勿直接把 PE 列当现价倍数用——现价倍数需自算（128.15 ÷ 6.065 = 21.1×）。
- **H 股 00668 与 A 股 300866 是同一家公司的两个报价**，H 股价（港元）不可与 A 股价（人民币）直接比较，折算后再算溢价。
