- **动力电池系统**：车用锂离子电池（三元 / 磷酸铁锂、方形为主），交付物从电芯到电池包、CTP/CTC 底盘集成；下游为全球车企与商用车厂（2025 年第一大客户占 13.7%，按保密协议未披露名称；海外点名 VW / BMW / Stellantis / Volvo）。
- **储能电池系统**：发电侧大储 / 工商业 / 户储 / 数据中心，从电芯到集装箱式液冷系统与整站方案（天恒 6.25MWh 液冷舱、TENER Stack 9MWh、TENER H 高温舱）；2025 年系统集成出货 +160%（报表未单列收入）。
- **电池材料及回收**：邦普循环为主体——正极材料 / 前驱体销售 + 废旧电池回收再生（2025 年回收 21 万吨、再生锂盐 2.4 万吨）。
- **电池矿产资源**：锂 / 镍 / 钴资源自有与合作开采冶炼（2026-04 拟设时代资源集团整合）。
- **其他业务**：换电（巧克力 / 骐骥，2025 年末累计 1,325 座）、技术授权与联合研发、电动船舶（配套近 900 艘）、eVTOL（峰飞航空，持股 38.23%）、零碳解决方案。

## 经营模式要点

研发—制造—销售一体化重资产；采购端长协 + 合资锁定四大主材（直接材料占营业成本 71.8%）；2025 年末产能 772GWh（利用率 96.9%）、在建 321GWh（宁德 / 溧阳 / 宜宾 / 福鼎 / 中州 / 济宁及匈牙利、印尼）；结算以票据为主（应收款项融资 + 应收票据约 1,210 亿），对上游应付票据及账款 4,239 亿（≈ 年收入 100%）。

## 公司与治理（2025-12-31）

- 实控人：曾毓群（董事长兼总经理），通过厦门瑞庭间接持股 22.45%，瑞庭零质押；控股股东：厦门瑞庭。
- 联席董事长潘健（2025-01 起）；副董事长李平、周佳；2025-12 治理结构调整（原监事会主席转任执行董事）。
- 员工 185,839 人（+40.8%），其中研发 22,901 人（12.3%）。
- 总股本 45.64 亿股（含 H 股 1.559 亿股；H 股 2025-05-20 上市，发行价 263 港元，募资 410 亿港元）；回购专户 3,198 万股。
- 重要股东：香港中央结算（陆股通）15.17% ／ 黄世霖 9.21% ／ 宁波联合创新 6.23% ／ 李平 4.33%（约 16% 持股质押）／ HKSCC NOMINEES 3.42% ／ 本田技研（中国）0.91%。

## 股东回报

连续三年现金分红率 50%（FY2025 全年约 361 亿 = 中期 45.68 + 年度预案 315.3）；2026-08 股东大会通过新一轮回购（至多 6,981 万股、价格上限 573 元/股）；2026 中期分红 10 派 14.11 已于 2026-08-10 实施。
