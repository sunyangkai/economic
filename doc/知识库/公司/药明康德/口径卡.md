## 口径决定

1. **分部口径 = 官方"报告分部"四分法**：化学业务（WuXi Chemistry）/ 测试业务（WuXi Testing）/ 生物学业务（WuXi Biology）/ 其他业务（Others），并区分**持续经营 / 终止经营**——2025 年公司完成 WuXi ATU 业务的美国和英国运营主体及美国医疗器械测试业务出售（终止经营收入 2025A 20.35 亿、2026H1 归零），可比期间已重述。**旧版"ATU / DDSU 独立分部"口径作废**。
2. **利润双口径并存，估值用调整后基数**：①归母净利（含非经常）；②扣非归母。2025A 归母 191.51 亿中含**出售联营企业药明合联（WuXi XDC Cayman）部分股权及剥离业务收益**（投资收益 85.88 亿，2024A 仅 6.04 亿），扣非归母 132.41 亿——**2025 归母被一次性收益抬高约 45%，跨期比较一律双口径并列**。2026 年起非经常大额收益不再有。
3. **EPS 三口径**：①年报基本 EPS 6.70 元（加权平均股本 ≈28.6 亿股，含库存股扣减）；②期末股本口径 = 归母 ÷ 期末总股本；③扣非 EPS 4.63 元。**机构一致预期与本文估值统一用"期末股本口径"**（当前总股本约 30.12 亿股：191.51/30.12 = 6.36 元，与东财一致预期 2025A EPS 6.3594 完全吻合）。总股本变动：2023 末 29.69 → 2024 末 28.88（回购注销）→ 2025 末 29.84 亿股（**2025-08-07 完成 7,380 万股 H 股配售 @104.27 港元** + 可转债转股，部分被回购注销抵消）。
4. **区域收入口径 = 管理层讨论口径**（持续经营业务，按客户所在地）：美国 / 欧洲 / 中国 / 其他地区。分地区表另按"境内 / 境外"披露（客户母公司所在地）。美元收入占主导（美国客户 72%），**汇兑损益计入财务费用**（2025A 汇兑损失 10.14 亿 vs 2024A 收益 4.53 亿，系美元兑人民币下行）。
5. **non-IFRS 经调整口径**（公司港股披露习惯）：经调整归母净利（加回股权激励费用等）、经调整自由现金流（经营现金流 − capex）。2026H1 经调整归母 115.71 亿（净利率 40.0%）、经调整 FCF 70.21 亿；**2026 全年经调整 FCF 指引 135-145 亿**。该口径仅用于管理层表态与 FCF 佐证，估值基数仍用 A 股口径调整后利润。
6. **净现金口径**：货币资金 351.3 + 交易性金融资产（理财）58.1 − 有息负债（短借 59.9 + 一年内到期 1.6 + 长借 18.2 = 79.7）= **净现金 ≈ 329.7 亿（2025-12-31）**。另持投资组合：其他非流动金融资产（生物医药股权）81.3 + 长期股权投资 21.4 亿——均不参与估值（模型纪律），作安全边际披露。
7. **周期与拐点读数前提**：CXO 订单领先收入（在手订单 → 1-2 年转化），利润被公允价值变动 / 投资处置 / 汇兑三重扰动；2024 年为行业下行年（收入 -2.7%），2025-2026 为订单兑现拐点（美国客户收入 +34.3%）。
8. **现价口径**：153.53 元（2026-09-07 10:51 盘中，腾讯行情），总市值 4,623.4 亿、PE-TTM 21.3×、PB 5.65×。财务基线 = **2025 年报**（2026-03-24 披露），此后实绩一律进 `财报跟踪/`。

## θ 测定依据（留痕）

- **θ₀ ≈ 0.85**：NP_adj,0 = 2026E 调整后归母 ≈222 亿（2025 扣非 132.4 亿 × 2026 经营性增长，官方指引 + 中报进度 + 一致预期三方交叉验证）。稳态拆解——①DA ≈ 40 亿（2025A 35.6 亿，随新产能爬坡上行）；②维持性 capex ≈ 40 亿（2026 总 capex 指引 75-85 亿中，产能扩张为大头、维持性约一半）；③营运资本常态占用 ≈8-10 亿/年（应收 63 天 + 存货 90 亿随收入增长，2025 增量 30 亿属增长型，常态化按增速约 1/3 折算）。DP₀ ≈ 222 + 40 − 40 − 10 ≈ 212 → θ₀ ≈ 0.95？——**不采用**：经营现金流中投资组合处置与利息收入的现金贡献不具经营代表性（2025 经营现金流 172 亿含汇兑与投资回收扰动），且 2026 capex 上调至 75-85 亿直接压低现金转化。按官方经调整 FCF 指引校验：135-145 亿 ÷ 归母 222 ≈ 0.62（含全部 capex）；按"扣非净利 − 扩张性 capex"口径 ≈ (222 − 45扩张) / 222 ≈ 0.80。**综合取 θ₀ = 0.85**（介于两口径之间，偏保守）。
- **θₓ = 0.82**：成熟期 CXO 属"一般制造业偏上"——重资产（capex/收入 12%+，高于一般制造业）但营运资本占用温和（净现比 1.2-1.3 量级）、净现金 330 亿、分红+回购已达归母 45.7%（可分派有实盘证据）。取"一般制造业 0.70-0.85"区间上沿偏下，θₓ = 0.82。θ = 0.15×0.85 + 0.85×0.82 = **0.82**。

## 已知口径坑

- **"持续经营收入 434.2 亿"与"总收入 454.6 亿"别混**：终止经营业务（ATU 美英主体 + 美国医疗器械测试）2025 年收入 20.35 亿、2026 年起归零；同比增速以各自口径计算（持续经营 +21.4%、总收入 +15.8%）。
- **投资收益 85.88 亿在"投资收益"科目、不在终止经营**：出售药明合联部分股权（联营企业权益法处置）走持续经营口径的投资收益；剥离业务收益计入终止经营损益；扣非口径两者均已剔除。
- 2025H1 归母 85.61 亿中非经常 ≈ +29.8 亿（药明合联出售收益主段），2025H2 非经常 ≈ +29.3 亿；2026H1 非经常仅 +5.1 亿——**2026 年归母增速（+29.4%）远低于扣非增速（+89.4%）系基数效应**。
- EPS 分母：机构预测/估值用期末总股本（当前 ≈30.12 亿股）；年报披露基本 EPS 用加权平均股本（≈28.6 亿股，含库存股扣减）——两者相差约 5%，跨口径引用需注明。
