# 基于利润预测的固定DCF估值体系

## 一、设计哲学

**两条原则**：

> **① 估值对象是"可分派现金的能力"，不是资产负债表。**
> **② 主观判断只放在利润与资本开支上，其余因子一律规则化。**

**判断放在哪**——每个变量归谁管，一次说清：

| 环节 | 归属 | 规则 |
| --- | --- | --- |
| 三年利润增速 | 主观 | 逐项预测 |
| 扩张期资本开支与营运资本 | 主观 | 逐年规划；无规划时按 $1/ROIC$ 兜底 |
| 过渡期年数 | 规则 | 固定 7 年 |
| 折现率 | 规则 | $R = r_f + 6.8\%$ |
| 终局增速 | 规则 | 由名义 GDP 增速解出 |
| 永续兑现系数 | 规则 | $\theta_x = 1 - g_\infty/ROIC$ |

**当前取值**：$R = 8.45\%$（$r_f$ 1.65% + ERP 6.8%）、过渡期 7 年、$g_\infty = 2.33\%$。ERP 的取值依据见 `doc/估值理论/ERP取值说明.md`。

**换来三件事**：

- 自由度收窄——可调的只剩利润路径与资本开支；
- 公司之间可比——同一把尺子量所有公司；
- 可复盘——误差回到"利润判断对不对"，而不是藏在分母或终值假设里。

**一个容易走偏的地方**：账上现金**不单独加回估值**（管理层的现金不等于股东的钱），但也**不是零价值**——它是扩张性支出的支付来源，让当年的扣减不落在利润上（§3.3 的 $P_t$）。

> 现金的两面：**不能分配，但能增长**。旧模型对全部年份乘同一个兑现系数，等于把这块价值记作零，现金流充沛的公司因此被系统性低估；本模型给它的定价上限是 $F$ 本身。

### 适用边界

| 公司类型 | 适用 | 原因 / 改用 |
| --- | :---: | --- |
| 成长型、成熟型**非周期**公司（成长蓝筹） | ✅ | 利润稳定为正、capex 可规划、ROIC 可估计——三个前提都成立 |
| **周期股** | ❌ | 当期利润不代表常态，先做正常化与周期定位 → `doc/估值理论/周期股估值.md` |
| **银行** | ❌ | 利润被拨备调节、净资产是估值分母 → `doc/估值理论/银行估值.md` |
| **保险、综合金融集团** | ❌ | 利润由准备金与精算假设驱动，不是可分派现金的代理 → `doc/估值理论/保险公司估值.md` |
| **亏损公司** | ❌ | 利润为负，PE 没有分母；且扩张靠外部融资，本模型不建模摊薄 |
| **早期盈利微薄的科创公司** | ❌ | 利润基数极小，增速与 PE 被机械放大；`E/ROIC` 也失去经济含义，应等利润成形后再套 |
| 由亏转盈的第一年 | ⚠️ | 可用，但利润基数须先正常化，并在报告中说明 |

> 一句话：本模型估的是**已经成形的利润**。利润本身还不可预测（周期、承保、信贷）或还没成形（亏损、早期科创）时，换模型或推迟估值，而不是硬套。

## 二、估值体系的核心结构

本体系把企业价值拆成两段：

1. **扩张期（前 N = 10 年：3 年明确预测 + 7 年过渡）**：逐年算可分配利润  
   $DP_t = NP_{adj,t} - (E_t - P_t)$  
   ——扩张性消耗 $E_t$ 先由账上现金垫（$P_t$），垫不动的部分才从当年利润里扣。
2. **永续期（第 11 年起）**：不再逐年排 capex，用兑现系数把它折成一个稳定的比例  
   $DP_{N+1} = NP_{adj,N+1} \times \theta_x$

**θ 只出现在第二段。** 第一段按每家公司的实际资本开支与现金余额逐笔扣，不用统一系数近似；永续期因为增速固定、每年投的钱与经营资本成固定比例，才可以用一个系数概括（推导见 `doc/估值理论/可分配利润算例.md` §一.2）。

## 三、方程组与参数含义

### 3.1 方程组

$$
\begin{cases}
V_0
=
\displaystyle \sum_{t=1}^{N}\frac{DP_t}{(1+R)^t}
+
\displaystyle \frac{DP_{N+1}}{(R-g_{\infty})(1+R)^N}
\\[1.2em]
DP_t = NP_{adj,t} - (E_t - P_t), \qquad t = 1 \dots N
\\[0.8em]
E_t = (\text{Capex}_t - MC_t) + \Delta WC_t,\qquad MC_t \equiv DA_t
\\[0.8em]
P_t = \min(\max(E_t,0),\ C_t),\qquad C_0 = F,\qquad C_{t+1} = C_t - P_t
\\[0.8em]
DP_{N+1} = NP_{adj,N+1} \times \theta_x
\\[0.8em]
\theta_x = 1 - \displaystyle\frac{g_{\infty}}{ROIC^{*}}
\\[0.8em]
R = r_f + ERP,\qquad ERP = 6.8\%
\\[0.8em]
g_{\infty}=\displaystyle \frac{0.35m}{1+0.35m}\times 0.04
\end{cases}
$$

**符号**：

| 符号 | 含义 | 口径 |
| --- | --- | --- |
| $NP_{adj}$ | 调整后归母净利润 | 剔除一次性项目 |
| $\text{Capex}$ | 资本开支 | 购建固定资产、无形资产等的现金支出 |
| $DA$ | 折旧摊销 | 维持性支出按它取：$MC\equiv DA$ |
| $\Delta WC$ | 营运资本增量 | 常态化占用，不取单年波动 |
| $F$ | 可供发展资金 | 货币资金 + 交易性金融资产 |
| $ROIC^{*}$ | 稳态经营资本回报率 | $NOPAT/(NFA+WC)$，剔除现金与理财 |
| $N$ | 扩张期年数（上式的求和上限与终值指数） | **固定 10**（3 + 7） |

### 3.2 利润路径与过渡期

三年明确预测之后，增速从 $g_3$ 线性衰减到 $g_{\infty}$（其取值见 §3.6）。**过渡期固定 7 年（$N=10$），不因个股调整**——7 年大致覆盖一个行业产能周期。

**方向性**：$g_3>g_{\infty}$ 抬高估值、$g_3<g_{\infty}$ 压低估值，临界点是 $g_3=g_{\infty}$（与 3 年口径对照：$g_3=10\%$ 高 11.4%，$g_3=0\%$ 低 3.2%）。这是**结构性偏移，不是"统一更保守"**，必须在报告里交代。

**自由度**：过渡期定死之后，可调的只剩利润路径 $[g_1,g_2,g_3]$、扩张期资本开支与永续 $\theta_x$（或 $ROIC^{*}$）。

### 3.3 扩张期：逐年可分配利润 $DP_t$

$$
DP_t = NP_{adj,t} - (E_t - P_t)
$$

三件事决定当年能分多少：

| 量 | 算式 | 含义 |
| --- | --- | --- |
| 扩张性消耗 $E_t$ | $(\text{Capex}_t - MC_t) + \Delta WC_t$ | 为增长多花的钱：多买的设备 + 多垫的货款 |
| 现金垫付 $P_t$ | $\min(\max(E_t,0),\ C_t)$ | 这笔钱里由账上现金付掉的部分，不动利润；$E_t<0$（回收资本）时不垫付 |
| 账上现金 $C_t$ | $C_0 = F$，$C_{t+1} = C_t - P_t$ | 只出不进的一次性存量，花完为止 |

**为什么只扣 $\text{Capex} - MC$**：$MC$ 是维持现有产能必须花的钱，约等于折旧 $DA$；折旧已经作为成本在利润里扣过一次，若再把买设备的钱全额扣一次，等于把"换新"算了两遍。本模型统一取 **$MC \equiv DA$**（维持性支出按历史成本回补），设备重置涨价的差额留给永续期的 $g_\infty \times NFA$ 处理（推导与口径细节见 `doc/估值理论/可分配利润算例.md` §一.2）。

**无 capex 规划时的兜底**：拿不出逐年规划时，用边际资本系数 $k=1/ROIC$ 反推

$$
E_t = \frac{\Delta NP_{adj,t}}{ROIC}
$$

即"利润每多增 1 元，要投回 $1/ROIC$ 元"。这只是估算，**有 capex 规划时一律用规划值**。

**现金不增加利润，但递延本身值钱**：$P_t$ 不产生新的经营利润，它做的是把扩张性支出从利润里挪到账上现金里。若 $F \le \sum E_t$，扩张期合计为

$$
\sum_{t=1}^{N} DP_t = \sum_{t=1}^{N} NP_{adj,t} - \sum_{t=1}^{N} E_t + F
$$

多出来的正好是一个 $F$，与现金在哪几年被花掉无关。**这就是现金在估值里的全部价值——上限 $F$，且要用得出去才成立**（若公司拿着现金不分也不投，它确实不产生股东价值）。

**十年表怎么排**——列从左到右，就是一年的计算顺序：

| 年 | g | 利润 | Capex | DA | 扩张性 capex | ΔWC | E | 期初 C | P | DP |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

1. **利润**：$NP_t$ 由增速路径滚出来（3 年明确 + 7 年衰减），不用手填
2. **三列原始输入**：Capex、DA、ΔWC 逐年排——这是整张表**唯一**的主观判断
3. **算 E**：$(\text{Capex} - DA) + \Delta WC$
4. **递推现金**：$P=\min(E,\ 期初C)$，期末 $C$ = 期初 $C - P$，即下一行的期初 C
5. **算 DP**：$NP - (E - P)$

三条硬约束：① 行数正好 $N$（默认 10），不多不少；② 期末 $C$ 不单列，只有 T10 的期末余量要在文中交代（余量为 0 说明现金恰好用尽）；③ **利润与 $E$ 必须同一口径**——capex 是合并数、利润是归母时，$E$ 要先按归母占比折算，否则少数股东那份被扣了两遍。

**列完必须逐列解释路径**——表格本身只是一堆数，报告里要交代：利润为什么是这个增速、capex 为什么先升后降、DA 为什么滞后于 capex、ΔWC 的峰值对应哪笔实际占用、$E$ 的下降来自扩张性 capex 还是营运资本，以及这条路径与历史强度差多少。**没有这段解释，表就只能看，不能信。**

### 3.4 永续期：兑现系数 $\theta_x$

$$
DP_{N+1} = NP_{adj,N+1} \times \theta_x
$$

**θₓ 不是经验打分，它有稳态解**：

$$
\theta_x = 1 - \frac{g_{\infty}}{ROIC^{*}},\qquad ROIC^{*} = \frac{NOPAT}{NFA + WC}
$$

**读法**：永续期不再扩产，但只要名义收入还以 $g_\infty$ 增长，每年仍要为两处资本补钱——折旧按历史成本回补、重置价每年涨 $g_\infty$（$g_\infty \times NFA$），应收存货按名义金额同步涨（$g_\infty \times WC$）。合计就是 $g_\infty \times IC$，占利润的比例正好是 $g_\infty / ROIC^{*}$，剩下 $1 - g_\infty/ROIC^{*}$ 可分配。**$ROIC^{*}$ 高，意味着用很少的资产就能赚很多钱，增长几乎不吃利润。**

**它给什么定价**——把终值写成 $V/NP = \dfrac{1-g_\infty/ROIC}{R-g_\infty}$，三条边界直接读出来：

- $ROIC = R$ 时 $\dfrac{1-g/R}{R-g} = \dfrac{1}{R}$，与零增长完全相同：**增长中性**
- $ROIC < R$ 时，有增长的估值**低于**零增长（ROIC 6%、R 8.45%，低 16%）：增长毁灭价值
- $ROIC > R$ 时增长才创造价值：ROIC 越高、增长越便宜，终值倍数向"零成本增长"的上限 $\dfrac{1}{R-g_\infty}=16.3$ 收敛（ROIC 29% 时为 15.0x，已到上限的 92%）

| 类型 | $NFA/NOPAT$ | $WC/NOPAT$ | $ROIC^{*}$ | $\theta_x$ | 增长要投回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 重资产（长江电力） | 9.94 | 0.15 | 9.9% | 0.765 | 23.5% |
| 轻资产（贵州茅台） | 0.29 | 0.58 | 113.9% | 0.980 | 2.0% |

> 2025 年报数据；"增长要投回" = $1 - \theta_x = g_\infty/ROIC^{*}$。**θ 的高低本质是"增长要不要一直买设备"**，不是公司好坏的评价。

**$ROIC$ 怎么取**——θₓ 由它决定，全部判断都落在这一处：

1. **取稳态值**：满产满销、无爬坡扰动的年份，$ROIC^{*}=NOPAT/(NFA+WC)$。**不要用爬坡期 ROIC**——新产能先提折旧、后满产，爬坡期被摊薄，用它算会系统性低估 θₓ。
2. **公司尚未稳态时**，取同行业成熟公司的 ROIC 中枢；或用公司自身成熟年份的 $DP/NP_{adj}$ 反推 $ROIC = g_{\infty}/(1-DP/NP_{adj})$。
3. **表外资本先并进 IC**：研发费用化、商誉、并购标的未计入 $NFA/WC$ 时，$ROIC$ 被高估、θₓ 跟着虚高——先把这些资本补进分母再算，**不要直接压低 $\theta_x$**。

**取值要多准**——$\theta_x$ 对 ROIC 的敏感度是双曲线（$\dfrac{d\theta_x}{dROIC}=\dfrac{g_\infty}{ROIC^2}$），所以只有一段区间值得较真。下表用重资产样本（增速 [6%, 5%, 4%]、十年 capex 60→24、$F$=50）只调 ROIC：

| ROIC | $\theta_x$ | 内在 PE | 每 1pp ROIC 的估值影响 |
| ---: | ---: | ---: | ---: |
| 5% | 53.3% | 11.7x | **12.0%** |
| 6% | 61.1% | 12.5x | 7.1% |
| 8% | 70.8% | 13.5x | 4.2% |
| 10% | 76.7% | 14.2x | 2.3% |
| 15% | 84.4% | 15.0x | 1.0% |
| 20% | 88.3% | 15.4x | 0.6% |
| 30% | 92.2% | 15.8x | 0.3% |

- **拐点在 10%**：ROIC 低于 10% 的公司，ROIC 取错 1pp 就是估值差 2%—12%，必须用稳态年份算准（钢铁、化工、煤炭、航运、面板、电力都在这一带）
- **高于 15% 可以粗取**：1pp 只值 1% 以下，纠结 ROIC 没有意义（消费、软件、白酒这类）
- **低于 5% 要小心**：若走 $E=\Delta NP/ROIC$ 兜底，ROIC 低于 $g_1/(1+g_1)$ 时第一年的 E 就超过当年利润，$DP_t<0$——现实中必须外部融资，模型不再适用

> **一处口径提醒**：上表是在**利润路径给定**的前提下量的。现实中 ROIC 与利润同源（ROIC 升通常来自利润率或周转率改善，净利同时上升）——按现实口径，ROIC 每 1pp 的影响要再乘上利润的变化，比上表更大。

**两个边界**：

- **经营资本 IC ≤ 0**（客户/供应商垫资的公司）：$ROIC$ 分母为负、公式失效，按 $\theta_x = 1.0$ 处理——工具里给一个足够大的 $ROIC$（如 5，对应 θₓ = 99.5%），与 1.0 的差异 < 1%；
- **ROIC 的历史斜率比水平更重要**：若 ROIC 在系统性下行，用当期值会高估 θₓ，应在报告里说明并取偏低值。

> **口径**：上式中的 $ROIC$ 按同期口径计算——利润与经营资本同属一年，同一份报告里前后一致。

### 3.5 折现率 $R$

$$
R = r_f + ERP,\qquad ERP = 6.8\%
$$

- $r_f$：10 年期国债收益率，当前 1.65%，故 $R = 8.45\%$；
- $ERP = 6.8\%$：股权风险溢价，取机构并购评估 20 案例的均值 6.84% / 中位数 6.79%。

**ERP 的取值依据、三种算法、20 案例分布与敏感性表见 `doc/估值理论/ERP取值说明.md`**——完整证据链在那份文档，本节不重复。

**为什么这样设定**：

- 用无风险利率反映估值底座随利率变化（**R 随 $r_f$ 浮动，ERP 不随 $r_f$ 漂移**）；
- 用固定风险补偿隔离市场情绪；
- 不针对个股上调或下调折现率——个股风险通过**压低利润路径**进入估值（确定性等价：把不确定性的代价从分母搬到分子的利润预测）。代价是忽略系统性风险暴露差异（周期股 vs 公用事业），换来全市场可比与不可操纵——**一致性 > 精确性**。

**与评估报告口径的差异**：评估报告用 $K_e = r_f + \beta\times MRP + \varepsilon$，后面还挂个股特性风险 $\varepsilon\approx2\%$；本模型 $\varepsilon\equiv0$，个股风险全部前置到利润路径。因此**不能把评估报告的 MRP 与本模型的 ERP 直接互换**，也不能在报告里对个股再上调 ERP。

### 3.6 终局增速 $g_\infty$

$$
g_{\infty}=\frac{0.35m}{1+0.35m}\times 0.04
$$

$m$ 是名义 GDP 增速的数字输入（4 表示 4%），当前取 $m=4$，得 $g_{\infty}\approx 2.33\%$。**含义**：成熟企业只能分享宏观增长的一部分，且边际递减——$m$ 再高，$g_\infty$ 也渐近收敛于 4% 上限，不会无限上升。

**参数来源（拟合函数，无独立经济含义）**：系数（0.35、0.04）由历史 GDP 增速与社零增速的回归测试校准得出，非主观选取；作用是提供机械一致的映射，并保证 $R-g_\infty$ 利差为正、终值有界。$m\in[3,5]$ 时 $g_\infty\in[2.05\%,2.55\%]$，落在"成熟企业永续增速 2—3%"的常用区间。

### 3.7 估值结果与边界

$V_0$ 就是股东价值，**不再乘任何系数**。四件事要注意：

- **不单独加回净现金、不减净负债**：账上现金的去向已在 §3.3 的 $P_t$ 里体现（先垫扩张性支出），且现金可能用于发展或管理层不分配，不构成股东价值（见"一、设计哲学"）。若需评估"全部现金可分派"的上限，可在研报中作为敏感性披露，但不进入基准估值。
- **扩张期不足十年要有规划**：若 capex 规划只做到第 5 年，后 5 年用 $k=1/ROIC$ 兜底并注明；不能直接跳过。
- **$DP_t$ 为负的情形**：扩张性支出超过当年利润时，$DP_t$ 会为负——现实中要靠外部融资补缺口。本模型把缺口全额从利润里扣，不建模融资成本与摊薄，**结果偏保守**；这类公司应在报告里单独说明。
- **与 FCF DCF 的关系**：本模型在扩张期就是 $FCF_t = NP_{adj,t} - E_t$ 的折现（只是把"现金垫付"$P_t$ 单独拆出来，以体现存量现金的递延作用）；永续期则用 θₓ 把 $E_\infty$ 折成固定比例。**它不是另一套理论，而是 FCF DCF 在"资本开支可预测、终局可用系数概括"两个假设下的简化**。

---

## 四、体系的核心原则

### 1. 主观判断主要放在利润预测与资本开支规划中

企业之间的差异，主要通过以下变量表达：

- 未来三年利润增速  
- 利润率变化  
- 景气和竞争格局变化  
- 高增长持续时间  
- **扩张期资本开支与营运资本的逐年占用**

而不是通过折现率自由调整表达。

### 2. 折现率、过渡期与终局增速统一规则化

- 折现率统一由无风险利率加固定股权风险溢价决定（$R = r_f + 6.8\%$）；
- **过渡期固定 7 年**，全公司统一，不因个股调整；
- 终局增速统一由名义 GDP 增速公式决定；
- 分母、过渡期与终局不再成为随意调节估值的旋钮。

**注意（T=7 的方向性）**：固定 7 年对 g3 > g∞ 的公司抬高估值、对 g3 < g∞ 的公司压低估值（临界点 g3 = g∞）。这不是"统一更保守"，而是结构性偏移，**必须在报告里交代**。

### 3. θ 只作用于永续期，不给成长期打折

成长期"该扣多少"由当年的实际资本开支决定，不用一个折价系数盖过去——高增长年份本来就要投更多钱，把它压成一个常数 θ，既掩盖了差异，也让不同增速的公司被同一个系数错待。θ 只在永续期出现，因为那里增速固定、资本与利润同比例增长，才可以概括成一个比例。

### 4. 营运资本只扣常态占用，不扣阶段性波动

例如：

- 备货  
- 大客户延迟一个季度回款  
- 季度性项目节奏  

这类时点因素只影响当期现金，不直接影响长期利润兑现能力。  
$\Delta WC_t$ 扣除的是：

> **正常经营和正常增长所需的常态化营运资本新增占用。**

## 五、程序实现说明

实现见 `tools/valuation.js`，与本文档同一套公式。

- 函数参数拆分为两个对象：`company` 与 `macro`；
- `company.growthForecasts` 为**未来三年利润增速预测数组**，格式为 `[g1, g2, g3]`；
- 函数内部默认当前利润 `np0 = 1`，因此最终直接返回 **PE**；
- `company.roic` **必填**：稳态 ROIC，$\theta_x = 1 - g_\infty/ROIC$ 由它解出；
- 扩张期资本消耗 `E_t` 两种给法，任选其一（按常用程度排序）：
  - `company.capex` + `company.da` + `company.deltaWc`：三张逐年表，内部算 $E_t = (Capex_t - DA_t) + \Delta WC_t$——**正式报告最常用**；
  - `company.expansionSpend`：已经算好 $E_t$，直接给逐年值；
  - 两者都不给时，用 `roic` 兜底：$E_t = \Delta NP_t / ROIC$；
  - 数组长度必须等于总年数 $N$（默认 10 = 3 + 7）；
- `company.availableFunds` 为可供发展资金 $F$（缺省 0）；
- 程序**不负责**从报表算 ROIC、capex 规划或 $F$，这些由外部分析输入；
- 当前宏观参数默认取值：`macro.rf = 0.0165`，`macro.nominalGdpGrowth = 4`，`macro.equityRiskPremium = 0.068`；
- 过渡期默认 **7 年**（`transitionYears = 7`），全公司统一，不因个股调整；
- 程序只负责：生成利润路径 → 逐年扣 $E_t$、按 $P_t$ 摊销现金 → 折现扩张期 → 用 θₓ 折现终值 → 返回 PE。

## 六、JavaScript 实现（与 `tools/valuation.js` 一致的核心函数）

```js
const DEFAULT_MACRO = { rf: 0.0165, nominalGdpGrowth: 4, equityRiskPremium: 0.068 };

/**
 * 三段式利润估值：扩张期逐年扣 E，永续期用 θₓ
 *
 * company.growthForecasts  [g1, g2, g3]（必填，长度必须为 3）
 * company.transitionYears  过渡期年数，默认 7（研报基准固定 7）
 * company.expansionSpend   逐年 E_t（长度 N）
 * company.capex/da/deltaWc 三张逐年表（长度 N），内部算 E_t
 * company.roic             稳态 ROIC（必填）：解出 θₓ = 1 − g∞/ROIC；无 capex 规划时兜底算 E
 * company.availableFunds   可供发展资金 F，默认 0
 * macro.rf / nominalGdpGrowth / equityRiskPremium  缺省取 DEFAULT_MACRO
 *
 * @returns {{pe, pvExpansion, pvTerminal, thetaX, R, gInfinity, npPath, ePath, dpPath, cashPath}}
 */
export function calculateValuation({ company = {}, macro = {} } = {}) {
  const { growthForecasts, transitionYears = 7, availableFunds = 0, roic } = company;
  const { rf, nominalGdpGrowth, equityRiskPremium } = { ...DEFAULT_MACRO, ...macro };

  if (!Array.isArray(growthForecasts) || growthForecasts.length !== 3) {
    throw new Error('growthForecasts 必须是长度为 3 的数组');
  }
  growthForecasts.forEach((g, i) => {
    if (!Number.isFinite(g) || g <= -1) throw new Error(`g${i + 1} 必须是大于 -1 的有限数字`);
  });
  if (!Number.isInteger(transitionYears) || transitionYears < 0) {
    throw new Error('transitionYears 必须是大于等于 0 的整数');
  }
  if (availableFunds < 0) throw new Error('availableFunds（F）不能为负');

  const R = rf + equityRiskPremium;
  const gInfinity = (0.35 * nominalGdpGrowth / (1 + 0.35 * nominalGdpGrowth)) * 0.04;
  if (R <= gInfinity) throw new Error('折现率 R 必须大于终局增速 g∞');

  // 稳态 ROIC：必填，既是 θₓ 的唯一来源，也是无 capex 规划时 E 的兜底
  if (!Number.isFinite(roic) || roic <= 0) {
    throw new Error('company.roic 必填且须为正数：θₓ = 1 − g∞/ROIC');
  }
  if (roic <= gInfinity) throw new Error('ROIC 必须大于 g∞，否则 θₓ ≤ 0');
  const theta = 1 - gInfinity / roic;

  const N = 3 + transitionYears;

  // ① 利润路径：前 3 年明确，其后线性衰减到 g∞
  const [g1, g2, g3] = growthForecasts;
  const np = [1];
  np.push(np[0] * (1 + g1)); // 必须分三次：push 会先求值再入栈
  np.push(np[1] * (1 + g2));
  np.push(np[2] * (1 + g3));
  for (let t = 4; t <= N; t++) {
    const gt = g3 + ((t - 3) / (transitionYears + 1)) * (gInfinity - g3);
    np.push(np[t - 1] * (1 + gt));
  }

  // ② 逐年扩张性消耗 E_t：规划值优先，其次三张表，最后 ROIC 兜底
  let ePath;
  if (Array.isArray(company.expansionSpend)) {
    ePath = company.expansionSpend;
  } else if (Array.isArray(company.capex)) {
    if (!Array.isArray(company.da) || !Array.isArray(company.deltaWc)) {
      throw new Error('capex 需与 da、deltaWc 同时提供');
    }
    ePath = company.capex.map((c, i) => c - company.da[i] + company.deltaWc[i]); // MC ≡ DA
  } else {
    ePath = Array.from({ length: N }, (_, i) => (np[i + 1] - np[i]) / roic); // 兜底
  }
  if (ePath.length !== N) throw new Error(`E 数组长度必须等于 ${N}`);

  // ③ 现金先垫，垫不动才扣利润
  const cashPath = [availableFunds];
  const dpPath = [];
  let pvExpansion = 0;
  for (let t = 1; t <= N; t++) {
    const cash = cashPath[t - 1];
    const e = ePath[t - 1];
    const p = Math.min(Math.max(e, 0), cash);
    const dp = np[t] - (e - p);
    dpPath.push(dp);
    pvExpansion += dp / Math.pow(1 + R, t);
    cashPath.push(cash - p);
  }

  // ④ 永续期：唯一用到 θ 的地方（θ 由上面的 ROIC 解出）
  const npNext = np[N] * (1 + gInfinity);
  const pvTerminal = (npNext * theta) / (R - gInfinity) / Math.pow(1 + R, N);

  return { pe: pvExpansion + pvTerminal, pvExpansion, pvTerminal, thetaX: theta, R, gInfinity, npPath: np.slice(1), ePath, dpPath, cashPath };
}
```

## 七、调用示例

**① 有 capex 规划**——最常用的一种：三张逐年表 + 账上现金，$\theta_x$ 仍由稳态 ROIC 解出（30% → 92.2%）：

```js
const v = calculateValuation({
  company: {
    growthForecasts: [0.12, 0.12, 0.12],
    capex:          [1.1, 1.3, 1.5, 1.6, 1.6, 1.6, 1.6, 1.6, 1.6, 1.6],
    da:             [0.6, 0.7, 0.8, 0.85, 0.9, 0.95, 1.0, 1.05, 1.1, 1.15],
    deltaWc:        [0.1, 0.12, 0.13, 0.12, 0.1, 0.09, 0.08, 0.07, 0.06, 0.05],
    availableFunds: 1.5,   // F：先垫支出，1.5 到第 3 年耗尽
    roic: 0.30,            // → θₓ = 92.2%
  },
});

console.log(v.pe);            // 23.2  —— 内在 PE
console.log(v.pvExpansion);   // 7.6   —— 扩张期十年可分配利润的现值
console.log(v.pvTerminal);    // 15.6  —— 终值现值（占 67%）
console.log(v.dpPath);        // 逐年 DP，可直接核对十行表
```

**② 无 capex 规划时的兜底**——只给利润路径与稳态 ROIC；`macro` 全部取默认（$r_f$ 1.65% / $m=4$ / ERP 6.8%），$E_t$ 按 $\Delta NP/ROIC$ 反推，$F$ 默认 0：

```js
const v2 = calculateValuation({
  company: {
    growthForecasts: [0.12, 0.12, 0.12],
    roic: 0.30,            // → θₓ = 1 − 2.33%/30% = 92.2%
  },
});

console.log(v2.pe);           // 23.6  —— 内在 PE
console.log(v2.thetaX);       // 0.922 —— 实际使用的 θₓ
```

**同一组利润路径、不同资本强度**（都用 ② 的兜底调用，只改 `roic`）：

| 稳态 ROIC | θₓ | 扩张期现值 | 终值现值 | 内在 PE |
| --- | ---: | ---: | ---: | ---: |
| 30%（轻资产） | 92.2% | 8.0 | 15.6 | **23.6x** |
| 15%（一般制造） | 84.4% | 5.2 | 14.3 | **19.5x** |

## 八、一句话总纲

> **本体系以未来利润现值为估值基础，采用统一折现率（R = rf + 6.8%）、统一 7 年过渡期与统一终局增速：扩张期逐年按"利润 − 扩张性消耗"得到可分配利润（账上现金不单独加回，其价值只体现为把扣减延后，上限为 $F$），只有永续期用兑现系数 θₓ = 1 − g∞/ROIC* 把增长税折成固定比例。主观判断因此只落在利润预测与资本开支规划上。**
