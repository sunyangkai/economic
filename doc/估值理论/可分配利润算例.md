# 可分配利润

> **用途**：讲清"公司赚到的利润，为什么不是全部可分配"——钱被哪些环节留下、各留多少、怎么算。
> **定位**：`doc/估值理论/估值模型.md` 里兑现系数 θ 的推导底稿；θ 的稳态锚见 `doc/估值理论/不同企业的θ为什么不一样.md`。
> **结构**：一、理论（利润去哪了）｜二、符号定义｜三、扩张期逐年算｜四、永续期与两段接口。

## 一、理论：利润去哪了

一家公司赚到的利润，不是全部可分配的。**留下的是四类钱**——成长期两类，永续期两类，后两类的量级小得多：

| 阶段 | 要额外花的钱 | 为什么 |
| --- | --- | --- |
| **成长期** | ① 维持性资本支出 | 设备会坏，得换新。**不做这笔生意就没了** |
| | ② 扩张性资本支出 | 要做得更大，就得多买设备、多盖厂。**这是增长的前提** |
| **永续期** | ① 维持性支出超过折旧的部分 | 折旧是当年买设备的**老价格**，重置换的是**今天的价格** |
| | ② 营运资本增加 | 名义收入涨，客户欠款和仓库库存同步涨，钱被占在里面 |

### 1. 成长期：只扣扩张性那一半

全篇最容易混的地方——**"买设备的钱"不等于"扩张的钱"**：

```
买设备的钱（Capex）
├── 维持性（MC）≈ 折旧摊销   ← 换旧设备，不做这生意就没了
└── 扩张性 = Capex − MC      ← 多买的设备，为了增长
```

$$E_{\text{扩张}} = (\text{Capex} - MC) + \Delta WC$$

**只扣扩张性那部分**——折旧已在 NOPAT 里扣过一次，若再把买设备的钱全额扣一次，等于把"换新"算了两遍。这就是 `MC ≈ DA` 且 `MC` 不进 E 的理由（它通过折旧体现在 NOPAT 里）；`ΔWC` 是增长配套多垫的货款。

> **一句话**：赚的钱减掉"为了变大而多花的钱"，才是能分的——换旧设备的钱不算"多花"。

### 2. 永续期：两类"增长税"，都随 g∞ 走

推导起点是现金流恒等式（NOPAT 的三处修正：加回 DA、减去 Capex、减去 ΔWC）：

$$FCF = NOPAT - (\text{Capex} - D\!A) - \Delta WC$$

永续期不再盖新厂、不再铺渠道，但只要名义收入还以 $g_\infty$ 增长，账上两处资本就得按比例补钱——**补的是"涨价"，不是"扩产"**：

| 资本项 | 稳态年增量 | 为什么 |
| --- | --- | --- |
| 固定资产 | $\text{Capex}_\infty - D\!A = g_\infty \times NFA$ | 折旧按**历史成本**回补，重置价每年涨 $g_\infty$，差的那一截要自己掏 |
| 营运资本 | $\Delta WC_\infty = g_\infty \times WC$ | 应收、存货按名义金额记账，收入涨多少，占款涨多少 |

代入恒等式，永续期从利润里扣的就只剩这一笔：

$$E_\infty = g_\infty \times (NFA + WC) = g_\infty \times IC^*$$

$$FCF_\infty = NOPAT - E_\infty = NOPAT \times \left(1 - \frac{g_\infty}{ROIC^*}\right), \qquad ROIC^* = \frac{NOPAT}{IC^*}$$

$$\boxed{\;\theta_x = 1 - \frac{g_\infty}{ROIC^*}, \qquad DP_\infty = NOPAT \times \theta_x\;}$$

- **换新不构成扣减**：Capex 里补 DA 的那一截与折旧正好抵消，一进一出为零，只剩涨价
- **存量已经买好，所以便宜**：增长只对**已有**的经营资本按 $g_\infty$ 付费，不用把资产再买一遍。$g_\infty = 0$ 时 $E_\infty = 0$、$\theta_x = 1$，这是 θ 的上限

> **口径只能取一种**：上式成立的前提是 **MC = DA**（维持性支出按历史成本换新，涨价单列）。若把 MC 定义为"含涨价的维持性支出"，$\text{Capex} - MC$ 里已含 $g_\infty \times NFA$，再补一次就是**双倍增长税**——这是这个公式最容易被算错的地方。$g_\infty \times NFA$ 在存量原值上线性补，不做复利展开。

### 3. 为什么 θ 能这么高

关键在"存量已经在那儿了"：厂房设备、存货应收都买好了，不用为增长再买一次。同一笔增长占多少利润，取决于这些存量能撑起多少利润：

$$\theta_x = 1 - \frac{g_\infty}{ROIC^*} = 1 - \frac{g_\infty \times IC^*}{NOPAT}$$

分子是"增长要付的钱"（存量资本的涨价），分母是"能赚的钱"。**ROIC\* 高，意味着用很少的资产就能赚很多钱，增长自然不需要占用太多利润。**

| 类型 | 公司 | NFA/NOPAT | WC/NOPAT | ROIC\* | θₓ | 增长要投回 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 重资产 | 长江电力 | 9.94 | 0.15 | 9.9% | 0.765 | 23.5% |
| 轻资产 | 贵州茅台 | 0.29 | 0.58 | 113.9% | 0.980 | 2.0% |

> 2025 年报。**θ 的高低本质是"增长要不要一直买设备"**，不是公司好坏的评价；"增长要投回"= 1 − θₓ = g∞ / ROIC\*。

## 二、符号定义

| 符号 | 中文 | 公式 | 口径要点 |
| --- | --- | --- | --- |
| **存量（资产负债表期末）** | | | |
| **NFA** | 净固定资产 | 固定资产 + 在建工程 | 含在建工程（钱已付、未转固）；不含长期股权投资 |
| **WC** | 净营运资本 | 应收 + 存货 − 应付 − 合同负债 | 应收存货是垫出去（+），应付合同负债是别人垫的（−）；可为负 |
| **IC** | 经营资本 | NFA + WC | 剔除现金、理财、长期股权投资；永续期起点记作 IC\*（见 §四） |
| **F** | 可供发展资金 | 货币资金 + 交易性金融资产 | 扩张的支付来源；**不扣有息负债**（利息已加回 NOPAT，负债成本在 WACC）；**不产生 NOPAT、不进 IC** |
| **C_t** | 期初可用现金 | C₀ = F；C_{t+1} = C_t − P_t | 缓冲池余额，只用于付 E |
| **流量（利润表 / 现金流量表）** | | | |
| **NOPAT** | 税后经营利润 | (营业利润 + 财务费用) × (1 − t) | 财务费用加回（为负照加，即剔利息收入）；t 用实际税率，不用 25% 法定税率 |
| **DA** | 折旧与摊销 | 固定资产折旧 + 无形资产/长期待摊摊销 | 不流出现金 |
| **Capex** | 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | 含扩张与维持两部分 |
| **MC** | 维持性资本开支 | 维持现有经营能力所必需的 capex，**≈ DA** | 只保产能、不扩产 |
| **ΔWC** | 营运资本增量 | WC_t − WC_{t−1} | 增长的配套占用 |
| **E** | 扩张性消耗 | (Capex − MC) + ΔWC | 扩张期从利润里扣的就是它 |
| **P_t** | 现金垫付 | min(E_t, C_t) | **当年 E 里由账上现金垫付的部分**；利润只需承担 E − P |
| **DP** | 可分配利润 | NOPAT − (E − P) | 扣完 E 后真正能分的 |
| **比率与增量** | | | |
| **ROIC** | 经营资本回报率 | NOPAT / IC | 不是 ROE（分子分母都不含融资结构与非经营资产） |
| **ΔNP** | NOPAT 增量 | NOPAT_t − NOPAT_{t−1} | 估 E 的辅助量 |
| **k** | 边际资本系数 | E / ΔNP | E 的兜底估法，非主算式 |
| **θ** | 兑现系数 | DP / NOPAT；永续 = 1 − g∞ / ROIC\* | **只在永续里定义** |

## 三、扩张期：从利润里扣掉 E（现金先垫）

### 1. 四个"期"与分界信号

| 说法 | 年份 | 增速 | 本质 |
| --- | --- | --- | --- |
| **明确预测期** | 前 3 年 | 各家不同 | **真正在判断业务** |
| **过渡期** | 第 4—10 年（固定 7 年） | 由 g₃ 线性衰减至 2.33% | **数学过渡，不含经营判断** |
| **成长期／扩张期** | 前两段合称（共 10 年） | 由正到衰减 | 逐年排 capex |
| **永续期** | 第 11 年起 | 固定 2.33% | 改公式，见第四节 |

**"成长期"不是时点，是状态**：只要还在主动扩产、扩渠道（capex 明显高于折旧、营运资本持续增加），就还在成长期——可能 5 年，也可能 15 年；本算例统一按 10 年（3 年明确 + 7 年衰减），以覆盖一个行业产能周期。**跨过界线的信号有两个**：capex 回落到接近折旧、营运资本占收入比稳定。

### 2. 输入与逐年顺序

**输入四样**：

- **NOPAT₀**：基年税后经营利润
- **g_t**：10 年增速序列（前 3 年明确预测，后 7 年衰减到 2.33%）
- **Capex 与 DA**：逐年规划，按在建工程、募投项目、产能规划预估，**不做线性外推**
- **F**：可供发展资金（货币资金 + 交易性金融资产）

**逐年顺序**（最后列说明它落在测算表的哪几列）：

| 步 | 算什么 | 算式 | 落在表里 |
| --- | --- | --- | --- |
| 1 | 当年利润 | $NOPAT_t = NOPAT_{t-1}(1 + g_t)$ | NOPAT |
| 2 | 扩张性消耗 | $E_t = (\text{Capex}_t - D\!A_t) + \Delta WC_t$ | 扩张性 capex、ΔWC → E |
| 3 | 现金垫付 | $P_t = \min(E_t, C_t)$ | 期初 C → 现金付 P |
| 4 | 可分配 | $DP_t = NOPAT_t - (E_t - P_t)$ | DP |
| 5 | 余额结转 | $C_{t+1} = C_t - P_t$ | 期末 C（= 下一行期初 C） |

**C 只减不增**：第 5 步没有流入项——假设可分配利润全额分掉、不回流，也不新增融资，**F 是一次性存量**，花完为止。所以垫付只发生在开头几年，之后 $P$ 恒为 0、E 全由利润承担。这也是把 F 固定的原因：只有池子不被补充，$\sum_{t=1}^{10} DP_t = \sum_{t=1}^{10} NOPAT_t - \sum_{t=1}^{10} E_t + F$（$F \leq \sum_{t=1}^{10} E_t$ 时）才成立；若允许留存利润回填，$\sum_{t=1}^{10} DP_t$ 会一直升到 $\sum_{t=1}^{10} NOPAT_t$（全部由现金垫付）为止。

## 四、永续期：回到 θ

扩张期每年增速不同，capex 只能逐年排；**一旦增速固定为 $g_\infty$，每年要投的钱就与经营资本成固定比例**，$E$ 可以一次算出来——这是换用 θ 系数法的原因（推导见 §一.2）：

$$E_\infty = g_\infty \times IC^*,\qquad \theta_x = 1 - \frac{g_\infty}{ROIC^*} = 1 - \frac{E_\infty}{NOPAT},\qquad DP_\infty = NOPAT \times \theta_x$$

### 1. 三个参数

**只有三个是真输入**，其余都由它们算出来：

| 参数 | 怎么来的 | 本例 |
| --- | --- | ---: |
| $g_\infty$ | **外生**：全市场统一的终局增速，见 `doc/估值理论/估值模型.md` 终局增速一节 | 2.33% |
| NOPAT | **取表**：稳态年利润，取扩张期最后一年（T10） | 273.7 |
| $IC^*$ | **累加**：基年家底 + 十年沉淀，见下式 | 821.0 |

其中 $IC^*$ 是永续期起点（第 11 年年初 = 第 10 年末）的经营资本 $NFA + WC$：

$$IC^* = IC_0 + \sum_{t=1}^{10} E_t = 300 + \underbrace{429}_{\text{买设备} \to NFA} + \underbrace{92}_{\text{垫货款} \to WC} = 821$$

因为 MC = DA，每年 $E_t$ 恰好等于当年净新增的经营资本 $\Delta IC_t$，十年累加就是稳态家底。

### 2. 结果

参数定了就没有自由度——$ROIC^*$ 也是相除得来的，不是假设：

| 量 | 算式 | 结果 |
| --- | --- | ---: |
| $ROIC^*$ | $NOPAT / IC^* = 273.7 / 821.0$ | 33.3% |
| $E_\infty$ | $g_\infty \times IC^* = 2.33\% \times 821.0$ | 19.1 |
| $DP_\infty$ | $NOPAT - E_\infty = 273.7 - 19.1$ | 254.6 |
| $\theta_x$ | $1 - g_\infty / ROIC^* = 1 - 2.33\% / 33.3\%$ | **93.0%** |

**两个数要交下去**：$DP_\infty$ 是估值用的稳态可分配利润，$\theta_x$ 是兑现系数——估值模型里 $\theta = 0.15\theta_0 + 0.85\theta_x$，长期权重全压在这一项上。

### 3. 校验与边界

**接得上 §三**：E 从 T10 的 19.0 到 19.1、DP 从 254.7 到 254.6，各差 0.1（Capex 规划取整）。差得远，说明 capex 规划漏项、或扩张期排长了、或 $ROIC^*$ 用了爬坡期值。

> **口径注**：上表用 $IC^*$ 配 T10 的利润 273.7（末期资本法）。严格按"第 11 年"应配 $273.7 \times 1.0233 = 280.1$，即 $ROIC^* = 34.1\%$、$\theta_x = 93.2\%$，比这里高 0.17pp。取 T10 是为了与 §三 表格末行直接对照；方向偏保守，不高估。

两个边界：

- **IC ≤ 0**（客户/供应商垫资的公司）：分母为负、公式失效，θ 取 1.0 封顶
- **$ROIC^*$ 必须用稳态值**：公司尚在爬坡时，取同行业成熟公司的 ROIC 中枢替代，不要用当期值

**两段的接口不是同一个式子**：前 10 年用**规划法**（Capex 逐年排，k 只是无规划时的兜底），永续期用**系数法**（k = 1/ROIC\*，g = g∞）。差别不在系数，在**增速与 capex 的边际收口**——永续期只收"增量"，不收"总量"。
