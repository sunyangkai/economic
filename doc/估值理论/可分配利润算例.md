# 可分配利润

> **用途**：讲清"公司赚到的利润，为什么不是全部可分配"——钱被哪些环节留下、各留多少、怎么算。
> **定位**：`doc/估值理论/估值模型.md` 里兑现系数 θ 的推导底稿；θ 的稳态锚见 `doc/估值理论/不同企业的θ为什么不一样.md`。
> **结构**：一、理论（利润去哪了）｜二、符号定义｜三、扩张期逐年算｜四、永续期回到 θ｜五、两段怎么接上。

## 一、理论：利润去哪了

一家公司赚到的利润，不是全部可分配的。**留下的是三类钱**——前两类只在成长期出现，第三类永续期仍在：

| 阶段 | 要额外花的钱 | 为什么 |
| --- | --- | --- |
| **成长期** | ① 维持性资本支出 | 设备会坏，得换新。**不做这笔生意就没了** |
| | ② 扩张性资本支出 | 要做得更大，就得多买设备、多盖厂。**这是增长的前提** |
| **永续低增长期** | ① 维持性支出超过折旧的部分 | 折旧是当年买设备的**老价格**，重置换的是**今天的价格** |
| | ② 营运资本增加 | 名义收入涨，客户欠款和仓库库存同步涨，钱被占在里面 |

### 1. 成长期：两类资本支出必须分清

这是全篇最容易混的地方——**"买设备的钱"不等于"扩张的钱"**：

```
买设备的钱（Capex）
├── 维持性（MC）≈ 折旧摊销   ← 换旧设备，不做这生意就没了
└── 扩张性 = Capex − MC      ← 多买的设备，为了增长
```

**从利润里扣的只有扩张性那部分。** 因为折旧已经在利润表里扣过一次了，买设备的钱若全额再扣一次，等于把"换新"算了两遍：

$$E_{\text{扩张}} = (\text{Capex} - MC) + \Delta WC$$

- `Capex − MC`：扩张性 capex（多买的设备）
- `ΔWC`：增长的配套占用（多垫的货款）
- **`MC` 本身不进 E**——它已通过折旧体现在 NOPAT 里

> **一句话**：赚的钱减掉"为了变大而多花的钱"，才是能分的。换旧设备的钱不算"多花"，因为不做这笔生意连现有的钱都赚不到。

### 2. 永续期：只剩两类"增长税"

扩张结束后，公司不再盖新厂、不再铺新渠道，只跟着通胀走（$g_\infty \approx 2.33\%$）。此时：

$$E_\infty = \underbrace{(MC - DA)}_{\text{设备涨价}} + \underbrace{g_\infty \times NFA}_{\text{重置成本上升}} + \underbrace{g_\infty \times WC}_{\text{营运资本占用}}$$

**但这一项与第二项会重复，只能取一种写法**：

- 若把 MC 定义为"维持现有产能必须花的钱"，它本身**已经包含涨价**——此时 `ΔNFA` 里不该再有一次
- 若把 MC 定义为"按历史成本换新"（≈ DA），那涨价要单独用 `g∞ × NFA` 补

**规范写法**（本文采用，与 `不同企业的θ为什么不一样.md` §1.2 的推导一致）：

$$E_\infty = g_\infty \times (NFA + WC) = g_\infty \times IC^*, \qquad \theta_x = 1 - \frac{g_\infty}{ROIC^*}$$

**读法**：永续期**不是"不换设备"**。换新的钱（≈ 折旧）与折旧本身正好抵消后，只剩两类真正从利润里扣的"增长税"：

| 增长税 | 算式 | 为什么 |
| --- | ---: | --- |
| 设备涨价 | g∞ × NFA | 同样产能，明年再造要贵 2.33% |
| 多垫货款 | g∞ × WC | 名义收入涨，应收存货同步涨 |

> **三种写法的一致性**：`MC − DA + ΔNFA + ΔWC` 在 `MC = DA` 时退化为 `ΔNFA + ΔWC`，即 `g∞ × IC*`，三者等价。**但若 MC 取"含涨价的维持性支出"，就会与 `ΔNFA` 里的涨价重复**——这是最容易算出双倍增长税的地方。

### 3. 为什么增长只吃这么一点

公司的经营资产（厂房设备 + 存货应收）**已经买好了**，不用为增长再买一次。增长吃的是**这些存量资产的 2.33%（= g∞）**：

$$E_\infty = g_\infty \times IC^*$$

**关键在"存量已经在那儿了"**。同样的增长，要看这些存量资产能撑起多少利润：

$$\theta_x = 1 - \frac{g_\infty}{ROIC^*} = 1 - \frac{g_\infty \times IC^*}{NOPAT}$$

分子是"增长要付的钱"（= g∞ 买那一份资产的增量），分母是"能赚的钱"。**ROIC\* 高，意味着用很少的资产就能赚很多钱，增长自然不需要占用太多利润。**

| 公司类型 | NFA/NOPAT | WC/NOPAT | ROIC\* | θₓ | 为什么 |
| --- | ---: | ---: | ---: | ---: | --- |
| 重资产（水电） | 9.94 | 0.15 | 9.9% | 0.765 | 每赚 1 元压 10 元大坝，增长要一直补设备 |
| 轻资产（白酒） | 0.29 | 0.58 | 113.9% | 0.980 | 一间酒厂支撑全部利润，增长几乎不花钱 |

> 数据取自 `不同企业的θ为什么不一样.md` §2.1（长江电力 / 贵州茅台，2025 年报）。**θ 的高低本质是"增长要不要一直买设备"**，不是公司好坏的评价。

## 二、符号定义

| 符号 | 中文 | 公式 | 口径要点 |
| --- | --- | --- | --- |
| **存量（资产负债表期末）** | | | |
| **NFA** | 净固定资产 | 固定资产 + 在建工程 | 含在建工程（钱已付、未转固）；不含长期股权投资 |
| **WC** | 净营运资本 | 应收 + 存货 − 应付 − 合同负债 | 应收存货是垫出去（+），应付合同负债是别人垫的（−）；可为负 |
| **IC** | 经营资本 | NFA + WC | 剔除现金、理财、长期股权投资 |
| **F** | 可供发展资金 | 货币资金 + 交易性金融资产 | 扩张的支付来源；**不扣有息负债**（NOPAT 已加回利息，负债成本在 WACC 里） |
| **C_t** | 期初可用现金 | C₀ = F；C_{t+1} = C_t − P_t | 缓冲池余额，只用于付 E |
| **流量（利润表 / 现金流量表）** | | | |
| **NOPAT** | 税后经营利润 | (营业利润 + 财务费用) × (1 − t) | 财务费用加回（为负照加，即剔利息收入）；t 用实际税率，不用 25% 法定税率 |
| **DA** | 折旧与摊销 | 固定资产折旧 + 无形资产/长期待摊摊销 | 不流出现金 |
| **Capex** | 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | 含扩张与维持两部分 |
| **MC** | 维持性资本开支 | 维持现有经营能力所必需的 capex，**≈ DA** | 只保产能、不扩产 |
| **ΔWC** | 营运资本增量 | WC_t − WC_{t−1} | 增长的配套占用 |
| **E** | 扩张性消耗 | (Capex − MC) + ΔWC | 扩张期从利润里扣的就是它 |
| **P_t** | 现金垫付 | min(E_t, C_t) | 由存量现金支付的部分，不扣利润 |
| **DP** | 可分配利润 | NOPAT − (E − P) | |
| **比率与增量** | | | |
| **ROIC** | 经营资本回报率 | NOPAT / IC | 不是 ROE（分子分母都不含融资结构与非经营资产） |
| **ΔNP** | NOPAT 增量 | NOPAT_t − NOPAT_{t−1} | 估 E 的辅助量 |
| **k** | 边际资本系数 | E / ΔNP | E 的兜底估法，非主算式 |
| **θ** | 兑现系数 | DP / NOPAT；永续 = 1 − g∞ / ROIC\* | **只在永续里定义** |

注一：DA 与 MC 只作 E 的构成，不进 DP 的加减项——Capex 与 DA 的差额已含在 E 里，再加一次 DA 就是重复。

注二：F 是**支付手段**，不是收入——它不产生 NOPAT，也不进 IC（本节已剔除），只用来推迟 E 对利润的挤压。

## 三、扩张期：从利润里扣掉 E（现金先垫）

### 1. 先厘清几个"期"

文档里会出现四个词，指的不是一回事：

| 说法 | 年份 | 增速 | 怎么算 | 本质 |
| --- | --- | ---: | --- | --- |
| **明确预测期** | 前 3 年 | 各家不同（如 +27%/+9%/+8%） | 逐项预测 | **真正在判断业务** |
| **过渡期** | 第 4—10 年（固定 7 年） | 由 g₃ 线性衰减至 2.33% | 逐年算 | **数学过渡，不含经营判断** |
| **成长期／扩张期** | 前两段合称 | 由正到衰减 | 逐年算 | **"逐项列出来"的那 10 年** |
| **永续期** | 第 11 年起 | 固定 2.33% | 公式 | 只剩"跟通胀走" |

**"成长期"不是严格的时点划分，而是一个状态**：只要企业还在**主动扩产、扩渠道**（capex 明显高于折旧、营运资本持续增加），就还在成长期。它可能持续 5 年，也可能 15 年——**本算例统一按 10 年处理**（3 年明确 + 7 年衰减），因为要覆盖一个典型的行业产能周期。

> **成长期与永续期的分界不在年份，在"还需不需要主动投钱扩产"**。分界线一旦跨过，就不再逐年排 capex，改用 θ 系数法。判断是否跨过，看两个信号：capex 是否已回落到接近折旧、营运资本占收入比是否稳定。

### 2. 逐年算法

**总年数 10 年**：前 3 年明确预测利润，第 4—10 年增速从第三年线性衰减至 2.33%（与 `doc/估值理论/估值模型.md` 的 T=7 过渡期一致）。**Capex 逐年按在建工程、募投项目、产能规划预估，不做线性外推**。

### 3. 输入与步骤

**输入四样**：NOPAT₀、10 年 g_t 序列、Capex/DA 逐年规划（无规划时用 k 兜底）、可供发展资金 F。

**数值例（下文各表通用）**：基年 NOPAT 100、IC 300（ROIC 33.3%）、F = 150；前 3 年 g = 20% / 18% / 15%，随后 7 年线性衰减；Capex 按规划先升后降（90 → 113 → 85），DA 随产能投放递增（30 → 71）。

| 步 | 算式 |
| --- | --- |
| 1 利润 | NOPAT_t = NOPAT_{t−1} × (1 + g_t) |
| 2 扩张性消耗 | E_t = (Capex_t − MC_t) + ΔWC_t |
| 3 现金垫付 | P_t = min(E_t, C_t) |
| 4 可分配 | DP_t = NOPAT_t − (E_t − P_t) |
| 5 余额结转 | C_{t+1} = C_t − P_t |

### 6. 读法

- 现金只**推迟**扣减，不**取消**扣减。T1—T2 的 DP 与 NOPAT 相等（全由现金付），T3 现金见底、利润开始承压
- 累计 DP = 1,708.3，比无现金的 1,558.3 多 **150.0 = F**，一分不多一分不少
- E 从 70.0 一路降到 19.0，**不是因为 capex 变小，而是扩张性 capex 从 60.0 收到 14.0、ΔWC 从 10.0 收到 5.0**——成熟是收在边际上，不是收在总量上
- 10 年 E 合计 521.0，除以利润增量 173.7，k ≈ 3.0，与基年 1/ROIC = 3 一致——扩张期没有偷改资本效率

## 四、永续期：回到 θ

扩张结束、企业进入稳态后，不再逐年排 capex，改用兑现系数：

$$DP_\infty = NOPAT \times \theta_x,\qquad \theta_x = 1 - \frac{g_\infty}{ROIC^*},\qquad E_\infty = g_\infty \times IC^*$$

三段的分工：

| 量 | 取哪个口径 | 为什么 |
| --- | --- | --- |
| NOPAT | 稳态年利润 | T10 的 273.7 |
| ROIC\* | **满产满销后的稳态 ROIC** | 不用爬坡期 ROIC——新产能先提折旧、后满产，爬坡期 ROIC 被摊薄，用它算 θₓ 会系统性低估 |
| g∞ | 2.33% | 全市场统一，见 `doc/估值理论/估值模型.md` 终局增速一节 |

**数值例（接第三节）**：IC\* = 300 + ΣE = 300 + 521.0 = 821.0。

| 量 | 计算 | 结果 |
| --- | --- | ---: |
| ROIC\* | 273.7 / 821.0 | 33.3% |
| E∞ | 2.33% × 821.0 | 19.1 |
| DP∞ | 273.7 − 19.1 | 254.6 |
| θₓ | 1 − 2.33% / 33.3% | **93.0%** |

**读法**：永续期**同样要扣 E**，只是 E 从 T10 的 19.0 收敛到 19.1——两者几乎相等，正是过渡期结束的标志；DP∞ = 254.6 与 T10 的 254.7 也几乎相等。θₓ 就是这个扣减之后的余额占比。永续期不再有现金垫付：C 在 T2 已耗尽。

> **与第一节的呼应**：这里的 `E∞ = g∞ × IC*` 就是第一节说的"两类增长税"合起来——`g∞ × NFA`（设备涨价）+ `g∞ × WC`（多垫货款）。**换新本身不构成扣减**，因为折旧已在 NOPAT 里扣过、买设备的钱又花掉，一进一出抵消。这正是 θ 能高到 93% 的原因：赚的钱里只有 7% 被增长吃掉。

两个边界：

- **IC ≤ 0**（客户/供应商垫资的公司）：公式分母为负、失效，θ 取 1.0 封顶
- **ROIC\* 必须用稳态值**：若公司尚在爬坡，取同行业成熟公司的 ROIC 中枢替代，不要用当期值

## 五、两段怎么接上

**校验两条**：

- **T10 的 E 应落到 $g_\infty \times IC_T$**：19.0 vs 19.1，差 0.1（Capex 规划取整），可接受
- **T10 的 DP 应接上 DP∞**：254.7 vs 254.6，差 0.1

若差得远，说明 capex 规划漏项、或扩张期排长了、或 ROIC\* 用了爬坡期值。

**两段的接口不是同一个式子**：

- 前 10 年用**规划法**（Capex 逐年排），k 只是无规划时的兜底
- 永续期用**系数法**（k = 1/ROIC\*，g = g∞）

差别不在系数，在**增速与 capex 的边际收口**：E 从 70.0 一路收到 19.0，收的是"增量"，不是"总量"。
