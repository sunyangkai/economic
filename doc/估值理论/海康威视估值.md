# 海康威视估值（新模型试算）

> **用途**：用 `doc/估值理论/估值模型.md`（θ 只作用于永续期）给海康做一次完整估值，并与主报告 `海康威视.md` §五 的旧口径（θ = 0.795 全期折价）对照。
> **不改主报告**：本文是模型切换的效果试算，主报告结论仍是旧的。
> **数据基线**：2025 年报 + 2026 三季报；金额单位亿元；91.65 亿股；现价 32.42 元（2026-10-22）；折现率与终局增速见 §二。
> **复算**：全部数字由 `tools/valuation.js` 的 `calculateValuation()` 实跑，命令见 §六。

---

## 一、结论

| 口径 | 内在 PE | 对应股价（2025A EPS 1.5489） | 相对现价 32.42 元 |
| --- | ---: | ---: | ---: |
| **新模型（本文）** | **25.6x** | **~40 元** | **<span style="color:#d02020">+22%</span>** |
| 旧模型（主报告，θ = 0.795 全期） | 21.4x | ~33 元 | +2% |

- 终值占总价值 **57%**，扩张期占 43%（旧模型里前 10 年同样被 θ 打折，占比更低）
- 永续兑现系数 $\theta_x = 92.0\%$（由 2025 年 ROIC 29.0% 解出）
- 按 TTM EPS 1.9408 元折算，内在 TTM PE 20.4x（现价 16.7x）

**一句话**：模型切换后海康的估值高约 20%，**不是因为更乐观的利润假设**（利润路径一模一样），而是两处口径变化——永续折价由 0.795 升到 0.920，以及扩张期改由资本开支扣、而账上 465 亿现金把这笔扣减垫掉了。

**新旧模型对现金的处理，差在哪**：旧模型对全部年份乘同一个兑现系数，465 亿现金在估值里等于 0；新模型承认它"**不能分配、但能支撑增长**"——十年扩张性支出 345 亿由它垫付，利润一分没被挤占。这块在估值上值 **+1.7x**（§4.4 第 ③ 步），不是安慰性的说法，是可以拆出来单独计价的。

## 二、输入

| 参数 | 取值 | 来源 |
| --- | ---: | --- |
| 基年归母净利润 $NP_0$ | 141.95 亿 | 2025A（EPS 1.5489 元，91.65 亿股） |
| 利润增速 $[g_1,g_2,g_3]$ | +27.5% / +9% / +8% | 主报告基准（一致预期为 +27.5% / +13.2% / +12.3%） |
| 过渡期 | 7 年，之后 $g_\infty$ = 2.33% | 模型固定 |
| $F$（可供发展资金） | 465.1 亿 | 2025 年末货币资金（交易性金融资产为 0） |
| $ROIC$（稳态） | 29.0% | 2025 年 NOPAT 149.1 / 经营资本 513.8（NFA 220.9 + WC 292.9） |
| $R$ | 8.45% | $r_f$ 1.65% + ERP 6.8% |
| $\theta_x$ | 92.0% | $1 - 2.33\%/29.0\%$ |

**扩张期资本消耗**的逐年规划（Capex、DA、ΔWC）见 §3.1 的表——三者合起来就是 $E_t$。

> **三处口径约定**：① 利润用归母、capex 用合并数，故把 $E$ 乘归母占比 92%（2025 年 141.95/154.33），这会**低估**可分配利润；② $F$ 取全部货币资金，未区分经营周转所需的部分；③ $ROIC$ 用 NOPAT 口径（149.1/513.8），与归母利润不同源，但 $\theta_x$ 只取决于资本强度，影响在 1pp 以内。

### 3.2 这条路径怎么来的

**① 利润**：2026 年 +27.5% 主要由前三季度带动（归母 129.11 亿、同比 +38.5%），Q4 退到 +6% 附近（2025Q4 基数高）；2027 年起回到个位数。比卖方一致预期（2027 +13.2%、2028 +12.3%）低约 4pp，理由是元器件涨价压毛利、创新业务少数股东分流——**分歧只在 2027 年之后，2026 年两边基本一致**。

**② Capex**：2026—2028 抬到 43.6—44.8 亿，对应在建工程与新产能投放；2029 年后回落到 36—37 亿的平台，仅比 2025 年的 36.2 亿略高——**没有假设资本开支大幅收缩**。

**③ DA**：从 21.1 升到 31.8，是 2026—2028 那批 capex 转固后的折旧，滞后约 2 年，所以 2029 年后 capex 降了、折旧还在升。

**④ ΔWC**：2026 年 80.5 亿是峰值，对应三季报存货从 204.7 亿升到 333.3 亿（+128.6 亿，官方口径"采购备货"）；2027 年回落到 26.1 亿，之后逐年收敛到 12.9 亿，假设备货在 2027 年消化、收入增速放缓后应收同步回落。

**⑤ E**：从 89.1 收到 18.2，降 80%。**不是 capex 变小**（capex 反而从 29.7 升到 37.1），而是两处边际同时收窄：扩张性 capex 从 8.6 收到 5.3、ΔWC 从 80.5 收到 12.9——这正是"成熟收在边际上，不是总量上"。

**⑥ 现金与 DP**：十年 E（归母）合计 345 亿，账上 465 亿全部垫得住，所以 **DP ≡ 归母净利**，一分利润没被挤占；期末还余 120 亿。

**⑦ 这条路径最该被质疑的地方**：2021—2025 年实际 E 合计 **212 亿**，但年际波动极大（102.0 / 79.7 / 49.8 / 33.9 / **−53.5**，2025 年为负是因为应收一次性释放）。本表规划十年合计 375 亿、且逐年平滑下降——隐含"资本占用迅速正常化、不再反复"。2026 年的 89 亿（对应实际备货）可信，但 2027 年起就降到 47 亿，低于 2021—2022 的 102、79.7，接近 2023—2024 的 49.8、33.9。**若回到 2021—2022 的强度，后半段要整体上修 E**，估值随之下修（见 §五）。

**永续期**：$NP_{2036} = 302.9 \times 1.0233 = 310.0$，$DP_\infty = 310.0 \times 92.0\% = 285.1$，终值 $285.1/(8.45\%-2.33\%) = 4{,}661$ 亿，折现回 2026 年为 2,071 亿。

**合计**：扩张期现值 1,566 亿 + 终值现值 2,071 亿 = 3,637 亿 ÷ 141.95 亿 = **25.6x**。

## 五、这套结果可信吗

**先看敏感性排序**——三个可争议的输入，各自值多少：

| 输入 | 变动 | 内在 PE | 影响 |
| --- | --- | ---: | ---: |
| $\theta_x$ | 79.5%（旧口径）→ 92.0%（ROIC 解出） | 23.6x → 25.6x | **+2.0x（+8%）** |
| 现金 $F$ | 465 亿 → 0 | 25.6x → 23.9x | −1.7x（−7%） |
| 资本消耗 $E$ | 345 亿 → 690 亿（翻倍） | 25.6x → 24.8x | −0.8x（−3%） |

**结论很清楚：这个估值几乎全部押在 $\theta_x$ 上**，capex 与现金的影响都在个位数百分比内（因为十年 E 只占十年利润的 14%）。

**$\theta_x$ 该取 80% 还是 92%？** 这是本文唯一真需要判断的地方：

- **92% 的逻辑**：海康 2025 年 ROIC 29.0%，稳态增长只需把 2.33%/29% = 8% 的利润投回去，剩下 92% 可分。规划期 capex 仍高于折旧（36 亿 vs 21 亿），但差额在收窄——扩张性 capex 从 2026 年 8.6 亿收到 2035 年 5.3 亿，占当年利润只有 2%—5%，转固高峰已过。
- **80% 的逻辑**：2021—2024 年实际兑现率只有 53.7%（NOPAT 573.8 亿、FCF 308.1 亿），五年均值 70.7%。若那种"利润被应收和扩产吃掉"的模式重演，92% 就太乐观——**两者差的 12pp 不是算错，是问的问题不同**：历史兑现率含扩张期的资本沉淀，公式锚只算稳态增长的开销。

**怎么验证**：盯两条线——① 未来三年 capex 是否持续低于折旧；② 营运资本占收入比是否继续回落（2026 年因备货升到 201.79 天，需要看到回落）。两条都成立，92% 站得住；任一条反转，就该回到 0.85—0.88 区间，PE 约 24.5—25x。

## 六、复算

```js
import { calculateValuation } from './tools/valuation.js';

const E = [82.0, 43.2, 44.3, 31.9, 30.2, 28.2, 25.8, 22.9, 20.0, 16.7]; // 合并 E × 92%

const v = calculateValuation({
  company: {
    np0: 141.95,                       // 基年归母（亿元）
    growthForecasts: [0.275, 0.09, 0.08],
    expansionSpend: E,                 // 逐年扩张性消耗（亿元）
    availableFunds: 465.1,             // F
    roic: 0.29,                        // → θₓ = 92.0%
  },
  macro: { rf: 0.0165, nominalGdpGrowth: 4 },
});

console.log(v.pe);           // 25.6
console.log(v.dpPath);       // 十年 DP（亿元）
console.log(v.thetaX);       // 0.920
```
