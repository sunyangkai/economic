# 不同企业的 θ 为什么不一样

> **用途**：解释统一估值模型里兑现系数 θ 的来源与差异机制——为什么有的公司 θ 接近 1、有的只有 0.7 多。
> **定位**：`doc/估值理论/估值模型.md` §4.4—4.7 的展开说明，不改变模型结构（θ 仍按 0.15θ₀ + 0.85θₓ 加权）。
> **结构**：一、逻辑推导（公式从哪来）｜二、案例说明（两家公司、一个谱系）｜三、名词解释（符号怎么对）。
> **状态**：v3，2026-10-24。数据基线：各公司 2025 年报（`api/` 接口取数）。

---

## 一、逻辑推导

### 1.1 自由现金流：NOPAT 的三处修正

自由现金流（A 股并购评估里"企业自由现金流"的标准写法，见[上交所评估说明](https://static.sse.com.cn/disclosure/listedinfo/announcement/c/new/2025-11-06/603082_20251106_G2SM.pdf#51#24)）定义为：

$$FCF = NOPAT + D\!A - \text{Capex} - \Delta WC$$

它之所以不是 NOPAT 本身，是因为 NOPAT 是**权责发生制**的经营利润，里面有三处与现金无关的处理：

| NOPAT 里的处理 | 是否伴随现金流动 | 修正 |
| --- | --- | --- |
| 扣了 D&A（折旧摊销） | **不流出**——设备的钱在购买那年已付 | **加回** D&A |
| 没扣 Capex（资本开支） | **流出**——会计把它资本化，只通过每年折旧抵税 | **减去** Capex |
| 收入按交付确认、成本按耗用结转 | **时点不同**——卖了货没收钱、进了货没付钱 | **减去** ΔWC |

用一组数验证（收入 1,000、付现成本 600、折旧 50、税率 25%、capex 80；应收 +30、存货 +20、应付 +10）：

| 步骤 | 金额 |
| --- | ---: |
| EBIT = 1,000 − 600 − 50 | 350.0 |
| NOPAT = 350 × (1 − 25%) | 262.5 |
| + D&A | +50.0 |
| − Capex | −80.0 |
| − ΔWC（30 + 20 − 10） | −40.0 |
| **= FCF** | **192.5** |

> 直接数现金核对：客户实付 970 − 供应商实付 610 − 买设备 80 − 交税 87.5 = **192.5**。两条路径相等——加回 D&A、减去 Capex，本质是把"按年摊销的设备钱"还原成"实际付出的设备钱"。

**分子的两个口径约束**：

- **用 NOPAT 不用净利润**：这个 FCF 未扣利息，属于**全体资本提供者**（债权人 + 股东），因而按 WACC 折现得企业价值（EV）。若用净利润起算，得到的是股东口径现金流，须按 Ke 折现并另处理净借款；主模型用 WACC，就必须配 NOPAT。利息的税盾已含在 WACC 的税后债务成本里，再算进现金流是重复计算。
- **投资收益、公允价值变动、其他收益不进 NOPAT**：它们不是经营所得，留在分子里会虚高 ROIC（口径细节见 §三 3.2）。

### 1.2 稳态：增长只吃两处资本

把上式合并一步，语义更清楚：

$$FCF = NOPAT - \underbrace{(\text{Capex} - D\!A)}_{\text{净投资}} - \Delta WC$$

**永续稳态**下，增长只通过两处资本占用体现，两者都随名义增速同步扩张：

| 资本项 | 稳态年增量 | 为什么 |
| --- | --- | --- |
| 固定资产 | $\Delta NFA = g_\infty \times NFA$ | 即使零实物扩张，重置成本也随通胀上涨（设备原值 100、10 年后重置 125.9，年化 capex > D&A） |
| 营运资本 | $\Delta WC = g_\infty \times WC$ | 应收/存货/应付按名义金额计价，名义收入涨，占款也涨 |

同时稳态下 $\text{Capex} = D\!A + g_\infty \times NFA$（D&A 补折旧，多出的部分补重置成本上涨）。代入整理：

$$FCF = NOPAT - g_\infty \times (NFA + WC) = NOPAT \times \left(1 - \frac{g_\infty}{ROIC_{\text{经营}}}\right)$$

$$\boxed{\theta_{\text{终值}} = \frac{FCF}{NOPAT} = 1 - \frac{g_\infty}{ROIC_{\text{经营}}},\qquad ROIC_{\text{经营}} = \frac{NOPAT}{NFA + WC}}$$

**读法**：θ 不是"公司质量评分"，而是"增长要付的资本过路费"——每赚 1 元利润要垫多少资本，决定了其中多少必须留在公司里换设备、垫应收，剩下的才分得出去。**当 $g_\infty = 0$ 时，capex = D&A、ΔWC = 0，FCF = NOPAT、θ = 1**，这正是 θ 的上限，也是"θ 衡量为增长付的代价"的数学根据。

### 1.3 三条使用边界

- **只算经营资本**（NFA + WC）。现金、理财、长期股权投资不随收入增长，**必须从分母剔除**——现金是存量余额，不需要按 g 补充，把它算进去等于假设公司每年为了多留现金而少分红。海康按全口径算 θₓ 会从 0.920 掉到 0.841，差 0.079、估值差约 8%；
- **$g_\infty$ 用终局增速 2.33%**，不用预测期增速（8%—30%）。用 8% 代入海康得 $\theta = 1 - 8\%/29\% = 0.724$，那是"若永远以 8% 增长要付的代价"，不是终值期的——**θₓ 只在终值期定义**；
- **经营资本 ≤ 0 时取 θ = 1.0 封顶**。客户和供应商先垫资的公司（东鹏、美的）增长不需要自有资本，公式分母为负、失效，封顶 1.0 也与它们长期净现比 > 1 的事实一致。

## 二、案例说明

### 2.1 两个例子：一个压大坝，一个压基酒

| 2025 年（亿元） | 长江电力 | 贵州茅台 |
| --- | ---: | ---: |
| 营业收入 | 862.4 | 1,720.5 |
| 营业利润 | 426.0 | 1,148.1 |
| 财务费用（加回，算 EBIT） | +93.7 | −8.2 |
| 实际税率 | 16.3% | 25.7% |
| **NOPAT** | **435.2** | **847.4** |
| 固定资产 + 在建工程（NFA） | 4,324.8 | 249.6 |
| 净营运资本（WC） | 64.4 | 494.2 |
| **经营资本（NFA + WC）** | **4,389.2** | **743.8** |
| NFA / NOPAT | **9.94** | **0.29** |
| WC / NOPAT | 0.15 | 0.58 |
| **ROIC 经营** | **9.9%** | **113.9%** |
| **θₓ** | **0.765** | **0.980** |
| 维持 2.33% 增长须投回利润的比例 | 23.5% | 2.0% |

**长江电力**：每赚 1 元 NOPAT，账上压着 9.94 元水电站资产。这 10 元资产每年要为 2.33% 的名义增长补约 0.23 元重置成本——占 1 元利润的 23%，**分不出来**。它的营运资本几乎可忽略（0.15：卖电给电网，账期短、无存货），**θ 低完全由固定资产造成**。

**贵州茅台**：同样赚 1 元只压 0.29 元厂房，一间酒厂支撑 847 亿税后利润；再加 0.58 元营运资本，大头是基酒库存 614.3 亿。ROIC 113.9%，维持 2.33% 增长只需把利润的 2% 投回去，**利润几乎全额可分**。

> 茅台的 0.58 里藏着"基酒越放越值钱"的定性差异——θ 只认金额、不认资产质量。这类差异要另做定性补充，不能指望 θ 表达。

**同样是最优质的两类中国资产，θ 差 0.215——差别不在"好不好"，在"要不要一直买设备"。**

### 2.2 资本形态谱系：θ 的差异约 80% 由此解释

| 形态 | 典型公司 | NFA/NOPAT | WC/NOPAT | ROIC | θₓ |
| --- | --- | ---: | ---: | ---: | ---: |
| **固定资产主导** | 长江电力 | 9.94 | 0.15 | 9.9% | 0.765 |
| | 顺丰控股 | 4.23 | 0.14 | 22.9% | 0.898 |
| | 伊利股份 | 3.14 | −0.72 | 41.3% | 0.944 |
| | 三一重工 | 2.69 | 2.22 | 20.4% | 0.886 |
| | 宁德时代 | 2.52 | −0.53 | 50.4% | 0.954 |
| **营运资本主导** | 海康威视 | 1.48 | **1.96** | 29.0% | 0.920 |
| | 药明康德 | 1.32 | 0.56 | 53.2% | 0.956 |
| **轻资产** | 贵州茅台 | 0.29 | 0.58 | 113.9% | 0.980 |
| | 迈瑞医疗 | 1.30 | 0.26 | 64.1% | 0.964 |
| **负营运资本** | 美的集团 | 1.22 | **−1.02** | 513.4% | 0.995 |
| | 东鹏饮料 | 1.46 | **−1.50** | 分母为负，**公式失效** | → 1.0 |

> 数据口径：2025 年报；符号定义见 §三。

**同为"轻资产"，海康 0.920 与茅台 0.980 差在哪？** 差在营运资本——海康 WC/NOPAT = 1.96（政府客户与渠道商占款），茅台只有 0.58。**海康是"轻固定资产、重营运资本"的组合，最容易被误判**：看固定资产以为它轻，实际每赚 1 元压着 1.96 元应收和存货。

## 三、名词解释

### 3.1 符号总表

| 符号 | 名称 | 口径定义 | 出现在 |
| --- | --- | --- | --- |
| **NOPAT** | 税后经营利润 | (营业利润 + 财务费用) × (1 − 实际税率) = EBIT × (1 − t)；**加回利息、也剔利息收入** | θ 的分子、ROIC 的分子、FCF 的起点 |
| **EBIT** | 息税前利润 | 营业利润 + 财务费用（财务费用为负时同式，效果是剔除利息收入） | 只作 NOPAT 的中间量 |
| **D&A** | 折旧与摊销 | 现金流量表"固定资产折旧 + 无形资产/长期待摊费用摊销" | FCF 中**加回** |
| **Capex** | 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | FCF 中**扣除** |
| **ΔWC** | 营运资本增加 | 本期 WC − 上期 WC；稳态下取 $g_\infty \times WC$ | FCF 中**扣除** |
| **NFA** | 净固定资产 | 固定资产 + 在建工程（不含长期股权投资） | ROIC 的分母 |
| **WC** | 净营运资本 | 应收 + 存货 − 应付 − 合同负债 | ROIC 的分母 |
| **IC** | 经营资本 | NFA + WC，**剔除现金、理财、长期股权投资** | ROIC 的分母 |
| **ROIC 经营** | 经营资本回报率 | NOPAT / IC | θ 公式的分母 |
| **g∞** | 终局名义增速 | 2.33%（默认参数，见 `估值模型.md` 终局增速一节） | θ 公式的分子 |
| **FCF** | 自由现金流 | NOPAT + D&A − Capex − ΔWC；稳态下 = NOPAT × θ | θ 的分子 |
| **NP_adj** | 调整后净利润 | 归母口径、剔一次性项目（见 `估值模型.md`） | 主模型估值分子，**≠ NOPAT** |
| **θ₀ / θₓ** | 当前/终值兑现系数 | θ = 0.15θ₀ + 0.85θₓ；本文算的是 θₓ | `估值模型.md` §4.4—4.7 |

### 3.2 NOPAT 详解（全文的分子）

**NOPAT = Net Operating Profit After Tax，税后经营利润**——公司用经营资产、在**不问钱是谁出的**前提下，一年净赚多少。三个动作各有用途，缺一个口径就偏：

| 动作 | 在算什么 | 为什么这么算 |
| --- | --- | --- |
| 营业利润**加回**财务费用 | 把利息支出还原 → EBIT | 利息是**融资决策**的结果，不是经营能力。加回后杠杆高低不再影响这个数，长电与茅台才可比 |
| 财务费用**为负时照加**（茅台 −8.2） | 把利息**收入**一并剔掉 | 账上现金的利息不是经营赚的，留在里面会虚增"经营"回报 |
| 乘 **(1 − 实际税率)** | 用实际税负，不用 25% 法定税率 | 长电 16.3%（水电优惠）、茅台 25.7%，用法定税率会把两者的税后利润同时算错 |

可复核：长电 $(426.0 + 93.7) \times (1 - 16.3\%) \approx 435.0$（取 435.2）；茅台 $(1{,}148.1 - 8.2) \times (1 - 25.7\%) \approx 847.0$（取 847.4），尾差为四舍五入。

**为什么分子必须是 NOPAT、不能是净利润**——这是分子与分母的**匹配**问题：分母 NFA + WC 是债权人与股东**共同垫付**的经营资产，分子就必须是**共同享有**的付息前税后经营利润。若分子换成归母净利润（已扣利息），高杠杆公司的 ROIC 被系统性压低、低杠杆公司被抬高，**θ 的高低就变成"谁借钱多"的函数，不再是资本形态的函数**。

**一个口径提醒（本文数据未处理）**：A 股"营业利润"里混着**投资收益、公允价值变动损益、其他收益（政府补助）、资产处置收益**，严格说不是经营所得，算 ROIC 时应剔除。本文样本此类占比小、影响可忽略；但用在投资收益占比高的公司上（持股型平台、部分医药与科技公司），ROIC 会被虚高、θ 被算高。

### 3.3 三个最容易混的数

| 数 | 与 NOPAT 的关系 | 用在哪 |
| --- | --- | --- |
| **EBIT** | NOPAT = EBIT × (1 − t)，只差一层税 | 只作中间量，不直接进模型 |
| **净利润 / NP_adj** | NOPAT 减掉税后利息才是股东所得；归母净利润还要再扣少数股东损益 | 主模型估值分子用 NP_adj（股东口径），**NOPAT 只在 θ 的稳态锚里用，两处不可混用** |
| **FCF / 可分配现金 DP** | NOPAT 是"赚了多少"，FCF 是"能拿走多少"，差额 $NOPAT \times (1-\theta)$ 正是必须投回 NFA + WC 的钱 | 折现的现金流 |
