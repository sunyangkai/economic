# 宏观参数说明：GDP 平减指数与永续增速公式

> **状态：已归档（2026-10-22）。** 本文档原为 `估值模型v2.md` 的附则；v2 草案已删除，其 $g_\infty = \pi + \beta \times g_{\text{实际GDP}}$ 分档口径**未被采用**。**当前模型（`估值模型.md` §5.5）仍用饱和型映射式 $g_\infty = \frac{0.35m}{1+0.35m}\times 4\%$，不用本文档的公式。**（注：该式的系数 0.35 与 4% 是**设定值**，不是拟合结果；它满足"低于名义 GDP、有界、落在成熟企业永续 2—3% 区间"三条约束，见 `估值模型.md` §7.16。）
>
> **保留本文档的理由**：它把"名义增长 = 实际增长 + 价格因素"、GDP 平减指数与 CPI/PPI 的区别讲清楚了，是理解 $g_\infty$ 经济含义（以及为什么用名义 GDP 增速 $m$ 作输入）的背景读物。
>
> **阅读方式**：只读 §一—§四、§七（概念与推导），**§五、§六、§八 的 $\pi+\beta$ 口径与分档规则不适用当前模型**，作历史记录。

## 一、从一个面馆讲起：名义增长与实际增长

### 1.1 例子

| 年份 | 销量 | 单价 | 收入 |
|---|---:|---:|---:|
| 2025 | 10,000 碗 | 20 元 | 200,000 元 |
| 2026 | 10,500 碗 | 21 元 | 220,500 元 |

**收入名义增长：**

$$\frac{220{,}500}{200{,}000} - 1 = 10.25\%$$

### 1.2 拆解这 10.25%

| 来源 | 计算 | 幅度 | 概念 |
|---|---|---:|---|
| 真多卖了 | $10{,}500 / 10{,}000 - 1$ | **+5.00%** | **实际增长** |
| 涨价了 | $21 / 20 - 1$ | **+5.00%** | **价格因素** |
| 合起来 | $1.05 \times 1.05 - 1$ | **+10.25%** | **名义增长** |

$$\text{名义增长} = (1 + \text{实际增长}) \times (1 + \text{价格因素}) - 1$$

**近似关系（小数相乘可以忽略）：**

$$\text{名义增长} \approx \text{实际增长} + \text{价格因素}$$

## 二、平减指数的定义

### 2.1 定义

**平减指数 = 从名义增长中剔除实际增长后，剩下的纯价格因素。**

$$\text{平减指数} = \frac{1 + \text{名义增长}}{1 + \text{实际增长}} - 1$$

**代入面馆例子：**

$$\frac{1.1025}{1.05} - 1 = 5.00\%$$

**它回答一个问题：如果东西一件都没多卖，光是涨价，收入会涨多少？**

### 2.2 放大到整个国家

把所有面馆、工厂、服务业加总：

$$\text{GDP平减指数} = \frac{\text{全部名义产出}}{\text{全部实际产出}} - 1$$

**它衡量"整个经济所有产出的价格变化"。**

### 2.3 恒等式

$$\boxed{g_{\text{名义GDP}} = \pi + g_{\text{实际GDP}}}$$

（严格形式是相乘，加法是近似，误差在 0.1pp 量级）

## 三、三个价格指标的区别

### 3.1 当前数值（2026）

| 指标 | 当前值 | 覆盖范围 | 观察视角 |
|---|---:|---|---|
| **CPI** | **+0.9%** | 居民消费的一篮子商品 | 消费者买入 |
| **PPI** | **+5.0%** | 工业品出厂价 | 工厂卖出 |
| **GDP 平减指数** | **约 −0.7%** | **全部产出**（农业 + 工业 + 服务业） | 经济整体 |

### 3.2 为什么 PPI +5%，平减指数却 −0.7%

| 原因 | 说明 |
|---|---|
| PPI 只覆盖工业 | 当前工业上游在涨（输入性能源涨价） |
| 服务业价格在跌 | 服务业占经济比重很大，但 PPI 不含 |
| 农业基本没涨 | |
| **加总后整体为负** | 所以平减指数是 −0.7% |

### 3.3 为什么 CPI +0.9%，平减指数却 −0.7%

| 原因 | 说明 |
|---|---|
| CPI 是消费者到手价 | 包含流通环节、税、渠道加价 |
| 平减指数是生产者卖出价 | 中间环节可以提价，生产企业拿到的钱不一定增加 |

## 四、为什么模型必须用平减指数

### 4.1 原因一：只有它能维持恒等式

**代入 2026 年的实际数据验证：**

| π 取什么 | π + 实际 GDP（4.7%） | 应等于名义 GDP（4.0%） | 结果 |
|---|---:|---:|---|
| CPI = 0.9% | 0.9 + 4.7 = **5.6%** | 4.0% | ❌ 差 1.6pp |
| PPI = 5.0% | 5.0 + 4.7 = **9.7%** | 4.0% | ❌ 差 5.7pp |
| **平减 = −0.7%** | **−0.7 + 4.7 = 4.0%** | 4.0% | ✅ **完全吻合** |

**如果用 CPI 或 PPI，公式算出的"伪名义 GDP"和真实名义 GDP 对不上，整个推导链断裂。**

### 4.2 原因二：企业提价能力对应的是产出价格

**模型里 $\pi$ 的含义是"企业的长期提价能力"。**

| 指标 | 对应什么 | 能否代表企业提价能力 |
|---|---|---|
| CPI | 消费者买东西的贵了多少 | ❌ 含流通环节和税，非产出价格 |
| PPI | 工业品出厂价的贵了多少 | ❌ 只覆盖工业，不含服务与农业 |
| **平减指数** | **全部产出价格的贵了多少** | ✅ **正是企业提价的中枢** |

### 4.3 原因三：经济逻辑自洽

**一家企业长期的平均提价能力，最多就是"所有产出价格的涨幅"。**

- 提价**超过**平减指数 → 在抢份额（不可永续）
- 提价**低于**平减指数 → 在丢份额（最终会退出市场）

**所以用平减指数作为提价能力的锚，是最保守也最自洽的选择。**

## 五、永续增速公式的推导

### 5.1 企业的收入只能从三个地方来

**回到面馆，明年收入怎么变？只有三条路：**

| 方式 | 做法 | 结果 |
|---|---|---|
| ① 涨价 | 20 元 → 21 元，碗数不变 | +5% |
| ② 多卖 | 10,000 → 10,500 碗 | +5% |
| ③ 抢份额 | 隔壁店关了，客人过来 | 更多，但有上限 |

$$\text{收入增速} = \text{涨价} + \text{多卖} + \text{抢份额}$$

### 5.2 三个来源各自的长期极限

**① 涨价 → 长期极限是通胀 π**

你涨 5%，但全城物价也涨 5%，你的真实购买力增长为 0。你比别家涨得多，客人就跑掉。长期看绝大多数企业只能跟着物价涨。

$$\text{涨价} \approx \pi$$

**② 多卖 → 长期极限是实际 GDP**

多卖 5% 只有两个来源：这条街吃面的需求涨了 5%，或你把别家客人抢过来。全城所有店"多卖的量的总和"就是经济总量的增长。

$$\text{多卖} \approx g_{\text{实际GDP}}$$

**③ 抢份额 → 永续期必须归零**

永续意味着无限远的时间。如果一家公司永远比行业快，它迟早吃掉整个行业——数学上无法持续。

$$\text{份额提升} = 0$$

### 5.3 合起来

$$g_\infty = \text{涨价} + \text{多卖} + \text{份额}$$

$$g_\infty = \pi + g_{\text{实际GDP}} + 0$$

$$g_\infty = \pi + g_{\text{实际GDP}}$$

**右边正好是名义 GDP 增速的定义，所以：**

$$g_\infty \le g_{\text{名义GDP}}$$

### 5.4 用 2026 年数据验证

$$g_{\text{实际GDP}} = 4.7\%, \quad \pi = -0.7\%$$

$$4.7\% + (-0.7\%) = 4.0\%$$

**这正是当前名义 GDP 增速 4.0%。永续期的公司增速上限也就是 4.0%——再高就意味着它永远跑赢整个经济。**

## 六、为什么要乘 β

### 6.1 天花板不等于个体

$\pi + g_{\text{实际}}$ 是**整个经济体**的增速，不是**一家成熟公司**的增速。

**成熟公司通常跑不过经济平均：**

| 原因 | 例子 |
|---|---|
| 新行业不断出现 | 报纸 vs 互联网 |
| 新公司不断进入 | 外资 vs 国产 |
| 成熟公司多在低增长行业 | 现已成熟的行业，量增长慢于新兴行业 |

$$g_\infty = \pi + \beta \times g_{\text{实际GDP}}, \quad \beta \le 1$$

### 6.2 β 的含义

**β = 这家公司所在行业的"量增长"，是经济实际增长的几成。**

| β | g∞（π=2%，实际 4.5%） | 含义 |
|---|---:|---|
| **1.0** | 6.50% | 跟经济一样快 —— **不可能永久** |
| 0.50 | 4.25% | 只有经济一半快 |
| 0.35 | 3.58% | 明显慢 |
| 0.25 | 3.13% | 很慢 |
| 0.10 | 2.45% | 几乎不增长 |
| 0 | 2.00% | 完全停滞，只靠涨价 |

### 6.3 β ≤ 1 是硬约束

$$\pi + 1.0 \times g_{\text{实际}} = g_{\text{名义GDP}}$$

**β = 1 意味着这家公司永远跟经济一样快，要求它永不被颠覆、永不丢份额。这是极强假设，所以成熟公司必须 β < 1。**

## 七、为什么不能用历史增速反推 β

### 7.1 反推会得到什么

**用历史增速反推 β（π=2.5%，实际 GDP=6%，2015–2025 口径）：**

| 公司 | 近 5 年增速 | 反推 β | 问题 |
|---|---:|---:|---|
| 贵州茅台 | 12.5% | **1.67** | β > 1，不可能永续 |
| 美的集团 | 10.1% | **1.27** | β > 1 |
| 伊利股份 | 10.3% | **1.30** | β > 1 |
| 长江电力 | 5.6% | 0.52 | 范围内 |
| 海康威视 | 1.2% | **−0.22** | β < 0 |

### 7.2 为什么反推不成立

**茅台近 5 年 12.5%，但那 12.5% 里包含：**

| 来源 | 能永续吗 |
|---|---|
| 提价（通胀约 2.5%） | ✅ |
| 行业量增长 | ✅ |
| **份额提升** | ❌ 有限期 |
| **结构升级 / 高端化** | ❌ 有限期 |

**12.5% 远超 $2\% + 4.5\% = 6.5\%$ 的天花板——多出的部分必须在有限期内消化。**

### 7.3 结论

**历史增速 ≠ 永续增速。** 不能用历史增速反推企业的终局增速（这一条对当前模型同样成立）。

## 八、π 的动态规则（防通缩失真）

### 8.1 问题

当前平减指数为 −0.7%（通缩）。如果直接用作永续假设，会让所有估值系统性偏低——但通缩通常是周期性的，不应被当作"永远"。

### 8.2 规则

$$\pi = \min\left(2.0\%,\ \text{近 3 年平减指数均值} + 1.0\%\right), \quad \text{下限 } 0\%$$

### 8.3 各情景下的取值

| 情景 | 近 3 年平减均值 | +1% | 最终 π |
|---|---:|---:|---:|
| 通缩期 | −0.50% | 0.50% | **0.50%** |
| 温和通胀 | 1.23% | 2.23% | **2.00%** |
| 高通胀 | 2.77% | 3.77% | **2.00%** |
| 正常 | 2.00% | 3.00% | **2.00%** |

### 8.4 规则的意图

| 设计 | 作用 |
|---|---|
| +1% 缓冲 | 通缩时自动下调，但不会跟着单年波动 |
| 上限 2% | 高通胀期不过度抬高估值 |
| 下限 0% | 极端通缩时也不至于给出负永续增长 |

### 8.5 对估值的影响

**以 A 档（β=0.5）为例：**

| π | g∞ | PE | 相对 π=2% |
|---|---:|---:|---:|
| 2.0% | 4.25% | 19.8x | — |
| 1.0% | 3.25% | 16.5x | −17% |
| 0.5% | 2.75% | 15.3x | −23% |

**通缩持续时，全部估值下调 17%–23%。这是模型必须披露的风险。**

## 九、概念速查表

| 概念 | 一句话 |
|---|---|
| **实际 GDP** | 东西**多卖了多少**（剔除价格） |
| **GDP 平减指数 π** | 东西**卖贵了多少**（剔除量的增加） |
| **名义 GDP** | 收入**总共涨了多少** = 两者相乘 |
| **CPI** | 消费者**买东西**贵了多少（含流通环节） |
| **PPI** | 工厂**卖东西**贵了多少（只算工业） |
| **β** | 行业的量增长是经济实际增长的几成 |
| **g∞** | 永续增速 = π + β × 实际 GDP |
| **R** | 折现率 = rf + ERP |

## 十一、一句话总纲

> **平减指数衡量"东西卖贵了多少"，实际 GDP 衡量"东西多卖了多少"，两者相乘就是名义 GDP。企业永续只能靠涨价（π）+ 部分行业量增长（β × 实际 GDP），份额贡献必须归零——这就是 $g_\infty = \pi + \beta \times g_{\text{实际GDP}}$ 的全部含义。**
