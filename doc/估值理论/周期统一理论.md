# 趋势价值周期理论

## 状态划分

### 维度划分

- **风险偏好**：基本面驱动的"确定性"和趋势驱动的"可能性"两端分布。
- **定价视野**：远期的"叙事驱动"和近期的"业绩驱动"两端分布。

### 状态空间

两个维度划分出四个状态：科技、成长、红利、周期。

四个状态不是顺序轮动，而是状态分布。极端保守的红利和极端风险偏好的科技可以同时存在。

## 状态定义

### 第一象限：科技

- **特点**：技术驱动，渗透率提升，远期爆发。缺乏业绩支撑，叙事性强。
- **触发**：颠覆性技术出现/落地。流动性宽松。
- **奖励**：远期爆发的可能性。

### 第二象限：成长

- **特点**：现金流优异，有明确成长预期，较高估值，较高波动。
- **触发**：宏观经济上行。温和通胀。PPI/CPI/社零数据同步走强。
- **奖励**：相对稳定的持续增长预期。

### 第三象限：红利

- **特点**：稳定现金流、高股息、低估值，低波动、类债券。
- **触发**：宏观经济下行。无风险利率走低。
- **奖励**：当前的确定性。

### 第四象限：周期

- **特点**：利润周期性。价格弹性强。剧烈波动。
- **触发**：供需错配。国际大宗商品价格走强。国际央行的宏观调控（黄金）。地缘政治局势（原油）。
- **奖励**：短期剧烈的弹性。

## 概念解释

### 拥挤

该象限性价比已经消失。

| 象限 | 拥挤信号 |
|------|----------|
| 红利 | 股息率已跌到历史极低水平，风险溢价非常小，和债券比没有优势。 |
| 成长 | PEG 远大于 1，好公司的未来增长已被过度定价，价格突破PE估值通道上轨。 |
| 周期 | P/B 到了历史最高位，但商品价格已开始涨不动或回落。 |
| 科技 | P/S 到了天价，渗透率的故事开始被证伪或证缓。 |

### 泡沫

该象限极端的拥挤，性价比完全消失甚至倒挂。

### 洼地

触发信号已经出现，但价格未得到反应的状态象限。

### 轮动

不同事件催化每个象限景气度的形成，当交易拥挤后，该象限得到兑现，交易开始流向洼地。

强调市场资金在四种资产之间的权重分布，而不是历史阶段。权重转移视为轮动。
