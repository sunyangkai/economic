# 中国社会消费品零售总额数据（社零）— 指标目录

> **长期口径警示（2026 年新"全口径消费"口径）**：2026 年起统计局新增发布 **"社会消费商品和服务零售总额"**——社零只统计实物商品 + 餐饮，不含旅游、教育、医疗等服务消费；新口径把服务消费全部纳入，能更真实反映消费总量。**看消费总量用新口径，看商品零售节奏用社零，两者不可直接相加或替代。**

## 一、核心监测清单（重要数据看哪些）

| 数据 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| 社会消费品零售总额（当月、累计） | 月度（次月 15 日左右） | 名义消费总量；与 GDP、CPI 对照看"量价" |
| **除汽车以外的社零** | 月度 | 剔除汽车以旧换新扰动后的内生消费 |
| **社会消费商品和服务零售总额（新全口径）** | 月度（2026 年 6 月起） | 含服务消费的全口径消费，社零只含餐饮服务 |
| 服务零售额 | 月度 | 旅游、教育、医疗等服务消费——社零测不到的增量 |
| 商品零售 vs 餐饮收入 | 月度 | 商品弱/服务强是当前主要结构特征 |
| 限额以上 vs 限额以下 | 月度 | 限额以上偏企业端，限额以下偏小微/个体，剪刀差反映商户景气 |
| 网上商品零售额 vs 线下 | 月度 | 渠道迁移；线上吃类高增反映必选消费韧性 |
| 分品类（汽车、家电、通讯器材、粮油食品等） | 月度 | 汽车=最大拖累；家电家具建材=地产链；通讯器材=升级消费 |
| 零售业态（便利店/超市/百货/专卖店） | 月度 | 业态景气分化，百货、品牌专卖店偏弱 |
| CPI 与社零实际增速 | 月度 | 名义增速减价格 = 真实"量"的扩张速度 |

> **只盯五个核心数字：社零累计同比、除汽车以外社零、全口径消费（含服务零售额）、网上商品零售额、汽车类同比。**

> **⚠️ 2026 年起统计局新增发布"社会消费商品和服务零售总额"**：社零只统计实物商品 + 餐饮，不含旅游、教育、医疗等服务消费；新口径把服务消费全部纳入，能更真实反映消费总量。1—7 月社零 +1.2%，但全口径消费 +2.6%——看消费不能只盯社零。

## 三、口径提醒

1. **社零 vs 社会消费商品和服务零售总额（2026 年新口径）**：社零只含实物商品 + 餐饮服务；新口径把全部服务消费纳入。两者**不可直接相加或替代**，看总量用新口径，看商品零售节奏用社零。
2. **网上零售口径调整（2026 年起）**：原"网上零售额"改为"网上商品和服务零售额"（统计范围扩大）；"实物商品网上零售额"改为"网上商品零售额"（范围不变）；新增"网上服务零售额"。与 2025 年及以前的"网上零售额"**不可比**。
3. **限额以上口径**：限额以上单位每年动态调整（批发 2,000 万/零售 500 万/住宿餐饮 200 万以上），同比增速的同期数与本期范围一致，与上年公布数据存在口径差异。
4. **名义 vs 实际**：社零官方发布均为名义增速（未扣除价格）。看"量"请减 CPI，或参考统计局发布的扣除价格因素增速。
5. **汽车类口径**："汽车类"含汽车整车及零部件零售，受新能源价格战、以旧换新政策节奏影响大，单月波动剧烈，解读时优先看"除汽车以外社零"。
6. **分品类月度边界**：官方月度仅发布 16 类"限额以上单位"商品零售额（1—2 月合并发布、无单月拆分）；更细的商品（如汽车分燃油/新能源、家电分空调/冰箱）官方月度不发布，需用行业数据（乘联会、奥维云网、中怡康等）或年度《中国统计年鉴》。
7. **单月值口径**：分品类单月同比为"当月同比"；累计同比受 1—2 月基数影响，两者走势可能背离（如通讯器材 5 月单月 +0.7% 但累计仍 +13.8%），看拐点用单月、看趋势用累计。

## 四、数据来源与查找指南

**官方来源**：
- 国家统计局官网 →"数据"→"最新发布"：`https://www.stats.gov.cn/sj/zxfb/`（每月 15 日左右发布上月社零）
- 统计局贸经司首席统计师解读（王全众）：`https://www.stats.gov.cn/xxgk/jd/sjjd2020/`（随数据同步发布）
- 国民经济运行情况新闻发布会（季度发布，含全口径消费数据）
- 国家数据：`https://data.stats.gov.cn/`（历史序列、分地区、分品类）

**查找技巧**：
- 社零月度发布标题固定为"20XX 年 X 月份社会消费品零售总额增长 X.X%"；
- 分品类、分业态数据在页面底部"主要数据"表格中，注意"当月"与"累计"两列；
- 全口径消费（含服务零售额）从 2026 年 6 月起随月度数据发布，也可在季度发布会上获取。
