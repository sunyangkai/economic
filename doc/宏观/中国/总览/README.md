# 总览文件夹说明

本文件夹存放中国宏观经济的**月度评价**，每月单独一个文件，按评价月份命名（如 `2026年8月.md`），旧文件保留、便于回溯。

## 命名与维护规则

- 文件名：`YYYY年M月.md`（评价时间，即撰写月份）；
- 每月 15 日左右，主要数据（社零、PPI、金融、财政）发布齐全后，新建当月评价文件；
- 新文件复制上月文件骨架，更新头部"本期评价 / 数据版本 / 下次更新"，在"数据快照"替换最新数字，在"下半年观察清单"勾掉已验证项；
- 文件内的核心判断、情景与风险应随当月数据滚动修订，不是简单追加；
- 数据以官方发布为准，跨月比较注意基期与口径变化（见各专题文档）。
