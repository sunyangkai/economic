# 中国规模以上工业增加值数据（工业）

> **数据版本：2026 年 1—7 月（2026-08-17 发布）**
> 下次更新：2026-09-15 前后（1—8 月）
> 数据来源：国家统计局月度国民经济运行情况发布会（stats.gov.cn）

---

## 长期口径警示（每次看数据前先过一遍）

- **实际增速**：工业增加值增速为实际增速（扣除价格因素），与 PPI、利润等名义指标不可直接比较——"量强价弱"时两者背离是正常现象。
- **规模以上口径**：年主营业务收入 2000 万元及以上的工业企业；企业每年进出统计范围，同比增速按可比口径计算。
- **1 月免报**：1 月份工业数据免报，1—2 月合并发布累计数据，单月看 3 月起。
- **环比数据**：经季节调整，且统计局会对历史环比进行修订，以最新发布为准。

## 二、口径提醒

- **实际增速**：工业增加值增速为实际增速（扣除价格因素），与 PPI、利润等名义指标不可直接比较——"量强价弱"时两者背离是正常现象。
- **规模以上口径**：年主营业务收入 2000 万元及以上的工业企业；企业每年进出统计范围，同比增速按可比口径计算。
- **环比数据**：经季节调整，且统计局会对历史环比进行修订，以最新发布为准。
- **1 月免报**：1 月份工业数据免报，1—2 月合并发布累计数据，单月看 3 月起。
- **产品产量**：产量为实物量（万吨/万辆/亿块等），与增加值增速（价值量）含义不同；太阳能电池、原油加工量等因价格或需求结构原因可能出现"量价背离"。
- **出口交货值**：指工业企业自营/委托出口及交给外贸部门出口的产品价值，与海关货物出口口径不完全一致（方向通常一致）。

## 三、数据来源与查找指南

- 国家统计局官网（stats.gov.cn）→「数据解读 / 最新发布」→《2026 年 X 月份规模以上工业增加值增长》，次月 **15 日前后** 随月度国民经济运行情况发布会发布。
- 交叉验证：外贸机电出口增速（验证出口交货值）、PPI（验证量价关系）、PMI 生产与高技术分项（先行验证）、工业企业利润（验证盈利）、发电量与耗电量（实物交叉验证）。
- 常用检索词："2026 年 X 月份规模以上工业增加值增长"、"2026 年 1—X 月份规模以上工业增加值"。
