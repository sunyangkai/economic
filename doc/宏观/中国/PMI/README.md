# 中国采购经理指数（PMI）— 指标目录

> **长期口径警示**：PMI 是**环比类扩散指数**，50 为荣枯线——大于 50 表示扩张、小于 50 表示收缩，反映的是边际变化方向，**不等于同比增速**。三套指数（制造业 PMI、非制造业商务活动指数、综合 PMI 产出指数）口径不同、**不能直接替代**。

## 一、核心监测清单

| 指标 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| 制造业 PMI | 月度（每月最后一天/次月首日） | 最领先的景气指标；50 为荣枯线，连续破线=政策加码窗口 |
| PMI 新订单 / 生产指数 | 月度 | 需求与供给的相对强弱；新订单回落快于生产=需求走弱 |
| PMI 购进价 / 出厂价 | 月度 | 上游通胀与中下游利润挤压；剪刀差扩大=利润向上游集中 |
| 装备 / 高技术制造业 PMI | 月度 | 新动能景气，领先于总量 |
| 非制造业商务活动（服务业 / 建筑业） | 月度 | 服务消费与基建地产的边际变化 |
| 生产经营活动预期 | 月度 | 企业信心，领先实际投资 1—2 个季度 |

> **只盯三个核心数字：制造业 PMI、新订单指数、出厂价格指数。**

## 三、口径提醒

- **PMI 是环比类扩散指数**：50 为荣枯线，大于 50 表示扩张、小于 50 表示收缩；反映的是边际变化方向，不等于同比增速。
- **三套指数**：制造业 PMI（含分项）、非制造业商务活动指数、综合 PMI 产出指数，口径不同、不能直接替代。
- **分项含义**：生产、新订单、价格等分项均为扩散指数，衡量"比上月改善的企业占比"；新订单是需求端的领先项。
- **春节错位**：1—2 月读数受春节时点影响较大，看趋势以季度或 3 月移动平均为准。
- **发布时点**：每月最后一天 / 次月首日发布当月数据，是所有宏观指标中最早发布的月度数据。

## 四、数据来源与查找指南

- 国家统计局官网（stats.gov.cn）→「数据解读 / 最新发布」→《中国采购经理指数运行情况》+ 首席统计师解读，每月 **最后一天 / 次月首日** 发布。
- 交叉验证：工业增加值（验证生产的量）、PPI 购进-出厂价差（验证价格分项）、社零与地产数据（验证消费品与建筑业分项）、外贸新出口订单（验证外需）。
- 常用检索词："2026 年 X 月中国采购经理指数运行情况"、"首席统计师解读 X 月中国采购经理指数"。
