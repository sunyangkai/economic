## 一、核心监测清单（重要数据看哪些）

| 数据 | 发布频率/时点 | 看什么信号 |
|------|------|------|
| 一般公共预算收入（总量、同比） | 月度（次月 18—22 日） | 财政"造血"能力，与名义经济冷暖挂钩 |
| 税收 vs 非税 | 月度 | 税收占比高 = 收入质量好；非税高增常含一次性因素 |
| 主要税种 | 月度 | 增值税→工业流通、企业所得税→企业盈利、个税→居民收入、印花税→股市、消费税→消费、契税+土增→地产 |
| 一般公共预算支出（总量、同比） | 月度 | 支出增速 > 收入增速 = 财政扩张；反之偏紧 |
| 支出科目 | 月度 | 民生 vs 基建取向 |
| 收支差额/赤字进度 | 月度 | 累计赤字 vs 全年预算赤字 → 下半年发力空间 |
| 政府性基金收支、土地出让收入 | 月度 | 地方"第二本账"，地产冷热最直接的财政指标 |
| 专项债/特别国债发行进度 | 月度（财政部/中债登） | 基建实物工作量前瞻 |
| 债务付息支出 | 月度 | 财政腾挪空间的刚性约束 |
| 年度预算目标（赤字率、赤字、专项债、特别国债） | 每年 3 月 | 全年锚，所有执行数据对照它看 |

> **只盯五个核心数字：一般公共预算收入增速、税收收入增速、一般公共预算支出增速、累计赤字占预算赤字比例、土地出让收入增速。**

## 三、解读（按时间倒序维护）

> 每期数据发布后，在本文节**最顶部**插入新的"期间"条目；旧条目保留，便于回溯对比。最新一期始终在最上方。

### 2026 年上半年（1—6 月）｜数据发布：2026-07-22

> **核心矛盾：收入超目标、支出远滞后——财政整体处于"蓄力"状态。**

| 维度 | 状态 | 判断 |
|------|------|:------:|
| 收入增速 | +4.7%，高于全年目标（+2.2%） | 🟢 开局良好 |
| 税收质量 | 税收 +5.3% > 非税 +2.3%，税收占比 81% | 🟢 质量改善 |
| 支出力度 | +1.5%，远低于全年目标（+4.4%） | 🔴 明显偏慢 |
| 地产链条 | 契税 -14.7%、土增 -15.3%、土地出让 -31.5% | 🔴 持续拖累 |
| 股市贡献 | 证券交易印花税 +97.3% | 🟢 阶段性利好 |
| 消费 | 消费税 -3.4%，与社零偏弱互相印证 | 🟡 偏弱 |
| 赤字使用 | 仅 37.8%，下半年空间 3.66 万亿 | 🟡 蓄力待发 |
| 专项债发行 | 进度 47%，与序时基本持平 | 🟡 中性 |
| 转移支付 | 已下达 90.3% | 🟢 靠前发力 |

**月度节奏**：收入单月连续四个月同比 +6.6%~+8.7%，动能逐月抬升，6 月 +8.7% 为年内高点，累计增速从 1—2 月的 +0.7% 一路回升至上半年的 +4.7%。支出端 4、5 月单月负增长（-3.2%、-1.6%），6 月季末 +4.0% 放量，累计增速 1.5% 仍处低位——"季末冲量、日常克制"的执行节奏明显。政府性基金端，6 月单月土地出让收入推算约 1,730 亿、同比 -42.1%，地方"第二本账"压力未减。

**收入端**：上半年收入增速逐月回升（一季度 +2.4% → 上半年 +4.7%），高于预算目标 2.5 个百分点。拉动项主要是证券交易印花税（+97.3%）、个人所得税（+13.1%，工资增长 + 股市 + 征管加强）、国内增值税（+6.0%，工业和服务业增长、PPI 上行带动）、进口环节税（+11.8%，进口较快增长）。拖累项集中在两点：地产链条（契税、土增两位数下滑）和国内消费税（-3.4%）。地方层面，31 个省份中 28 个收入正增长，收入面较宽。

**支出端**：支出进度 47.8%，与时间进度（50%）和往年同期（2025 上半年 49.2%）基本相当，本身不算异常；真正的"偏慢"在增速口径——上半年支出同比仅 +1.5%，不到全年目标（+4.4%）的 1/3。按上半年节奏，全年支出增速只有约 +1.5%，要兑现 30.01 万亿的预算盘子，下半年支出需同比提速至约 +7%，是上半年的近 5 倍。结构上"民生强、基建弱"：卫生健康 +10.8%（育儿补贴、医保补助）、社保就业 +7.6%、住房保障 +6.1% 保持高增；城乡社区、交通运输、农林水等基建类科目全部负增长，节能环保 -10.3%。结合上半年 GDP 同比 +4.7%，财政对经济的拉动主要体现在民生端，基建端仍在收缩。

**政府性基金**：土地出让收入 -31.5%，地方"第二本账"持续萎缩，土地财政依赖加速转型。政府性基金支出 -16.4%，其中土地出让相关支出 -17.0%，意味着土地收入下滑正在直接压制地方支出能力。

**债务与政策**：上半年新增专项债发行 2.07 万亿（进度 47%），"自审自发"试点地区发行 1.6 万亿、占全国 77%，发行机制改革推进明显。转移支付下达 9.4 万亿（90.3%），中央对地方支持靠前。民生政策落地：育儿补贴约 1000 亿、学前免保教费补助 241 亿、城乡居民医保补助 3864 亿、以旧换新补贴 1250 亿（带动相关商品销售约 1.1 万亿）。

**下半年关注**：① 剩余赤字空间约 3.66 万亿 + 剩余专项债约 2.33 万亿 + 超长期特别国债 1.3 万亿，财政"弹药"充足，关键看基建类支出能否止跌回升；② 专项债发行能否提速并形成实物工作量；③ 契税、土增、土地出让三条地产线能否企稳；④ 债务付息支出（+4.5%）与收入增速的赛跑。

#### 深入观点小结：上半年支出为何远小于全年预期？财政在"留力"准备什么？

**核心判断：上半年克制是"主动留力为主、被动约束为辅"。财政不是没能力发力，而是在等三个窗口、备好三类弹药。**

**为什么能留力（主动留力的一面）**：上半年收入 +4.7%、超预算目标 2.5 个百分点，税收端靠印花税（+97.3%）、个税（+13.1%）、增值税（+6.0%）撑住了基本盘，GDP 同比 +4.7%。经济在没有强刺激的情况下运行尚可，财政就没有必要上半年打光子弹——"逆周期"工具的理性用法，是把弹药留给不确定性最大的时候。支出端"季末冲量、日常克制"（4、5 月单月负增长，6 月才 +4.0%），本身就是刻意选择的节奏，不是资金没到位。

**在等什么（三个窗口）**：
① **等外部不确定落地**——出口退税 +5.4% 说明上半年外需仍强，但关税与贸易摩擦的下行风险集中在三四季度，财政要为出口回落预留对冲；② **等项目与工具理顺**——专项债上半年只发 47%，叠加"自审自发"扩围、投向"负面清单"管理、项目资本金范围扩大等改革刚落地，项目端在重新梳理审核，资金要为"十五五"重大项目集中投放做准备；③ **等执行效率**——2026 年预算明确"更加积极既体现在扩大资金规模，更体现在提高资金使用效益"，主动控制节奏、避免资金沉淀空转，也是"过紧日子"思路的延续。

**留了哪些弹药**：剩余赤字空间约 3.66 万亿 + 剩余专项债约 2.33 万亿 + 超长期特别国债 1.3 万亿，合计约 7.3 万亿的可投放增量，对应下半年三种用途：对冲外需回落（稳出口、稳就业）、"十五五"重大项目与新质生产力集中投放（设备更新、城市更新）、岁末保增长冲刺（历史规律：Q4 是财政支出最集中的窗口）。

**但被动约束的一面不能忽视**：拖住整体支出的是地方——地方支出仅 +0.6%，接近零增长。土地出让收入 -31.5%（6 月单月 -42.1%），"第二本账"萎缩 + 化债约束 + 项目收益预期弱，让地方"不敢投、不能投"。中央把转移支付 90.3% 靠前下达，但钱到地方未必马上形成支出。所以"留力"既是主动选择，也部分是被动结果。

**验证清单（判断究竟是"主动留力"还是"被动受限"）**：
- 8—9 月专项债月度发行是否明显提速（上半年月均约 3,450 亿，若月均放量至 5,000 亿以上说明在赶进度）；
- 基建类支出单月同比能否转正（城乡社区、农林水、交通运输三条线）；
- 土地出让收入降幅是否收窄（-31.5% → 若 8 月后明显收窄，地方支出能力修复）；
- 特别国债资金下达与"两重""两新"项目开工节奏；
- 关键分水岭：若 9 月末基建类支出累计增速仍为负，则"留力"更多是"受限"，财政乘数预期要下修；若 Q3 转正放量，则证实"主动留力"，下半年财政对经济的拉动会明显强于上半年。

## 七、口径提醒

- **累计 vs 单月**：官方发布多为累计口径，单月需自行相减；
- **政府性基金与一般公共预算分开看**：卖地收入不进一般公共预算，只看一本账会漏掉地方真实财力；
- **出口退税是收入减项**：数值越大说明出口退税越多，不代表收入差；
- **非税收入注意一次性因素**（如 2024 年中央单位上缴专项收益抬高基数，导致 2025 年非税 -11.3%）；
- 增值税受留抵退税政策扰动，同比要结合政策背景看；
- 官方数据可能修订，引用时以最新发布为准。
