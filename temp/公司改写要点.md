# 各公司业务说明改写要点（内部草稿，改完即删）

共同点：药明康德已按新规范改好（标杆）。其余各公司 业务构成 普遍把经营数字写进了业务线标题与正文，需要：
1) 业务构成 → 只讲"做什么"（业务内容、技术、交付物、客户、与下游分工边界、产业链位置）；数字全部清出。
2) 分部经营数据 → 现有表格保留，把清出的数字迁入表格/注/经营状况解读。
3) 业务特点 → 结构性特点，不重复经营数字。
4) 章节导语 → 一句话定位 + 商业模式一句话。

各公司特别点：
- 东鹏饮料/中国中免/诺思兰德：章节开头没有公司定位导语（中国中免、东鹏开头直接进业务构成；诺思兰德 1.1 有"公司业务分三大板块"）。改写时可在章节开头补一句定位导语（与全文口吻一致），或不补（若原文风格如此）——但业务构成内数字要清理。
- 诺思兰德：子节编号用 1.1/1.2/1.3（全章风格），改写时保持 1.x 编号体系；经营数字已集中在 1.2 分部经营数据，业务构成(1.1)里"累计投入 1.71 亿元、总资产 3.47 亿元"等数字移入 1.2 注。
- 中国中免：业务构成(按业务类别) 每类标题都带"2025 年 xxx 亿、占 xx%"；分部经营数据已有 表A(官方) + 表B(业务类别重组)。改写：业务构成只讲每类渠道"做什么/模式是什么"，数字全部指向 表A/表B；经营状况解读放在表后。
- 柏楚电子：业务构成已经比较接近目标写法（有"定义"说明、下游客户），但"客户与研发底座"一段是数字堆（700+ 客户、员工 1,404 人、243 项专利）——这些是规模数字，移入分部经营数据或删除/定性化。
- 安克创新：业务构成三类各有分产品说明（已经讲"做什么"），但每类标题带"2025 年 xxx 亿、占 xx%、+xx%"；分部经营数据已有 板块/地区/渠道 三张表。清理标题数字即可，主体描述保留；注意导语有 305.14 亿等大数字。
- 比亚迪：业务构成（汽车/手机部件/电池光伏）标题和正文全是数字；分部经营数据有表+区域表。需要补"做什么"（整车含哪些、卖给谁、怎么赚钱；手机部件给谁代工什么；电池光伏做什么），并把销量/收入数字迁到分部表或注。
- 三一重工：业务构成按产品线（挖机/混凝土/起重/路面桩工/新能源/其他），每个标题带收入与毛利率；分部经营数据有产品表+区域表。需补每类产品"做什么/下游场景"（如挖机用于土方矿山、泵车用于混凝土浇筑等），数字迁入分部表。
- 迈瑞医疗：业务构成按产线（IVD/生命信息/影像/新兴），标题带收入占比增速毛利率；战略意义段落（剃刀模式等）其实是业务特点内容，可留在业务构成末尾定性或并入业务特点。需清理标题数字。
- 美的集团：业务构成（智能家居 ToC/商业及工业 ToB/海外业务）标题带收入占比增速毛利率；海外业务与分部表海外行重复。需补"做什么"（ToB 四块：楼宇科技/机器人/工业技术/创新业务各自做什么），数字迁入分部表。
- 恒瑞医药：业务构成（创新药销售/BD/仿制药）标题与正文带收入占比；但本章后面还有"创新药研发全流程"与"管线数量与进度统计"两个大节，是"做什么/商业模式怎么运转"的解释，属于业务构成应该承载的内容——改写时把这部分视为业务构成的延伸解释保留在章节内（不删除），并在业务构成开头说明"本节讲业务是什么 + 研发到收入的流程见后"；分部经营数据负责表格数字。
- 赤子城科技：业务构成有"产业链位置"段（已经讲与下游分工），但各产品线标题/正文带收入占比增速与产品级增速数字。清理经营数字（保留"做什么"：MICO 直播社交/YoHo 语音社交等面向什么市场、什么变现方式）；分部经营数据表格与解读已有，数字迁入。
- 国电南瑞：业务构成五大板块标题都带收入/增速/毛利率，且正文把细分（调度/变电/继保等）数字也塞进去。需补"做什么"（电网智能=电网调度/变电站自动化/继保/柔直换流等给电网提供什么）；细分数字迁入分部经营数据（可加注/小表）。
- 百济神州：业务构成按"血液肿瘤/实体肿瘤/安进产品/研发平台/生产供应链"组织，产品级"做什么"已较好（适应症、机制），但标题与正文带产品收入数字（39.28 亿美元等）。清理标题占比数字与正文收入数字；分部经营数据已有按产品表，迁入后正文不再重复。
- 中国平安：业务说明目前无"业务构成"总节，直接 1-5 板块各写一段（经营数字与商业模式混排），后有分部经营数据表。需要重构为 业务构成（每板块"做什么"：寿险卖什么产品给谁怎么赚、财险保什么险种、银行做什么、资管做什么、科技做什么）+ 分部经营数据（表+解读）+ 业务特点。
