# 业务说明改写复核清单（内部用，复核后删除）

每份被改文件需通过以下检查（git diff + 目视抽查）：

1. 改动 hunk 全部落在「## 一、业务说明」章节内（不含「---」及之后章节）。
2. 章节结构 = 导语 + ### 业务构成 + ### 分部经营数据 + ### 业务特点（诺思兰德保持 1.1/1.2/1.3 编号风格）。
3. 「### 业务构成」内无经营数字（收入/占比/增速/毛利率/规模/人数/装机量/亿元/万元/% 等），只讲"做什么"（服务内容、技术、交付物、下游客户、与下游分工边界、产业链位置）。
4. 「### 分部经营数据」表格保留原数字，清出的数字已迁入表格/注/经营状况解读，未丢信息、未发明数字。
5. 「### 业务特点」不重复分部经营数据的具体经营数字（可指引）。
6. markdown 表格未损坏、标题层级正确、分点列表条目间留空行。
7. 其他章节（零/二~九）未被改动。
